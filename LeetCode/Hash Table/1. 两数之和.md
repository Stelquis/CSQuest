# [1. 两数之和](https://leetcode.cn/problems/two-sum/)

- 🟢 **难度**：简单
- 🔑 **分类**：哈希
- 🏷️ **标签**：`数组`、`哈希表`

## 题目描述

给定一个整数数组 `nums` 和一个整数目标值 `target`，请你在该数组中找出 **和为目标值** *`target`*  的那 **两个** 整数，并返回它们的数组下标。

你可以假设每种输入只会对应一个答案，并且你不能使用两次相同的元素。

你可以按任意顺序返回答案。

**示例 1：**

```
输入：nums = [2,7,11,15], target = 9
输出：[0,1]
解释：因为 nums[0] + nums[1] == 9 ，返回 [0, 1] 。
```

**示例 2：**

```
输入：nums = [3,2,4], target = 6
输出：[1,2]
```

**示例 3：**

```
输入：nums = [3,3], target = 6
输出：[0,1]
```

**提示：**

- `2 <= nums.length <= 10^4`
- `-10^9 <= nums[i] <= 10^9`
- `-10^9 <= target <= 10^9`
- **只会存在一个有效答案**

**进阶：** 你可以想出一个时间复杂度小于 `O(n^2)` 的算法吗？

## 题解一：暴力枚举

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        int x=0,y=0;
        for(int i=0;i<nums.length;i++){
            for(int j=i+1;j<nums.length;j++){
                if(nums[i]+nums[j]==target){
                    return new int[]{i,j};
                }
            }
        }
        return new int[]{x,y};
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n target，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        int[] res = new Solution().twoSum(nums, target);
        System.out.println(res[0] + " " + res[1]);
        sc.close();
    }
}
```

## 题解二：哈希表

### ☕ Java

```java
import java.util.HashMap;
import java.util.Map;

import java.util.Scanner;

class Solution {
    public int[] twoSum(int[] nums, int target) {
        Map<Integer,Integer> map = new HashMap<>();
        for(int i=0;i<nums.length;i++){
            int need = target-nums[i];
            if(map.containsKey(need)){
                return new int[]{i,map.get(need)};
            }
            map.put(nums[i], i);
        }
        return new int[0];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n target，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        int[] res = new Solution().twoSum(nums, target);
        System.out.println(res[0] + " " + res[1]);
        sc.close();
    }
}
```

```python
import sys

    def twoSum(self, nums: List[int], target: int) -> List[int]:

            need = target - nums[i]
```

```cpp
#include <unordered_map>
#include <vector>

class Solution {
public:
    vector<int> twoSum(vector<int>& nums, int target) {
        unordered_map<int, int> mp;
        for (int i = 0; i < nums.size(); i++) {
            int need = target - nums[i];
            if (mp.count(need)) {
                return {i, mp[need]};
            }
            mp[nums[i]] = i;
        }
        return {};
    }
};
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

/**
 * Note: The returned array must be malloced, assume caller calls free().
 */
int* twoSum(int* nums, int numsSize, int target, int* returnSize) {
    // 开放寻址哈希表：线性探测
    int cap = 1;
    while (cap < numsSize * 2) {
        cap <<= 1;
    }
    int* keys = (int*)malloc(cap * sizeof(int));
    int* vals = (int*)malloc(cap * sizeof(int));
    char* used = (char*)calloc(cap, sizeof(char));

    for (int i = 0; i < numsSize; i++) {
        int need = target - nums[i];
        unsigned int h = ((unsigned int)need * 2654435761u) & (cap - 1);
        while (used[h]) {
            if (keys[h] == need) {
                int* res = (int*)malloc(2 * sizeof(int));
                res[0] = i;
                res[1] = vals[h];
                *returnSize = 2;
                free(keys);
                free(vals);
                free(used);
                return res;
            }
            h = (h + 1) & (cap - 1);
        }

        h = ((unsigned int)nums[i] * 2654435761u) & (cap - 1);
        while (used[h]) {
            h = (h + 1) & (cap - 1);
        }
        keys[h] = nums[i];
        vals[h] = i;
        used[h] = 1;
    }

    free(keys);
    free(vals);
    free(used);
    *returnSize = 0;
    return NULL;
}

int main(void) {
    // ACM 输入：第一行 n target，第二行 n 个整数
    int n, target;
    if (scanf("%d %d", &n, &target) != 2) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    int returnSize = 0;
    int* res = twoSum(nums, n, target, &returnSize);
    printf("%d %d\n", res[0], res[1]);
    free(nums);
    free(res);
    return 0;
}
```
