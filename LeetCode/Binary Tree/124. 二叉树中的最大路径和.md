# [124. 二叉树中的最大路径和](https://leetcode.cn/problems/binary-tree-maximum-path-sum/)

- 🔴 **难度**：困难
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`深度优先搜索`、`动态规划`、`二叉树`、`树形 DP`

## 题目描述

二叉树中的 **路径** 被定义为一条节点序列，序列中每对相邻节点之间都存在一条边。同一个节点在一条路径序列中 **至多出现一次** 。该路径 **至少包含一个** 节点，且不一定经过根节点。

**路径和** 是路径中各节点值的总和。

给你一个二叉树的根节点 `root` ，返回其 **最大路径和** 。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/13/exx1.jpg)

```
输入：root = [1,2,3]
输出：6
解释：最优路径是 2 -> 1 -> 3 ，路径和为 2 + 1 + 3 = 6
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/10/13/exx2.jpg)

```
输入：root = [-10,9,20,null,null,15,7]
输出：42
解释：最优路径是 15 -> 20 -> 7 ，路径和为 15 + 20 + 7 = 42
```

**提示：**
- 树中节点数目范围是 `[1, 3 * 10^4]`
- `-1000 <= Node.val <= 1000`

> ⚠️ 与 543（直径）的三点差异：① 路径形状不再必须"穿过拐点"——一条腿、两条腿、只有自己都合法；② 权重有负数——负的腿要"拒收"（按 0 计）；③ 全负树的最优路径就是最大权重的那个节点自己——`ans` 初值必须用 `Integer.MIN_VALUE`。

## 题解一：后序深度优先搜索（双公式）

每个节点两个身份，对应两条公式：

- **给父节点的汇报**（竖链，到我为止，只能挑一条腿继续向上）：`node.val + max(0, max(左链, 右链))`——负腿拒收
- **自己账本**（山形路径，左右腿都可要）：`node.val + max(0,左链) + max(0,右链)`——拐点候选

两条公式原材料相同（`node.val` + 拒收后的两条腿），只差"挑一条"还是"两条全要"。账本取全局最大。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，递归栈

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public static int ans;

    public int maxPathSum(TreeNode root) {
        ans = Integer.MIN_VALUE;    // 全负树的最优就是某个节点自己，不能初始化为 0
        dfs(root);
        return ans;
    }

    // 返回"以 root 结尾、向下延伸"的最大链和（给父节点拼山形路径用）
    public static int dfs(TreeNode root) {
        if (root == null) {
            return 0;               // 空腿贡献 0（配合拒收语义）
        }
        int l = dfs(root.left);     // 左边递上来的链
        int r = dfs(root.right);    // 右边递上来的链
        // 账本：山形路径（拐点=root，两腿都要，负腿已按 0 拒收——l/r 本身恒 >= 0）
        ans = Math.max(ans, l + r + root.val);
        // 汇报：只挑一条腿
        return Math.max(0, Math.max(l, r) + root.val);
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().maxPathSum(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
import sys
from collections import deque
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        self.ans = float('-inf')    # 全负树的最优是某个节点自己
        self.dfs(root)
        return self.ans

    def dfs(self, node: Optional[TreeNode]) -> int:
        if node is None:
            return 0                # 空腿贡献 0
        left = self.dfs(node.left)
        right = self.dfs(node.right)
        # 账本：山形路径（两腿都要）
        self.ans = max(self.ans, left + right + node.val)
        # 汇报：只挑一条腿
        return max(0, max(left, right) + node.val)


def build_tree(tokens, pos):
    """按层序遍历建树，'null' 表示空节点"""
    if pos[0] >= len(tokens) or tokens[pos[0]] == "null":
        pos[0] += 1
        return None
    root = TreeNode(int(tokens[pos[0]]))
    pos[0] += 1
    queue = deque([root])
    while queue:
        cur = queue.popleft()
        for i in range(2):
            if pos[0] >= len(tokens):
                break
            child = None
            if tokens[pos[0]] != "null":
                child = TreeNode(int(tokens[pos[0]]))
                queue.append(child)
            if i == 0:
                cur.left = child
            else:
                cur.right = child
            pos[0] += 1
    return root
```

## 题解二：朴素枚举拐点（对比理解）

与 543 的朴素版同构：对每个节点，**重新**计算其左右子树的最大竖链（每轮从零递归到底），组装"山形候选"，所有节点取最大。逻辑与题解一等价，但深度被反复重算。

- 时间复杂度：`O(n²)`（每个节点触发一次 O(子树) 的竖链计算，链状树最坏）
- 空间复杂度：`O(h)`
- 对比要点：题解一的优化本质 = **竖链算一遍就够了**——它在回溯路上本来就会出现，不要扔掉重算

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public int maxPathSum(TreeNode root) {
        if (root == null) {
            return Integer.MIN_VALUE;    // 空树没有路径
        }
        // 拐点候选：负腿拒收（maxDown 已含自身值，但可能整体为负，需再拒收）
        int through = root.val
                + Math.max(0, maxDown(root.left))
                + Math.max(0, maxDown(root.right));
        int leftAns = root.left != null ? maxPathSum(root.left) : Integer.MIN_VALUE;
        int rightAns = root.right != null ? maxPathSum(root.right) : Integer.MIN_VALUE;
        int best = Math.max(leftAns, rightAns);
        return Math.max(through, best);
    }

    // 从 node 向下延伸的最大链和（负贡献拒收）
    public static int maxDown(TreeNode node) {
        if (node == null) {
            return 0;
        }
        int child = Math.max(maxDown(node.left), maxDown(node.right));
        return node.val + Math.max(child, 0);
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().maxPathSum(root));
        sc.close();
    }

    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {

    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;

    }
}
```

```python
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def maxPathSum(self, root: Optional[TreeNode]) -> int:
        if root is None:
            return float('-inf')         # 空树没有路径
        through = root.val \
            + max(0, self.max_down(root.left)) \
            + max(0, self.max_down(root.right))
        left_ans = self.maxPathSum(root.left) if root.left else float('-inf')
        right_ans = self.maxPathSum(root.right) if root.right else float('-inf')
        return max(through, left_ans, right_ans)

    def max_down(self, node: Optional[TreeNode]) -> int:
        if node is None:
            return 0
        child = max(self.max_down(node.left), self.max_down(node.right))
        return node.val + max(child, 0)
```
