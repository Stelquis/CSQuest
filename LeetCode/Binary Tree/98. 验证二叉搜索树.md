# [98. 验证二叉搜索树](https://leetcode.cn/problems/validate-binary-search-tree/)

- 🟡 **难度**：中等
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`深度优先搜索`、`二叉搜索树`、`二叉树`

## 题目描述

给你一个二叉树的根节点 `root` ，判断其是否是一个有效的二叉搜索树。

**有效** 二叉搜索树定义如下：
- 节点的左子树只包含 **严格小于** 当前节点的数。
- 节点的右子树只包含 **严格大于** 当前节点的数。
- 所有左子树和右子树自身必须也是二叉搜索树。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/12/01/tree1.jpg)

```
输入：root = [2,1,3]
输出：true
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/12/01/tree2.jpg)

```
输入：root = [5,1,4,null,null,3,6]
输出：false
解释：根节点的值是 5 ，但是右子节点的值是 4 。
```

**提示：**
- 树中节点数目范围在`[1, 10^4]` 内
- `-2^31 <= Node.val <= 2^31 - 1`

## 题解一：中序遍历 + 验证严格递增

BST 的定义（左 < 根 < 右，递归成立）⟺ 中序遍历序列**严格递增**。因此中序收集全部节点值，再扫一遍验证相邻元素满足 `前 < 后`。两个易错点：

- **严格递增**：相等也算违规（BST 要求节点值互异），比较用 `>=` 判 false
- **相邻即可**：递增性有传递性，`1<5 且 5<6` 自动推出 `1<6`，无需两两比较

反例说明为何父子检查不够：`[5,1,4,null,null,3,6]` 每对父子都合规，但中序序列 `1,5,3,4,6` 在 5→3 处断裂——跨层违规被中序捕获。

- 时间复杂度：`O(n)`，遍历一次 + 扫描一次
- 空间复杂度：`O(n)`，存放整个中序序列

### ☕ Java

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public boolean isValidBST(TreeNode root) {
        List<Integer> res = new ArrayList<>();
        inorder(root, res);
        // 相邻比较（传递性保证全局有序），严格递增才合法
        for (int i = 1; i < res.size(); i++) {
            if (res.get(i - 1) >= res.get(i)) {
                return false;
            }
        }
        return true;
    }

    // 中序遍历收集节点值（左 → 根 → 右）
    public static void inorder(TreeNode node, List<Integer> res) {
        if (node == null) {
            return;
        }
        inorder(node.left, res);
        res.add(node.val);
        inorder(node.right, res);
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().isValidBST(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
            return
        self.inorder(node.left, res)
        res.append(node.val)
        self.inorder(node.right, res)
```

## 题解二：中序遍历 + 前驱指针（边走边比）

题解一的升级：序列是否递增，走到每个位置时其实已知道答案。维护 `prev`（中序访问顺序中"上一个被访问的节点"），每个节点被访问时只和 `prev` 比一次，免去整段数组的存储。

`prev` 必须是**成员变量**（跨递归层共享）：比较发生在 `dfs(node.left)` 返回之后、`dfs(node.right)` 之前——这个"夹缝"正是中序访问 node 的时刻，而 prev 指向的节点可能在左子树深处，局部变量跨不了栈帧。注意：入口处 `prev = null` 重置（多测试用例下静态状态会串味）；`prev` 判 null 而非初始化为最小值（值域边界是合法节点值）。

- 时间复杂度：`O(n)`，一遍遍历
- 空间复杂度：`O(h)`，只需一个前驱指针 + 递归栈，省掉 O(n) 数组

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    private static TreeNode prev = null;   // 中序访问顺序中"上一个被访问的节点"

    public boolean isValidBST(TreeNode root) {
        prev = null;                // 多测试用例防串味
        return dfs(root);
    }

    public static boolean dfs(TreeNode node) {
        if (node == null) {
            return true;
        }
        if (!dfs(node.left)) {
            return false;           // 左子树先访问完
        }
        // 中序时刻：node 紧跟在 prev 之后，相邻比较
        if (prev != null && prev.val >= node.val) {
            return false;
        }
        prev = node;                // node 荣升为"上一个"
        return dfs(node.right);
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().isValidBST(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
import sys
from collections import deque
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def isValidBST(self, root: Optional[TreeNode]) -> bool:
        self.prev = None    # "上一个被访问的节点"，None 表示还没见过值
        return self.dfs(root)

    def dfs(self, node: Optional[TreeNode]) -> bool:
        if node is None:
            return True
        if not self.dfs(node.left):
            return False    # 左子树先访问完
        # 中序时刻：node 紧跟在 prev 之后，相邻比较
        if self.prev is not None and self.prev.val >= node.val:
            return False
        self.prev = node    # node 荣升为"上一个"
        return self.dfs(node.right)
```
