# [230. 二叉搜索树中第 K 小的元素](https://leetcode.cn/problems/kth-smallest-element-in-a-bst/)

- 🟡 **难度**：中等
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`深度优先搜索`、`二叉搜索树`、`二叉树`

## 题目描述

给定一个二叉搜索树的根节点 `root` ，和一个整数 `k` ，请你设计一个算法查找其中第 `k` 小的元素（`k` 从 1 开始计数）。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/01/28/kthtree1.jpg)

```
输入：root = [3,1,4,null,2], k = 1
输出：1
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/28/kthtree2.jpg)

```
输入：root = [5,3,6,2,4,null,null,1], k = 3
输出：3
```

**提示：**
- 树中的节点数为 `n` 。
- `1 <= k <= n <= 10^4`
- `0 <= Node.val <= 10^4`

**进阶：** 如果二叉搜索树经常被修改（插入/删除操作）并且你需要频繁地查找第 `k` 小的值，你将如何优化算法？

## 题解一：中序遍历 + 数组取下标

BST 的中序遍历是**严格升序序列**（98 题验证过的等价性质），所以“第 k 小”就是中序序列的第 `k - 1` 个下标。中序收集全部节点值后直接取下标。

- 时间复杂度：`O(n)`，完整遍历一次
- 空间复杂度：`O(n)`，存放整个中序序列（另有 `O(h)` 递归栈）

### ☕ Java

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public int kthSmallest(TreeNode root, int k) {
        List<Integer> ans = new ArrayList<>();
        inorder(root, ans);
        return ans.get(k - 1);
    }

    // 中序遍历收集节点值（BST 中序 = 升序序列）
    public static void inorder(TreeNode root, List<Integer> ans) {
        if (root == null) {
            return;
        }
        inorder(root.left, ans);
        ans.add(root.val);
        inorder(root.right, ans);
    }

    public static void main(String[] args) {
        // ACM 输入：第一行层序序列（null 表示空节点），第二行 k
        Scanner sc = new Scanner(System.in);
        java.util.List<String> tokens = new ArrayList<>();
        while (sc.hasNext()) {
            tokens.add(sc.next());
        }
        int k = Integer.parseInt(tokens.get(tokens.size() - 1));   // 最后一个 token 是 k
        tokens.remove(tokens.size() - 1);
        TreeNode root = buildTree(tokens);
        System.out.println(new Solution().kthSmallest(root, k));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(java.util.List<String> tokens) {
        if (tokens.isEmpty() || "null".equals(tokens.get(0))) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(tokens.get(0)));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int i = 1;
        while (!queue.isEmpty() && i < tokens.size()) {
            TreeNode cur = queue.poll();
            if (!"null".equals(tokens.get(i))) {
                cur.left = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.left);
            }
            i++;
            if (i >= tokens.size()) {
                break;
            }
            if (!"null".equals(tokens.get(i))) {
                cur.right = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.right);
            }
            i++;
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
import sys
from collections import deque
from typing import List, Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def kthSmallest(self, root: Optional[TreeNode], k: int) -> int:
        ans: List[int] = []
        self.inorder(root, ans)
        return ans[k - 1]

    def inorder(self, node: Optional[TreeNode], ans: List[int]) -> None:
        if node is None:
            return
        self.inorder(node.left, ans)
        ans.append(node.val)
        self.inorder(node.right, ans)


def build_tree(tokens, pos):
    """按层序遍历建树，'null' 表示空节点"""
    if pos[0] >= len(tokens) or tokens[pos[0]] == "null":
        pos[0] += 1
        return None
    root = TreeNode(int(tokens[pos[0]]))
    pos[0] += 1
    queue = deque([root])
    while queue:
        cur = queue.popleft()
        for i in range(2):
            if pos[0] >= len(tokens):
                break
            child = None
            if tokens[pos[0]] != "null":
                child = TreeNode(int(tokens[pos[0]]))
                queue.append(child)
            if i == 0:
                cur.left = child
            else:
                cur.right = child
            pos[0] += 1
    return root

    # ACM 输入：第一行层序序列（null 表示空节点），第二行 k
    tokens = sys.stdin.read().split()
```

## 题解二：中序遍历 + 计数提前退出

题解一必须走完全树才知道第 k 个；但中序是升序的，**数到第 k 个访问的节点就是答案**，后面整片子树都不用再走。用一个跨递归层共享的计数器，访问时自减，减到 0 即记录答案。

- 时间复杂度：`O(h + k)`，最坏 `O(n)`，但答案靠左时远小于全树
- 空间复杂度：`O(h)`，递归栈（无需存储整个序列）
- 与进阶的呼应：单次查询已优化；若树频繁修改且频繁查询，则给每个节点**维护左子树节点数**（类似顺序统计树），查询走“左子树计数 vs k”的二分式下行，`O(h)` 且不受修改后重遍历影响

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    private static int count = 0;    // 剩余需要跳过的节点数
    private static int ans = 0;

    public int kthSmallest(TreeNode root, int k) {
        count = k;                   // 入口重置，防多用例串味
        ans = 0;
        dfs(root);
        return ans;
    }

    // 中序遍历，访问一个节点就消耗一个计数
    public static void dfs(TreeNode node) {
        if (node == null || count == 0) {   // count==0：答案已到手，剪枝
            return;
        }
        dfs(node.left);
        if (--count == 0) {                 // 我是第 k 个被访问的
            ans = node.val;
            return;
        }
        dfs(node.right);
    }

    public static void main(String[] args) {
        // ACM 输入：第一行层序序列（null 表示空节点），第二行 k
        Scanner sc = new Scanner(System.in);
        java.util.List<String> tokens = new java.util.ArrayList<>();
        while (sc.hasNext()) {
            tokens.add(sc.next());
        }
        int k = Integer.parseInt(tokens.get(tokens.size() - 1));   // 最后一个 token 是 k
        tokens.remove(tokens.size() - 1);
        TreeNode root = buildTree(tokens);
        System.out.println(new Solution().kthSmallest(root, k));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(java.util.List<String> tokens) {
        if (tokens.isEmpty() || "null".equals(tokens.get(0))) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(tokens.get(0)));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int i = 1;
        while (!queue.isEmpty() && i < tokens.size()) {
            TreeNode cur = queue.poll();
            if (!"null".equals(tokens.get(i))) {
                cur.left = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.left);
            }
            i++;
            if (i >= tokens.size()) {
                break;
            }
            if (!"null".equals(tokens.get(i))) {
                cur.right = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.right);
            }
            i++;
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```
