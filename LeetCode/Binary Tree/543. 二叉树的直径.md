# [543. 二叉树的直径](https://leetcode.cn/problems/diameter-of-binary-tree/)

- 🟢 **难度**：简单
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`深度优先搜索`、`二叉树`、`树形 DP`

## 题目描述

给你一棵二叉树的根节点，返回该树的 **直径** 。

二叉树的 **直径** 是指树中任意两个节点之间最长路径的 **长度** 。这条路径可能经过也可能不经过根节点 `root` 。

两节点之间路径的 **长度** 由它们之间边数表示。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/03/06/diamtree.jpg)

```
输入：root = [1,2,3,4,5]
输出：3
解释：3 ，取路径 [4,2,1,3] 或 [5,2,1,3] 的长度。
```

**示例 2：**

```
输入：root = [1,2]
输出：1
```

**提示：**

- 树中节点数目在范围 `[1, 10^4]` 内
- `-100 <= Node.val <= 100`

## 题解一：深度优先搜索（单次遍历，树形 DP）

直径路径一定存在一个“拐点”（路径上位置最高的节点）：路径 = 拐点左子树最深处 + 穿过拐点 + 右子树最深处。因此**枚举每个节点作为拐点**，经过它的路径边数 = `左子树深度 + 右子树深度`，取全局最大。

实现上让递归**照常返回深度**（服务父节点拼路径），路过每个节点时**顺手用两个孩子的深度更新全局答案**——一趟遍历同时产出两种信息：

- 返回值（子树深度，节点数口径）：给上一层用 → `max(L, R) + 1`，`+1` 数的是自己
- 副作用（经过本节点的直径，边数口径）：给全局答案用 → `L + R`（拐点被左右各计一次，`+1` 与 `-1` 恰好对消）
- 时间复杂度：`O(n)`，每个节点恰好访问一次
- 空间复杂度：`O(h)`，递归栈深度为树高，最坏（链状树）为 `O(n)`

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public static int ans = 0;

    public int diameterOfBinaryTree(TreeNode root) {
        ans = 0;               // 多测试用例下防残留
        dfs(root);
        return ans;
    }

    // 返回以 root 为根的子树深度（节点数），顺路更新全局直径（边数）
    public static int dfs(TreeNode root) {
        if (root == null) {
            return 0;
        }
        int left = dfs(root.left);
        int right = dfs(root.right);
        ans = Math.max(left + right, ans);      // 经过本节点的直径（边数）
        return Math.max(left, right) + 1;       // 给父节点的深度（节点数）
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().diameterOfBinaryTree(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
import sys
from collections import deque
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def diameterOfBinaryTree(self, root: Optional[TreeNode]) -> int:
        self.ans = 0
        self.dfs(root)
        return self.ans

    def dfs(self, node: Optional[TreeNode]) -> int:
        if node is None:
            return 0
        left = self.dfs(node.left)
        right = self.dfs(node.right)
        self.ans = max(self.ans, left + right)      # 经过本节点的直径（边数）
        return max(left, right) + 1                 # 给父节点的深度（节点数）


def build_tree(tokens, pos):
    """按层序遍历建树，'null' 表示空节点"""
    if pos[0] >= len(tokens) or tokens[pos[0]] == "null":
        pos[0] += 1
        return None
    root = TreeNode(int(tokens[pos[0]]))
    pos[0] += 1
    queue = deque([root])
    while queue:
        cur = queue.popleft()
        for i in range(2):
            if pos[0] >= len(tokens):
                break
            child = None
            if tokens[pos[0]] != "null":
                child = TreeNode(int(tokens[pos[0]]))
                queue.append(child)
            if i == 0:
                cur.left = child
            else:
                cur.right = child
            pos[0] += 1
    return root


if __name__ == "__main__":
    # ACM 输入：一行层序序列，null 表示空节点
    tokens = sys.stdin.read().split()
    root = build_tree(tokens, [0])
    print(Solution().diameterOfBinaryTree(root))
```

## 题解二：朴素枚举（自顶向下，用于对比理解）

最直接的翻译：对每个节点求一次“左深 + 右深”，取最大。`depth` 每次都重新递归整棵子树，节点被反复遍历。

- 时间复杂度：`O(n^2)`（每个节点的枚举都触发一次 `O(子树)` 的深度计算，链状树最坏退化）
- 空间复杂度：`O(h)`，递归栈
- 对比题解一，优化的本质是：**深度算一遍就够了**——子树深度在回溯路上本来就路过，不要扔掉重算

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public int diameterOfBinaryTree(TreeNode root) {
        if (root == null) {
            return 0;
        }
        // 经过当前节点的边数 + 左右子树里各自的答案
        int through = depth(root.left) + depth(root.right);
        int leftAns = diameterOfBinaryTree(root.left);
        int rightAns = diameterOfBinaryTree(root.right);
        return Math.max(through, Math.max(leftAns, rightAns));
    }

    // 最大深度（节点数口径，同 104）
    public static int depth(TreeNode node) {
        if (node == null) {
            return 0;
        }
        return Math.max(depth(node.left), depth(node.right)) + 1;
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        System.out.println(new Solution().diameterOfBinaryTree(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }
}

class TreeNode {

    TreeNode left;
    TreeNode right;
```
