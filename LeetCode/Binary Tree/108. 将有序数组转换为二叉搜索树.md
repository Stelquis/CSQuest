# [108. 将有序数组转换为二叉搜索树](https://leetcode.cn/problems/convert-sorted-array-to-binary-search-tree/)

- 🟢 **难度**：简单
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`二叉搜索树`、`数组`、`分治`、`二叉树`

## 题目描述

给你一个整数数组 `nums` ，其中元素已经按 **升序** 排列，请你将其转换为一棵 平衡 二叉搜索树。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/02/18/btree1.jpg)

```
输入：nums = [-10,-3,0,5,9]
输出：[0,-3,9,-10,null,5]
解释：[0,-10,5,null,-3,null,9] 也将被视为正确答案：
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/02/18/btree.jpg)

```
输入：nums = [1,3]
输出：[3,1]
解释：[1,null,3] 和 [3,1] 都是高度平衡二叉搜索树。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 按 **严格递增** 顺序排列

## 题解一：分治（递归取中点）

平衡要求每个节点左右子树高度差 ≤ 1。有序数组取**中点**当根，左右两半的元素个数最接近；左右两半各自仍是“有序数组 → 平衡 BST”的原问题——规模缩小、形式不变，递归。

- 传参用**下标区间** `build(nums, left, right)`（数组不动，只圈“视野”），避免每层复制子数组的 O(n log n) 开销
- 中点用 `left + (right - left) / 2`，防止 `left + right` 溢出
- 递归函数**自己创建节点并返回**：调用方只接住返回值，“挂到哪”由函数内部决定

- 时间复杂度：`O(n)`，每个元素恰好建一个节点
- 空间复杂度：`O(log n)`，递归栈深度 = 平衡树高（不计输出）

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public TreeNode sortedArrayToBST(int[] nums) {
        return build(nums, 0, nums.length - 1);
    }

    // 把 nums[l..r] 建成平衡 BST，返回根；空区间返回 null
    public static TreeNode build(int[] nums, int l, int r) {
        if (l > r) {
            return null;
        }
        int mid = l + (r - l) / 2;
        TreeNode root = new TreeNode(nums[mid]);   // 中点当根
        root.left = build(nums, l, mid - 1);       // 左半段递归
        root.right = build(nums, mid + 1, r);      // 右半段递归
        return root;
    }

    public static void main(String[] args) {
        // ACM 输入：一行升序数字（无 null 占位）
        Scanner sc = new Scanner(System.in);
        int[] nums = readArray(sc);
        TreeNode root = new Solution().sortedArrayToBST(nums);
        System.out.println(levelOrder(root));
        sc.close();
    }

    public static int[] readArray(Scanner sc) {
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        return nums;
    }

    // 层序输出（含 null 占位，修剪末尾），如 [0, -3, 9, -10, null, 5]
    public static String levelOrder(TreeNode root) {
        if (root == null) {
            return "[]";
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        java.util.List<String> items = new java.util.ArrayList<>();
        items.add(String.valueOf(root.val));
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (cur.left != null) {
                items.add(String.valueOf(cur.left.val));
                queue.offer(cur.left);
            } else {
                items.add("null");
            }
            if (cur.right != null) {
                items.add(String.valueOf(cur.right.val));
                queue.offer(cur.right);
            } else {
                items.add("null");
            }
        }
        // 修剪末尾多余的 null
        int end = items.size();
        while (end > 0 && items.get(end - 1).equals("null")) {
            end--;
        }
        return items.subList(0, end).toString().replace(" ", "");
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

## 题解二：显式栈迭代（分治的迭代化）

把递归改成显式栈：栈里放“任务”——(父节点, 挂左还是挂右, 区间 l..r)。弹出任务时创建节点挂到父节点上，再把左右两个子任务压栈。区间为空的任务直接挂 null。执行顺序不再是从上到下，但最终树与递归版完全一致。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，栈中任务数与节点数同阶

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    // 栈中任务：给 parent 挂 isLeft 孩子时，用 nums[l..r] 建子树
    static class Task {
        TreeNode parent;
        boolean isLeft;
        int l, r;

        Task(TreeNode parent, boolean isLeft, int l, int r) {
            this.parent = parent;
            this.isLeft = isLeft;
            this.l = l;
            this.r = r;
        }
    }

    public TreeNode sortedArrayToBST(int[] nums) {
        if (nums.length == 0) {
            return null;
        }
        TreeNode root = new TreeNode();
        Deque<Task> stack = new ArrayDeque<>();
        stack.push(new Task(root, true, 0, nums.length - 1));   // 根也是一次"挂接"任务
        while (!stack.isEmpty()) {
            Task task = stack.pop();
            if (task.l > task.r) {
                // 空区间，挂 null
                if (task.isLeft) {
                    task.parent.left = null;
                } else {
                    task.parent.right = null;
                }
                continue;
            }
            int mid = task.l + (task.r - task.l) / 2;
            TreeNode node = new TreeNode(nums[mid]);
            if (task.isLeft) {
                task.parent.left = node;
            } else {
                task.parent.right = node;
            }
            // 子任务先压右后压左（栈后进先出，顺序不影响结果）
            stack.push(new Task(node, false, mid + 1, task.r));
            stack.push(new Task(node, true, task.l, mid - 1));
        }
        return root.left;
    }

    public static void main(String[] args) {
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        TreeNode root = new Solution().sortedArrayToBST(nums);
        System.out.println(levelOrder(root));
        sc.close();
    }

    public static String levelOrder(TreeNode root) {
        if (root == null) {
            return "[]";
        }
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        java.util.List<String> items = new java.util.ArrayList<>();
        items.add(String.valueOf(root.val));
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            for (TreeNode child : new TreeNode[]{cur.left, cur.right}) {
                if (child != null) {
                    items.add(String.valueOf(child.val));
                    queue.offer(child);
                } else {
                    items.add("null");
                }
            }
        }
        int end = items.size();
        while (end > 0 && items.get(end - 1).equals("null")) {
            end--;
        }
        return items.subList(0, end).toString().replace(" ", "");
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }
}
```

```python
import sys
from collections import deque
from typing import List, Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def sortedArrayToBST(self, nums: List[int]) -> Optional[TreeNode]:
        if not nums:
            return None
        root = TreeNode()
        # 栈中任务：(父节点, 挂左还是挂右, 区间 l, r)
        stack = [(root, True, 0, len(nums) - 1)]
        while stack:
            parent, is_left, l, r = stack.pop()
            if l > r:
                if is_left:
                    parent.left = None
                else:
                    parent.right = None
                continue
            mid = l + (r - l) // 2
            node = TreeNode(nums[mid])
            if is_left:
                parent.left = node
            else:
                parent.right = node
            stack.append((node, False, mid + 1, r))
            stack.append((node, True, l, mid - 1))
        return root.left


def level_order(root):

            else:
                items.append("null")

    return "[" + ", ".join(items[:end]) + "]"
```

```cpp
struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* sortedArrayToBST(vector<int>& nums) {
        if (nums.empty()) {
            return nullptr;
        }
        struct Task {
            TreeNode* parent;
            bool isLeft;
            int l, r;
        };
        TreeNode* dummy = new TreeNode();
        stack<Task> st;
        st.push({dummy, true, 0, (int)nums.size() - 1});
        while (!st.empty()) {
            Task task = st.top();
            st.pop();
            if (task.l > task.r) {
                task.isLeft ? task.parent->left = nullptr : task.parent->right = nullptr;
                continue;

            int mid = task.l + (task.r - task.l) / 2;
            TreeNode* node = new TreeNode(nums[mid]);
            task.isLeft ? task.parent->left = node : task.parent->right = node;
            st.push({node, false, mid + 1, task.r});
            st.push({node, true, task.l, mid - 1});
        }
        return dummy->left;
    }
};

    return res + "]";
```

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct TreeNode {
    int val;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;

// 栈中任务
typedef struct {
    TreeNode* parent;
    int isLeft;
    int l, r;
} Task;

TreeNode* sortedArrayToBST(int* nums, int n) {
    if (n == 0) {
        return NULL;
    }
    TreeNode* dummy = (TreeNode*)malloc(sizeof(TreeNode));
    Task* stack = (Task*)malloc((2 * n + 1) * sizeof(Task));
    int top = 0;
    stack[top++] = (Task){dummy, 1, 0, n - 1};
    while (top > 0) {
        Task task = stack[--top];
        TreeNode** slot = task.isLeft ? &task.parent->left : &task.parent->right;
        if (task.l > task.r) {
            *slot = NULL;
            continue;
        }
        int mid = task.l + (task.r - task.l) / 2;
        TreeNode* node = (TreeNode*)malloc(sizeof(TreeNode));
        node->val = nums[mid];
        node->left = node->right = NULL;
        *slot = node;
        stack[top++] = (Task){node, 0, mid + 1, task.r};
        stack[top++] = (Task){node, 1, task.l, mid - 1};
    }
    TreeNode* root = dummy->left;
    free(dummy);
    free(stack);
    return root;
}
```
