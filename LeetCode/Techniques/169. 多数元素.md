# [169. 多数元素](https://leetcode.cn/problems/majority-element/)

- 🟢 **难度**：简单
- 🎩 **分类**：技巧
- 🏷️ **标签**：`数组`、`哈希表`、`分治`、`计数`、`排序`、`摩尔投票算法`

## 题目描述

给定一个大小为 `n` 的数组 `nums` ，返回其中的多数元素。多数元素是指在数组中出现次数 **大于** `⌊ n/2 ⌋` 的元素。

你可以假设数组是非空的，并且给定的数组总是存在多数元素。

**示例 1：**

```
输入：nums = [3,2,3]
输出：3
```

**示例 2：**

```
输入：nums = [2,2,1,1,1,2,2]
输出：2
```

**提示：**
- `n == nums.length`
- `1 <= n <= 5 * 10^4`
- `-10^9 <= nums[i] <= 10^9`
- 输入保证数组中一定有一个多数元素。

**进阶：** 尝试设计时间复杂度为 O(n)、空间复杂度为 O(1) 的算法解决此问题。

## 题解一：哈希计数

### ☕ Java

```java
import java.util.HashMap;
import java.util.Map;
import java.util.Scanner;

class Solution {
    public int majorityElement(int[] nums) {
        Map<Integer, Integer> map = new HashMap<>();
        for (int num : nums) {
            map.put(num, map.getOrDefault(num, 0) + 1);
        }
        for (Map.Entry<Integer, Integer> entry : map.entrySet()) {
            if (entry.getValue() > nums.length / 2) {
                return entry.getKey();
            }
        }
        return 0;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().majorityElement(nums));
        sc.close();
    }
}
```

```python
import sys
from typing import List


class Solution:
    def majorityElement(self, nums: List[int]) -> int:
        count = {}
        for num in nums:
            count[num] = count.get(num, 0) + 1
        for key, value in count.items():
            if value > len(nums) // 2:
                return key
        return 0


if __name__ == "__main__":
```

### ➕ C++

```cpp
#include <unordered_map>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    int majorityElement(vector<int>& nums) {
        unordered_map<int, int> count;
        for (int num : nums) {
            count[num]++;
        }
        for (auto& kv : count) {
            if (kv.second > (int)nums.size() / 2) {
                return kv.first;
            }
        }
        return 0;
    }
};

int main() {
    // ACM 输入：第一行 n，第二行 n 个整数
    int n;
    cin >> n;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    cout << Solution().majorityElement(nums) << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

static unsigned int hashInt(int v, int cap) {
    return ((unsigned int)v * 2654435761u) & (cap - 1);
}

int majorityElement(int* nums, int numsSize) {
    // 开放寻址哈希表：元素值 -> 出现次数
    int cap = 1;
    while (cap < numsSize * 2) {
        cap <<= 1;
    }
    int* keys = (int*)malloc(cap * sizeof(int));
    int* vals = (int*)calloc(cap, sizeof(int));
    char* used = (char*)calloc(cap, sizeof(char));

    int ans = 0;
    for (int i = 0; i < numsSize; i++) {
        int v = nums[i];
        unsigned int h = hashInt(v, cap);
        while (used[h] && keys[h] != v) {
            h = (h + 1) & (cap - 1);
        }
        if (!used[h]) {
            used[h] = 1;
            keys[h] = v;
            vals[h] = 0;
        }
        vals[h]++;
        if (vals[h] > numsSize / 2) {
            ans = v;
            break;
        }
    }

    free(keys);
    free(vals);
    free(used);
    return ans;
}

int main(void) {
    // ACM 输入：第一行 n，第二行 n 个整数
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    printf("%d\n", majorityElement(nums, n));
    free(nums);
    return 0;
}
```

## 题解二：摩尔投票

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int majorityElement(int[] nums) {
        int flag = nums[0];
        int count = 1;
        for (int i = 1; i < nums.length; i++) {
            if (count == 0) {
                flag = nums[i];
                count = 1;
            } else if (flag != nums[i]) {
                count--;
            } else {
                count++;
            }
        }
        return flag;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().majorityElement(nums));
        sc.close();
    }
}
```
