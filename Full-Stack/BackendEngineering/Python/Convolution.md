## 卷积到底在做什么？

先忘掉神经网络，想象你拿着一块小小的"模板"，在一张大图上从左到右、从上到下滑动。

每到一个位置，就做三件事：

1. 截取模板覆盖的局部区域；
2. 将局部区域与模板逐元素相乘；
3. 把所有乘积加起来，得到一个数。

这个数表示：**当前局部区域与模板有多匹配**。

因此，卷积也可以理解成一种"局部模式探测器"。

假设有一个竖直边缘检测模板：

```
 1   0  -1
 1   0  -1
 1   0  -1
```

当图像某个位置的左侧较亮、右侧较暗时，它与这个模板的响应就会比较大。模板滑过整张图后，我们会得到一张新的二维数组，这就是**特征图**（feature map）。

在传统图像处理中，模板常由人手工设计；在神经网络中，模板里的数字由数据自动学习。这些可学习的模板，就是**卷积核**（kernel）或**滤波器**（filter）。

## 先从一维卷积理解"滑动加权求和"

设输入序列为：

```
x = [2, 1, 3, 0, 4]
```

卷积核为：

```
k = [1, 0, -1]
```

步幅为 1，不做填充。第一次覆盖前三个元素：

```
[2, 1, 3] · [1, 0, -1]
= 2×1 + 1×0 + 3×(-1)
= -1
```

继续向右滑动：

```
[1, 3, 0] · [1, 0, -1] = 1
[3, 0, 4] · [1, 0, -1] = -1
```

最终输出：

```
[-1, 1, -1]
```

这个例子已经包含了卷积的核心：

- 卷积核只查看一个局部窗口；
- 同一组权重会在所有位置重复使用；
- 输出记录了不同位置对同一模式的响应。

一维卷积常用于音频、传感器数据、时间序列和文本序列。二维卷积只是把滑动方向从一个维度扩展到两个维度。

### 一个容易被忽略的术语细节

严格的数学卷积会先把卷积核翻转，再进行滑动计算；深度学习框架中的"卷积"通常不翻转卷积核，严格来说执行的是**互相关**（cross-correlation）。

不过，卷积核本身是通过训练学习出来的，翻不翻转不会削弱模型的表达能力。久而久之，行业里仍习惯把这一算子称为卷积。

## 二维卷积：完整手算一次

考虑一个 4×4 的单通道输入：

```
X =
1  2  0  1
3  1  2  2
0  1  3  1
2  2  1  0
```

卷积核为：

```
K =
 1  0
-1  1
```

设步幅 stride=1，填充 padding=0。

左上角第一个窗口是：

```
1  2
3  1
```

对应输出为：

```
1×1 + 2×0 + 3×(-1) + 1×1 = -1
```

将卷积核逐格滑动后，得到：

```
Y =
-1  3  0
 4  3  0
 0  0  2
```

输入是 4×4，卷积核是 2×2，没有填充，所以输出变成了 3×3。

这也说明：**卷积不仅改变数值，还可能改变空间尺寸。**

## 卷积的统一数学表达

在深度学习中，二维卷积通常以四维张量为输入：

```
[N, C_in, H_in, W_in]
```

其中：

- $N$：批量大小；
- $C_{in}$：输入通道数；
- $H_{in}$：输入高度；
- $W_{in}$：输入宽度。

卷积核权重的形状通常为：

```
[C_out, C_in / groups, K_h, K_w]
```

普通卷积中 groups=1，其前向计算可以写成：

$$
Y[o, i, j] = b_o + \sum_{c=0}^{C_{in}-1} \sum_{u=0}^{K_h-1} \sum_{v=0}^{K_w-1}
X[c,\; i \cdot s + u \cdot d,\; j \cdot s + v \cdot d] \cdot W[o, c, u, v]
$$

这里：

- $s$ 表示步幅 stride；
- $p$ 表示填充 padding；
- $d$ 表示空洞率 dilation；
- $b_o$ 是第 $o$ 个输出通道的偏置。

看起来复杂，但本质仍然是：**取局部窗口、逐元素相乘、求和、加偏置。**

## 输出尺寸怎么算？

这是卷积中最常用、也最容易出错的公式。

对于高度方向：

$$
H_{out} = \left\lfloor \frac{H_{in} + 2p - d \times (K_h - 1) - 1}{s} \right\rfloor + 1
$$

宽度方向同理。

定义卷积核的有效尺寸：

$$
K_{eff} = d \times (K - 1) + 1
$$

那么公式也可以记为：

$$
H_{out} = \left\lfloor \frac{H_{in} + 2p - K_{eff}}{s} \right\rfloor + 1
$$

**例 1：最常见的 3×3 卷积**

- 输入：32×32
- 卷积核：3×3
- stride：1
- padding：1
- dilation：1

$$
H_{out} = \left\lfloor \frac{32 + 2 - 3}{1} \right\rfloor + 1 = 32
$$

输出空间尺寸仍是 32×32。

**例 2：使用步幅 2 下采样**

- 输入：32×32
- 卷积核：3×3
- stride：2
- padding：1

$$
H_{out} = \left\lfloor \frac{32 + 2 - 3}{2} \right\rfloor + 1 = 16
$$

输出变成 16×16。

**例 3：空洞卷积**

- 输入：32×32
- 卷积核：3×3
- stride：1
- padding：2
- dilation：2

有效卷积核尺寸为：

$$
K_{eff} = 2 \times (3 - 1) + 1 = 5
$$

所以输出仍为：

$$
H_{out} = \left\lfloor \frac{32 + 4 - 5}{1} \right\rfloor + 1 = 32
$$

### "same" 不总等于简单的对称填充

当步幅为 1、卷积核尺寸为奇数时，想保持输入输出尺寸一致，通常可取：

$$
p = \frac{K - 1}{2}
$$

但当 stride > 1 时，很多框架里的 `same` 表示让输出尺寸接近：

$$
H_{out} = \left\lceil \frac{H_{in}}{s} \right\rceil
$$

这时上下或左右两边的填充量可能并不完全对称。跨框架迁移模型时，要特别留意 `same` 的具体定义。

## 多通道卷积到底怎么算？

一张 RGB 图像有 3 个通道，因此输入形状可以写成：

```
[3, H, W]
```

如果使用一个 3×3 卷积核，它并不是只有一个二维矩阵，而是有 3 个切片：

```
[3, 3, 3] = [输入通道数, 核高, 核宽]
```

这个卷积核会：

1. 分别与 R、G、B 三个通道的局部区域做乘法；
2. 将三个通道上的结果全部相加；
3. 再加一个偏置；
4. 生成一个输出通道。

因此：

- **一个完整卷积核生成一个输出通道；**
- **有多少个卷积核，就有多少个输出通道。**

例如：

```python
nn.Conv2d(
    in_channels=3,
    out_channels=64,
    kernel_size=3,
    padding=1
)
```

表示模型会学习 64 个卷积核，每个卷积核的形状都是 3×3×3，最终得到 64 张特征图。

需要注意：卷积中的"通道"不是简单独立处理。普通卷积会同时进行两类操作：

- 在空间维度上提取局部模式；
- 在通道维度上融合信息。

## 参数量和计算量如何计算？

设卷积核大小为 $K_h \times K_w$，输入通道数为 $C_{in}$，输出通道数为 $C_{out}$，分组数为 $g$。

### 参数量

不含偏置时：

$$
P = \frac{C_{in}}{g} \times C_{out} \times K_h \times K_w
$$

含偏置时再加：

$$
C_{out}
$$

普通卷积中 $g = 1$。

例如，一个 3×3、输入通道 64、输出通道 128 的普通卷积，不含偏置时参数量为：

$$
3 \times 3 \times 64 \times 128 = 73{,}728
$$

**参数量与输入图片的高宽无关。**这正是权重共享带来的优势：无论图片是 32×32 还是 1024×1024，卷积核参数都不变。

### 乘加次数

对单个样本，近似乘加次数 MACs 为：

$$
MACs = H_{out} \times W_{out} \times C_{out} \times \frac{C_{in}}{g} \times K_h \times K_w
$$

如果输出是 56×56，上述卷积需要：

$$
56 \times 56 \times 128 \times 64 \times 3 \times 3 = 231{,}211{,}008
$$

约为 2.31 亿次乘加。

有的资料把一次乘法和一次加法合计为 2 FLOPs，有的把一次乘加记为 1 次操作。因此**比较模型计算量时，先确认统计口径**。

## 卷积为什么适合图像？

卷积的优势不是"它能做乘法"，而是它引入了三个非常重要的结构假设。

### 1. 局部连接

图像中的相邻像素往往关系更紧密。边缘、角点、纹理等基础视觉模式，通常都能在小范围内被识别。

卷积核不必一开始就观察整张图片，只需先处理局部区域，再通过多层堆叠逐渐整合更大范围的信息。

### 2. 权重共享

一条竖直边缘无论出现在左上角还是右下角，本质上仍是竖直边缘。因此，同一个检测器可以在所有位置复用。

如果为每个位置单独学习一套参数，不仅参数量巨大，也会失去这种合理的先验。

### 3. 平移等变性

忽略边界和步幅带来的离散效应时，如果输入向右移动，卷积输出也会相应向右移动。这叫**平移等变**（translation equivariance）。

需要区分：

- 卷积天然更接近平移等变；
- 它并不天然完全平移不变；
- 平移不变性通常来自池化、下采样、全局聚合、数据增强以及模型整体学习。

## 卷积层到底学到了什么？

训练前，卷积核通常是随机初始化的。训练过程中，反向传播不断调整其中的权重，使模型在目标任务上的损失下降。

在图像网络中，经常可以观察到这样的层级结构：

- 浅层偏向边缘、方向、颜色对比等基础模式；
- 中层逐渐组合出纹理、轮廓和局部结构；
- 深层进一步组合成与任务相关的部件和语义特征。

这不是人为写入的固定规则，而是局部连接、数据分布和训练目标共同作用的结果。

### 从"模板匹配"到"特征组合"

单个卷积层像是在寻找局部模板。多个卷积层叠加后，后一层可以组合前一层已经提取出的特征。

例如：

```
像素变化 → 边缘 → 角点与纹理 → 局部形状 → 物体部件 → 高层语义
```

卷积网络的强大之处，就在于它能够用大量简单、局部、可学习的操作，逐层构建复杂表示。

## 卷积如何通过反向传播学习？

设损失函数为 $L$，卷积输出上的梯度为 $\frac{\partial L}{\partial Y}$。

那么卷积核中某个权重的梯度，本质上是：

> **所有使用过这个权重的位置上，"输入值 × 对应输出梯度"的累加。**

可写为：

$$
\frac{\partial L}{\partial W[o,c,u,v]} = \sum_{i,j} X[c,\; i \cdot s + u \cdot d,\; j \cdot s + v \cdot d] \cdot \frac{\partial L}{\partial Y[o,i,j]}
$$

偏置梯度更简单：

$$
\frac{\partial L}{\partial b_o} = \sum_{i,j} \frac{\partial L}{\partial Y[o,i,j]}
$$

输入梯度则是把每个输出位置的梯度乘以卷积核权重，再累加回它曾经覆盖的输入位置。

这解释了两个现象：

1. 同一个卷积核在多个位置共享，因此它的梯度也来自多个位置的共同贡献；
2. 输入梯度会发生"散射累加"，这与转置卷积的计算结构密切相关。

实际开发中不需要手写这些梯度，自动微分框架会完成计算。但理解这个过程，有助于排查梯度异常和自定义算子问题。

## 六个核心超参数

### 1. Kernel Size：卷积核尺寸

常见尺寸有 1×1、3×3、5×5、7×7。

卷积核越大，单层能直接看到的局部范围越大，但参数量和计算量也会增加。

在输入输出通道相同的情况下：

- 一个 5×5 卷积的参数系数是 25；
- 两个连续的 3×3 卷积拥有同样大小的理论感受野，参数系数是 18；
- 两层之间还能插入一次非线性激活。

因此，连续的小卷积核在许多经典网络中非常常见。不过，大卷积核也有自己的价值，实际选择取决于任务、架构和硬件。

### 2. Stride：步幅

步幅决定卷积核每次移动多少格。

- stride=1：逐格扫描，信息保留较完整；
- stride=2：输出高宽通常减半，可用于下采样；
- 更大步幅：计算量降低，但容易过早丢失细节。

步幅卷积可以同时完成特征提取和下采样。

### 3. Padding：填充

最常见的是零填充，即在输入边缘补零。

填充有三大作用：

- 控制输出尺寸；
- 让边缘像素有更多被卷积核覆盖的机会；
- 方便堆叠多层卷积和构建残差连接。

但填充也会引入边界假设。除零填充外，还有反射填充、复制填充和循环填充等方式，适合不同数据结构。

### 4. Dilation：空洞率

空洞卷积会在卷积核采样点之间插入间隔。

对于 3×3 卷积核：

- dilation=1，有效尺寸是 3×3；
- dilation=2，有效尺寸是 5×5；
- dilation=3，有效尺寸是 7×7。

它能在不显著增加参数量的情况下扩大感受野，常用于语义分割和时序建模。

代价是采样变得稀疏，连续堆叠不当时可能产生"栅格效应"，遗漏局部信息。

### 5. Groups：分组数

分组卷积把输入通道和输出通道分成若干组，各组独立卷积，最后在通道维拼接。

- groups=1：普通卷积；
- groups>1：分组卷积；
- groups=in_channels：深度卷积的核心形式。

通常要求：

```
in_channels % groups == 0
out_channels % groups == 0
```

分组越多，通道之间的直接交互越少，参数量和计算量通常也越低。

### 6. Bias：偏置

每个输出通道通常对应一个偏置参数。

如果卷积后紧接带可学习平移参数的批归一化层，卷积偏置往往可以关闭：

```python
nn.Conv2d(..., bias=False)
```

这不是硬性规定，但可以减少冗余参数。

## 感受野：一层卷积到底"看见"多大范围？

**感受野**（receptive field）指某个输出特征理论上受输入中多大区域影响。

单个 3×3 卷积只能直接观察 3×3 区域；连续堆叠三层、步幅都为 1 时，理论感受野依次为：

```
第 1 层：3×3
第 2 层：5×5
第 3 层：7×7
```

更一般地，定义：

- $RF_l$：第 $l$ 层的感受野大小；
- $J_l$：第 $l$ 层相邻输出点在原输入上的间隔，也叫 jump；
- $K_{eff,l}$：该层有效卷积核尺寸；
- $S_l$：该层步幅。

递推关系为：

$$
RF_l = RF_{l-1} + (K_{eff,l} - 1) \times J_{l-1}
$$

$$
J_l = J_{l-1} \times S_l
$$

初始时：

$$
RF_0 = 1, \quad J_0 = 1
$$

例如：

| 层 | 卷积核 | 步幅 | 感受野 | 间隔 |
| --- | --- | --- | --- | --- |
| 输入 | — | — | 1 | 1 |
| Conv1 | 3 | 1 | 3 | 1 |
| Conv2 | 3 | 2 | 5 | 2 |
| Conv3 | 3 | 1 | 9 | 2 |

还要注意，**理论感受野不等于模型实际有效利用的区域**。深层网络中，虽然理论感受野很大，但中心区域往往影响更强，这通常被称为有效感受野现象。

## 1×1 卷积：明明不看邻居，为什么还有用？

1×1 卷积在空间上只看一个像素位置，但会读取该位置上的全部输入通道。

因此，它本质上是在每个空间位置执行同一个通道线性变换：

$$
Y[o, i, j] = \sum_{c=0}^{C_{in}-1} W[o, c] \cdot X[c, i, j] + b_o
$$

它常用于：

- 压缩通道，减少后续计算量；
- 扩展通道，提高表示维度；
- 混合不同通道的信息；
- 对齐残差分支的通道数；
- 在深度卷积后恢复通道交互。

例如：

```
输入：56×56×256
1×1 卷积输出：56×56×64
```

空间尺寸不变，通道从 256 压缩到 64，后续 3×3 卷积的计算量会显著下降。

可以把 1×1 卷积理解成：**对每一个像素位置共享使用的全连接层。**

## 分组卷积与深度可分离卷积

### 1. 分组卷积

普通卷积中，每个输出通道都连接全部输入通道。分组卷积则把通道拆成多个子空间，每组独立处理。

假设：

```
C_in = 64
C_out = 128
groups = 4
```

那么每组看到 16 个输入通道，并生成 32 个输出通道。

分组卷积能降低计算量，也能促使不同组学习相对独立的特征。但它减少了跨组信息交流，通常需要借助通道混洗、1×1 卷积或后续层重新融合。

### 2. 深度卷积

深度卷积（depthwise convolution）为每个输入通道单独执行空间卷积。

典型情况下：

```
in_channels = C
groups = C
out_channels = C
```

它只负责空间特征提取，不负责充分混合通道。

### 3. 深度可分离卷积

深度可分离卷积通常分成两步：

1. K×K 深度卷积：逐通道提取空间特征；
2. 1×1 点卷积：混合通道并改变通道数。

普通卷积参数量：

$$
P_{normal} = K \times K \times C_{in} \times C_{out}
$$

深度可分离卷积参数量：

$$
P_{ds} = K \times K \times C_{in} + C_{in} \times C_{out}
$$

当 $K = 3$、$C_{in} = C_{out} = 128$ 时：

```
普通卷积：3×3×128×128 = 147,456
深度卷积：3×3×128     =   1,152
点卷积：  1×1×128×128 =  16,384
合计：17,536
```

参数量约减少到普通卷积的八分之一左右。

不过，**理论计算量降低不一定等比例转化为真实延迟下降**。内存访问、算子融合、张量尺寸和具体硬件都会影响实际速度。

---

## 空洞卷积：不增加参数，也能扩大视野

空洞卷积通过稀疏采样扩大卷积核覆盖范围。

普通 3×3 卷积：

```
● ● ●
● ● ●
● ● ●
```

dilation=2 时，可以想象成：

```
● · ● · ●
· · · · ·
● · ● · ●
· · · · ·
● · ● · ●
```

虽然有效覆盖范围变成 5×5，真正参与计算的仍只有 9 个采样点，所以参数量不变。

它的典型优势是：

- 保持较高空间分辨率；
- 在不使用更大卷积核的情况下扩大感受野；
- 适合密集预测任务。

常见风险包括：

- 采样过于稀疏，丢失连续局部信息；
- 多层使用相同大空洞率，可能出现栅格状盲区；
- 边界处需要更大的填充。

---

## 转置卷积：它不是"卷积的逆运算"

转置卷积常用于扩大空间尺寸，例如解码器、生成模型和分割网络的上采样部分。

"转置"来自线性代数视角：如果普通卷积可以写成矩阵乘法：

$$
Y = C X
$$

那么转置卷积对应的是：

$$
X' = C^{T} Y
$$

它并不意味着能够从卷积结果无损恢复原输入，因此**不是通常意义上的逆运算**。

一维情况下，其输出尺寸公式可写为：

$$
L_{out} = (L_{in} - 1) \times s - 2p + K_{eff} + output\_padding
$$

`output_padding` 主要用于解决步幅大于 1 时的尺寸歧义，它不会像普通 padding 那样真的在输出边缘补一圈值。

### 棋盘格伪影

转置卷积可能因为窗口重叠不均匀产生棋盘格伪影。常见替代方案是：

> **插值上采样（最近邻或双线性）+ 普通卷积**

两种方案各有优缺点，不能一概而论；但遇到规则纹理伪影时，应优先检查上采样方式、卷积核大小与步幅的组合。

---

## 卷积是怎样被高效执行的？

公式看起来像大量嵌套循环，但高性能框架通常不会简单逐元素实现。

常见策略包括：

### 1. Direct Convolution

直接按卷积定义计算。实现直观，适合某些小尺寸或特定硬件场景。

### 2. im2col + GEMM

把每个局部窗口展开成矩阵的一列，再把卷积转成大规模矩阵乘法。

优点是可以利用高度优化的矩阵乘法库；缺点是展开过程可能产生较大临时内存。

### 3. Winograd

常用于小卷积核，尤其是部分 3×3 卷积场景，通过减少乘法次数提升性能。数值稳定性和适用尺寸需要权衡。

### 4. FFT Convolution

利用频域中卷积对应乘法的性质，适合较大卷积核或较长序列，但变换本身也有开销。

现代深度学习库会根据输入尺寸、数据类型、硬件和可用工作空间选择不同算法。因此：

> **参数更少、FLOPs 更低，并不必然意味着在真实设备上运行更快。**

评估模型时，最好同时测量参数量、理论计算量、峰值内存、实际延迟和吞吐量。

## 用 NumPy 从零实现二维卷积

下面实现的是单通道二维互相关，支持步幅、填充和空洞率。

```python
import numpy as np

def conv2d_single_channel(
    x: np.ndarray,
    kernel: np.ndarray,
    stride: int = 1,
    padding: int = 0,
    dilation: int = 1,
) -> np.ndarray:
    """单通道 2D 卷积（实际执行互相关）。

    Args:
        x: 输入，形状为 [H, W]。
        kernel: 卷积核，形状为 [K_h, K_w]。
        stride: 步幅，必须为正整数。
        padding: 四周零填充大小，必须为非负整数。
        dilation: 空洞率，必须为正整数。

    Returns:
        输出二维数组。
    """
    if x.ndim != 2 or kernel.ndim != 2:
        raise ValueError("x 和 kernel 都必须是二维数组")
    if stride <= 0 or dilation <= 0 or padding < 0:
        raise ValueError("stride、dilation 必须为正，padding 必须非负")

    x = np.asarray(x, dtype=np.float64)
    kernel = np.asarray(kernel, dtype=np.float64)

    h_in, w_in = x.shape
    k_h, k_w = kernel.shape

    effective_k_h = dilation * (k_h - 1) + 1
    effective_k_w = dilation * (k_w - 1) + 1

    h_out = (h_in + 2 * padding - effective_k_h) // stride + 1
    w_out = (w_in + 2 * padding - effective_k_w) // stride + 1

    if h_out <= 0 or w_out <= 0:
        raise ValueError("卷积核有效尺寸大于填充后的输入尺寸")

    x_padded = np.pad(
        x,
        ((padding, padding), (padding, padding)),
        mode="constant",
    )

    output = np.empty((h_out, w_out), dtype=np.float64)

    for i in range(h_out):
        for j in range(w_out):
            top = i * stride
            left = j * stride
            window = x_padded[
                top : top + effective_k_h : dilation,
                left : left + effective_k_w : dilation,
            ]
            output[i, j] = np.sum(window * kernel)

    return output


x = np.array([
    [1, 2, 0, 1],
    [3, 1, 2, 2],
    [0, 1, 3, 1],
    [2, 2, 1, 0],
])

kernel = np.array([
    [1, 0],
    [-1, 1],
])

print(conv2d_single_channel(x, kernel))
# [[-1. 3. 0.]
#  [ 4. 3. 0.]
#  [ 0. 0. 2.]]
```

这个实现适合帮助理解原理，但真实项目应使用 PyTorch、TensorFlow、JAX 等框架中的优化算子。

## 在 PyTorch 中使用卷积

### 1. 最基本的 Conv2d

```python
import torch
import torch.nn as nn

x = torch.randn(8, 3, 224, 224)

conv = nn.Conv2d(
    in_channels=3,
    out_channels=64,
    kernel_size=3,
    stride=2,
    padding=1,
    bias=False,
)

y = conv(x)
print(y.shape)
# torch.Size([8, 64, 112, 112])
```

逐项理解：

- 批量大小 8 不变；
- 输入通道从 3 变成输出通道 64；
- 步幅为 2，所以高宽从 224 约减半到 112；
- padding=1 配合 3×3 卷积，使下采样尺寸整齐。

### 2. 一个可运行的小型卷积网络

```python
import torch
import torch.nn as nn

class TinyCNN(nn.Module):
    def __init__(self, num_classes: int = 10) -> None:
        super().__init__()
        self.features = nn.Sequential(
            nn.Conv2d(3, 32, 3, stride=1, padding=1, bias=False),
            nn.BatchNorm2d(32),
            nn.ReLU(inplace=True),

            nn.Conv2d(32, 64, 3, stride=2, padding=1, bias=False),
            nn.BatchNorm2d(64),
            nn.ReLU(inplace=True),

            nn.Conv2d(64, 128, 3, stride=2, padding=1, bias=False),
            nn.BatchNorm2d(128),
            nn.ReLU(inplace=True),

            nn.AdaptiveAvgPool2d(1),
        )
        self.classifier = nn.Linear(128, num_classes)

    def forward(self, x: torch.Tensor) -> torch.Tensor:
        x = self.features(x)
        x = torch.flatten(x, 1)
        return self.classifier(x)

model = TinyCNN(num_classes=10)
x = torch.randn(4, 3, 32, 32)
logits = model(x)
print(logits.shape)  # torch.Size([4, 10])
```

尺寸变化如下：

```
[4, 3, 32, 32]
[4, 32, 32, 32]
[4, 64, 16, 16]
[4, 128, 8, 8]
[4, 128, 1, 1]
[4, 10]
```

**养成逐层写尺寸的习惯，是避免网络结构错误最有效的方法之一。**

## 卷积网络的实用设计原则

下面不是不可违反的定律，而是可靠的起点。

### 1. 默认从 3×3 卷积开始

3×3 在局部建模能力、参数量和硬件优化之间通常有较好平衡。需要更大范围时，可以堆叠多层、使用空洞卷积，或直接采用更大卷积核。

### 2. 优先使用奇数卷积核

奇数卷积核有明确中心点，更容易做对称填充，也便于保持空间对齐。

### 3. 分辨率降低时，通道数通常增加

空间尺寸下降会减少计算量，因此网络常在下采样后增加通道数，以保存和扩展特征表达能力。

典型趋势是：

```
高分辨率、少通道 → 低分辨率、多通道
```

### 4. 不要过早、过猛地下采样

网络前几层包含大量细粒度信息。过大的卷积核或步幅可能快速丢失小目标、纹理和边界信息。

### 5. 用残差连接改善深层训练

残差结构让网络学习对输入的增量变化，并为梯度提供更直接的传播路径。构建较深卷积网络时，残差连接往往比单纯堆叠卷积更稳定。

### 6. 同时关注算术量和内存访问

1×1 卷积、深度卷积、分组卷积的理论 FLOPs 可能很低，但真实速度取决于硬件利用率、张量布局和算子实现。最终应在目标设备上基准测试。

### 7. 明确数据格式

PyTorch 常用：

```
NCHW = [batch, channel, height, width]
```

部分工具和框架常见：

```
NHWC = [batch, height, width, channel]
```

格式混淆会直接导致尺寸错误，甚至在某些情况下产生没有报错但语义错误的结果。

## 最常见的十个误区

**误区 1：卷积核只是一个二维矩阵**

多通道输入下，一个输出卷积核还包含输入通道维度，完整形状通常是 `[C_in, K_h, K_w]`。

**误区 2：有多少输入通道，就有多少输出通道**

输出通道数由卷积核数量决定，与输入通道数不必相同。

**误区 3：卷积天然具有平移不变性**

卷积更准确的性质是平移等变。完全不变通常需要池化、全局聚合和整体训练共同形成。

**误区 4：padding 只用于保持尺寸**

padding 还影响边界信息、特征对齐和网络的边界假设。

**误区 5：stride=2 与池化完全等价**

二者都能下采样，但步幅卷积的下采样权重可学习，池化则使用固定聚合规则。它们的表示与优化行为不同。

**误区 6：转置卷积能恢复原图**

转置卷积不是逆卷积，不能保证恢复卷积前的信息。

**误区 7：FLOPs 更低，模型一定更快**

真实延迟还受内存、并行度、算子融合、批量大小和硬件支持影响。

**误区 8：卷积核越大越好**

更大卷积核带来更大局部视野，也带来更多计算和参数。是否有效取决于任务与架构。

**误区 9：加了 dilation，卷积核参数也会增多**

空洞率只改变采样间隔，不改变卷积核中的权重数量。

**误区 10：卷积公式算对，网络就一定没问题**

公式正确只是第一步。还要检查输入归一化、初始化、梯度、数据标签、损失函数、训练模式和推理模式。

## 卷积层排错清单

遇到模型不收敛、输出异常或尺寸报错时，可以按以下顺序排查。

### 1. 打印每一层形状

确认：

- 批量维是否丢失；
- 通道顺序是否正确；
- 下采样是否符合预期；
- 残差相加的两条分支形状是否一致。

### 2. 手算一个输出尺寸

不要只依赖"感觉"。把 $H_{in}$、$K$、$s$、$p$、$d$ 代入公式。

### 3. 用极小数据集过拟合

选择少量样本训练到接近零损失。若连少量样本都无法拟合，通常说明实现、数据或优化流程存在问题。

### 4. 使用简单输入做单元测试

例如：

- 全 1 输入配合全 1 卷积核；
- 单个脉冲输入；
- 人工构造的水平或竖直边缘；
- 与框架参考实现比较输出。

### 5. 检查数值范围

关注：

- 输入是否归一化；
- 激活是否爆炸或全部变成零；
- 梯度是否出现 NaN 或无穷大；
- 混合精度下是否发生溢出。

### 6. 检查训练与推理模式

含 BatchNorm、Dropout 等层时，应正确使用：

```python
model.train()
model.eval()
```

### 7. 做梯度检查

自定义卷积算子时，可用有限差分近似梯度，与自动微分结果比较。注意使用双精度和足够小的测试张量。

## 面试与自测：你真的掌握卷积了吗？

**问题 1**：输入尺寸 64×64，卷积核 3×3，stride=2，padding=1，输出是多少？

答案：

$$
H_{out} = \left\lfloor \frac{64 + 2 - 3}{2} \right\rfloor + 1 = 32
$$

所以输出为 32×32。

**问题 2**：输入通道 32，输出通道 64，卷积核 3×3，有偏置，参数量是多少？

答案：

$$
3 \times 3 \times 32 \times 64 + 64 = 18{,}496
$$

**问题 3**：为什么 1×1 卷积能融合通道？

答案：它在每个空间位置读取全部输入通道，并对通道向量执行线性变换。

**问题 4**：空洞卷积为什么不增加参数量？

答案：它只拉大卷积核采样点之间的距离，并没有增加可学习权重的数量。

**问题 5**：深度卷积为什么通常还要接 1×1 卷积？

答案：深度卷积主要在每个通道内提取空间特征，缺少充分的跨通道交互；1×1 点卷积负责通道混合。

**问题 6**：转置卷积为何可能产生棋盘格？

答案：不同输出位置接收到的卷积核重叠次数可能不均匀，导致周期性的响应差异。

**问题 7**：连续三个 3×3、步幅为 1 的卷积，理论感受野多大？

答案：7×7。

**问题 8**：普通卷积相比全连接层，核心结构先验是什么？

答案：局部连接与权重共享，以及由此产生的平移等变倾向。

## 一张表总结常见卷积

| 类型 | 核心做法 | 主要优势 | 常见注意点 |
| --- | --- | --- | --- |
| 普通卷积 | 同时进行空间提取和通道融合 | 表达能力强、支持成熟 | 计算量可能较大 |
| 1×1 卷积 | 每个位置做通道线性变换 | 压缩、扩展、融合通道 | 不直接聚合邻域信息 |
| 分组卷积 | 通道分组后独立卷积 | 降低计算、形成子空间 | 跨组交流减少 |
| 深度卷积 | 每个通道独立做空间卷积 | 参数和计算量低 | 通道融合能力弱 |
| 深度可分离卷积 | 深度卷积 + 1×1 点卷积 | 高效兼顾空间与通道建模 | 实际加速依赖硬件 |
| 空洞卷积 | 拉开卷积核采样间距 | 不增参数地扩大感受野 | 可能产生栅格效应 |
| 转置卷积 | 使用卷积线性变换的转置结构 | 可学习上采样 | 可能出现棋盘格伪影 |

## 卷积公式速查卡

**有效卷积核尺寸**

$$
K_{eff} = d \times (K - 1) + 1
$$

**普通卷积输出尺寸**

$$
H_{out} = \left\lfloor \frac{H_{in} + 2p - K_{eff}}{s} \right\rfloor + 1
$$

**转置卷积输出尺寸**

$$
H_{out} = (H_{in} - 1) \times s - 2p + K_{eff} + output\_padding
$$

**分组卷积参数量**（含偏置）

$$
P = \frac{C_{in}}{g} \times C_{out} \times K_h \times K_w + C_{out}
$$

**分组卷积乘加次数**

$$
MACs = H_{out} \times W_{out} \times C_{out} \times \frac{C_{in}}{g} \times K_h \times K_w
$$

**感受野递推**

$$
RF_l = RF_{l-1} + (K_{eff,l} - 1) \times J_{l-1}, \quad J_l = J_{l-1} \times S_l
$$

## 结语：真正理解卷积，要抓住三条主线

卷积的知识点很多，但可以归结为三条主线。

**第一条是计算主线**：局部窗口滑动，逐元素相乘并求和；步幅、填充和空洞率共同决定采样方式与输出尺寸。

**第二条是表示主线**：卷积通过局部连接和权重共享学习可复用模式，多层堆叠后逐渐从低级特征走向高级语义。

**第三条是工程主线**：参数量不等于计算量，计算量不等于真实速度；网络设计还要考虑通道、分辨率、内存访问、硬件与数值稳定性。

当你能够做到下面四件事，就不再只是"会调用卷积层"：

1. 看到参数就能推导输入输出形状；
2. 能解释每种卷积变体解决了什么问题、付出了什么代价；
3. 能从感受野、通道交互和计算成本三个角度分析结构；
4. 遇到训练或部署问题时，能设计可验证的排错实验。

卷积并不神秘。它只是一种结构化的线性运算，但正是"局部、共享、可学习"这三个特点，让它成为深度学习中最重要、最耐用的基础算子之一。
