## 目录结构

- `code/` —— Java 源码。`classNNN/` 对应第 N 讲，内部为 `CodeNN_描述.java`（一讲可含多题）
- `ppt/` —— 每讲课件，`算法讲解NNN【难度】主题.pdf`
- `note/` —— 汇总笔记（Markdown）：
  - `HelloDSA(Base).md`（001–098 讲）
  - `HelloDSA(Improve).md`（099–101 讲）
