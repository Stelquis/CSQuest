## 规范

- **题解**：文件名 `题号. 中文题名.md`；结构为「标题 → 难度/分类/标签 → 题目描述 → 题解（思路、复杂度、易错点）→ 四语言代码块」
- **代码**：每段均为可直接编译运行的**完整程序**（ACM 式输入输出）；Java 辅助函数一律 `public static`
- **索引**：完成一题在题目行标 ✅，整个分类完成时分类标题补 ✅；详情见 [LeetCode/README.md](LeetCode/README.md) 的「规范」一节
- **课程归档**：`classNNN` 对应第 N 讲，课件命名 `算法讲解NNN【难度】主题.pdf`
