# [35. 搜索插入位置](https://leetcode.cn/problems/search-insert-position/)

- 🟢 **难度**：简单
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`

## 题目描述

给定一个排序数组和一个目标值，在数组中找到目标值，并返回其索引。如果目标值不存在于数组中，返回它将会被按顺序插入的位置。

请必须使用时间复杂度为 `O(log n)` 的算法。

**示例 1:**

```
输入: nums = [1,3,5,6], target = 5
输出: 2
```

**示例 2:**

```
输入: nums = [1,3,5,6], target = 2
输出: 1
```

**示例 3:**

```
输入: nums = [1,3,5,6], target = 7
输出: 4
```

**提示:**
- `1 <= nums.length <= 10^4`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 为 **无重复元素** 的 **升序** 排列数组
- `-10^4 <= target <= 10^4`

## 题解：闭区间二分查找

在有序数组中"查找 + 找插入位置"用一套逻辑就能统一：在**闭区间 `[l, r]`** 内二分。

- `nums[mid] < target`：目标（或插入点）必在右半，`l = mid + 1`；
- `target < nums[mid]`：必在左半，`r = mid - 1`；
- 相等：直接命中，返回 `mid`。

循环以 `l > r` 结束。**此时 `l` 恰好是"第一个大于 `target` 的下标"，也就是插入位置**——因为整个查找过程维护着不变量：`l` 左侧全部 `< target`，`r` 右侧全部 `> target`，区间压空时 `l` 就顶在了插入点上。头尾两种边界也自然成立：`target` 比所有元素小时 `l` 停在 `0`，比所有元素大时 `l` 停在 `n`。

模拟 `nums = [1,3,5,6]`、`target = 2`：

```
l=0, r=3 → mid=1, nums[1]=3 > 2 → r=0
l=0, r=0 → mid=0, nums[0]=1 < 2 → l=1
l > r，退出 → 返回 1 ✓（2 应插在下标 1）
```

- 时间复杂度：`O(log n)`，每次迭代区间减半
- 空间复杂度：`O(1)`

**习惯写法**：`mid = (l + r) / 2` 在 `l + r` 超出整型范围时会溢出（本题数据范围不会触发），更稳妥的写法是 `mid = l + (r - l) / 2`。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int searchInsert(int[] nums, int target) {
        int l = 0, r = nums.length - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            int midVal = nums[mid];
            if (midVal < target) {
                l = mid + 1;
            } else if (target < midVal) {
                r = mid - 1;
            } else {
                return mid;
            }
        }
        return l;               // 未找到时 l 即插入位置
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n 和 target，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().searchInsert(nums, target));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def searchInsert(self, nums: List[int], target: int) -> int:
        l, r = 0, len(nums) - 1
        while l <= r:
            mid = (l + r) // 2
            if nums[mid] < target:
                l = mid + 1
            elif target < nums[mid]:
                r = mid - 1
            else:
                return mid
        return l                # 未找到时 l 即插入位置


if __name__ == "__main__":
    # ACM 输入：第一行 n 和 target，第二行 n 个整数
    data = sys.stdin.read().split()
    n, target = int(data[0]), int(data[1])
    nums = [int(x) for x in data[2:2 + n]]
    print(Solution().searchInsert(nums, target))
```

```cpp
int main() {
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int searchInsert(int* nums, int numsSize, int target) {
    int l = 0, r = numsSize - 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (nums[mid] < target) {
            l = mid + 1;
        } else if (target < nums[mid]) {
            r = mid - 1;
        } else {
            return mid;
        }
    }
    return l;                   /* 未找到时 l 即插入位置 */
}

int main(void) {
    /* ACM 输入：第一行 n 和 target，第二行 n 个整数 */
    int n, target;
    if (scanf("%d %d", &n, &target) != 2) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    printf("%d\n", searchInsert(nums, n, target));
    free(nums);
    return 0;
}
```
