# [34. 在排序数组中查找元素的第一个和最后一个位置](https://leetcode.cn/problems/find-first-and-last-position-of-element-in-sorted-array/)

- 🟡 **难度**：中等
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`

## 题目描述

给你一个按照非递减顺序排列的整数数组 `nums`，和一个目标值 `target`。请你找出给定目标值在数组中的开始位置和结束位置。

如果数组中不存在目标值 `target`，返回 `[-1, -1]`。

你必须设计并实现时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入：nums = [5,7,7,8,8,10], target = 8
输出：[3,4]
```

**示例 2：**

```
输入：nums = [5,7,7,8,8,10], target = 6
输出：[-1,-1]
```

**示例 3：**

```
输入：nums = [], target = 0
输出：[-1,-1]
```

**提示：**
- `0 <= nums.length <= 10^5`
- `-10^9 <= nums[i] <= 10^9`
- `nums` 是一个非递减数组
- `-10^9 <= target <= 10^9`

## 题解：两次带偏置的二分（找左端点 + 找右端点）

普通二分命中就返回，但 `target` 有重复元素时，命中点未必是边界。技巧是：**命中后不要停，记录候选答案，然后继续向边界方向压**：

- **找左端点**：命中时 `ansL = mid; r = mid - 1`——记下候选，但左边可能还有更早的出现位置；
- **找右端点**：命中时 `ansR = mid; l = mid + 1`——同理继续向右压。

两段循环几乎一样，只差命中后的压向。若两轮下来候选仍是 `-1`，说明 `target` 不存在。进入二分前用 `nums[0]` / `nums[len-1]` 做范围剪枝，可提前排除不在数组范围的情况。

模拟 `nums = [5,7,7,8,8,10]`、`target = 8`：

```
找左端点: mid=2, 7<8 → l=3; mid=4, 命中 → ansL=4, r=3;
          mid=3, 命中 → ansL=3, r=2; 区间压空 → ansL=3 ✓
找右端点: mid=2, 7<8 → l=3; mid=4, 命中 → ansR=4, l=5;
          mid=5, 10>8 → r=4; 区间压空 → ansR=4 ✓
结果 [3, 4]
```

- 时间复杂度：两轮二分各 `O(log n)`，总计 `O(log n)`
- 空间复杂度：`O(1)`

**备注**：两轮也可以统一成"找 `lower_bound`（第一个 `>= target`）和 `upper_bound - 1`（最后一个 `<= target`）"的写法，与 C++ 标准库同名函数语义一致；也可以在第一轮结束后若 `ansL == -1` 直接返回，省掉第二轮——但整体复杂度不变。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int[] searchRange(int[] nums, int target) {
        int len = nums.length;
        if (len == 0 || target < nums[0] || target > nums[len - 1]) {
            return new int[]{-1, -1};
        }
        int ansL = -1, ansR = -1;
        // 第一次二分：命中后继续向左压，找第一个出现位置
        int l = 0, r = len - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (target < nums[mid]) {
                r = mid - 1;
            } else if (target > nums[mid]) {
                l = mid + 1;
            } else {
                ansL = mid;         // 记录候选，左边可能还有
                r = mid - 1;
            }
        }
        // 第二次二分：命中后继续向右压，找最后一个出现位置
        l = 0;
        r = len - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (target < nums[mid]) {
                r = mid - 1;
            } else if (target > nums[mid]) {
                l = mid + 1;
            } else {
                ansR = mid;         // 记录候选，右边可能还有
                l = mid + 1;
            }
        }
        return new int[]{ansL, ansR};
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n 和 target，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        int[] ans = new Solution().searchRange(nums, target);
        System.out.println(ans[0] + " " + ans[1]);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def searchRange(self, nums: List[int], target: int) -> List[int]:
        n = len(nums)
        if n == 0 or target < nums[0] or target > nums[n - 1]:
            return [-1, -1]
        # 第一次二分：命中后继续向左压，找第一个出现位置
        ans_l, l, r = -1, 0, n - 1
        while l <= r:
            mid = (l + r) // 2
            if target < nums[mid]:
                r = mid - 1
            elif target > nums[mid]:
                l = mid + 1
            else:
                ans_l = mid         # 记录候选，左边可能还有
                r = mid - 1
        # 第二次二分：命中后继续向右压，找最后一个出现位置
        ans_r, l, r = -1, 0, n - 1
        while l <= r:
            mid = (l + r) // 2
            if target < nums[mid]:
                r = mid - 1
            elif target > nums[mid]:
                l = mid + 1
            else:
                ans_r = mid         # 记录候选，右边可能还有
                l = mid + 1
        return [ans_l, ans_r]


if __name__ == "__main__":
    # ACM 输入：第一行 n 和 target，第二行 n 个整数
    data = sys.stdin.read().split()
    n, target = int(data[0]), int(data[1])
    nums = [int(x) for x in data[2:2 + n]]
    print(" ".join(map(str, Solution().searchRange(nums, target))))
```

#include <stdio.h>
#include <stdlib.h>

int* searchRange(int* nums, int numsSize, int target, int* returnSize) {
    int *ans = (int*)malloc(2 * sizeof(int));
    *returnSize = 2;
    ans[0] = -1;
    ans[1] = -1;
    if (numsSize == 0 || target < nums[0] || target > nums[numsSize - 1]) {
        return ans;
    }
    /* 第一次二分：命中后继续向左压，找第一个出现位置 */
    int l = 0, r = numsSize - 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (target < nums[mid]) {
            r = mid - 1;
        } else if (target > nums[mid]) {
            l = mid + 1;
        } else {
            ans[0] = mid;           /* 记录候选，左边可能还有 */
            r = mid - 1;
        }
    }
    /* 第二次二分：命中后继续向右压，找最后一个出现位置 */
    l = 0;
    r = numsSize - 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (target < nums[mid]) {
            r = mid - 1;
        } else if (target > nums[mid]) {
            l = mid + 1;
        } else {
            ans[1] = mid;           /* 记录候选，右边可能还有 */
            l = mid + 1;
        }
    }
    return ans;
}

int main(void) {
    /* ACM 输入：第一行 n 和 target，第二行 n 个整数 */
    int n, target;
    if (scanf("%d %d", &n, &target) != 2) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    int returnSize;
    int* ans = searchRange(nums, n, target, &returnSize);
    printf("%d %d\n", ans[0], ans[1]);
    free(ans);
    free(nums);
    return 0;
}
