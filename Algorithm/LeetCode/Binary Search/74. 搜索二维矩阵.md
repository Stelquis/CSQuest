# [74. 搜索二维矩阵](https://leetcode.cn/problems/search-a-2d-matrix/)

- 🟡 **难度**：中等
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`、`矩阵`

## 题目描述

给你一个满足下述两条属性的 `m x n` 整数矩阵：
- 每行中的整数从左到右按非严格递增顺序排列。
- 每行的第一个整数大于前一行的最后一个整数。

给你一个整数 `target` ，如果 `target` 在矩阵中，返回 `true` ；否则，返回 `false` 。

你必须编写一个时间复杂度为 `O(log(m * n))` 的解决方案。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/05/mat.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 3
输出：true
```

**示例 2：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2020/11/25/mat2.jpg)

```
输入：matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]], target = 13
输出：false
```

**提示：**
- `m == matrix.length`
- `n == matrix[i].length`
- `1 <= m, n <= 100`
- `-10^4 <= matrix[i][j], target <= 10^4`

## 题解：两次二分（先定位行，再行内查）

矩阵的第二条性质"每行第一个整数大于前一行的最后一个整数"说明：**各行之间也是有序的**。因此可以把查找拆成两段独立的二分：

1. **第一次二分（行首列）**：找"**最后一个首元素 `<= target`** 的行"。由于行间递增，`target` 若存在必落在这样的行里。注意命中时**不能返回**——更靠下的行首可能同样 `<= target`，要记下候选行号 `num` 后继续向右压（这正是 35 题"返回插入位置"的变体：找**最后一个**满足条件的位置）。
2. **第二次二分（行内）**：在第 `num` 行内做标准闭区间二分查 `target`。

进入二分前先用 `matrix[0][0]` / `matrix[m-1][n-1]` 做范围剪枝，小于最小值或大于最大值直接 `false`。

模拟 `matrix = [[1,3,5,7],[10,11,16,20],[23,30,34,60]]`：

```
target = 3：
  行定位: mid=1, 首元素 10 > 3 → r=0; mid=0, 首元素 1 <= 3 → num=0, l=1 → 定位第 0 行
  行内:   mid=1, matrix[0][1]=3 命中 → true ✓

target = 13：
  行定位: mid=1, 10 <= 13 → num=1, l=2; mid=2, 23 > 13 → r=1 → 定位第 1 行
  行内:   3 < 13? 10<13<16 → 区间压空 → false ✓
```

- 时间复杂度：`O(log m + log n) = O(log(m·n))`，满足题目要求
- 空间复杂度：`O(1)`

**进阶思路**：既然矩阵逐行拼接就是一个长度 `m·n` 的升序序列，也可以只做**一次二分**：对下标 `idx ∈ [0, m·n)` 二分，用 `matrix[idx / n][idx % n]` 把一维坐标映射回二维——这就是标准库 `lower_bound` 风格的写法，复杂度同样是 `O(log(m·n))`。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public boolean searchMatrix(int[][] matrix, int target) {
        int m = matrix.length;
        int n = matrix[0].length;
        if (target < matrix[0][0] || target > matrix[m - 1][n - 1]) {
            return false;
        }
        // 第一次二分：定位 target 所在的行（最后一个首元素 <= target 的行）
        int num = -1, l = 0, r = m - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (target >= matrix[mid][0]) {
                num = mid;          // 候选行，继续向右压找更靠后的
                l = mid + 1;
            } else {
                r = mid - 1;
            }
        }
        // 第二次二分：在第 num 行内查找
        l = 0;
        r = n - 1;
        while (l <= r) {
            int mid = (l + r) / 2;
            if (target < matrix[num][mid]) {
                r = mid - 1;
            } else if (target > matrix[num][mid]) {
                l = mid + 1;
            } else {
                return true;
            }
        }
        return false;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m、n 和 target，接下来 m 行每行 n 个整数
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[][] matrix = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                matrix[i][j] = sc.nextInt();
            }
        }
        System.out.println(new Solution().searchMatrix(matrix, target));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def searchMatrix(self, matrix: List[List[int]], target: int) -> bool:
        m, n = len(matrix), len(matrix[0])
        if target < matrix[0][0] or target > matrix[m - 1][n - 1]:
            return False
        # 第一次二分：定位 target 所在的行（最后一个首元素 <= target 的行）
        num, l, r = -1, 0, m - 1
        while l <= r:
            mid = (l + r) // 2
            if target >= matrix[mid][0]:
                num = mid           # 候选行，继续向右压找更靠后的
                l = mid + 1
            else:
                r = mid - 1
        # 第二次二分：在第 num 行内查找
        l, r = 0, n - 1
        while l <= r:
            mid = (l + r) // 2
            if target < matrix[num][mid]:
                r = mid - 1
            elif target > matrix[num][mid]:
                l = mid + 1
            else:
                return True
        return False


if __name__ == "__main__":
    # ACM 输入：第一行 m、n 和 target，接下来 m 行每行 n 个整数
    data = sys.stdin.read().split()
    m, n, target = int(data[0]), int(data[1]), int(data[2])
    vals = [int(x) for x in data[3:3 + m * n]]
    matrix = [vals[i * n:(i + 1) * n] for i in range(m)]
    print(str(Solution().searchMatrix(matrix, target)).lower())
```

            l = mid + 1;
        } else {
            r = mid - 1;
        }
    }
    /* 第二次二分：在第 num 行内查找 */
    l = 0;
    r = n - 1;
    while (l <= r) {
        int mid = (l + r) / 2;
        if (target < matrix[num][mid]) {

int main(void) {
    /* ACM 输入：第一行 m、n 和 target，接下来 m 行每行 n 个整数 */

    if (scanf("%d %d %d", &m, &n, &target) != 3) {
