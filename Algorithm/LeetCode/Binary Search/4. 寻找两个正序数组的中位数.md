# [4. 寻找两个正序数组的中位数](https://leetcode.cn/problems/median-of-two-sorted-arrays/)

- 🔴 **难度**：困难
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`、`分治`

## 题目描述

给定两个大小分别为 `m` 和 `n` 的正序（从小到大）数组 `nums1` 和 `nums2`。请你找出并返回这两个正序数组的 **中位数** 。

算法的时间复杂度应该为 `O(log (m+n))` 。

**示例 1：**

```
输入：nums1 = [1,3], nums2 = [2]
输出：2.00000
解释：合并数组 = [1,2,3] ，中位数 2
```

**示例 2：**

```
输入：nums1 = [1,2], nums2 = [3,4]
输出：2.50000
解释：合并数组 = [1,2,3,4] ，中位数 (2 + 3) / 2 = 2.5
```

**提示：**
- `nums1.length == m`
- `nums2.length == n`
- `0 <= m <= 1000`
- `0 <= n <= 1000`
- `1 <= m + n <= 2000`
- `-10^6 <= nums1[i], nums2[i] <= 10^6`

## 题解：二分分割线（在短数组上找划分）

中位数的本质：把合并后的大数组**切一刀**，左半元素个数固定为 `half = (m+n+1)/2`，且左边全部 `<=` 右边。不必真的合并——在两个数组里各切一刀（`nums1` 切在 `i`，`nums2` 切在 `j`），令 `i + j = half`，再验证"**交叉有序**"：

```
        nums1:  aL | aR          （aL = nums1[i-1]，aR = nums1[i]）
        nums2:  bL | bR          （bL = nums2[j-1]，bR = nums2[j]）

合法划分需同时满足：aL <= bR 且 bL <= aR
```

**在短数组上二分 `i ∈ [0, m]`**（先保证 `nums1` 较短，这样 `j = half - i` 始终落在 `[0, n]` 内，不越界）：

- `aL > bR`：`i` 切大了（左半混进了过大的数），`r = i - 1`；
- `bL > aR`：`i` 切小了，`l = i + 1`；
- 两条件同时满足：找到合法分割线。

切在数组端点时用 `±∞` 哨兵（`Integer.MIN_VALUE` / `MAX_VALUE`）补位，让比较自然成立、免去边界特判。找到分割后：

- 总数为**奇数**：中位数 = 左半最大值 `max(aL, bL)`；
- 总数为**偶数**：中位数 = `(max(aL, bL) + min(aR, bR)) / 2`。

模拟示例 2 `nums1 = [1,2]`、`nums2 = [3,4]`（`half = 2`）：

```
i=1, j=1: aL=1, aR=2 | bL=3, bR=4 → bL > aR (3>2) → i 太小, l=2
i=2, j=0: aL=2, aR=+∞ | bL=-∞, bR=3 → 交叉有序 ✓
maxL=2, minR=3 → (2+3)/2 = 2.5 ✓
```

- 时间复杂度：`O(log min(m, n))`，优于题目要求的 `O(log(m+n))`
- 空间复杂度：`O(1)`

**易错点**：交换保证短数组是 `nums1` 这一步不能省——若在长数组上二分，`j = half - i` 可能为负或超过 `n`，交叉比较读到越界下标。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public double findMedianSortedArrays(int[] nums1, int[] nums2) {
        // 确保 nums1 是短数组，j = half - i 才不会越界
        if (nums1.length > nums2.length) {
            int[] t = nums1;
            nums1 = nums2;
            nums2 = t;
        }
        int m = nums1.length, n = nums2.length;
        int half = (m + n + 1) / 2;     // 左半部分的元素个数
        int l = 0, r = m;
        while (l <= r) {
            int i = (l + r) / 2;        // nums1 的切割点
            int j = half - i;           // nums2 的切割点
            int aL = (i == 0) ? Integer.MIN_VALUE : nums1[i - 1];
            int aR = (i == m) ? Integer.MAX_VALUE : nums1[i];
            int bL = (j == 0) ? Integer.MIN_VALUE : nums2[j - 1];
            int bR = (j == n) ? Integer.MAX_VALUE : nums2[j];

            if (aL > bR) {
                r = i - 1;              // i 切大了
            } else if (bL > aR) {
                l = i + 1;              // i 切小了
            } else {
                int maxL = Math.max(aL, bL);
                if ((m + n) % 2 == 1) {
                    return maxL;        // 奇数：左半最大值
                }
                int minR = Math.min(aR, bR);
                return (maxL + minR) / 2.0;   // 偶数：左最大与右最小的均值
            }
        }
        return 0.0;                     // 按题意不会到达
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m 和 n，第二行 m 个整数，第三行 n 个整数
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[] nums1 = new int[m];
        int[] nums2 = new int[n];
        for (int i = 0; i < m; i++) {
            nums1[i] = sc.nextInt();
        }
        for (int i = 0; i < n; i++) {
            nums2[i] = sc.nextInt();
        }
        System.out.printf("%.1f%n", new Solution().findMedianSortedArrays(nums1, nums2));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def findMedianSortedArrays(self, nums1: List[int], nums2: List[int]) -> float:
        # 确保 nums1 是短数组，j = half - i 才不会越界
        if len(nums1) > len(nums2):
            nums1, nums2 = nums2, nums1
        m, n = len(nums1), len(nums2)
        half = (m + n + 1) // 2         # 左半部分的元素个数
        l, r = 0, m
        while l <= r:
            i = (l + r) // 2            # nums1 的切割点
            j = half - i                # nums2 的切割点
            a_l = nums1[i - 1] if i > 0 else float("-inf")
            a_r = nums1[i] if i < m else float("inf")
            b_l = nums2[j - 1] if j > 0 else float("-inf")
            b_r = nums2[j] if j < n else float("inf")

            if a_l > b_r:
                r = i - 1               # i 切大了
            elif b_l > a_r:
                l = i + 1               # i 切小了
            else:
                max_l = max(a_l, b_l)
                if (m + n) % 2 == 1:
                    return max_l        # 奇数：左半最大值
                min_r = min(a_r, b_r)
                return (max_l + min_r) / 2   # 偶数：左最大与右最小的均值


if __name__ == "__main__":
    # ACM 输入：第一行 m 和 n，第二行 m 个整数，第三行 n 个整数
    data = sys.stdin.read().split()
    m, n = int(data[0]), int(data[1])
    nums1 = [int(x) for x in data[2:2 + m]]
    nums2 = [int(x) for x in data[2 + m:2 + m + n]]
    print(f"{Solution().findMedianSortedArrays(nums1, nums2):.1f}")
```

double findMedianSortedArrays(int* nums1, int numsSize1, int* nums2, int numsSize2) {
    /* 确保 nums1 是短数组，j = half - i 才不会越界 */
    if (numsSize1 > numsSize2) {
        int *t = nums1;
        nums1 = nums2;
        nums2 = t;
        int ts = numsSize1;
        numsSize1 = numsSize2;
        numsSize2 = ts;
    }
    int m = numsSize1, n = numsSize2;
    int half = (m + n + 1) / 2;         /* 左半部分的元素个数 */
    int l = 0, r = m;
    while (l <= r) {
        int i = (l + r) / 2;            /* nums1 的切割点 */
        int j = half - i;               /* nums2 的切割点 */
        int aL = (i == 0) ? INT_MIN : nums1[i - 1];
        int aR = (i == m) ? INT_MAX : nums1[i];
        int bL = (j == 0) ? INT_MIN : nums2[j - 1];
        int bR = (j == n) ? INT_MAX : nums2[j];

        if (aL > bR) {
            r = i - 1;                  /* i 切大了 */
        } else if (bL > aR) {
            l = i + 1;                  /* i 切小了 */
        } else {
            int maxL = aL > bL ? aL : bL;
            if ((m + n) % 2 == 1) {
                return maxL;            /* 奇数：左半最大值 */
            }
            int minR = aR < bR ? aR : bR;
            return (maxL + minR) / 2.0; /* 偶数：左最大与右最小的均值 */
        }
    }
    return 0.0;                         /* 按题意不会到达 */
}

int main(void) {
    /* ACM 输入：第一行 m 和 n，第二行 m 个整数，第三行 n 个整数 */
