# [153. 寻找旋转排序数组中的最小值](https://leetcode.cn/problems/find-minimum-in-rotated-sorted-array/)

- 🟡 **难度**：中等
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`

## 题目描述

已知一个长度为 `n` 的数组，预先按照升序排列，经由 `1` 到 `n` 次 **旋转** 后，得到输入数组。例如，原数组 `nums = [0,1,2,4,5,6,7]` 在变化后可能得到：
- 若旋转 `4` 次，则可以得到 `[4,5,6,7,0,1,2]`
- 若旋转 `7` 次，则可以得到 `[0,1,2,4,5,6,7]`

注意，数组 `[a[0], a[1], a[2], ..., a[n-1]]` **旋转一次** 的结果为数组 `[a[n-1], a[0], a[1], a[2], ..., a[n-2]]` 。

给你一个元素值 **互不相同** 的数组 `nums` ，它原来是一个升序排列的数组，并按上述情形进行了多次旋转。请你找出并返回数组中的 **最小元素** 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入：nums = [3,4,5,1,2]
输出：1
解释：原数组为 [1,2,3,4,5] ，旋转 3 次得到输入数组。
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2]
输出：0
解释：原数组为 [0,1,2,4,5,6,7] ，旋转 4 次得到输入数组。
```

**示例 3：**

```
输入：nums = [11,13,15,17]
输出：11
解释：原数组为 [11,13,15,17] ，旋转 4 次得到输入数组。
```

**提示：**
- `n == nums.length`
- `1 <= n <= 5000`
- `-5000 <= nums[i] <= 5000`
- `nums` 中的所有整数 **互不相同**
- `nums` 原来是一个升序排序的数组，并进行了 `1` 至 `n` 次旋转

## 题解：二分定位旋转点

旋转后的数组是**两段各自升序的子数组拼接**，最小值就是第二段的起点（即"旋转点"；旋转 `n` 次等于没转时，最小值就是 `nums[0]`）。它可以用二分定位：拿 `nums[mid]` 和 `nums[r]` 比——

- `nums[mid] > nums[r]`：`mid` 落在左段，"断崖"（最小值）必在 `(mid, r]`，`l = mid + 1`；
- 否则 `mid` 已在右段（或就是最小值），最小值在 `[l, mid]`，`r = mid`。

循环条件 `l < r`，区间收缩到一点，`nums[r]` 即最小值。两个关键细节：

- **必须和 `nums[r]` 比、不能和 `nums[0]` 比**：`nums[mid] > nums[0]` 时断崖既可能在左半也可能在右半，信息不足；和 `nums[r]` 比则两种分支的含义都明确（左段任意值都严格大于右段任意值，元素互不相同保证了 `>` 判断可靠）；
- **`r = mid` 而不是 `mid - 1`**：`nums[mid] <= nums[r]` 时 `mid` 本身可能就是最小值，不能丢。

模拟 `nums = [3,4,5,1,2]`：

```
l=0, r=4 → mid=2, nums[2]=5 > nums[4]=2 → l=3
l=3, r=4 → mid=3, nums[3]=1 > nums[4]=2? 否 → r=3
l == r = 3 → 返回 nums[3] = 1 ✓
```

- 时间复杂度：`O(log n)`，每轮区间至少减半
- 空间复杂度：`O(1)`

**关联题目**：本题正是 [33. 搜索旋转排序数组](<33. 搜索旋转排序数组.md>)解法的第一步——先定位旋转点，再在两段升序区间上分别二分查 `target`。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int findMin(int[] nums) {
        int len = nums.length;
        int l = 0, r = len - 1;
        while (l < r) {
            int mid = (l + r) / 2;
            if (nums[mid] > nums[r]) {
                l = mid + 1;        // 断崖在 mid 右边
            } else {
                r = mid;            // mid 已在右段（或就是最小值）
            }
        }
        return nums[r];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().findMin(nums));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def findMin(self, nums: List[int]) -> int:
        l, r = 0, len(nums) - 1
        while l < r:
            mid = (l + r) // 2
            if nums[mid] > nums[r]:
                l = mid + 1         # 断崖在 mid 右边
            else:
                r = mid             # mid 已在右段（或就是最小值）
        return nums[r]


if __name__ == "__main__":
    # ACM 输入：第一行 n，第二行 n 个整数
    data = sys.stdin.read().split()
    n = int(data[0])
    nums = [int(x) for x in data[1:1 + n]]
    print(Solution().findMin(nums))
```

#include <stdio.h>
#include <stdlib.h>

int findMin(int* nums, int numsSize) {
    int l = 0, r = numsSize - 1;
    while (l < r) {
        int mid = (l + r) / 2;
        if (nums[mid] > nums[r]) {
            l = mid + 1;            /* 断崖在 mid 右边 */
        } else {
            r = mid;                /* mid 已在右段（或就是最小值） */
        }
    }
    return nums[r];
}

    /* ACM 输入：第一行 n，第二行 n 个整数 */
    int n;
    if (scanf("%d", &n) != 1) {
