# [33. 搜索旋转排序数组](https://leetcode.cn/problems/search-in-rotated-sorted-array/)

- 🟡 **难度**：中等
- 🎯 **分类**：二分查找
- 🏷️ **标签**：`数组`、`二分查找`

## 题目描述

整数数组 `nums` 按升序排列，数组中的值 **互不相同** 。

在传递给函数之前，`nums` 在预先未知的某个下标 `k`（`0 <= k < nums.length`）上进行了 **向左旋转**，使数组变为 `[nums[k], nums[k+1], ..., nums[n-1], nums[0], nums[1], ..., nums[k-1]]`（下标 **从 0 开始** 计数）。例如， `[0,1,2,4,5,6,7]` 下标 `3` 上向左旋转后可能变为 `[4,5,6,7,0,1,2]` 。

给你 **旋转后** 的数组 `nums` 和一个整数 `target` ，如果 `nums` 中存在这个目标值 `target` ，则返回它的下标，否则返回 `-1` 。

你必须设计一个时间复杂度为 `O(log n)` 的算法解决此问题。

**示例 1：**

```
输入：nums = [4,5,6,7,0,1,2], target = 0
输出：4
```

**示例 2：**

```
输入：nums = [4,5,6,7,0,1,2], target = 3
输出：-1
```

**示例 3：**

```
输入：nums = [1], target = 0
输出：-1
```

**提示：**
- `1 <= nums.length <= 5000`
- `-10^4 <= nums[i] <= 10^4`
- `nums` 中的每个值都 **独一无二**
- 题目数据保证 `nums` 在预先未知的某个下标上进行了旋转
- `-10^4 <= target <= 10^4`

## 题解：定位旋转点 + 两段标准二分

旋转后的数组 = **两段各自升序的子数组拼接**，且左段的所有值都大于右段的所有值。与其在旋转数组上硬想二分条件，不如分两步走：

**第一步：二分定位旋转点（最小值下标）。** 拿 `nums[mid]` 和 `nums[r]` 比：

- `nums[mid] > nums[r]`：`mid` 处在左段（"断崖"在 mid 右边），最小值必在 `(mid, r]`，`l = mid + 1`；
- 否则 `mid` 已在右段，最小值在 `[l, mid]`，`r = mid`。

循环条件 `l < r`，区间收缩到一点即为旋转点 `place`。**必须和 `nums[r]` 比、不能和 `nums[0]` 比**：和 `nums[0]` 比会误判旋转点落在左半（`nums[mid] > nums[0]` 时断崖既可能在左也可能在右）；而和 `nums[r]` 比永远只有"mid 在左段 / 右段"两种明确含义。

**第二步：在 `[0, place-1]` 和 `[place, n-1]` 两段上各做一次标准闭区间二分**（35 题同款）。若 `place = 0`（相当于未旋转），左段为空自然跳过，逻辑无需特判。

模拟 `nums = [4,5,6,7,0,1,2]`、`target = 0`：

```
定位旋转点: mid=3, 7 > 2 → l=4; mid=5, 1 > 2? 否 → r=5;
            mid=4, 0 > 1? 否 → r=4; l == r → place=4
左段 [0,3] 查 0: 4,5,6,7 → 未命中
右段 [4,6] 查 0: mid=5, 1>0 → r=4; mid=4, 命中 → 返回 4 ✓
```

- 时间复杂度：`O(log n)`（两轮定位 + 两段二分，共 3 次 `O(log n)`）
- 空间复杂度：`O(1)`

**进阶思路**：也可以**一次二分**直接在旋转数组上找——关键观察是"`mid` 劈开后，`[l, mid]` 和 `[mid, r]` 至少有一段是完全有序的"，先判断哪段有序、再看 `target` 是否落在有序段的范围内来决定收缩方向，同样 `O(log n)`。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public int search(int[] nums, int target) {
        // 第一步：二分定位旋转点（最小值下标）
        int len = nums.length;
        int l = 0, r = len - 1;
        while (l < r) {
            int mid = (l + r) / 2;
            if (nums[mid] > nums[r]) {
                l = mid + 1;        // 断崖在 mid 右边
            } else {
                r = mid;            // mid 已在右段
            }
        }
        int place = l;
        // 第二步：在两段升序区间上分别标准二分
        int ans = binarySearch(nums, 0, place - 1, target);
        if (ans != -1) {
            return ans;
        }
        return binarySearch(nums, place, len - 1, target);
    }

    public static int binarySearch(int[] nums, int l, int r, int t) {
        while (l <= r) {
            int mid = (l + r) / 2;
            if (t < nums[mid]) {
                r = mid - 1;
            } else if (t > nums[mid]) {
                l = mid + 1;
            } else {
                return mid;
            }
        }
        return -1;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n 和 target，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int target = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().search(nums, target));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def search(self, nums: List[int], target: int) -> int:
        # 第一步：二分定位旋转点（最小值下标）
        l, r = 0, len(nums) - 1
        while l < r:
            mid = (l + r) // 2
            if nums[mid] > nums[r]:
                l = mid + 1         # 断崖在 mid 右边
            else:
                r = mid             # mid 已在右段
        place = l
        # 第二步：在两段升序区间上分别标准二分
        ans = self._binary_search(nums, 0, place - 1, target)
        if ans != -1:
            return ans
        return self._binary_search(nums, place, len(nums) - 1, target)

    @staticmethod
    def _binary_search(nums: List[int], l: int, r: int, t: int) -> int:
        while l <= r:
            mid = (l + r) // 2
            if t < nums[mid]:
                r = mid - 1
            elif t > nums[mid]:
                l = mid + 1
            else:
                return mid
        return -1


if __name__ == "__main__":
    # ACM 输入：第一行 n 和 target，第二行 n 个整数
    data = sys.stdin.read().split()
    n, target = int(data[0]), int(data[1])
    nums = [int(x) for x in data[2:2 + n]]
    print(Solution().search(nums, target))
```
