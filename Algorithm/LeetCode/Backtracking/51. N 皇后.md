# [51. N 皇后](https://leetcode.cn/problems/n-queens/)

- 🔴 **难度**：困难
- ↩️ **分类**：回溯
- 🏷️ **标签**：`数组`、`回溯`、`X 算法`

## 题目描述

按照国际象棋的规则，皇后可以攻击与之处在同一行或同一列或同一斜线上的棋子。

**n 皇后问题** 研究的是如何将 `n` 个皇后放置在 `n×n` 的棋盘上，并且使皇后彼此之间不能相互攻击。

给你一个整数 `n` ，返回所有不同的 **n 皇后问题** 的解决方案。

每一种解法包含一个不同的 **n 皇后问题** 的棋子放置方案，该方案中 `'Q'` 和 `'.'` 分别代表了皇后和空位。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/13/queens.jpg)

```
输入：n = 4
输出：[[".Q..","...Q","Q...","..Q."],["..Q.","Q...","...Q",".Q.."]]
解释：如上图所示，4 皇后问题存在两个不同的解法。
```

**示例 2：**

```
输入：n = 1
输出：[["Q"]]
```

**提示：**
- `1 <= n <= 9`

## 题解：回溯（逐行放置 + 坐标记位）

### 一个把问题砍半的推理

`n` 个皇后要放进 `n` 行，而**任意两个都不能在同一行**（否则互相攻击）。于是——

> **每一行恰好放一个皇后。**

这一下就不用"在 `n×n` 个格子里挑 `n` 个"了，而是**一行一行处理，每行只决定"放哪一列"**。用一个 `int[] pos`，规定 `pos[row] = col`：数组下标即行号，天然的"一行一个"。

放第 `row` 行时，只需保证它不和**已放好的 `0..row-1` 行**冲突。冲突有三类，但"同一行"已天然杜绝，只剩两条：

| 冲突 | 判据（对每个已放的 `r`） |
|---|---|
| 同一列 | `pos[r] == col` |
| 同一 ↘ 斜线 | `r - pos[r] == row - col` |
| 同一 ↙ 斜线 | `r + pos[r] == row + col` |

**斜线不变量**是这题的灵魂：沿 ↘ 方向走，`row` 与 `col` 同增同减，所以 **`row - col` 是常数**；沿 ↙ 方向走，`row` 增 `col` 减，所以 **`row + col` 是常数**。同一个常数 ⟺ 同一条斜线。

### 路线 A：只存坐标，判断时回头扫（本题采用）

状态只有 `pos` 一份。`canPlace(row, col)` 扫 `r = 0 .. row-1` 逐行比对三条判据。递归如下：

```
dfs(row):
    if row == n:                          → 把 pos 翻译成 n 行字符串，收集，return   ①
    for col = 0 .. n-1:                                                            ②
        if canPlace(pos, row, col):                                                  ③
            pos[row] = col                → 选                                         ④
            dfs(row + 1)                  → 递归下一行                                ⑤
```

**这里有一个与本分类其他题截然相反的漂亮结论：不需要撤销。**

- `canPlace` 只读 `r < row` 的格子，**从不读 `pos[row]` 及之后**；
- 某次 `pos[row] = col` 试完返回后，残留的值**下一轮循环的赋值会直接覆盖**，而更靠后的行不会被检查。

对比 22 / 46 / 131：那些题的 `path` 是**追加式**的（`add` / `remove` 必须成对，长度会变）；而 `pos` 是**定长、按下标覆盖**的，没有"多出来"要清。所以本题连 `pos[row] = 0` 这种还原都不用写。

出口处 `transform(pos, n)` 把坐标翻译成 `n` 行字符串：每行长度 `n`，第 `pos[r]` 个字符是 `'Q'`，其余 `'.'`。注意它**每次现场新建**一个列表，所以塞进 `ans` 时**天然就是快照**——不像 131 要手动 `new ArrayList<>(path)`（那是"复用同一条 path"才需要的）。

决策树（`n = 4`，只展开到达解的两条链，✗ = 被某条冲突挡住）：

```
row0
├─ col0 → 后续全枯（略）
├─ col1 (0,1)
│   ├─ col0 ✗ 同列      col2 ✗ 同 ↘(0-1 = 1-2 = -1)
│   └─ col3 (1,3)
│       ├─ col0 (2,0)
│       │   └─ col2 (3,2)  ✅ 收 [".Q..","...Q","Q...","..Q."]
│       └─ 其余列 ✗
├─ col2 (0,2)
│   └─ col0 (1,0)
│       └─ col3 (2,3)
│           └─ col1 (3,1)  ✅ 收 ["..Q.","Q...","...Q",".Q.."]
└─ col3 → 后续全枯（略）
```

- 时间复杂度：`O(n!)`，剪枝后实际远小于朴素枚举的 `O(n^n)`；随着行数增加，冲突剪枝使每行可选列数迅速下降
- 空间复杂度：`O(n)`，递归深度 `n` 与 `pos`（不计返回答案）

**对比 22 / 46 / 78 / 131**：仍是"选择 → 递归 → 撤销"的骨架，但**本题的撤销被"覆盖式写法"省掉了**——这是"状态是定长数组而非变长路径"带来的差异。另外本题的剪枝点很强：只有通过三条冲突判据的 `col` 才有分支。

**易错点**：

1. **斜线的两个不变量记反**：↘ 是 `row - col`（同增同减），↙ 是 `row + col`。写反会导致漏判或误判；
2. **`canPlace` 的循环边界**：只扫 `r < row` 的**已放行**，别扫到当前行或未放行；
3. **出口别忘了翻译 + 收集**：`row == n` 时要 `transform` 出字符串列表再 `ans.add`；
4. `transform` 每行都是**新建**的 `String`，收集时无需额外拷贝——但若你改用**复用同一个 `char[][]` 棋盘**的写法，就必须手动把每行转成新 `String` 存档。

**备注**：与题解标签 `X 算法` 相关的是把问题建模成**精确覆盖**后用 DLX（Dancing Links）求解，属于同一问题的另一种通用武器；本题 `n <= 9`，回溯足矣。

另一条**路线 B**（把判断降到 `O(1)`）：额外开三个布尔数组 `colUsed[n]`、`diag1[2n-1]`（存 `row + col`）、`diag2[2n-1]`（存 `row - col + n - 1`，用于把负下标挪到非负）。放置时同时点亮三格、回溯时同时熄灭三格，判断变 `O(1)`，代价是多一份"三处一起撤销"的簿记。更激进的做法是用**位运算**把三个占用集合压进三个 `int`（`(1 << n) - 1` 表示全集），通过左右移位模拟斜线，是 N 皇后最快的经典实现。

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Solution {
    public List<List<String>> solveNQueens(int n) {
        List<List<String>> ans = new ArrayList<>();
        int[] pos = new int[n];
        backTrack(pos, 0, n, ans);
        return ans;
    }

    public static void backTrack(int[] pos, int row, int n, List<List<String>> ans) {
        if (row == n) {                             // n 行都放好了
            ans.add(transform(pos, n));             // transform 每次新建列表，天然快照
            return;
        }
        for (int col = 0; col < n; col++) {
            if (canPlace(pos, row, col)) {
                pos[row] = col;                     // 选（无需撤销：按下标覆盖，检查只看 r < row）
                backTrack(pos, row + 1, n, ans);
            }
        }
    }

    // 判断 (row, col) 能否落子：只需与已放好的 0..row-1 行比较
    public static boolean canPlace(int[] pos, int row, int col) {
        for (int r = 0; r < row; r++) {
            if (pos[r] == col                     // 同一列
             || r - pos[r] == row - col           // 同一 ↘ 斜线（row - col 同增同减）
             || r + pos[r] == row + col) {        // 同一 ↙ 斜线（row + col 恒定）
                return false;
            }
        }
        return true;
    }

    // 把坐标数组 pos 翻译成 n 行字符串
    public static List<String> transform(int[] pos, int n) {
        List<String> board = new ArrayList<>();
        for (int r = 0; r < n; r++) {
            StringBuilder sb = new StringBuilder();
            for (int c = 0; c < n; c++) {
                sb.append(c == pos[r] ? 'Q' : '.');
            }
            board.add(sb.toString());
        }
        return board;
    }

    public static void main(String[] args) {
        // ACM 输入：一行整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        List<List<String>> ans = new Solution().solveNQueens(n);
        StringBuilder out = new StringBuilder();
        for (List<String> board : ans) {
            out.append(board).append('\n');
        }
        System.out.print(out);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def solveNQueens(self, n: int) -> List[List[str]]:
        ans: List[List[str]] = []
        pos = [0] * n

        def can_place(row: int, col: int) -> bool:
            for r in range(row):
                if (pos[r] == col                     # 同一列
                        or r - pos[r] == row - col      # 同一 ↘ 斜线
                        or r + pos[r] == row + col):    # 同一 ↙ 斜线
                    return False
            return True

        def transform() -> List[str]:
            board = []
            for r in range(n):
                board.append("".join('Q' if c == pos[r] else '.' for c in range(n)))
            return board

        def back_track(row: int):
            if row == n:
                ans.append(transform())     # transform 每次新建，天然快照
                return
            for col in range(n):
                if can_place(row, col):
                    pos[row] = col          # 选（无需撤销）
                    back_track(row + 1)

        back_track(0)
        return ans


if __name__ == "__main__":
    # ACM 输入：一行整数 n
    n = int(sys.stdin.read().split()[0])
    for board in Solution().solveNQueens(n):
        print(board)
```

### ➕ C++

```cpp
#include <string>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    vector<vector<string>> solveNQueens(int n) {
        vector<vector<string>> ans;
        vector<int> pos(n, 0);
        backTrack(pos, 0, n, ans);
        return ans;
    }

    static void backTrack(vector<int>& pos, int row, int n,
                          vector<vector<string>>& ans) {
        if (row == n) {
            ans.push_back(transform(pos, n));       // transform 每次新建，天然快照
            return;
        }
        for (int col = 0; col < n; col++) {
            if (canPlace(pos, row, col)) {
                pos[row] = col;                     // 选（无需撤销）
                backTrack(pos, row + 1, n, ans);
            }
        }
    }

    static bool canPlace(const vector<int>& pos, int row, int col) {
        for (int r = 0; r < row; r++) {
            if (pos[r] == col                       // 同一列
             || r - pos[r] == row - col             // 同一 ↘ 斜线
             || r + pos[r] == row + col) {          // 同一 ↙ 斜线
                return false;
            }
        }
        return true;
    }

    static vector<string> transform(const vector<int>& pos, int n) {
        vector<string> board(n, string(n, '.'));
        for (int r = 0; r < n; r++) {
            board[r][pos[r]] = 'Q';
        }
        return board;
    }
};

int main() {
    // ACM 输入：一行整数 n
    int n;
    cin >> n;
    vector<vector<string>> ans = Solution().solveNQueens(n);
    for (const vector<string>& board : ans) {
        cout << "[";
        for (int i = 0; i < (int)board.size(); i++) {
            if (i > 0) cout << ", ";
            cout << board[i];
        }
        cout << "]\n";
    }
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

static char ***ans;
static int ansSize;
static int cap;

/* 判断 (row, col) 能否落子：只需与已放好的 0..row-1 行比较 */
static bool canPlace(const int *pos, int row, int col) {
    for (int r = 0; r < row; r++) {
        if (pos[r] == col                           /* 同一列 */
         || r - pos[r] == row - col                 /* 同一 ↘ 斜线 */
         || r + pos[r] == row + col) {              /* 同一 ↙ 斜线 */
            return false;
        }
    }
    return true;
}

static void backTrack(int *pos, int row, int n) {
    if (row == n) {                                 /* 收集：坐标 -> 字符串 */
        if (ansSize == cap) {                       /* 动态扩容 */
            cap *= 2;
            ans = (char ***)realloc(ans, cap * sizeof(char **));
        }
        ans[ansSize] = (char **)malloc(n * sizeof(char *));
        for (int r = 0; r < n; r++) {
            ans[ansSize][r] = (char *)malloc(n + 1);
            for (int c = 0; c < n; c++) {
                ans[ansSize][r][c] = (c == pos[r]) ? 'Q' : '.';
            }
            ans[ansSize][r][n] = '\0';
        }
        ansSize++;
        return;
    }
    for (int col = 0; col < n; col++) {
        if (canPlace(pos, row, col)) {
            pos[row] = col;                         /* 选（无需撤销） */
            backTrack(pos, row + 1, n);
        }
    }
}

char ***solveNQueens(int n, int *returnSize, int **returnColumnSizes) {
    cap = 16;
    ans = (char ***)malloc(cap * sizeof(char **));
    ansSize = 0;
    int *pos = (int *)malloc((n > 0 ? n : 1) * sizeof(int));
    backTrack(pos, 0, n);
    free(pos);
    *returnSize = ansSize;
    *returnColumnSizes = (int *)malloc((ansSize > 0 ? ansSize : 1) * sizeof(int));
    for (int i = 0; i < ansSize; i++) {
        (*returnColumnSizes)[i] = n;
    }
    return ans;
}

int main(void) {
    /* ACM 输入：一行整数 n */
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int returnSize;
    int *colSizes;
    char ***res = solveNQueens(n, &returnSize, &colSizes);
    for (int i = 0; i < returnSize; i++) {
        printf("[");
        for (int r = 0; r < colSizes[i]; r++) {
            if (r > 0) {
                printf(", ");
            }
            printf("%s", res[i][r]);
            free(res[i][r]);
        }
        printf("]\n");
        free(res[i]);
    }
    free(res);
    free(colSizes);
    return 0;
}
```
