# [22. 括号生成](https://leetcode.cn/problems/generate-parentheses/)

- 🟡 **难度**：中等
- ↩️ **分类**：回溯
- 🏷️ **标签**：`字符串`、`动态规划`、`回溯`、`括号序列`

## 题目描述

数字 `n` 代表生成括号的对数，请你设计一个函数，用于能够生成所有可能的并且 **有效的** 括号组合。

**示例 1：**

```
输入：n = 3
输出：["((()))","(()())","(())()","()(())","()()()"]
```

**示例 2：**

```
输入：n = 1
输出：["()"]
```

**提示：**
- `1 <= n <= 8`

## 题解：回溯（预算 + 欠债双闸门）

合法括号串的定义有两条：① 恰好 `n` 个 `(`、`n` 个 `)`；② **任意前缀**里左括号数 `>=` 右括号数。暴力枚举 `2^(2n)` 个等长串再筛选太慢，我们改成**从左往右一位一位地拼**，每个位置只有两个选择：填 `(` 或填 `)`。

关键是给这两个"按钮"各配一道闸门，把非法分支**当场**剪掉：

| 按钮 | 闸门 | 负责堵住的死法 |
|---|---|---|
| 填 `(` | `left < n`（**预算**） | 左括号超额，生成不出 `"()(("` 这类"宇宙外"的串 |
| 填 `)` | `right < left`（**欠债**） | 右括号多于左括号，如 `"())"`、开头就是 `")"` |

两道闸门分工不同：**预算闸门守的是"数量恰好 `n` 对"这条宇宙边界**（左括号牌就 `n` 张，用完为止）；**欠债闸门守的才是"前缀合法"**（右括号永远不能超过已放下的左括号）。二者都守住后，走到长度 `2n` 时必然 `left == right == n`，所以出口直接写 `left == n && right == n` 即可，无需再校验。

**终止条件**：`left == n && right == n` → 当前路径就是一个答案，存档后返回。每往下走一层做了选择（`append`），退回时必须**撤销**（`deleteCharAt`），让现场与进入本层时完全一致，同层的兄弟分支才能在干净状态上继续。

决策树（`n = 3`，✗ 表示该分支被闸门拦住）：

```
""  (0,0)
└─ '(' → "("  (1,0)                     [')' 被欠债闸门拦住]
   ├─ '(' → "(("  (2,0)
   │  ├─ '(' → "((("  (3,0)
   │  │  └─ ')' → "((()"  (3,1)         ['(' 被预算闸门拦住]
   │  │     └─ ')' → "((())"  (3,2)
   │  │        └─ ')' → "((()))"  ★ 存档
   │  └─ ')' → "(()"  (2,1)
   │     ├─ '(' → "(()("  (3,1)
   │     │  └─ ')' → "(()()"  (3,2)
   │     │     └─ ')' → "(()())"  ★ 存档
   │     └─ ')' → "(())"  (2,2)
   │        └─ '(' → "(())("  (3,2)      [')' 被欠债闸门拦住]
   │           └─ ')' → "(())()"  ★ 存档
   └─ ')' → "()"  (1,1)
      ├─ '(' → "()("  (2,1)              [')' 被欠债闸门拦住]
      │  ├─ '(' → "()(("  (3,1)
      │  │  └─ ')' → "()(()"  (3,2)
      │  │     └─ ')' → "()(())"  ★ 存档
      │  └─ ')' → "()()"  (2,2)
      │     ├─ '(' → "()()("  (3,2)
      │     │  └─ ')' → "()()()"  ★ 存档
      │     └─ ')' ✗ 欠债
      └─ ')' ✗ 欠债
```

- 时间复杂度：答案是第 `n` 个 **Catalan 数** ≈ `4^n / (n^(3/2) · √π)` 个，每个长 `2n`，故 `O(n · Catalan(n))`，常记作 `O(4^n / √n)`
- 空间复杂度：`O(n)`，递归栈深最多 `2n`，加上复用的 `path`

**对比 17 / 46 / 78**：框架仍是"选择列表 → 做选择 → 递归 → 撤销选择"，且都是**固定 `2n` 层**（每层填一个字符）。区别在"选择列表"的形态：46 每层选"没用过的数"、78 每层做"选/不选"、17 每层选"映射字母"，而本题每层最多两个选择且**受闸门动态约束**——这正是剪枝型回溯的典型：不是枚举所有组合再筛，而是让非法分支根本走不出来。

**易错点**：

1. **撤销用的是 `deleteCharAt(len - 1)` 而非 `delete(len - 1)`**——`StringBuilder.delete` 只有 `(start, end)` 双参重载，单参写法直接编译报错；
2. 出口条件用短路与 `&&`，别写成按位与 `&`（本题两边都是 `boolean`，`&` 能算对但属误用）；
3. 答案字段**不要加 `static`**——static 字段被所有实例共享，同 46 / 78 / 155 的坑。既然辅助函数必须是 `static`（本仓库规范），把 `ans` 当参数传下去最干净。

**备注**：还有两种等价写法——① **传 `String` 免撤销**：每层用 `cur + '('` 生成**新串**，`String` 不可变、天然是快照，连 `deleteCharAt` 都省了，代价是每层 `O(n)` 拷贝；② **递推/记忆化**：由 Catalan 递推式 `f(n) = { "(" + f(i) + ")" + f(n-1-i) | 0 <= i < n }` 直接构造，属于"分治"思路，与回溯殊途同归。

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Solution {
    public List<String> ans = new ArrayList<>();

    public List<String> generateParenthesis(int n) {
        ans = new ArrayList<>();
        backtrack(ans, new StringBuilder(), 0, 0, n);
        return ans;
    }

    public static void backtrack(List<String> ans, StringBuilder sb,
                                 int left, int right, int n) {
        if (left == n && right == n) {          // 等价于"长度到 2n"：两样都刚好用完
            ans.add(sb.toString());             // String 不可变，天然快照
            return;
        }
        if (left < n) {                         // 预算闸门：左括号最多 n 个
            sb.append('(');
            backtrack(ans, sb, left + 1, right, n);
            sb.deleteCharAt(sb.length() - 1);   // 撤销选择
        }
        if (right < left) {                     // 欠债闸门：右括号不能多于左括号
            sb.append(')');
            backtrack(ans, sb, left, right + 1, n);
            sb.deleteCharAt(sb.length() - 1);   // 撤销选择
        }
    }

    public static void main(String[] args) {
        // ACM 输入：一行整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        List<String> ans = new Solution().generateParenthesis(n);
        StringBuilder sb = new StringBuilder();
        for (String s : ans) {
            sb.append(s).append('\n');
        }
        System.out.print(sb);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def generateParenthesis(self, n: int) -> List[str]:
        ans: List[str] = []
        path: List[str] = []

        def backtrack(left: int, right: int):
            if left == n and right == n:    # 等价于"长度到 2n"
                ans.append("".join(path))   # join 生成新串，天然快照
                return
            if left < n:                    # 预算闸门
                path.append("(")
                backtrack(left + 1, right)
                path.pop()                  # 撤销选择
            if right < left:                # 欠债闸门
                path.append(")")
                backtrack(left, right + 1)
                path.pop()                  # 撤销选择

        backtrack(0, 0)
        return ans


if __name__ == "__main__":
    # ACM 输入：一行整数 n
    n = int(sys.stdin.read().split()[0])
    for s in Solution().generateParenthesis(n):
        print(s)
```

### ➕ C++

```cpp
#include <string>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    vector<string> generateParenthesis(int n) {
        vector<string> ans;
        string path;
        backtrack(ans, path, 0, 0, n);
        return ans;
    }

    static void backtrack(vector<string>& ans, string& path,
                          int left, int right, int n) {
        if (left == n && right == n) {      // 等价于"长度到 2n"
            ans.push_back(path);            // push_back 自带拷贝快照
            return;
        }
        if (left < n) {                     // 预算闸门
            path.push_back('(');
            backtrack(ans, path, left + 1, right, n);
            path.pop_back();                // 撤销选择
        }
        if (right < left) {                 // 欠债闸门
            path.push_back(')');
            backtrack(ans, path, left, right + 1, n);
            path.pop_back();                // 撤销选择
        }
    }
};

int main() {
    // ACM 输入：一行整数 n
    int n;
    cin >> n;
    vector<string> ans = Solution().generateParenthesis(n);
    for (const string& s : ans) {
        cout << s << "\n";
    }
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static char **ans;
static int ansSize;

static void backtrack(char *path, int depth, int left, int right, int n) {
    if (left == n && right == n) {              /* 等价于"长度到 2n" */
        ans[ansSize] = (char *)malloc(depth + 1);
        memcpy(ans[ansSize], path, depth);      /* 拍快照 */
        ans[ansSize][depth] = '\0';
        ansSize++;
        return;
    }
    if (left < n) {                             /* 预算闸门 */
        path[depth] = '(';
        backtrack(path, depth + 1, left + 1, right, n);
    }
    if (right < left) {                         /* 欠债闸门 */
        path[depth] = ')';
        backtrack(path, depth + 1, left, right + 1, n);
    }
    /* 撤销选择：path[depth] 会被上一层覆盖，无需清 */
}

char **generateParenthesis(int n, int *returnSize) {
    long long c = 1;                            /* C(2n, n) / (n + 1) = 第 n 个 Catalan 数 */
    for (int i = 1; i <= n; i++) {
        c = c * (n + i) / i;
    }
    long long total = c / (n + 1);
    ans = (char **)malloc(total * sizeof(char *));
    ansSize = 0;
    char *path = (char *)malloc(2 * n + 1);
    backtrack(path, 0, 0, 0, n);
    free(path);
    *returnSize = ansSize;
    return ans;
}

int main(void) {
    /* ACM 输入：一行整数 n */
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int returnSize;
    char **res = generateParenthesis(n, &returnSize);
    for (int i = 0; i < returnSize; i++) {
        printf("%s\n", res[i]);
        free(res[i]);
    }
    free(res);
    return 0;
}
```
