# [79. 单词搜索](https://leetcode.cn/problems/word-search/)

- 🟡 **难度**：中等
- ↩️ **分类**：回溯
- 🏷️ **标签**：`深度优先搜索`、`数组`、`字符串`、`回溯`、`矩阵`

## 题目描述

给定一个 `m x n` 二维字符网格 `board` 和一个字符串单词 `word` 。如果 `word` 存在于网格中，返回 `true` ；否则，返回 `false` 。

单词必须按照字母顺序，通过相邻的单元格内的字母构成，其中“相邻”单元格是那些水平相邻或垂直相邻的单元格。同一个单元格内的字母不允许被重复使用。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/04/word2.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCCED"
输出：true
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/11/04/word-1.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "SEE"
输出：true
```

**示例 3：**

![](https://assets.leetcode.com/uploads/2020/10/15/word3.jpg)

```
输入：board = [['A','B','C','E'],['S','F','C','S'],['A','D','E','E']], word = "ABCB"
输出：false
```

**提示：**
- `m == board.length`
- `n = board[i].length`
- `1 <= m, n <= 6`
- `1 <= word.length <= 15`
- `board` 和 `word` 仅由大小写英文字母组成

**进阶：** 你可以使用搜索剪枝的技术来优化解决方案，使其在 `board` 更大的情况下可以更快解决问题？

## 题解：网格 DFS 回溯

这题把回溯从"序列"搬到了"网格"：不再逐层拼一个串，而是**在一个格子上选下一步走向哪个邻居**。与 22 / 46 / 78 相比，多了一个维度——**位置**，也多了一条硬约束——**同一格子不能重复踩**。

两件事必须厘清：

1. **起点不固定**：`word` 的首字符可能出现在任何格子上，所以要在 `exist` 里**两层循环枚举每个格子当起点**，任一成功即整体成功；不是只在 `(0,0)` 搜一次。
2. **`k` 表示"当前待匹配的字符下标"（0-based）**：进来时要求 `board[i][j] == word[k]`，成功则带着 `k + 1` 往四个邻居递归。全程 0-based，初值 `0`，出口是 `k == word.length()`。

递归函数 `dfs(i, j, k)` 的四类判断，顺序不能乱：

```
dfs(i, j, k):
    if k == word.length()            → true        ① 整串匹配完
    if i,j 越界                       → false       ② 会崩的先挡
    if visited[i][j] || board[i][j] != word[k] → false  ③ 踩过 / 字符不符
    visited[i][j] = true                            ④ 标记踩过
    ok = 上 || 下 || 左 || 右（各带 k+1）            ⑤ 四方向递归
    visited[i][j] = false                           ⑥ 撤销，还原现场
    return ok
```

三个细节决定了这题对不对：

- **①必须在②之前**：最后一格匹配成功后，下一层会带着 `k == word.length()` 落到**越界的邻居格**上。若先判越界，就永远返回不了 `true`——这一层必须是"匹配完成"优先。
- **④⑥ 必须成对**：一条分支走死退回来时，必须把 `visited` 擦干净，否则同一起点的**兄弟分支**会误以为那些格子还被占用，把本可走通的路判死。反过来说，因为每条分支退出时都自己清理了现场，**换下一个起点重新搜时无需手动清空整个 `visited`**。
- **⑤不能写成 `if (上 || 下 || 左 || 右) return true;`**：`||` 一短路就直接 `return`，**跳过了⑥的撤销**，会留下脏标记污染后续搜索。正确姿势是**先用变量接住四路结果 → 再撤销 → 最后返回**。

**终止条件**：`k == word.length()` 到达即命中。这是"**存在性**"搜索——只要一条路径成立就返回 `true`，不需要 22 / 46 那样的 `ans` 收集器。

搜索过程（示例 2，`word = "SEE"`，只展开以 `S` 为起点的两支）：

```
起点候选 'S': (1,0) 与 (1,3)
├─ (1,0)S   邻居 (0,0)A,(2,0)A,(1,1)F   → 无 'E'  ✗
└─ (1,3)S   邻居 (0,3)E,(2,3)E,(1,2)C
   ├─ (0,3)E   邻居 (0,2)C,(1,3)已踩      → 无 'E'  ✗
   └─ (2,3)E   邻居 (2,2)E,(1,3)已踩
      └─ (2,2)E  k=3==word.length()       → ✅ 路径 (1,3)→(2,3)→(2,2)
```

示例 3 `"ABCB"` 走 `A→B→C` 都顺，但第 4 个 `B` 只能落在 `(0,1)`——那里**已被本路径踩过**，`visited` 挡住 → 全部分支失败 → `false`。这正是"不能重复使用格子"在起作用。

- 时间复杂度：`O(m · n · 3^L)`，`L = word.length()`。每格起点一次搜索，每步除"来路"外的 3 个邻居分支，故 `3^L`
- 空间复杂度：`O(L + m · n)`，递归深度 `L`，加 `visited` 网格

**对比 22 / 46 / 78**：同样是"选择 → 递归 → 撤销"，但"选择"从"填哪个字符 / 选哪个数"变成了"**往哪个邻居走**"，且由于存在"不能重复踩"的约束，撤销的对象也从 `path` 变成了 **`visited` 标记**。

**易错点**（都是实打实踩过的坑）：

1. `exist` 里**忘了枚举起点**，只在 `(0,0)` 搜一次；
2. 递归**忘了 `k + 1`**，四路都传原始 `k`，原地打转；
3. 用 `||` 短路直接 `return true`，**跳过了 `visited` 的撤销**；
4. 越界写成 `i > board.length`——应为 `i >= board.length`（`j` 同理），否则 `i == m` 会数组越界；
5. `k` 的语义（0-based 还是 1-based）与 `charAt(k)` / 出口条件**不统一**。

**进阶剪枝**（呼应题面）：

- **字符频次预检**：先统计 `board` 与 `word` 的字符计数，若 `word` 中某字符需求量超过网格中该字符总数，直接返回 `false`；进一步地，若 `word` 末尾字符在网格中出现更少，可**从尾部反向搜**，让分支更早枯死；
- **原地改字符省 `visited`**：进入 `(i,j)` 时把 `board[i][j]` 临时改成 `'#'`（任何不会出现在 `word` 里的字符），回溯时改回原字符——用输入本身当标记，省掉 `O(m · n)` 的 `visited` 空间（代价是"修改了输入"，需自行评估是否可接受）。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public boolean exist(char[][] board, String word) {
        boolean[][] visited = new boolean[board.length][board[0].length];
        for (int i = 0; i < board.length; i++) {
            for (int j = 0; j < board[0].length; j++) {
                if (backTrack(board, word, visited, 0, i, j)) {
                    return true;
                }
            }
        }
        return false;
    }

    // k：当前待匹配的字符下标（0-based）
    public static boolean backTrack(char[][] board, String word, boolean[][] visited,
                                    int k, int i, int j) {
        if (k == word.length()) {                       // 整串匹配完
            return true;
        } else if (i < 0 || i >= board.length || j < 0 || j >= board[0].length) {
            return false;                               // 越界（会崩的先挡）
        } else if (visited[i][j]) {
            return false;                               // 本路径已踩过
        } else if (board[i][j] != word.charAt(k)) {
            return false;                               // 字符不符
        }
        visited[i][j] = true;                           // 标记踩过
        boolean up    = backTrack(board, word, visited, k + 1, i - 1, j);
        boolean down  = backTrack(board, word, visited, k + 1, i + 1, j);
        boolean left  = backTrack(board, word, visited, k + 1, i, j - 1);
        boolean right = backTrack(board, word, visited, k + 1, i, j + 1);
        visited[i][j] = false;                          // 撤销：还原现场
        return up || down || left || right;             // 任一方向命中即成功
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m n，接下来 m 行每行一个长度 n 的字符串，最后一行 word
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        char[][] board = new char[m][];
        for (int i = 0; i < m; i++) {
            board[i] = sc.next().toCharArray();
        }
        String word = sc.next();
        System.out.println(new Solution().exist(board, word));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def exist(self, board: List[List[str]], word: str) -> bool:
        m, n = len(board), len(board[0])
        visited = [[False] * n for _ in range(m)]

        def dfs(i: int, j: int, k: int) -> bool:
            if k == len(word):                  # 整串匹配完
                return True
            if i < 0 or i >= m or j < 0 or j >= n:
                return False                    # 越界（会崩的先挡）
            if visited[i][j] or board[i][j] != word[k]:
                return False                    # 踩过 / 字符不符
            visited[i][j] = True                # 标记踩过
            ok = (dfs(i - 1, j, k + 1) or dfs(i + 1, j, k + 1)
                  or dfs(i, j - 1, k + 1) or dfs(i, j + 1, k + 1))
            visited[i][j] = False               # 撤销：还原现场
            return ok

        for i in range(m):
            for j in range(n):
                if dfs(i, j, 0):
                    return True
        return False


if __name__ == "__main__":
    # ACM 输入：第一行 m n，接下来 m 行每行一个长度 n 的字符串，最后一行 word
    data = sys.stdin.read().split()
    m, n = int(data[0]), int(data[1])
    board = [list(data[2 + i]) for i in range(m)]
    word = data[2 + m]
    print("true" if Solution().exist(board, word) else "false")
```

```cpp
#include <string>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    bool exist(vector<vector<char>>& board, string word) {
        int m = (int)board.size(), n = (int)board[0].size();
        vector<vector<bool>> visited(m, vector<bool>(n, false));
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (backTrack(board, word, visited, 0, i, j)) {
                    return true;
                }
            }
        }
        return false;
    }

    // k：当前待匹配的字符下标（0-based）
    static bool backTrack(vector<vector<char>>& board, const string& word,
                          vector<vector<bool>>& visited, int k, int i, int j) {
        if (k == (int)word.size()) {                    // 整串匹配完
            return true;
        }
        if (i < 0 || i >= (int)board.size() || j < 0 || j >= (int)board[0].size()) {
            return false;                               // 越界
        }
        if (visited[i][j] || board[i][j] != word[k]) {
            return false;                               // 踩过 / 字符不符
        }
        visited[i][j] = true;                           // 标记踩过
        bool up    = backTrack(board, word, visited, k + 1, i - 1, j);
        bool down  = backTrack(board, word, visited, k + 1, i + 1, j);
        bool left  = backTrack(board, word, visited, k + 1, i, j - 1);
        bool right = backTrack(board, word, visited, k + 1, i, j + 1);
        visited[i][j] = false;                          // 撤销：还原现场
        return up || down || left || right;
    }
};

int main() {
    // ACM 输入：第一行 m n，接下来 m 行每行一个长度 n 的字符串，最后一行 word
    int m, n;
    cin >> m >> n;
    vector<vector<char>> board(m, vector<char>(n));
    for (int i = 0; i < m; i++) {
        string row;
        cin >> row;
        for (int j = 0; j < n; j++) {
            board[i][j] = row[j];
        }
    }
    string word;
    cin >> word;
    cout << (Solution().exist(board, word) ? "true" : "false") << "\n";
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

static int M, N;

static bool backTrack(char **board, char *word, int wordLen, char **visited,
                      int k, int i, int j) {
    if (k == wordLen) {                         /* 整串匹配完 */
        return true;
    }
    if (i < 0 || i >= M || j < 0 || j >= N) {
        return false;                           /* 越界（会崩的先挡） */
    }
    if (visited[i][j] || board[i][j] != word[k]) {
        return false;                           /* 踩过 / 字符不符 */
    }
    visited[i][j] = 1;                          /* 标记踩过 */
    bool up    = backTrack(board, word, wordLen, visited, k + 1, i - 1, j);
    bool down  = backTrack(board, word, wordLen, visited, k + 1, i + 1, j);
    bool left  = backTrack(board, word, wordLen, visited, k + 1, i, j - 1);
    bool right = backTrack(board, word, wordLen, visited, k + 1, i, j + 1);
    visited[i][j] = 0;                          /* 撤销：还原现场 */
    return up || down || left || right;         /* 任一方向命中即成功 */
}

bool exist(char **board, int boardSize, int *boardColSize, char *word) {
    M = boardSize;
    N = boardColSize[0];
    int wordLen = (int)strlen(word);
    char **visited = (char **)malloc(M * sizeof(char *));
    for (int i = 0; i < M; i++) {
        visited[i] = (char *)calloc(N, sizeof(char));
    }
    bool found = false;
    for (int i = 0; i < M && !found; i++) {
        for (int j = 0; j < N; j++) {
            if (backTrack(board, word, wordLen, visited, 0, i, j)) {
                found = true;
                break;
            }
        }
    }
    for (int i = 0; i < M; i++) {
        free(visited[i]);
    }
    free(visited);
    return found;
}

int main(void) {
    /* ACM 输入：第一行 m n，接下来 m 行每行一个长度 n 的字符串，最后一行 word */
    int m, n;
    if (scanf("%d %d", &m, &n) != 2) {
        return 0;
    }
    char **board = (char **)malloc(m * sizeof(char *));
    int *colSizes = (int *)malloc(m * sizeof(int));
    for (int i = 0; i < m; i++) {
        board[i] = (char *)malloc(n + 1);
        scanf("%s", board[i]);
        colSizes[i] = n;
    }
    char word[64];
    scanf("%s", word);
    printf("%s\n", exist(board, m, colSizes, word) ? "true" : "false");
    for (int i = 0; i < m; i++) {
        free(board[i]);
    }
    free(board);
    free(colSizes);
    return 0;
}
```
