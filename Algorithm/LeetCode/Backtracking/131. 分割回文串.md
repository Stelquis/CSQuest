# [131. 分割回文串](https://leetcode.cn/problems/palindrome-partitioning/)

- 🟡 **难度**：中等
- ↩️ **分类**：回溯
- 🏷️ **标签**：`字符串`、`动态规划`、`回溯`

## 题目描述

给你一个字符串 `s`，请你将 `s` 分割成一些 子串，使每个子串都是 **回文串** 。返回 `s` 所有可能的分割方案。

**示例 1：**

```
输入：s = "aab"
输出：[["a","a","b"],["aa","b"]]
```

**示例 2：**

```
输入：s = "a"
输出：[["a"]]
```

**提示：**
- `1 <= s.length <= 16`
- `s` 仅由小写英文字母组成

## 题解：回溯（逐段下刀 + 回文判定）

这题的"选择"既不是填字符，也不是走格子，而是**决定下一刀切在哪**。把 `s` 从左往右一段段地铺：手里有个指针 `start` 表示"**下一块从哪开始**"，站在 `start` 上枚举这一块的**右端点 `i`**，只要 `s[start..i]` 是回文，就选它、然后从 `i + 1` 继续铺下一块。

这样"**无缝、无重叠、正好铺满**"三个条件由 `start` 指针天然保证：每块都从 `start` 起（无缝），下一块从 `i + 1` 起（无重叠），`start` 走到 `n` 即铺满。所以不需要额外校验，只需要守住"每块是回文"。

递归函数 `dfs(start)` 的三段式：

```
dfs(start):
    if start == s.length()            → 拍快照收集，return    ① 铺满整串
    for i = start .. s.length() - 1:                           ② 枚举本块右端点
        if s[start..i] 是回文:                                  ③ 只在回文处下刀
            path.add(s[start..i])                               ④ 选
            dfs(i + 1)                                          ⑤ 递归下一块
            path.remove(最后一块)                                ⑥ 撤销
```

三个细节：

- **①收集时必须拍快照**：`ans.add(new ArrayList<>(path))`。`path` 是全程复用的同一条路，后续还会被 `remove`，直接存引用的话最终 `ans` 里所有元素都指向同一个（已清空的）列表——这是 46 / 78 反复出现的老坑；
- **③是剪枝点**：只在 `s[start..i]` 为回文时才有分支，非回文直接跳过，不进入递归；
- **⑥撤销成对**：`path.add` 与 `path.remove(path.size() - 1)` 一入一出，退回上一层时现场必须和进入时完全一致，同层后续的 `i` 才能在干净的 `path` 上继续。

决策树（`s = "aab"`，✗ = 该段非回文，直接跳过）：

```
dfs(0)
├─ i=0  "a"   ✓ → dfs(1)
│   ├─ i=1  "a"   ✓ → dfs(2)
│   │   └─ i=2  "b"   ✓ → dfs(3)  start==n  ✅ 收 ["a","a","b"]
│   └─ i=2  "ab"  ✗ 非回文
├─ i=1  "aa"  ✓ → dfs(2)
│   └─ i=2  "b"   ✓ → dfs(3)  start==n  ✅ 收 ["aa","b"]
└─ i=2  "aab" ✗ 非回文
```

- 时间复杂度：`O(n · 2^n)`，最坏（如全为同一字符）有 `2^(n-1)` 种切法；预计算回文表后每层均摊 `O(n)`。若每个子串都现场用双指针判回文，则再乘一个 `O(n)` 因子
- 空间复杂度：`O(n)`，递归深度与 `path`（不计返回答案）

**对比 79 / 46 / 78**：同样是"选择 → 递归 → 撤销"，但这里的"选择"是**在当前起点上选一个回文右端点**，递归跳转的坐标是 `i + 1`（而不是 `i + 1` 之外的固定步长）。与 79 的"存在性"搜索不同，本题和 22 / 46 / 78 一样要**收集所有解**，因此需要 `ans` + `path` + 拍快照。

**易错点**（都是实打实踩过的坑）：

1. **出口忘了收集**：`if (start == n) return;` 少了 `ans.add(...)`，结果 `ans` 永远是空的；
2. **忘了拍快照**：`ans.add(path)` 存的是引用，回溯把 `path` 掏空后，`ans` 里全变成 `[]`——必须 `ans.add(new ArrayList<>(path))`；
3. **`isPalindrome` 忘了移动指针**：双指针相等时若不 `left++ / right--`，会**死循环**（LeetCode 上表现为超时）；
4. **`substring` 左闭右开**：切 `s[start..i]` 要写 `s.substring(start, i + 1)`，忘了 `+ 1` 会少切一个字符；
5. 递归跳的是 `i + 1` 而非 `i`，否则下一块会和当前块重叠。

**备注**：判回文有优化空间——题目标签 `动态规划` 即指此。可先用 `O(n^2)` 预处理出 `pal[i][j]` 表示 `s[i..j]` 是否回文：

```
pal[i][j] = (s[i] == s[j]) && (j - i < 2 || pal[i + 1][j - 1])
```

之后每次判定降到 `O(1)`。本题 `n <= 16` 很小，现场双指针也完全够用；`pal` 表在 `n` 更大时收益明显。

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

class Solution {
    public List<List<String>> ans;

    public List<List<String>> partition(String s) {
        ans = new ArrayList<>();
        List<String> path = new ArrayList<>();
        backTrack(s, 0, path, ans);
        return ans;
    }

    public static void backTrack(String s, int start, List<String> path,
                                 List<List<String>> ans) {
        if (start == s.length()) {
            ans.add(new ArrayList<>(path));             // 拍快照：path 后续还会被撤销
            return;
        }
        for (int i = start; i < s.length(); i++) {
            if (isPalindrome(s, start, i)) {            // 只在回文处下刀
                path.add(s.substring(start, i + 1));    // 选：切出 s[start..i]（左闭右开故 i+1）
                backTrack(s, i + 1, path, ans);         // 下一块从 i+1 开始
                path.remove(path.size() - 1);           // 撤销选择
            }
        }
    }

    // 双指针判定 s[left..right] 是否回文
    public static boolean isPalindrome(String s, int left, int right) {
        while (left < right) {
            if (s.charAt(left) != s.charAt(right)) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串 s
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNext() ? sc.next() : "";
        List<List<String>> ans = new Solution().partition(s);
        StringBuilder sb = new StringBuilder();
        for (List<String> parts : ans) {
            sb.append(parts).append('\n');
        }
        System.out.print(sb);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def partition(self, s: str) -> List[List[str]]:
        ans: List[List[str]] = []
        path: List[str] = []

        def is_palindrome(left: int, right: int) -> bool:
            while left < right:
                if s[left] != s[right]:
                    return False
                left += 1
                right -= 1
            return True

        def back_track(start: int):
            if start == len(s):
                ans.append(path[:])             # 拍快照：path 后续还会被撤销
                return
            for i in range(start, len(s)):
                if is_palindrome(start, i):     # 只在回文处下刀
                    path.append(s[start:i + 1])  # 选：切出 s[start..i]
                    back_track(i + 1)            # 下一块从 i+1 开始
                    path.pop()                   # 撤销选择

        back_track(0)
        return ans


if __name__ == "__main__":
    # ACM 输入：一行字符串 s
    s = sys.stdin.read().split()[0]
    for parts in Solution().partition(s):
        print(parts)
```

### ➕ C++

```cpp
#include <string>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    vector<vector<string>> partition(string s) {
        vector<vector<string>> ans;
        vector<string> path;
        backTrack(s, 0, path, ans);
        return ans;
    }

    static void backTrack(const string& s, int start, vector<string>& path,
                          vector<vector<string>>& ans) {
        if (start == (int)s.size()) {
            ans.push_back(path);                            // push_back 自带拷贝快照
            return;
        }
        for (int i = start; i < (int)s.size(); i++) {
            if (isPalindrome(s, start, i)) {                // 只在回文处下刀
                path.push_back(s.substr(start, i - start + 1));  // 选
                backTrack(s, i + 1, path, ans);                  // 下一块从 i+1 开始
                path.pop_back();                                 // 撤销选择
            }
        }
    }

    // 双指针判定 s[left..right] 是否回文
    static bool isPalindrome(const string& s, int left, int right) {
        while (left < right) {
            if (s[left] != s[right]) {
                return false;
            }
            left++;
            right--;
        }
        return true;
    }
};

int main() {
    // ACM 输入：一行字符串 s
    string s;
    cin >> s;
    vector<vector<string>> ans = Solution().partition(s);
    for (const vector<string>& parts : ans) {
        cout << "[";
        for (int i = 0; i < (int)parts.size(); i++) {
            if (i > 0) cout << ", ";
            cout << parts[i];
        }
        cout << "]\n";
    }
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

static char ***ans;
static int *colSizes;
static int ansSize;
static int cap;

/* 双指针判定 s[left..right] 是否回文 */
static bool isPalindrome(const char *s, int left, int right) {
    while (left < right) {
        if (s[left] != s[right]) {
            return false;
        }
        left++;
        right--;
    }
    return true;
}

static void backTrack(const char *s, int n, int start, char **path, int depth) {
    if (start == n) {                               /* 铺满整串 */
        if (ansSize == cap) {                       /* 动态扩容 */
            cap *= 2;
            ans = (char ***)realloc(ans, cap * sizeof(char **));
            colSizes = (int *)realloc(colSizes, cap * sizeof(int));
        }
        ans[ansSize] = (char **)malloc(depth * sizeof(char *));
        for (int i = 0; i < depth; i++) {           /* 拍快照 */
            ans[ansSize][i] = (char *)malloc(strlen(path[i]) + 1);
            strcpy(ans[ansSize][i], path[i]);
        }
        colSizes[ansSize] = depth;
        ansSize++;
        return;
    }
    for (int i = start; i < n; i++) {
        if (isPalindrome(s, start, i)) {            /* 只在回文处下刀 */
            int len = i - start + 1;
            path[depth] = (char *)malloc(len + 1);  /* 选 */
            memcpy(path[depth], s + start, len);
            path[depth][len] = '\0';
            backTrack(s, n, i + 1, path, depth + 1);/* 下一块从 i+1 开始 */
            free(path[depth]);                      /* 撤销选择 */
        }
    }
}

char ***partition(char *s, int *returnSize, int **returnColumnSizes) {
    int n = (int)strlen(s);
    cap = 16;
    ans = (char ***)malloc(cap * sizeof(char **));
    colSizes = (int *)malloc(cap * sizeof(int));
    ansSize = 0;
    char **path = (char **)malloc(n * sizeof(char *));
    backTrack(s, n, 0, path, 0);
    free(path);
    *returnSize = ansSize;
    *returnColumnSizes = colSizes;
    return ans;
}

int main(void) {
    /* ACM 输入：一行字符串 s */
    char s[64];
    if (scanf("%63s", s) != 1) {
        return 0;
    }
    int returnSize;
    int *colSizes;
    char ***res = partition(s, &returnSize, &colSizes);
    for (int i = 0; i < returnSize; i++) {
        printf("[");
        for (int j = 0; j < colSizes[i]; j++) {
            if (j > 0) {
                printf(", ");
            }
            printf("%s", res[i][j]);
            free(res[i][j]);
        }
        printf("]\n");
        free(res[i]);
    }
    free(res);
    free(colSizes);
    return 0;
}
```
