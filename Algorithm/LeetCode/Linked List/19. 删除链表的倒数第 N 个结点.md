# [19. 删除链表的倒数第 N 个结点](https://leetcode.cn/problems/remove-nth-node-from-end-of-list/)

- 🟡 **难度**：中等
- 🔗 **分类**：链表
- 🏷️ **标签**：`链表`、`双指针`

## 题目描述

给你一个链表，删除链表的倒数第 `n` 个结点，并且返回链表的头结点。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/03/remove_ex1.jpg)

```
输入：head = [1,2,3,4,5], n = 2
输出：[1,2,3,5]
```

**示例 2：**

```
输入：head = [1], n = 1
输出：[]
```

**示例 3：**

```
输入：head = [1,2], n = 1
输出：[1]
```

**提示：**
- 链表中结点的数目为 `sz`
- `1 <= sz <= 30`
- `0 <= Node.val <= 100`
- `1 <= n <= sz`

**进阶：** 你能尝试使用一趟扫描实现吗？

## 题解一：量长度定位前驱（两趟扫描）

思路：先量长度 `len`，待删节点下标 `k = len - n`；走到**前驱**（下标 `k-1`）改 `next`。注意两件事：① 删头（`k=0`，即 `n==len`）时前驱不存在，需特判返回 `head.next`——条件必须翻译回语义确认，`n==len` 是"倒数第 len 个 = 正数第 1 个"；② 删除的本质是改前驱的 `next`，头节点没有前驱才需要特判。时间 `O(2n)`，空间 `O(1)`。

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        int len = getLength(head);
        if (n == len) return head.next;   // 删头：倒数第 len 个 = 正数第 1 个
        ListNode cur = head;
        for (int i = 1; i < len - n; i++) {   // 走 len-n-1 步到前驱
            cur = cur.next;
        }
        cur.next = cur.next.next;
        return head;
    }

    public static int getLength(ListNode head) {
        int len = 0;
        ListNode p = head;
        while (p != null) {
            len++;
            p = p.next;
        }
        return len;
    }

    public static ListNode buildList(int[] vals) {
        ListNode dummy = new ListNode(0), p = dummy;
        for (int v : vals) {
            p.next = new ListNode(v);
            p = p.next;
        }
        return dummy.next;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行节点个数 sz，第三行 sz 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int sz = sc.nextInt();
        int[] vals = new int[sz];
        for (int i = 0; i < sz; i++) {
            vals[i] = sc.nextInt();
        }
        ListNode res = new Solution().removeNthFromEnd(buildList(vals), n);
        StringBuilder sb = new StringBuilder();
        for (ListNode p = res; p != null; p = p.next) {
            if (p != res) sb.append(' ');
            sb.append(p.val);
        }
        System.out.println(sb);
        sc.close();
    }
}

// 单文件运行时入口类需在前，故 ListNode 定义置于 Solution 之后
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```

### 🐍 Python

```python
import sys
from typing import Optional


class ListNode:
    def __init__(self, val: int = 0, next: "Optional[ListNode]" = None):
        self.val = val
        self.next = next


class Solution:
    def removeNthFromEnd(self, head: Optional[ListNode], n: int) -> Optional[ListNode]:
        length = 0
        p = head
        while p is not None:
            length += 1
            p = p.next
        if n == length:
            return head.next   # 删头
        cur = head
        for _ in range(length - n - 1):
            cur = cur.next
        cur.next = cur.next.next
        return head


def build_list(vals):
    dummy = ListNode(0)
    p = dummy
    for v in vals:
        p.next = ListNode(v)
        p = p.next
    return dummy.next


if __name__ == "__main__":
    # ACM 输入：第一行 n，第二行节点个数 sz，第三行 sz 个整数
    data = sys.stdin.read().split()

    vals = [int(x) for x in data[2:2 + sz]]
    res = Solution().removeNthFromEnd(build_list(vals), n)
    out = []
    while res is not None:
        out.append(str(res.val))
        res = res.next
```

## 题解二：双指针一趟扫描（进阶，O(1) 空间一趟遍历）

思路：dummy 挂头；fast 先走 `n+1` 步（多走一步才能停在**前驱**），然后 fast/slow 同速前进，fast 到 null 时 slow 恰为待删节点的前驱，改 `next` 删除。无需量长度、无需删头特判（dummy 让头节点也有了前驱）。时间 `O(n)` 一趟，空间 `O(1)`。

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public ListNode removeNthFromEnd(ListNode head, int n) {
        ListNode dummy = new ListNode(0);
        dummy.next = head;
        ListNode fast = dummy;
        ListNode slow = dummy;
        for (int i = 0; i <= n; i++) {   // fast 先走 n+1 步，拉开 n+1 的距离
            fast = fast.next;
        }
        while (fast != null) {           // 同速前进，fast 到 null 时 slow 在前驱
            fast = fast.next;
            slow = slow.next;
        }
        slow.next = slow.next.next;
        return dummy.next;
    }

    public static ListNode buildList(int[] vals) {
        ListNode dummy = new ListNode(0), p = dummy;
        for (int v : vals) {
            p.next = new ListNode(v);
            p = p.next;
        }
        return dummy.next;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行节点个数 sz，第三行 sz 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int sz = sc.nextInt();
        int[] vals = new int[sz];
        for (int i = 0; i < sz; i++) {
            vals[i] = sc.nextInt();
        }
        ListNode res = new Solution().removeNthFromEnd(buildList(vals), n);
        StringBuilder sb = new StringBuilder();
        for (ListNode p = res; p != null; p = p.next) {
            if (p != res) sb.append(' ');
            sb.append(p.val);
        }
        System.out.println(sb);
        sc.close();
    }
}

// 单文件运行时入口类需在前，故 ListNode 定义置于 Solution 之后

    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
```
