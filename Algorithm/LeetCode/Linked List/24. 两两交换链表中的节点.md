# [24. 两两交换链表中的节点](https://leetcode.cn/problems/swap-nodes-in-pairs/)

- 🟡 **难度**：中等
- 🔗 **分类**：链表
- 🏷️ **标签**：`递归`、`链表`

## 题目描述

给你一个链表，两两交换其中相邻的节点，并返回交换后链表的头节点。你必须在不修改节点内部的值的情况下完成本题（即，只能进行节点交换）。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/10/03/swap_ex1.jpg)

```
输入：head = [1,2,3,4]
输出：[2,1,4,3]
```

**示例 2：**

```
输入：head = []
输出：[]
```

**示例 3：**

```
输入：head = [1]
输出：[1]
```

**提示：**
- 链表中节点的数目在范围 `[0, 100]` 内
- `0 <= Node.val <= 100`

## 题解一：迭代（首对单独处理 + pre 跟踪前驱）

思路：先把第一对交换并记下新头；之后每轮处理一对——`cur` 指向对内第一个节点，`pre` 指向上一对的尾巴（负责接驳）。四步：`cur` 越过 `next`、`next` 回指 `cur`、`pre` 接上 `next`、`pre/cur` 各就各位。时间 `O(n)`，空间 `O(1)`。

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public ListNode swapPairs(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = head.next;
        head.next = newHead.next;   // 1 越过 2 指向 3
        newHead.next = head;        // 2 回指 1，首对交换完成：2→1→3…
        ListNode pre = head;        // 上一对的尾巴（节点 1）
        ListNode cur = head.next;   // 下一对的第一个（节点 3）
        while (cur != null && cur.next != null) {
            ListNode next = cur.next;   // 对内第二个
            cur.next = next.next;       // cur 越过 next
            next.next = cur;            // next 回指 cur
            pre.next = next;            // 上一对尾巴接上 next
            pre = cur;                  // cur 成为新的尾巴
            cur = cur.next;             // 下一对
        }
        return newHead;
    }

    public static ListNode buildList(int[] vals) {
        ListNode dummy = new ListNode(0), p = dummy;
        for (int v : vals) {
            p.next = new ListNode(v);
            p = p.next;
        }
        return dummy.next;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] vals = new int[n];
        for (int i = 0; i < n; i++) {
            vals[i] = sc.nextInt();
        }
        ListNode res = new Solution().swapPairs(buildList(vals));
        StringBuilder sb = new StringBuilder();
        for (ListNode p = res; p != null; p = p.next) {
            if (p != res) sb.append(' ');
            sb.append(p.val);
        }
        System.out.println(sb);
        sc.close();
    }
}

// 单文件运行时入口类需在前，故 ListNode 定义置于 Solution 之后
class ListNode {
    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```

### 🐍 Python

```python
import sys
from typing import Optional


class ListNode:
    def __init__(self, val: int = 0, next: "Optional[ListNode]" = None):
        self.val = val
        self.next = next


class Solution:
    def swapPairs(self, head: Optional[ListNode]) -> Optional[ListNode]:
        if head is None or head.next is None:
            return head
        new_head = head.next
        head.next = new_head.next   # 1 越过 2
        new_head.next = head        # 2 回指 1
        pre, cur = head, head.next
        while cur is not None and cur.next is not None:
            nxt = cur.next
            cur.next = nxt.next
            nxt.next = cur
            pre.next = nxt
            pre = cur
            cur = cur.next
        return new_head


def build_list(vals):
    dummy = ListNode(0)
    p = dummy
    for v in vals:
        p.next = ListNode(v)
        p = p.next
    return dummy.next


if __name__ == "__main__":
    # ACM 输入：第一行 n，第二行 n 个整数
    data = sys.stdin.read().split()
    n = int(data[0])
    vals = [int(x) for x in data[1:1 + n]]
    res = Solution().swapPairs(build_list(vals))
    out = []
    while res is not None:
        out.append(str(res.val))
        res = res.next
    print(" ".join(out))
```

## 题解二：递归（三行核心）

思路：`swapPairs(head)` 的语义是"交换以 head 开头的整条链"——只需交换第一对，然后**相信递归**能把剩下部分处理成已交换的链，把新头接回来。递归出口：空或单节点。时间 `O(n)`，空间 `O(n)`（递归栈）。

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public ListNode swapPairs(ListNode head) {
        if (head == null || head.next == null) return head;
        ListNode newHead = head.next;          // 第二个节点将成为新头
        head.next = swapPairs(newHead.next);   // 相信递归：后面已两两交换好
        newHead.next = head;                   // 新头回指原头
        return newHead;
    }

    public static ListNode buildList(int[] vals) {
        ListNode dummy = new ListNode(0), p = dummy;
        for (int v : vals) {
            p.next = new ListNode(v);
            p = p.next;
        }
        return dummy.next;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] vals = new int[n];
        for (int i = 0; i < n; i++) {
            vals[i] = sc.nextInt();
        }
        ListNode res = new Solution().swapPairs(buildList(vals));
        StringBuilder sb = new StringBuilder();
        for (ListNode p = res; p != null; p = p.next) {
            if (p != res) sb.append(' ');
            sb.append(p.val);
        }
        System.out.println(sb);
        sc.close();
    }
}

// 单文件运行时入口类需在前，故 ListNode 定义置于 Solution 之后

    int val;
    ListNode next;
    ListNode() {}
    ListNode(int val) { this.val = val; }
    ListNode(int val, ListNode next) { this.val = val; this.next = next; }
}
```
