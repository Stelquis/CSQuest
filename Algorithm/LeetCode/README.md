## 规范

文件名统一为 `题号. 中文题名.md`，结构：`# [题名](力扣链接)` → 难度/分类/标签三行 → `## 题目描述`（题干、示例、`**提示：**` 数据范围，以中文为准）→ `## 题解一/二…`（标题写明思路与复杂度，多解法递增编号）→ `### ☕ Java / 🐍 Python / ➕ C++ / ⚙️ C`。

- 每段代码都是**完整程序**：含 ACM 式 `main`，从标准输入读、向标准输出打印，可直接复制运行；文档更新后所有代码块须实际编译运行验证
- Java：题目函数保持力扣签名（public 实例方法），自写辅助函数一律 `public static`，禁 `private`；`public class Solution` 放文件最前，`ListNode` 等自定义结构以非 public 类放文件末尾（单文件运行入口 + 单 public 类规则）
- C：使用 LeetCode 的 C 模板签名，哈希表等结构为手写开放寻址实现（含 `malloc` / `free`）
- 链表题的 `main` 自带 `buildList`，有环/相交等结构按题面 `pos` / `skip` 语义构造
- README 索引：完成一题在题目行打 ✅，整个分类完成时分类标题补 ✅；排序按难度（绿→黄→红），同难度内题号升序
