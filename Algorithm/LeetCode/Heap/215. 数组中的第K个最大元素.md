# [215. 数组中的第K个最大元素](https://leetcode.cn/problems/kth-largest-element-in-an-array/)

- 🟡 **难度**：中等
- ⛰️ **分类**：堆
- 🏷️ **标签**：`数组`、`分治`、`快速选择`、`排序`、`堆（优先队列）`

## 题目描述

给定整数数组 `nums` 和整数 `k`，请返回数组中第 `k` 个最大的元素。

请注意，你需要找的是数组排序后的第 `k` 个最大的元素，而不是第 `k` 个不同的元素。

你必须设计并实现时间复杂度为 `O(n)` 的算法解决此问题。

**示例 1:**

```
输入: [3,2,1,5,6,4], k = 2
输出: 5
```

**示例 2:**

```
输入: [3,2,3,1,2,4,5,5,6], k = 4
输出: 4
```

**提示：**
- `1 <= k <= nums.length <= 10^5`
- `-10^4 <= nums[i] <= 10^4`

## 题解：小顶堆维护前 K 大（优先队列）

反直觉的一点：**找第 K 大，用的却是小顶堆**。大顶堆只知道堆顶是最大值，第 2 大、第 3 大藏在堆的任意位置，无法直接定位；而小顶堆可以当"守门员"：

- 让堆中**始终只保留当前遇到过的最大的 k 个数**：元素全部入堆后，只要堆大小超过 `k`，就把堆顶（这 k 个里最小的）挤出去；
- 最终堆里剩下的就是整个数组最大的 `k` 个数，**堆顶 = 这 k 个里最小的 = 第 k 大**。

模拟 `nums = [3,2,1,5,6,4]`、`k = 2`（堆内变化）：

```
[3] → [2,3] → [2,3] → [3,5] → [5,6] → [4,5] → 挤出 4 → [5,6]
依次读入 3 2 1 5 6 4，每次超过 2 个就弹出最小值；堆顶 5 即第 2 大 ✓
```

- 时间复杂度：`O(n log k)`，每个元素最多进出堆各一次，堆大小始终 `<= k`
- 空间复杂度：`O(n)`（全量入堆；若边读边挤可优化到 `O(k)`）

**注**：题目提示要求 `O(n)` 算法，指的是快速选择（划分树 / 快排 partition）解法；本解法 `O(n log k)` 在力扣数据范围下同样能通过，且天然适合数据流场景（不必一次性拿到所有数据）。

### ☕ Java

```java
import java.util.PriorityQueue;
import java.util.Scanner;

class Solution {
    public int findKthLargest(int[] nums, int k) {
        // 小顶堆：堆中始终保留当前最大的 k 个
        PriorityQueue<Integer> heap = new PriorityQueue<>();
        for (int num : nums) {
            heap.offer(num);
        }
        while (heap.size() > k) {
            heap.poll();        // 挤掉这 k+1 个里最小的
        }
        return heap.peek();     // 堆顶 = 第 k 大
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n 和 k，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int k = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().findKthLargest(nums, k));
        sc.close();
    }
}
```

### 🐍 Python

```python
import heapq
import sys
from typing import List


class Solution:
    def findKthLargest(self, nums: List[int], k: int) -> int:
        # 小顶堆：堆中始终保留当前最大的 k 个
        heap = list(nums)
        heapq.heapify(heap)
        while len(heap) > k:
            heapq.heappop(heap)     # 挤掉这 k+1 个里最小的
        return heap[0]              # 堆顶 = 第 k 大


if __name__ == "__main__":
    # ACM 输入：第一行 n 和 k，第二行 n 个整数
    data = sys.stdin.read().split()
    n, k = int(data[0]), int(data[1])
    nums = [int(x) for x in data[2:2 + n]]
    print(Solution().findKthLargest(nums, k))
```

### ➕ C++

```cpp
#include <queue>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    int findKthLargest(vector<int>& nums, int k) {
        // 小顶堆：堆中始终保留当前最大的 k 个
        priority_queue<int, vector<int>, greater<int>> heap;
        for (int num : nums) {
            heap.push(num);
        }
        while ((int)heap.size() > k) {
            heap.pop();             // 挤掉这 k+1 个里最小的
        }
        return heap.top();          // 堆顶 = 第 k 大
    }
};

int main() {
    // ACM 输入：第一行 n 和 k，第二行 n 个整数
    int n, k;
    cin >> n >> k;
    vector<int> nums(n);
    for (int i = 0; i < n; i++) {
        cin >> nums[i];
    }
    cout << Solution().findKthLargest(nums, k) << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

/* 手写小顶堆 */
static int *heap;
static int heapSize;

static void swapNode(int i, int j) {
    int t = heap[i];
    heap[i] = heap[j];
    heap[j] = t;
}

static void siftUp(int i) {
    while (i > 0 && heap[i] < heap[(i - 1) / 2]) {
        swapNode(i, (i - 1) / 2);
        i = (i - 1) / 2;
    }
}

static void siftDown(int i) {
    while (2 * i + 1 < heapSize) {
        int child = 2 * i + 1;              /* 左孩子 */
        if (child + 1 < heapSize && heap[child + 1] < heap[child]) {
            child++;                        /* 选较小的孩子 */
        }
        if (heap[i] <= heap[child]) {
            break;
        }
        swapNode(i, child);
        i = child;
    }
}

static void heapPush(int val) {
    heap[heapSize] = val;
    siftUp(heapSize);
    heapSize++;
}

static int heapPop(void) {
    int top = heap[0];
    heap[0] = heap[--heapSize];
    siftDown(0);
    return top;
}

int findKthLargest(int* nums, int numsSize, int k) {
    heap = (int*)malloc(numsSize * sizeof(int));
    heapSize = 0;
    for (int i = 0; i < numsSize; i++) {
        heapPush(nums[i]);
    }
    while (heapSize > k) {
        heapPop();          /* 挤掉这 k+1 个里最小的 */
    }
    int ans = heap[0];      /* 堆顶 = 第 k 大 */
    free(heap);
    return ans;
}

int main(void) {
    /* ACM 输入：第一行 n 和 k，第二行 n 个整数 */
    int n, k;
    if (scanf("%d %d", &n, &k) != 2) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    printf("%d\n", findKthLargest(nums, n, k));
    free(nums);
    return 0;
}
```
