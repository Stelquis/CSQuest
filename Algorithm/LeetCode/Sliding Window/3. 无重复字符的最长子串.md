# [3. 无重复字符的最长子串](https://leetcode.cn/problems/longest-substring-without-repeating-characters/)

- 🟡 **难度**：中等
- 🪟 **分类**：滑动窗口
- 🏷️ **标签**：`哈希表`、`字符串`、`滑动窗口`

## 题目描述

给定一个字符串 `s` ，请你找出其中不含有重复字符的 **最长 子串** 的长度。

**示例 1:**

```
输入: s = "abcabcbb"
输出: 3 
解释: 因为无重复字符的最长子串是 "abc"，所以其长度为 3。注意 "bca" 和 "cab" 也是正确答案。
```

**示例 2:**

```
输入: s = "bbbbb"
输出: 1
解释: 因为无重复字符的最长子串是 "b"，所以其长度为 1。
```

**示例 3:**

```
输入: s = "pwwkew"
输出: 3
解释: 因为无重复字符的最长子串是 "wke"，所以其长度为 3。
     请注意，你的答案必须是 子串 的长度，"pwke" 是一个子序列，不是子串。
```

**提示：**
- `0 <= s.length <= 10^5`
- `s` 由英文字母、数字、符号和空格组成

## 题解：滑动窗口（记录上次出现位置）

### ☕ Java

```java
import java.util.Arrays;
import java.util.Scanner;

class Solution {
    public int lengthOfLongestSubstring(String s) {
        int ans = 0;
        char[] str = s.toCharArray();
        // 当前字符上一次出现的位置
        int[] last = new int[128];
        Arrays.fill(last, -1);
        int r = 0, l = 0;
        for (r = 0; r < s.length(); r++) {
            l = Math.max(l, last[str[r]] + 1);
            ans = Math.max(ans, r - l + 1);
            last[str[r]] = r;
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串（可含空格）
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine() : "";
        System.out.println(new Solution().lengthOfLongestSubstring(s));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys


class Solution:
    def lengthOfLongestSubstring(self, s: str) -> int:
        ans = 0
        # 当前字符上一次出现的位置
        last = [-1] * 128
        l = 0
        for r, ch in enumerate(s):
            idx = ord(ch)
            l = max(l, last[idx] + 1)
            ans = max(ans, r - l + 1)
            last[idx] = r
        return ans


if __name__ == "__main__":

    if data.endswith("\n"):
        data = data[:-1]
    if data.endswith("\r"):
        data = data[:-1]
    print(Solution().lengthOfLongestSubstring(data))
```

### ➕ C++

```cpp
#include <algorithm>
#include <string>
#include <iostream>
using namespace std;

class Solution {
public:
    int lengthOfLongestSubstring(string s) {
        int ans = 0;
        // 当前字符上一次出现的位置
        int last[128];
        fill(last, last + 128, -1);
        int l = 0;
        for (int r = 0; r < (int)s.size(); r++) {
            unsigned char c = (unsigned char)s[r];
            l = max(l, last[c] + 1);
            ans = max(ans, r - l + 1);
            last[c] = r;
        }
        return ans;
    }
};

int main() {
    // ACM 输入：一行字符串（可含空格）
    string s;
    getline(cin, s);
    cout << Solution().lengthOfLongestSubstring(s) << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <string.h>

int lengthOfLongestSubstring(char* s) {
    int ans = 0;
    // 当前字符上一次出现的位置
    int last[128];
    for (int i = 0; i < 128; i++) {
        last[i] = -1;
    }
    int l = 0;
    for (int r = 0; s[r] != '\0'; r++) {
        unsigned char c = (unsigned char)s[r];
        if (last[c] + 1 > l) {
            l = last[c] + 1;
        }
        if (r - l + 1 > ans) {
            ans = r - l + 1;
        }
        last[c] = r;
    }
    return ans;
}

int main(void) {
    // ACM 输入：一行字符串（可含空格）
    char s[100005];
    if (fgets(s, sizeof(s), stdin) == NULL) {
        s[0] = '\0';
    }
    s[strcspn(s, "\r\n")] = '\0';   // 去掉行尾换行
    printf("%d\n", lengthOfLongestSubstring(s));
    return 0;
}
```
