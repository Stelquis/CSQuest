# [114. 二叉树展开为链表](https://leetcode.cn/problems/flatten-binary-tree-to-linked-list/)

- 🟡 **难度**：中等
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`栈`、`树`、`深度优先搜索`、`链表`、`二叉树`

## 题目描述

给你二叉树的根结点 `root` ，请你将它展开为一个单链表：
- 展开后的单链表应该同样使用 `TreeNode` ，其中 `right` 子指针指向链表中下一个结点，而左子指针始终为 `null` 。
- 展开后的单链表应该与二叉树 [**先序遍历**](https://baike.baidu.com/item/%E5%85%88%E5%BA%8F%E9%81%8D%E5%8E%86/6442839?fr=aladdin) 顺序相同。

**示例 1：**

![](https://assets.leetcode.com/uploads/2021/01/14/flaten.jpg)

```
输入：root = [1,2,5,3,4,null,6]
输出：[1,null,2,null,3,null,4,null,5,null,6]
```

**示例 2：**

```
输入：root = []
输出：[]
```

**示例 3：**

```
输入：root = [0]
输出：[0]
```

**提示：**
- 树中结点数在范围 `[0, 2000]` 内
- `-100 <= Node.val <= 100`

**进阶：** 你可以使用原地算法（`O(1)` 额外空间）展开这棵树吗？

## 题解一：前序遍历收集 + 统一改指针

结果的顺序 = 先序序列，所以分两步：先**只读**地前序遍历把节点对象收进列表，再**统一**改指针——`left` 置 null、`right` 指向列表中的下一个节点。把"遍历"和"改结构"彻底分离，避开"边走边改"的陷阱。

> 陷阱警示：若在前序递归途中直接改 `cur.right = 下一个节点`，当前节点原右子树的引用会丢失（整棵子树失联）。先收集后操作则所有对象都在列表里，引用安全。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，列表存全部节点（另有 `O(h)` 递归栈）

### ☕ Java

```java
import java.util.ArrayList;
import java.util.LinkedList;
import java.util.List;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public void flatten(TreeNode root) {
        List<TreeNode> nodes = new ArrayList<>();
        order(root, nodes);
        for (int i = 1; i < nodes.size(); i++) {
            nodes.get(i - 1).left = null;
            nodes.get(i - 1).right = nodes.get(i);
        }
    }

    // 前序遍历收集节点对象（根 → 左 → 右）
    public static void order(TreeNode node, List<TreeNode> nodes) {
        if (node == null) {
            return;
        }
        nodes.add(node);
        order(node.left, nodes);
        order(node.right, nodes);
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        new Solution().flatten(root);
        System.out.println(toLeetCodeString(root));
        sc.close();
    }

    // 按层序遍历读入建树，null 表示空节点
    public static TreeNode buildTree(Scanner sc) {
        if (!sc.hasNext()) {
            return null;
        }
        String token = sc.next();
        if ("null".equals(token)) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(token));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (!sc.hasNext()) {
                break;
            }
            String left = sc.next();
            if (!"null".equals(left)) {
                cur.left = new TreeNode(Integer.parseInt(left));
                queue.offer(cur.left);
            }
            if (!sc.hasNext()) {
                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }

    // 展开后的链表按 LeetCode 层序格式输出：[1, null, 2, null, 3, ...]
    public static String toLeetCodeString(TreeNode root) {
        if (root == null) {
            return "[]";
        }
        StringBuilder sb = new StringBuilder("[");
        TreeNode cur = root;
        while (cur != null) {
            if (sb.length() > 1) {
                sb.append(", null, ");   // 每个节点之前补上一个 null 占位
            }
            sb.append(cur.val);
            cur = cur.right;
        }
        return sb.append("]").toString();
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
import sys
from collections import deque
from typing import List, Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def flatten(self, root: Optional[TreeNode]) -> None:
        """原地展开，无返回值"""
        nodes: List[TreeNode] = []
        self.order(root, nodes)
        for i in range(1, len(nodes)):
            nodes[i - 1].left = None
            nodes[i - 1].right = nodes[i]

    def order(self, node: Optional[TreeNode], nodes: List[TreeNode]) -> None:
        if node is None:
            return
        nodes.append(node)
        self.order(node.left, nodes)
        self.order(node.right, nodes)


def build_tree(tokens, pos):
    """按层序遍历建树，'null' 表示空节点"""
    if pos[0] >= len(tokens) or tokens[pos[0]] == "null":
        pos[0] += 1
        return None
    root = TreeNode(int(tokens[pos[0]]))
    pos[0] += 1
    queue = deque([root])
    while queue:
        cur = queue.popleft()
        for i in range(2):
            if pos[0] >= len(tokens):
                break
            child = None
            if tokens[pos[0]] != "null":
                child = TreeNode(int(tokens[pos[0]]))
                queue.append(child)
            if i == 0:
                cur.left = child
            else:
                cur.right = child
            pos[0] += 1
    return root


def to_leetcode_string(root):
    """展开后的链表按 LeetCode 层序格式输出"""
    if root is None:
        return "[]"
    items = []
    cur = root
    while cur:
        items.append(str(cur.val))
        if cur.right:
            items.append("null")
        cur = cur.right
    return "[" + ", ".join(items) + "]"

    # ACM 输入：一行层序序列，null 表示空节点
```

## 题解二：逆后序遍历 + 前驱指针（原地 O(1)）

进阶解法。关键洞察：链表要从头串到尾，那就**从尾往头倒着造**——按"右 → 左 → 根"（逆后序）遍历，用 `prev` 记录"已造好部分的头"：

```
访问 node 时：
    node.left = null
    node.right = prev      ← 接到已造好后半段的头部
    prev = node            ← 自己成为新的头
```

为什么不会丢子树？——每次访问到的节点，其左右子树都**已经处理完毕**（它们在本节点之前被访问），此刻修改本节点的指针不破坏任何未访问结构。`prev` 技巧第三次出场（98 判相邻、230 计数、114 串链）。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，仅递归栈，无额外列表（满足进阶要求）

### ☕ Java

```java
import java.util.LinkedList;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    private static TreeNode prev = null;   // 已造好部分的头

    public void flatten(TreeNode root) {
        prev = null;                       // 入口重置
        revPostorder(root);
    }

    // 逆后序：右 → 左 → 根
    public static void revPostorder(TreeNode node) {
        if (node == null) {
            return;
        }
        revPostorder(node.right);
        revPostorder(node.left);
        node.left = null;
        node.right = prev;
        prev = node;
    }

    public static void main(String[] args) {
        // ACM 输入：一行层序序列，null 表示空节点
        Scanner sc = new Scanner(System.in);
        TreeNode root = buildTree(sc);
        new Solution().flatten(root);
        System.out.println(toLeetCodeString(root));
        sc.close();
    }

                break;
            }
            String right = sc.next();
            if (!"null".equals(right)) {
                cur.right = new TreeNode(Integer.parseInt(right));
                queue.offer(cur.right);
            }
        }
        return root;
    }

// 展开后的链表按 LeetCode 层序格式输出
```
```c
void toLeetCodeString(TreeNode* root) {
    if (root == NULL) {
        printf("[]\n");
        return;
    }
    printf("[");
    TreeNode* cur = root;
    int first = 1;
    while (cur != NULL) {
        if (!first) {
            printf(", null");
        }
        printf(first ? "%d" : ", %d", cur->val);
        first = 0;
        cur = cur->right;
    }
    printf("]\n");
}

int main(void) {
    // ACM 输入：一行层序序列，null 表示空节点
    char tokens[4000][16];
    int n = 0;
    while (n < 4000 && scanf("%15s", tokens[n]) == 1) {
        n++;
    }
    TreeNode* root = buildTree(tokens, n);
    flatten(root);
    toLeetCodeString(root);
    return 0;
}
```
