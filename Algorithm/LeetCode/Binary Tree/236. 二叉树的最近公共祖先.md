# [236. 二叉树的最近公共祖先](https://leetcode.cn/problems/lowest-common-ancestor-of-a-binary-tree/)

- 🟡 **难度**：中等
- 🌳 **分类**：二叉树
- 🏷️ **标签**：`树`、`深度优先搜索`、`二叉树`、`最近公共祖先`、`Binary Lifting`

## 题目描述

给定一个二叉树, 找到该树中两个指定节点的最近公共祖先。

[百度百科](https://baike.baidu.com/item/%E6%9C%80%E8%BF%91%E5%85%AC%E5%85%B1%E7%A5%96%E5%85%88/8918834?fr=aladdin)中最近公共祖先的定义为：“对于有根树 T 的两个节点 p、q，最近公共祖先表示为一个节点 x，满足 x 是 p、q 的祖先且 x 的深度尽可能大（**一个节点也可以是它自己的祖先**）。”

**示例 1：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 1
输出：3
解释：节点 5 和节点 1 的最近公共祖先是节点 3 。
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2018/12/14/binarytree.png)

```
输入：root = [3,5,1,6,2,0,8,null,null,7,4], p = 5, q = 4
输出：5
解释：节点 5 和节点 4 的最近公共祖先是节点 5 。因为根据定义最近公共祖先节点可以为节点本身。
```

**示例 3：**

```
输入：root = [1,2], p = 1, q = 2
输出：1
```

**提示：**
- 树中节点数目在范围 `[2, 10^5]` 内。
- `-10^9 <= Node.val <= 10^9`
- 所有 `Node.val` `互不相同` 。
- `p != q`
- `p` 和 `q` 均存在于给定的二叉树中。

## 题解一：后序深度优先搜索（左右报告汇合）

LCA 的两种形态统一为一条判定规则：**第一个满足"左右子树各含一个目标"或"自己就是目标"的节点**。给 `dfs` 定合同——"node 的子树里能找到 p 或 q 吗？"：找到就非 null 返回（撞见本人直接返回自己，不深入），两手报告都非 null 即分岔点。

| 左手报告 | 右手报告 | 结论 |
|---|---|---|
| 有 | 有 | 分岔：我就是 LCA |
| 有 | 无 | 同一支线（祖先型），原样转发 |
| 无 | 有 | 同上 |
| 无 | 无 | 一无所获，返回 null |

逐帧 trace（`[3,5,1,6,2,0,8,null,null,7,4], p=5, q=4`，期望 5——祖先型）：

| 帧 | 节点 | 动作 | 返回 |
|---|---|---|---|
| 1 | 3 | 问左、问右、转发非空的那份 | 5 |
| 2 | 5 | 撞见 p，提前返回（6/2/7/4 均不访问）| 5 |
| 3 | 1 | 左右全空 | null |
| 4 | 8 | 左右全空 | null |

关键理解：`dfs(5)` 撞见 p 就返回时**并不知道 q 在哪**——它赌的是二选一：q 在 5 的子树里（答案=5）或在别处（5 作为线索上抛，等右边送来 q 的报告，由某祖先裁决）。两种情况返回 5 都不会错。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(h)`，递归栈

### ☕ Java

```java
import java.util.HashMap;
import java.util.LinkedList;
import java.util.Map;
import java.util.Queue;
import java.util.Scanner;

public class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        if (root == null || root == p || root == q) {
            return root;                          // 出口：走到头 / 撞见本人
        }
        TreeNode l = lowestCommonAncestor(root.left, p, q);
        TreeNode r = lowestCommonAncestor(root.right, p, q);
        if (l != null && r != null) {
            return root;                          // 两边都有：我是分岔点 = LCA
        }
        if (l == null && r == null) {
            return null;                          // 一无所获
        }
        return l != null ? l : r;                 // 只有一边：原样转发
    }

    public static void main(String[] args) {
        // ACM 输入：第一行层序序列（null 表示空节点），第二行 p 的值，第三行 q 的值
        Scanner sc = new Scanner(System.in);
        java.util.List<String> tokens = new java.util.ArrayList<>();
        while (sc.hasNext()) {
            tokens.add(sc.next());
        }
        int pVal = Integer.parseInt(tokens.get(tokens.size() - 2));
        int qVal = Integer.parseInt(tokens.get(tokens.size() - 1));
        java.util.List<String> tree = new java.util.ArrayList<>(tokens.subList(0, tokens.size() - 2));
        TreeNode root = buildTree(tree);
        // 建树时记录 值 → 节点对象（比较用引用 ==）
        Map<Integer, TreeNode> ref = new HashMap<>();
        mapRefs(root, ref);
        System.out.println(new Solution().lowestCommonAncestor(root, ref.get(pVal), ref.get(qVal)).val);
        sc.close();
    }

    public static TreeNode buildTree(java.util.List<String> tokens) {
        if (tokens.isEmpty() || "null".equals(tokens.get(0))) {
            return null;
        }
        TreeNode root = new TreeNode(Integer.parseInt(tokens.get(0)));
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        int i = 1;
        while (!queue.isEmpty() && i < tokens.size()) {
            TreeNode cur = queue.poll();
            if (!"null".equals(tokens.get(i))) {
                cur.left = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.left);
            }
            i++;
            if (i >= tokens.size()) {
                break;
            }
            if (!"null".equals(tokens.get(i))) {
                cur.right = new TreeNode(Integer.parseInt(tokens.get(i)));
                queue.offer(cur.right);
            }
            i++;
        }
        return root;
    }

    public static void mapRefs(TreeNode node, Map<Integer, TreeNode> ref) {
        if (node == null) {
            return;
        }
        ref.put(node.val, node);
        mapRefs(node.left, ref);
        mapRefs(node.right, ref);
    }
}

class TreeNode {
    int val;
    TreeNode left;
    TreeNode right;

    TreeNode() {}

    TreeNode(int val) { this.val = val; }

    TreeNode(int val, TreeNode left, TreeNode right) {
        this.val = val;
        this.left = left;
        this.right = right;
    }
}
```

```python
from typing import Optional


class TreeNode:
    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right


class Solution:
    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        if root is None or root is p or root is q:
            return root                          # 出口：走到头 / 撞见本人
        left = self.lowestCommonAncestor(root.left, p, q)
        right = self.lowestCommonAncestor(root.right, p, q)
        if left is not None and right is not None:
            return root                          # 两边都有：分岔点
        if left is None and right is None:
            return None
        return left if left is not None else right   # 转发


def build_tree(tokens, pos, ref):
    """按层序遍历建树，'null' 表示空节点；ref 记录 值→节点对象"""
    if pos[0] >= len(tokens) or tokens[pos[0]] == "null":
        pos[0] += 1
        return None
    root = TreeNode(int(tokens[pos[0]]))
    ref[root.val] = root
    pos[0] += 1
    queue = deque([root])
    while queue:
        cur = queue.popleft()
        for i in range(2):
            if pos[0] >= len(tokens):
                break
            child = None
            if tokens[pos[0]] != "null":
                child = TreeNode(int(tokens[pos[0]]))
                ref[child.val] = child
                queue.append(child)
            if i == 0:
                cur.left = child
            else:
                cur.right = child
            pos[0] += 1
    return root
```

```c
TreeNode* buildTree(char tokens[][16], int n) {
    if (n == 0 || strcmp(tokens[0], "null") == 0) {
        return NULL;
    }
    TreeNode** queue = (TreeNode**)malloc(n * sizeof(TreeNode*));
    int head = 0, tail = 0, i = 1;
    TreeNode* root = (TreeNode*)malloc(sizeof(TreeNode));
    root->val = atoi(tokens[0]);
    root->left = root->right = NULL;
    queue[tail++] = root;
    while (head < tail && i < n) {
        TreeNode* cur = queue[head++];
        if (strcmp(tokens[i], "null") != 0) {
            cur->left = (TreeNode*)malloc(sizeof(TreeNode));
            cur->left->val = atoi(tokens[i]);
            cur->left->left = cur->left->right = NULL;
            queue[tail++] = cur->left;
        }
        i++;
        if (i >= n) {
            break;
        }
        if (strcmp(tokens[i], "null") != 0) {
            cur->right = (TreeNode*)malloc(sizeof(TreeNode));
            cur->right->val = atoi(tokens[i]);
            cur->right->left = cur->right->right = NULL;
            queue[tail++] = cur->right;
        }
        i++;
    }
    free(queue);
    return root;
}
```

## 题解二：父指针表 + 祖先集合

另一条思路：先 DFS（或 BFS）给每个节点记录**父指针**，然后：从 `p` 出发沿父指针向上，把沿途所有祖先（含 p 自己）存进集合；再从 `q` 向上爬，**第一个出现在集合里的就是 LCA**。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，父表 + 集合（比题解一费，但思路可推广到多次查询/Binary Lifting 进阶）

### ☕ Java

```java
import java.util.HashMap;
import java.util.HashSet;
import java.util.LinkedList;
import java.util.Map;
import java.util.Queue;
import java.util.Scanner;
import java.util.Set;

public class Solution {
    public TreeNode lowestCommonAncestor(TreeNode root, TreeNode p, TreeNode q) {
        // 1. 记录每个节点的父指针
        Map<TreeNode, TreeNode> parent = new HashMap<>();
        parent.put(root, null);
        Queue<TreeNode> queue = new LinkedList<>();
        queue.offer(root);
        while (!queue.isEmpty()) {
            TreeNode cur = queue.poll();
            if (cur.left != null) {
                parent.put(cur.left, cur);
                queue.offer(cur.left);
            }
            if (cur.right != null) {
                parent.put(cur.right, cur);
                queue.offer(cur.right);
            }
        }
        // 2. p 的祖先链（含 p）入集合
        Set<TreeNode> ancestors = new HashSet<>();
        TreeNode cur = p;
        while (cur != null) {
            ancestors.add(cur);
            cur = parent.get(cur);
        }
        // 3. q 向上爬，第一个命中集合的就是 LCA
        cur = q;
        while (!ancestors.contains(cur)) {
            cur = parent.get(cur);
        }
        return cur;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行树序列，第二行 p 的值，第三行 q 的值
        Scanner sc = new Scanner(System.in);

            tokens.add(sc.next());
        }

        int qVal = Integer.parseInt(tokens.get(tokens.size() - 1));

        TreeNode root = buildTree(tree);

        sc.close();
    }

                queue.offer(cur.right);
            }
            i++;
        }
        return root;
    }

        }
        ref.put(node.val, node);
        mapRefs(node.left, ref);
        mapRefs(node.right, ref);
    }
}
```

```python
from typing import Dict, Optional

    def __init__(self, val=0, left=None, right=None):
        self.val = val
        self.left = left
        self.right = right

    def lowestCommonAncestor(self, root: 'TreeNode', p: 'TreeNode', q: 'TreeNode') -> 'TreeNode':
        # 1. 父指针表
        parent: Dict['TreeNode', Optional['TreeNode']] = {root: None}
        queue = deque([root])
        while queue:
            cur = queue.popleft()
            if cur.left:
                parent[cur.left] = cur
                queue.append(cur.left)
            if cur.right:
                parent[cur.right] = cur
                queue.append(cur.right)

            ancestors.add(cur)
            cur = parent[cur]
        # 3. q 向上爬，首个命中即 LCA
        cur = q
        while cur not in ancestors:
            cur = parent[cur]
        return cur
```

```cpp
#include <iostream>
#include <queue>
#include <sstream>
#include <string>
#include <unordered_map>
#include <unordered_set>
#include <vector>
using namespace std;

struct TreeNode {
    int val;
    TreeNode* left;
    TreeNode* right;
    TreeNode() : val(0), left(nullptr), right(nullptr) {}
    TreeNode(int x) : val(x), left(nullptr), right(nullptr) {}
};

class Solution {
public:
    TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
        unordered_map<TreeNode*, TreeNode*> parent;
        parent[root] = nullptr;
        queue<TreeNode*> bfs;          // 命名避开参数 q
        bfs.push(root);
        while (!bfs.empty()) {
            TreeNode* cur = bfs.front();
            bfs.pop();
            if (cur->left) {
                parent[cur->left] = cur;
                bfs.push(cur->left);
            }
            if (cur->right) {
                parent[cur->right] = cur;
                bfs.push(cur->right);
            }
        }
        unordered_set<TreeNode*> ancestors;
        TreeNode* cur = p;
        while (cur != nullptr) {
            ancestors.insert(cur);
            cur = parent[cur];
        }
        cur = q;                        // 这里的 q 是目标节点参数
        while (ancestors.find(cur) == ancestors.end()) {
            cur = parent[cur];
        }
        return cur;
    }
};

            ref[cur->left->val] = cur->left;

            break;
        }
        if (tokens[i] != "null") {
            cur->right = new TreeNode(stoi(tokens[i]));
            ref[cur->right->val] = cur->right;
            q.push(cur->right);
        }
        i++;
    }
    return root;
}

int main() {
    // ACM 输入：第一行树序列，第二行 p 的值，第三行 q 的值
    string line1, line2, line3;
    getline(cin, line1);
    getline(cin, line2);
    getline(cin, line3);
    vector<string> tokens;
    istringstream iss1(line1);
    string tok;
    while (iss1 >> tok) {
        tokens.push_back(tok);
    }
    int pVal = stoi(line2), qVal = stoi(line3);
    unordered_map<int, TreeNode*> ref;
    TreeNode* root = buildTree(tokens, ref);
    cout << Solution().lowestCommonAncestor(root, ref[pVal], ref[qVal])->val << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct TreeNode {
    int val;
    struct TreeNode* left;
    struct TreeNode* right;
} TreeNode;

TreeNode* findNode(struct TreeNode* node, int val) {
    if (node == NULL) {
        return NULL;
    }
    if (node->val == val) {
        return node;
    }
    TreeNode* l = findNode(node->left, val);
    return l != NULL ? l : findNode(node->right, val);
}

// 节点地址 → 父地址：用小型开放寻址哈希（以指针低位散列）
#define PCAP 4096
static struct TreeNode* pkeys[PCAP];
static struct TreeNode* pvals[PCAP];
static char pused[PCAP];

static unsigned int ptrHash(void* p) {
    unsigned long long x = (unsigned long long)p >> 4;
    return (unsigned int)((x * 0x9E3779B97F4A7C15ULL) >> 32);
}

static void pPut(struct TreeNode* key, struct TreeNode* val) {
    unsigned int h = ptrHash(key) & (PCAP - 1);
    while (pused[h] && pkeys[h] != key) {
        h = (h + 1) & (PCAP - 1);
    }
    pused[h] = 1;
    pkeys[h] = key;
    pvals[h] = val;
}

static struct TreeNode* pGet(struct TreeNode* key) {
    unsigned int h = ptrHash(key) & (PCAP - 1);
    while (pused[h]) {
        if (pkeys[h] == key) {
            return pvals[h];
        }
        h = (h + 1) & (PCAP - 1);
    }
    return NULL;
}

static int inSet(struct TreeNode** set, int n, struct TreeNode* x) {
    for (int i = 0; i < n; i++) {
        if (set[i] == x) {
            return 1;
        }
    }
    return 0;
}

TreeNode* lowestCommonAncestor(TreeNode* root, TreeNode* p, TreeNode* q) {
    // 1. BFS 记父指针
    TreeNode** queue = (TreeNode**)malloc(200000 * sizeof(TreeNode*));
    int head = 0, tail = 0;
    queue[tail++] = root;
    pPut(root, NULL);
    while (head < tail) {
        TreeNode* cur = queue[head++];
        if (cur->left) {
            pPut(cur->left, cur);
            queue[tail++] = cur->left;
        }
        if (cur->right) {
            pPut(cur->right, cur);
            queue[tail++] = cur->right;
        }
    }
    free(queue);
    // 2. p 的祖先链入集合
    TreeNode** ancestors = (TreeNode**)malloc(200000 * sizeof(TreeNode*));
    int cnt = 0;
    TreeNode* cur = p;
    while (cur != NULL) {
        ancestors[cnt++] = cur;
        cur = pGet(cur);
    }
    // 3. q 向上爬，首个命中即 LCA
    cur = q;
    while (!inSet(ancestors, cnt, cur)) {
        cur = pGet(cur);
    }
    free(ancestors);
    return cur;
}

// 按层序遍历读入建树，"null" 表示空节点
TreeNode* buildTree(char tokens[][16], int n) {
    if (n == 0 || strcmp(tokens[0], "null") == 0) {
        return NULL;
    }
    TreeNode** queue = (TreeNode**)malloc(n * sizeof(TreeNode*));
    int head = 0, tail = 0, i = 1;
    TreeNode* root = (TreeNode*)malloc(sizeof(TreeNode));
    root->val = atoi(tokens[0]);
    root->left = root->right = NULL;
    queue[tail++] = root;
    while (head < tail && i < n) {
        TreeNode* cur = queue[head++];
        if (strcmp(tokens[i], "null") != 0) {
            cur->left = (TreeNode*)malloc(sizeof(TreeNode));
            cur->left->val = atoi(tokens[i]);
            cur->left->left = cur->left->right = NULL;
            queue[tail++] = cur->left;
        }
        i++;
        if (i >= n) {
            break;
        }
        if (strcmp(tokens[i], "null") != 0) {
            cur->right = (TreeNode*)malloc(sizeof(TreeNode));
            cur->right->val = atoi(tokens[i]);
            cur->right->left = cur->right->right = NULL;
            queue[tail++] = cur->right;
        }
        i++;
    }
    free(queue);
    return root;
}

int main(void) {
    // ACM 输入：第一行树序列，第二行 p 的值，第三行 q 的值
    char tokens[200001][16];
    int n = 0;
    while (n < 200001 && scanf("%15s", tokens[n]) == 1) {
        n++;
    }
    int pVal = atoi(tokens[n - 2]);
    int qVal = atoi(tokens[n - 1]);
    TreeNode* root = buildTree(tokens, n - 2);
    TreeNode* p = findNode(root, pVal);
    TreeNode* q = findNode(root, qVal);
    printf("%d\n", lowestCommonAncestor(root, p, q)->val);
    return 0;
}
```
