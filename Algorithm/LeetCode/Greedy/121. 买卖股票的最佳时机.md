# [121. 买卖股票的最佳时机](https://leetcode.cn/problems/best-time-to-buy-and-sell-stock/)

- 🟢 **难度**：简单
- 🤑 **分类**：贪心算法
- 🏷️ **标签**：`数组`、`动态规划`

## 题目描述

给定一个数组 `prices` ，它的第 `i` 个元素 `prices[i]` 表示一支给定股票第 `i` 天的价格。

你只能选择 **某一天** 买入这只股票，并选择在 **未来的某一个不同的日子** 卖出该股票。设计一个算法来计算你所能获取的最大利润。

返回你可以从这笔交易中获取的最大利润。如果你不能获取任何利润，返回 `0` 。

**示例 1：**

```
输入：[7,1,5,3,6,4]
输出：5
解释：在第 2 天（股票价格 = 1）的时候买入，在第 5 天（股票价格 = 6）的时候卖出，最大利润 = 6-1 = 5 。
     注意利润不能是 7-1 = 6, 因为卖出价格需要大于买入价格；同时，你不能在买入前卖出股票。
```

**示例 2：**

```
输入：prices = [7,6,4,3,1]
输出：0
解释：在这种情况下, 没有交易完成, 所以最大利润为 0。
```

**提示：**
- `1 <= prices.length <= 10^5`
- `0 <= prices[i] <= 10^4`

## 题解一：暴力枚举

枚举所有买入日 `i` 与卖出日 `j`（`j > i`），用 `prices[j] - prices[i]` 更新答案。

- 时间复杂度：`O(n^2)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int maxProfit(int[] prices) {
        int maxProfit = 0;
        for (int i = 0; i < prices.length; i++) {
            for (int j = i + 1; j < prices.length; j++) {
                maxProfit = Math.max(maxProfit, prices[j] - prices[i]);
            }
        }
        return maxProfit;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] prices = new int[n];
        for (int i = 0; i < n; i++) {
            prices[i] = sc.nextInt();
        }
        System.out.println(new Solution().maxProfit(prices));
        sc.close();
    }
}
```

import sys
from typing import List


class Solution:
    def maxProfit(self, prices: List[int]) -> int:
        max_profit = 0
        for i in range(len(prices)):
            for j in range(i + 1, len(prices)):
                max_profit = max(max_profit, prices[j] - prices[i])
        return max_profit

int maxProfit(int* prices, int pricesSize) {

## 题解二：一次遍历（贪心，维护历史最低价）

最大利润 `max(prices[j] - prices[i])`（`i < j`）可改写为：固定卖出日 `j`，减数取 `[0..j]` 内的最低价，即 `max over j ( prices[j] - min(prices[0..j]) )`。

于是只需一次遍历，用 `minPrice` 记录「历史最低买入价」；遍历到当天时：

- 若当天价格更低，则更新 `minPrice`（应当在这天买入）
- 否则用 `prices[j] - minPrice` 更新最大利润（假想在这天卖出）

因为卖出一定在买入之后，而 `minPrice` 只来自当前天及之前，所以方案天然合法。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int maxProfit(int[] prices) {
        int minPrice = Integer.MAX_VALUE;
        int maxProfit = 0;
        for (int price : prices) {
            if (price < minPrice) {
                minPrice = price;               // 更新历史最低买入价
            } else if (price - minPrice > maxProfit) {
                maxProfit = price - minPrice;   // 假想当天卖出
            }
        }
        return maxProfit;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] prices = new int[n];
        for (int i = 0; i < n; i++) {
            prices[i] = sc.nextInt();
        }
        System.out.println(new Solution().maxProfit(prices));
        sc.close();
    }
}
```
