# [55. 跳跃游戏](https://leetcode.cn/problems/jump-game/)

- 🟡 **难度**：中等
- 🤑 **分类**：贪心算法
- 🏷️ **标签**：`贪心`、`数组`、`动态规划`

## 题目描述

给你一个非负整数数组 `nums` ，你最初位于数组的 **第一个下标** 。数组中的每个元素代表你在该位置可以跳跃的最大长度。

判断你是否能够到达最后一个下标，如果可以，返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入：nums = [2,3,1,1,4]
输出：true
解释：可以先跳 1 步，从下标 0 到达下标 1, 然后再从下标 1 跳 3 步到达最后一个下标。
```

**示例 2：**

```
输入：nums = [3,2,1,0,4]
输出：false
解释：无论怎样，总会到达下标为 3 的位置。但该下标的最大跳跃长度是 0 ， 所以永远不可能到达最后一个下标。
```

**提示：**
- `1 <= nums.length <= 10^4`
- `0 <= nums[i] <= 10^5`

## 题解一：贪心（维护最远可达下标）

不要纠结"这一步该跳多远"，只需回答一个问题：**用走过的位置，最远能覆盖到哪个下标？**

设 `reach` 为目前能到达的最远下标。逐个扫描 `i`：

- 若 `i > reach`，说明 `i` 之前的任何位置都够不到 `i`，于是后面的位置更够不到，直接返回 `false`；
- 否则把 `i` 的最远能力并入边界：`reach = max(reach, i + nums[i])`；
- 一旦 `reach >= n - 1`，已能覆盖终点，提前返回 `true`。

正确性依赖一个单调性：能到达 `p` 就能到达任意 `0..p`（跳跃长度可取 `0..nums[i]` 的连续值），因此"边界之内全部可达"成立，贪心不会漏解。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public boolean canJump(int[] nums) {
        int reach = 0;                          // 目前能到达的最远下标
        for (int i = 0; i < nums.length; i++) {
            if (i > reach) {
                return false;                   // 下标 i 断不可达
            }
            reach = Math.max(reach, i + nums[i]);
            if (reach >= nums.length - 1) {
                return true;                    // 已能覆盖终点
            }
        }
        return true;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().canJump(nums) ? "true" : "false");
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def canJump(self, nums: List[int]) -> bool:
        reach = 0                           # 目前能到达的最远下标
        for i, jump in enumerate(nums):
            if i > reach:
                return False                # 下标 i 断不可达
            reach = max(reach, i + jump)
            if reach >= len(nums) - 1:
                return True                 # 已能覆盖终点
        return True


if __name__ == "__main__":
    # ACM 输入：第一行 n，第二行 n 个整数
    data = sys.stdin.read().split()
    n = int(data[0])
    nums = [int(x) for x in data[1:1 + n]]
    print("true" if Solution().canJump(nums) else "false")
```

### ⚙️ C

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>

bool canJump(int* nums, int numsSize) {
    int reach = 0;                              // 目前能到达的最远下标
    for (int i = 0; i < numsSize; i++) {
        if (i > reach) {
            return false;                       // 下标 i 断不可达
        }
        if (i + nums[i] > reach) {
            reach = i + nums[i];
        }
        if (reach >= numsSize - 1) {
            return true;                        // 已能覆盖终点
        }
    }
    return true;
}

int main(void) {
    // ACM 输入：第一行 n，第二行 n 个整数
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int* nums = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &nums[i]);
    }
    printf("%s\n", canJump(nums, n) ? "true" : "false");
    free(nums);
    return 0;
}
```

## 题解二：反向贪心（从终点回推）

换个方向思考：与其从起点往前推"最远能到哪"，不如从终点往回找"**能到达当前目标的最左起点**"。

维护 `lastPos`（当前需要被到达的目标下标，初值 `n - 1`），从 `n - 2` 向左扫描：

- 若 `i + nums[i] >= lastPos`，说明从 `i` 一步（直接或经由更右的可达点）能到达目标，于是目标前移：`lastPos = i`；
- 扫描结束，若 `lastPos == 0`，说明能由起点一路回推到终点，返回 `true`。

每一步都取"最左能满足条件的起点"，把目标尽可能前移，因此不会错过任何可行解。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public boolean canJump(int[] nums) {
        int lastPos = nums.length - 1;          // 当前需要被到达的目标下标
        for (int i = nums.length - 2; i >= 0; i--) {
            if (i + nums[i] >= lastPos) {
                lastPos = i;                    // i 能到达目标，目标前移
            }
        }
        return lastPos == 0;                    // 能一路回推到起点
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] nums = new int[n];
        for (int i = 0; i < n; i++) {
            nums[i] = sc.nextInt();
        }
        System.out.println(new Solution().canJump(nums) ? "true" : "false");
        sc.close();
    }
}
```
