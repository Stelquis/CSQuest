# [763. 划分字母区间](https://leetcode.cn/problems/partition-labels/)

- 🟡 **难度**：中等
- 🤑 **分类**：贪心算法
- 🏷️ **标签**：`贪心`、`哈希表`、`双指针`、`字符串`

## 题目描述

给你一个字符串 `s` 。我们要把这个字符串划分为尽可能多的片段，同一字母最多出现在一个片段中。例如，字符串 `"ababcc"` 能够被分为 `["abab", "cc"]`，但类似 `["aba", "bcc"]` 或 `["ab", "ab", "cc"]` 的划分是非法的。

注意，划分结果需要满足：将所有划分结果按顺序连接，得到的字符串仍然是 `s` 。

返回一个表示每个字符串片段的长度的列表。

**示例 1：**

```
输入：s = "ababcbacadefegdehijhklij"
输出：[9,7,8]
解释：
划分结果为 "ababcbaca"、"defegde"、"hijhklij" 。
每个字母最多出现在一个片段中。
像 "ababcbacadefegde", "hijhklij" 这样的划分是错误的，因为划分的片段数较少。 
```

**示例 2：**

```
输入：s = "eccbbbbdec"
输出：[10]
```

**提示：**
- `1 <= s.length <= 500`
- `s` 仅由小写英文字母组成

## 题解一：贪心（一次遍历 + 最远边界）

要让片段尽量多，就要让每个片段**尽量短**，但同一个字母必须落在同一个片段里。于是对当前片段有一个硬约束：它的右边界至少要到片段内所有字母**最后出现位置**的最大值。

做法分两步：

1. 先扫一遍，用 `last[26]` 记录每个字母**最后出现**的下标。
2. 再扫一遍，维护当前片段的起点 `start` 与最远边界 `end`。每遇到一个字符就扩张边界 `end = max(end, last[c])`；当 `i == end` 时，说明 `[start, i]` 内出现的所有字母都已经收齐（不会在更后面再出现），可以在此切分，记下长度 `i - start + 1`，并把 `start` 移到 `i + 1`。

因为边界只增不减，且每次都在"最早可切"的位置切，故片段数最多。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，`last` 数组大小为字符集 26

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] last = new int[26];               // last[c] = 字母 c 最后出现的下标
        for (int i = 0; i < s.length(); i++) {
            last[s.charAt(i) - 'a'] = i;
        }
        List<Integer> ans = new ArrayList<>();
        int start = 0;
        int end = 0;
        for (int i = 0; i < s.length(); i++) {
            end = Math.max(end, last[s.charAt(i) - 'a']);   // 扩张当前片段右边界
            if (i == end) {                     // 片段内字母均已收齐，可以切分
                ans.add(end - start + 1);
                start = i + 1;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串 s
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        List<Integer> ans = new Solution().partitionLabels(s);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < ans.size(); i++) {
            if (i > 0) {
                sb.append(' ');
            }
            sb.append(ans.get(i));
        }
        System.out.println(sb);
        sc.close();
    }
}
```

## 题解二：区间合并

换个角度看：每个字母 `c` 定义了一个区间 `[first[c], last[c]]`（首次出现到末次出现）。原问题等价于——把所有这些区间**合并**成互不相交的若干区间，合并后每个区间的长度就是一个片段长度。

因为"同一字母只出现在一个片段"要求该字母的整个区间落在同一片段内，所以只要两个字母的区间有交叠（或包含），就必须合并。

做法：

1. 记录每个字母的 `first` 与 `last`，得到若干区间；
2. 按起点升序排序；
3. 依次合并：若下一个区间起点 `<=` 当前合并区间的终点，则合并（`end = max(end, last)`）；否则结算当前区间长度并开启新区间。

- 时间复杂度：`O(n + 26 log 26)`，排序开销相对字符集是常数
- 空间复杂度：`O(1)`，最多 26 个区间

**实现提示**：各语言都自带"首次/末次出现"的查询，无需手写哈希表——Java `s.indexOf(c)` / `s.lastIndexOf(c)`（找不到返回 `-1`），Python `s.find(c)` / `s.rfind(c)`，C++ `s.find(c)` / `s.rfind(c)`（找不到为 `npos`），C `strchr` / `strrchr`（返回指针，找不到为 `NULL`）。注意只对**出现过**的字母建区间，未出现的字母要跳过（排序后它们的 `first = -1` 会堆在最前面）。

**易错点**：合并是"遇到断点才结算"，所以**循环结束后必须补收最后一组区间**——最后一组没有断点，极易漏掉。例如只含单个字母时一个断点都没有，会直接返回空列表。

### ☕ Java

```java
import java.util.ArrayList;
import java.util.Arrays;
import java.util.List;
import java.util.Scanner;

public class Solution {
    public List<Integer> partitionLabels(String s) {
        int[] first = new int[26];
        int[] last = new int[26];
        Arrays.fill(first, -1);
        for (int i = 0; i < s.length(); i++) {
            int c = s.charAt(i) - 'a';
            if (first[c] == -1) {
                first[c] = i;                    // 记录首次出现位置
            }
            last[c] = i;                         // 记录末次出现位置
        }
        int[][] intervals = new int[26][2];      // 每个字母对应区间 [first, last]
        int m = 0;
        for (int c = 0; c < 26; c++) {
            if (first[c] != -1) {
                intervals[m][0] = first[c];
                intervals[m][1] = last[c];
                m++;
            }
        }
        Arrays.sort(intervals, 0, m, (a, b) -> a[0] - b[0]);   // 按起点升序
        List<Integer> ans = new ArrayList<>();
        int start = intervals[0][0];
        int end = intervals[0][1];
        for (int i = 1; i < m; i++) {
            if (intervals[i][0] <= end) {        // 与当前区间交叠，合并
                end = Math.max(end, intervals[i][1]);
            } else {                             // 不交叠，结算当前片段
                ans.add(end - start + 1);
                start = intervals[i][0];
                end = intervals[i][1];
            }
        }
        ans.add(end - start + 1);
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串 s
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        List<Integer> ans = new Solution().partitionLabels(s);
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < ans.size(); i++) {
            if (i > 0) {
                sb.append(' ');
            }
            sb.append(ans.get(i));
        }
        System.out.println(sb);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def partitionLabels(self, s: str) -> List[int]:
        first = {}
        last = {}
        for i, c in enumerate(s):
            if c not in first:
                first[c] = i                     # 记录首次出现位置
            last[c] = i                          # 记录末次出现位置
        intervals = sorted((first[c], last[c]) for c in first)   # 按起点升序
        ans = []
        start, end = intervals[0]
        for f, l in intervals[1:]:
            if f <= end:                         # 交叠，合并
                end = max(end, l)
            else:                                # 不交叠，结算当前片段
                ans.append(end - start + 1)
                start, end = f, l
        ans.append(end - start + 1)
        return ans


if __name__ == "__main__":
    # ACM 输入：一行字符串 s
    s = sys.stdin.read().strip()
    print(" ".join(map(str, Solution().partitionLabels(s))))
```

```cpp
#include <algorithm>
#include <string>
#include <utility>
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    vector<int> partitionLabels(string s) {
        int first[26], last[26];
        for (int c = 0; c < 26; c++) {
            first[c] = -1;
            last[c] = -1;
        }
        for (int i = 0; i < (int)s.size(); i++) {
            int c = s[i] - 'a';
            if (first[c] == -1) {
                first[c] = i;                    // 记录首次出现位置
            }
            last[c] = i;                         // 记录末次出现位置
        }
        vector<pair<int, int>> intervals;
        for (int c = 0; c < 26; c++) {
            if (first[c] != -1) {
                intervals.push_back({first[c], last[c]});
            }
        }
        sort(intervals.begin(), intervals.end());   // 按起点升序
        vector<int> ans;
        int start = intervals[0].first;
        int end = intervals[0].second;
        for (size_t i = 1; i < intervals.size(); i++) {
            if (intervals[i].first <= end) {         // 交叠，合并
                end = max(end, intervals[i].second);
            } else {                                 // 不交叠，结算当前片段
                ans.push_back(end - start + 1);
                start = intervals[i].first;
                end = intervals[i].second;
            }
        }
        ans.push_back(end - start + 1);
        return ans;
    }
};

int main() {
    // ACM 输入：一行字符串 s
    string s;
    cin >> s;
    vector<int> ans = Solution().partitionLabels(s);
    for (size_t i = 0; i < ans.size(); i++) {
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

typedef struct {
    int first;
    int last;
} Interval;

static int cmpInterval(const void* a, const void* b) {
    const Interval* x = (const Interval*)a;
    const Interval* y = (const Interval*)b;
    return x->first - y->first;
}

int* partitionLabels(char* s, int* returnSize) {
    int first[26], last[26];
    for (int c = 0; c < 26; c++) {
        first[c] = -1;
        last[c] = -1;
    }
    int n = (int)strlen(s);
    for (int i = 0; i < n; i++) {
        int c = s[i] - 'a';
        if (first[c] == -1) {
            first[c] = i;                        // 记录首次出现位置
        }
        last[c] = i;                             // 记录末次出现位置
    }
    Interval* iv = (Interval*)malloc(26 * sizeof(Interval));
    int m = 0;
    for (int c = 0; c < 26; c++) {
        if (first[c] != -1) {
            iv[m].first = first[c];
            iv[m].last = last[c];
            m++;
        }
    }
    qsort(iv, m, sizeof(Interval), cmpInterval);  // 按起点升序
    int* ans = (int*)malloc(n * sizeof(int));
    int cnt = 0;
    int start = iv[0].first;
    int end = iv[0].last;
    for (int i = 1; i < m; i++) {
        if (iv[i].first <= end) {                // 交叠，合并
            if (iv[i].last > end) {
                end = iv[i].last;
            }
        } else {                                 // 不交叠，结算当前片段
            ans[cnt++] = end - start + 1;
            start = iv[i].first;
            end = iv[i].last;
        }
    }
    ans[cnt++] = end - start + 1;
    free(iv);
    *returnSize = cnt;
    return ans;
}

int main(void) {
    // ACM 输入：一行字符串 s
    char s[505];
    if (scanf("%504s", s) != 1) {
        return 0;
    }
    int size = 0;
    int* ans = partitionLabels(s, &size);
    for (int i = 0; i < size; i++) {
        if (i) printf(" ");
        printf("%d", ans[i]);
    }
    printf("\n");
    free(ans);
    return 0;
}
```
