# [5. 最长回文子串](https://leetcode.cn/problems/longest-palindromic-substring/)

- 🟡 **难度**：中等
- 🗺️ **分类**：多维动态规划
- 🏷️ **标签**：`双指针`、`字符串`、`动态规划`、`Manacher 算法`

## 题目描述

给你一个字符串 `s`，找到 `s` 中最长的 回文 子串。

**示例 1：**

```
输入：s = "babad"
输出："bab"
解释："aba" 同样是符合题意的答案。
```

**示例 2：**

```
输入：s = "cbbd"
输出："bb"
```

**提示：**

- `1 <= s.length <= 1000`
- `s` 仅由数字和英文字母组成

## 思路辨析：为什么 62/64 的网格模板搬不动，以及区间 DP 的引入

62/64 的状态 `dp[i][j]` 依赖"上方/左方"，行列扫描即拓扑序。但"回文子串"由**两个端点共同确定**——状态必须同时携带起点 `i` 和终点 `j`，这便是区间 DP：

- `dp[i][j]` = `s[i..j]`（闭区间）**是否是回文**（boolean 可行性）
- 为什么不直接存"最长回文长度"：`s[i] != s[j]` 时，`s[i..j]` 的最长回文可能藏在任意内部位置，转移断裂；而"是否回文"有漂亮的递归定义——**状态定义选错，转移就死了**（与 139 的"枚举最后一枚"同级经验）
- 转移：`dp[i][j] = (s[i] == s[j]) && dp[i+1][j-1]`——两头相等 + 撕掉两头后仍是回文（回文定义本身是递归的）
- 基准：长度 1 全真；长度 2 看两端相等（`dp[i+1][j-1]` 的空区间公式未覆盖）
- **填表顺序是最大的坑**：依赖 `dp[i+1][j-1]` 位于"右下方"（行大、列小），既不在上方也不在左方——拓扑序按**区间长度递增**分层（DAG 思想的第三次应用），或等价地 `i` 降序、`j` 升序扫描

## 题解一：区间 DP（O(n²) 时间 / O(n²) 空间）

三个易错点（都踩过）：

1. **填表顺序**：`i` 升序会用到还没填的第 `i+1` 行，真回文被误判为非回文。反例 `"abcba"`：算 `(0,4)` 时 `dp[1][3]` 还是 0，整串被漏 → `i` 必须**降序**（或按长度）；
2. **内层漏扫末列**：`j < n-1` 导致以最后一字符结尾的段永不计算，`"abcba"` 只剩 `"bcb"` → `j` 要扫到 `n-1`；
3. **答案差一**：`j-i` 是长度减 1，用 `j-i > max`（`max` 初值 1）会漏掉长度 2 的回文。反例 `"cbbd"` → 返回 `"c"` 而非 `"bb"` → 按长度 `j-i+1` 比较。

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(n²)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) {
            return s; // 空串/单字符
        }
        // dp[i][j]：s[i..j]（闭区间）是否回文（1/0）
        int[][] dp = new int[n][n];
        for (int i = 0; i < n; i++) {
            dp[i][i] = 1; // 长度 1
        }
        for (int i = n - 2; i >= 0; i--) {      // 起点降序：右下行先就绪
            for (int j = i + 1; j < n; j++) {   // 扫到最后一列
                if (s.charAt(i) == s.charAt(j)) {
                    dp[i][j] = (j - i == 1) ? 1 : dp[i + 1][j - 1];
                }
            }
        }
        int max = 1, l = 0, r = 0;
        for (int i = 0; i < n; i++) {
            for (int j = i; j < n; j++) {
                if (dp[i][j] == 1 && j - i + 1 > max) { // 按长度比较
                    max = j - i + 1;
                    l = i;
                    r = j;
                }
            }
        }
        return s.substring(l, r + 1); // 左闭右开，+1 补回右端点
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestPalindrome(s));
        sc.close();
    }
}
```

## 题解二：中心扩展（O(n²) 时间 / O(1) 空间）

换视角：**每个回文都由一个中心决定**。奇数长度回文的中心是一个字符（n 个），偶数长度回文的中心是字符间的缝隙（n-1 个），合计 `2n-1` 个中心。枚举每个中心向两边扩展到不能扩，取最长。

对比 DP 的优势：不建表、没有填表顺序的坑、空间 O(1)、常数更小——力扣 5 的标准实践。时间仍 O(n²)（最坏 `"aaaa…a"`）。

实现细节：

- `expand(i, j)` 从 `(i, j)` 向两侧扩，循环结束时**多扩了一步**，长度为 `j - i - 1`；
- 由"中心 + 长度"反推端点：`l = c - (len-1)/2`，`r = c + len/2`（整数除法天然兼容奇偶两种中心）；
- Java `substring(l, r+1)` 左闭右开；C++ `substr(l, len)` 第二参是**长度**——两个语言在此最易混。

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public String longestPalindrome(String s) {
        int n = s.length();
        if (n < 2) {
            return s;
        }
        int l = 0, r = 0;
        for (int c = 0; c < n; c++) {
            int len = Math.max(expand(s, c, c), expand(s, c, c + 1)); // 奇/偶中心
            if (len > r - l + 1) {
                l = c - (len - 1) / 2; // 由中心+长度反推端点（兼容奇偶）
                r = c + len / 2;
            }
        }
        return s.substring(l, r + 1);
    }

    // 从 (i, j) 向两侧扩展，返回回文长度（多扩一步，减回）
    public static int expand(String s, int i, int j) {
        while (i >= 0 && j < s.length() && s.charAt(i) == s.charAt(j)) {
            i--;
            j++;
        }
        return j - i - 1;
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestPalindrome(s));
        sc.close();
    }
}
```

## 题解三：Manacher 算法（O(n) 时间 / O(n) 空间）

理论天花板，两步核心：

1. **统一奇偶**：插入分隔符 `#`（`"abba"` → `"#a#b#b#a#"`），所有回文变成**奇数长度**，只需处理一种中心；
2. **镜面复用**：维护当前"右伸最远"的回文（中心 `center`、右边界 `right`）。处理 `i < right` 时，其关于 `center` 的镜像位置 `2*center - i` 的半径已知，直接抄 `min(p[mirror], right - i)` 作起点，再尝试向外扩展。每个位置至多被扩展 O(1) 次 → 均摊 O(n)。

结论换算：`p[i]`（新串中的回文半径）恰等于**原串中该回文的长度**；原串起点 = `(i - p[i]) / 2`。

补充两条视野：区间 DP 还可沿对角线滚动压到 O(n) 空间（时间仍 O(n²)，练习价值大于实用）；另有哈希 + 二分答案长度的 O(n log n) 思路（答案长度有单调性：长回文存在 ⇒ 更短的也存在）。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public String longestPalindrome(String s) {
        int len = s.length();
        if (len < 2) {
            return s;
        }
        // 预处理：插入 '#'，统一奇偶
        char[] t = new char[2 * len + 1];
        t[0] = '#';
        for (int i = 0; i < len; i++) {
            t[2 * i + 1] = s.charAt(i);
            t[2 * i + 2] = '#';
        }
        int n = t.length;
        int[] p = new int[n];      // p[i]：以 t[i] 为中心的最大回文半径
        int center = 0, right = 0; // 右伸最远的回文：中心与右边界（含）
        int bestLen = 0, bestC = 0;
        for (int i = 0; i < n; i++) {
            int mirror = 2 * center - i;
            if (i < right) {
                p[i] = Math.min(p[mirror], right - i); // 镜面抄答案作起点
            }
            // 尝试继续向外扩展
            while (i - p[i] - 1 >= 0 && i + p[i] + 1 < n
                    && t[i - p[i] - 1] == t[i + p[i] + 1]) {
                p[i]++;
            }
            if (i + p[i] > right) { // 更新右伸最远
                center = i;
                right = i + p[i];
            }
            if (p[i] > bestLen) { // p[i] 恰为原串中该回文的长度
                bestLen = p[i];
                bestC = i;
            }
        }
        int start = (bestC - bestLen) / 2;
        return s.substring(start, start + bestLen);
    }

    public static void main(String[] args) {
        // ACM 输入：一行字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestPalindrome(s));
        sc.close();
    }
}
```

```c
char* longestPalindrome(const char* s) {
    int len = strlen(s);
    if (len < 2) {
        char* out = (char*)malloc(len + 1);
        strcpy(out, s);
        return out;
    }
    // 预处理：插入 '#'，统一奇偶
    int n = 2 * len + 1;
    char* t = (char*)malloc(n + 1);
    t[0] = '#';
    for (int i = 0; i < len; i++) {
        t[2 * i + 1] = s[i];
        t[2 * i + 2] = '#';
    }
    t[n] = '\0';
    int* p = (int*)calloc(n, sizeof(int)); // p[i]：最大回文半径
    int center = 0, right = 0;
    int bestLen = 0, bestC = 0;
    for (int i = 0; i < n; i++) {
        int mirror = 2 * center - i;
        if (i < right) {
            int a = p[mirror], b = right - i;
            p[i] = a < b ? a : b; // 镜面抄答案作起点
        }
        // 尝试继续向外扩展
        while (i - p[i] - 1 >= 0 && i + p[i] + 1 < n
                && t[i - p[i] - 1] == t[i + p[i] + 1]) {
            p[i]++;
        }
        if (i + p[i] > right) { // 更新右伸最远
            center = i;
            right = i + p[i];
        }
        if (p[i] > bestLen) { // p[i] 恰为原串中该回文的长度
            bestLen = p[i];
            bestC = i;
        }
    }
    int start = (bestC - bestLen) / 2;
    char* out = (char*)malloc(bestLen + 1);
    memcpy(out, s + start, bestLen);
    out[bestLen] = '\0';
    free(p);
    free(t);
    return out;
}

int main(void) {
    // ACM 输入：一行字符串
    char* s = (char*)malloc(2000);
    if (scanf("%s", s) != 1) {
        s[0] = '\0'; // 空输入按空串处理
    }
    char* ans = longestPalindrome(s);
    printf("%s\n", ans);
    free(ans);
    free(s);
    return 0;
}
```
