# [62. 不同路径](https://leetcode.cn/problems/unique-paths/)

- 🟡 **难度**：中等
- 🗺️ **分类**：多维动态规划
- 🏷️ **标签**：`数学`、`动态规划`、`组合数学`

## 题目描述

一个机器人位于一个 `m x n` 网格的左上角 （起始点在下图中标记为 “Start” ）。

机器人每次只能向下或者向右移动一步。机器人试图达到网格的右下角（在下图中标记为 “Finish” ）。

问总共有多少条不同的路径？

**示例 1：**

![](https://pic.leetcode.cn/1697422740-adxmsI-image.png)

```
输入：m = 3, n = 7
输出：28
```

**示例 2：**

```
输入：m = 3, n = 2
输出：3
解释：
从左上角开始，总共有 3 条路径可以到达右下角。
1. 向右 -> 向下 -> 向下
2. 向下 -> 向下 -> 向右
3. 向下 -> 向右 -> 向下
```

**示例 3：**

```
输入：m = 7, n = 3
输出：28
```

**示例 4：**

```
输入：m = 3, n = 3
输出：6
```

**提示：**
- `1 <= m, n <= 100`
- 题目数据保证答案小于等于 `2 * 10^9`

## 题解一：动态规划·二维（O(m·n)）

网格 DP 的入门模板。状态定义与转移：

- `dp[i][j]` = 从起点 `(0,0)` 走到 `(i,j)` 的不同路径数
- 只能向右或向下 → `(i,j)` 只能从**上方**或**左方**走来：`dp[i][j] = dp[i-1][j] + dp[i][j-1]`
- 边界：首行、首列全为 1（只有一条直路），`dp[0][0] = 1`

转移是"加法汇聚"而非取最值/可达性——两个依赖方向相反却**都要取**（旧值 + 新值一起加），所以一维化时升序扫描恰好正确（与 0/1 背包"只读旧值须倒序"形成对照：这里 `dp[j]` 的旧值当"上方"、新写的当"左方"，各取所需）。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m·n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int uniquePaths(int m, int n) {
        int[][] dp = new int[m][n];
        for (int i = 0; i < m; i++) {
            dp[i][0] = 1; // 首列：只有一路直下
        }
        for (int j = 0; j < n; j++) {
            dp[0][j] = 1; // 首行：只有一路直右
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = dp[i - 1][j] + dp[i][j - 1]; // 上方 + 左方
            }
        }
        return dp[m - 1][n - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：两个整数 m 和 n
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        System.out.println(new Solution().uniquePaths(m, n));
        sc.close();
    }
}
```

int uniquePaths(int m, int n) {

## 题解二：一维滚动数组（O(m·n) 时间 / O(n) 空间）

转移只依赖上一行（`dp[i-1][j]`）与同一行左列（`dp[i][j-1]`）→ 压掉行维度。一行数组滚动：更新 `dp[j]` 前它存的是上一行的值（当"上方"用），`dp[j-1]` 已是本行新值（当"左方"用）——**升序扫描恰好各取所需**，无需倒序。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Solution {
    public int uniquePaths(int m, int n) {
        int[] dp = new int[n];
        Arrays.fill(dp, 1); // 首行全 1
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[j] += dp[j - 1]; // 旧 dp[j]=上方，新 dp[j-1]=左方
            }
        }
        return dp[n - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：两个整数 m 和 n
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        System.out.println(new Solution().uniquePaths(m, n));
        sc.close();
    }
}
```

## 题解三：组合数学（O(min(m,n)) 时间 / O(1) 空间）

把走法翻译成计数问题：从起点到终点**必须**走 `m-1` 步下、`n-1` 步右，共 `m+n-2` 步——每条路径就是这串步骤的一个排列，路径数 = 在 `m+n-2` 个位置中选出 `m-1` 个"下"的方案数：

```
C(m+n-2, m-1)
```

计算用逐项乘除（`ans = ans * (total-k+i) / i`，`k = min(m,n)-1`）而非先算阶乘再相除——每一步中间结果都是真实的二项式系数 `C(total-k+i, i)`，**沿对角线单调递增、不超过最终答案**，配合题目"答案 ≤ 2×10⁹"的保证全程不溢出，且整除天然精确。

- 时间复杂度：`O(min(m,n))`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int uniquePaths(int m, int n) {
        int k = Math.min(m, n) - 1;   // 选"下"步数较少的一侧，减少乘除次数
        int total = m + n - 2;        // 总步数
        long ans = 1;
        for (int i = 1; i <= k; i++) {
            ans = ans * (total - k + i) / i; // 中间值是真实二项式系数，不溢出
        }
        return (int) ans;
    }

    public static void main(String[] args) {
        // ACM 输入：两个整数 m 和 n
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        System.out.println(new Solution().uniquePaths(m, n));
        sc.close();
    }
}
```
