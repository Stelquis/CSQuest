# [1143. 最长公共子序列](https://leetcode.cn/problems/longest-common-subsequence/)

- 🟡 **难度**：中等
- 🗺️ **分类**：多维动态规划
- 🏷️ **标签**：`字符串`、`动态规划`、`最长公共子序列`

## 题目描述

给定两个字符串 `text1` 和 `text2`，返回这两个字符串的最长 **公共子序列** 的长度。如果不存在 **公共子序列** ，返回 `0` 。

一个字符串的 **子序列** 是指这样一个新的字符串：它是由原字符串在不改变字符的相对顺序的情况下删除某些字符（也可以不删除任何字符）后组成的新字符串。
- 例如，`"ace"` 是 `"abcde"` 的子序列，但 `"aec"` 不是 `"abcde"` 的子序列。

两个字符串的 **公共子序列** 是这两个字符串所共同拥有的子序列。

**示例 1：**

```
输入：text1 = "abcde", text2 = "ace" 
输出：3  
解释：最长公共子序列是 "ace" ，它的长度为 3 。
```

**示例 2：**

```
输入：text1 = "abc", text2 = "abc"
输出：3
解释：最长公共子序列是 "abc" ，它的长度为 3 。
```

**示例 3：**

```
输入：text1 = "abc", text2 = "def"
输出：0
解释：两个字符串没有公共子序列，返回 0 。
```

**提示：**
- `1 <= text1.length, text2.length <= 1000`
- `text1` 和 `text2` 仅由小写英文字符组成。

## 思路辨析：双串前缀状态 + 盯"最后一对字符"

与 5 对照：区间 DP 的状态是"子串的两端"，这里是"**两个串各自考虑到哪**"——双前缀。转移依旧走 139 的老套路"盯最后一枚"：

- `dp[i][j]` = `text1` **前 i 个字符**与 `text2` **前 j 个字符**的 LCS 长度（前缀形式，天然覆盖空串）
- 末尾字符相等（`t1[i-1] == t2[j-1]`）：这对字符放进 LCS 末尾**不亏**（任何不用它的最优解都能等价替换成用它）→ `dp[i][j] = dp[i-1][j-1] + 1`
- 不等：两者至少一个不在末尾，放弃其一 → `dp[i][j] = max(dp[i-1][j], dp[i][j-1])`
- 基准：空串与任何串 LCS 为 0；依赖是**左上三格** `(i-1,j-1)、(i-1,j)、(i,j-1)`，行升序、列升序即拓扑序——**没有 5 那种"右下方"的坑**

踩过的坑：边界初始化必须带**前缀继承**语义。首列 `dp[i][0]` 是"`text2[0]` 在 `text1` 前 i+1 个字符中出现过没有"——一旦匹配就恒为 1，写成"只看第 i 位是否相等"会把它清零（反例 `"ab"` × `"a"` 得 0，正确 1）。

## 题解一：哨兵版（(m+1)×(n+1)，标准骨架，O(m·n)）

数组多开一行一列，**第 0 行/列代表空串**（全 0，天然免写），转移从 `(1,1)` 开始。"空串什么都没匹配过"让边界继承被统一进转移方程——这正是 139/152/背包压维里"加哨兵简化边界"的同一思想，也是 72 编辑距离等一切"前缀 × 前缀"双串 DP 的通用骨架。

易错点：尺寸 +1 与字符下标 `i-1 / j-1` **必须成对修改**——只扩数组不减下标（或反之）都会错位。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m·n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        // dp[i][j]：t1 前 i 个字符 × t2 前 j 个字符的 LCS
        // 第 0 行/列为空串基准（Java 数组默认全 0）
        int[][] dp = new int[m + 1][n + 1];
        for (int i = 1; i <= m; i++) {
            for (int j = 1; j <= n; j++) {
                if (text1.charAt(i - 1) == text2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;                 // 末尾配上
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]); // 放弃其一
                }
            }
        }
        return dp[m][n];
    }

    public static void main(String[] args) {
        // ACM 输入：两行，各一个字符串
        Scanner sc = new Scanner(System.in);
        String text1 = sc.nextLine().trim();
        String text2 = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestCommonSubsequence(text1, text2));
        sc.close();
    }
}
```

```python
class Solution:
    def longestCommonSubsequence(self, text1: str, text2: str) -> int:

        # dp[i][j]：t1 前 i 个 × t2 前 j 个的 LCS；第 0 行/列为空串基准
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int longestCommonSubsequence(char* text1, char* text2) {
    int m = strlen(text1), n = strlen(text2);
    // dp[i][j]：t1 前 i 个 × t2 前 j 个的 LCS；第 0 行/列为空串基准
    int** dp = (int**)calloc(m + 1, sizeof(int*));
    for (int i = 0; i <= m; i++) {
        dp[i] = (int*)calloc(n + 1, sizeof(int));
    }
    for (int i = 1; i <= m; i++) {
        for (int j = 1; j <= n; j++) {
            if (text1[i - 1] == text2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                int up = dp[i - 1][j], left = dp[i][j - 1];
                dp[i][j] = up > left ? up : left;
            }
        }
    }
    int ans = dp[m][n];
    for (int i = 0; i <= m; i++) {
        free(dp[i]);
    }
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：两行，各一个字符串
    char* text1 = (char*)malloc(2000);
    char* text2 = (char*)malloc(2000);
    if (scanf("%s %s", text1, text2) != 2) {
        printf("0\n");
        return 0;
    }
    printf("%d\n", longestCommonSubsequence(text1, text2));
    free(text1);
    free(text2);
    return 0;
}
```

## 题解二：首现位置版（m×n，边界用 indexOf，O(m·n)）

不加哨兵层，保留 `m × n` 数组，把边界的**前缀继承语义**显式写出来：`dp[0][j] = 1` 当且仅当 `text1[0]` 在 `text2` 中的**首次出现位置 ≤ j**（出现过就恒为 1），首列对称。Java 用 `indexOf`（-1 表示从未出现），Python 用 `find`，C++ 用 `string::find` + `npos`，C 用 `strchr` 返回的指针差。

与哨兵版数学等价（都补全了前缀语义），且利用了 LCS 边界值只能是 0/1 的特殊性。注意可扩展性差异：哨兵版是通用骨架（编辑距离的边界是 i、j 本身，首现位置特化写法就不适用）；实际刷题任选其一。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m·n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int longestCommonSubsequence(String text1, String text2) {
        int m = text1.length(), n = text2.length();
        int[][] dp = new int[m][n];

        // 首行：text1[0] 在 text2 中的首次出现位置 ≤ j → dp[0][j]=1
        int posInText2 = text2.indexOf(text1.charAt(0));
        if (posInText2 != -1) {
            for (int j = posInText2; j < n; j++) {
                dp[0][j] = 1;
            }
        }

        // 首列：text2[0] 在 text1 中的首次出现位置 ≤ i → dp[i][0]=1
        int posInText1 = text1.indexOf(text2.charAt(0));
        if (posInText1 != -1) {
            for (int i = posInText1; i < m; i++) {
                dp[i][0] = 1;
            }
        }

        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                if (text1.charAt(i) == text2.charAt(j)) {
                    dp[i][j] = dp[i - 1][j - 1] + 1;
                } else {
                    dp[i][j] = Math.max(dp[i - 1][j], dp[i][j - 1]);
                }
            }
        }
        return dp[m - 1][n - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：两行，各一个字符串
        Scanner sc = new Scanner(System.in);
        String text1 = sc.nextLine().trim();
        String text2 = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestCommonSubsequence(text1, text2));
        sc.close();
    }
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int longestCommonSubsequence(char* text1, char* text2) {
    int m = strlen(text1), n = strlen(text2);
    int** dp = (int**)calloc(m, sizeof(int*));
    for (int i = 0; i < m; i++) {
        dp[i] = (int*)calloc(n, sizeof(int));
    }

    // 首行：text1[0] 在 text2 中的首次出现位置 ≤ j → dp[0][j]=1
    char* hit = strchr(text2, text1[0]);
    if (hit != NULL) {
        for (int j = (int) (hit - text2); j < n; j++) {
            dp[0][j] = 1;
        }
    }

    // 首列：text2[0] 在 text1 中的首次出现位置 ≤ i → dp[i][0]=1
    hit = strchr(text1, text2[0]);
    if (hit != NULL) {
        for (int i = (int) (hit - text1); i < m; i++) {
            dp[i][0] = 1;
        }
    }

    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            if (text1[i] == text2[j]) {
                dp[i][j] = dp[i - 1][j - 1] + 1;
            } else {
                int up = dp[i - 1][j], left = dp[i][j - 1];
                dp[i][j] = up > left ? up : left;
            }
        }
    }
    int ans = dp[m - 1][n - 1];
    for (int i = 0; i < m; i++) {
        free(dp[i]);
    }
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：两行，各一个字符串
    char* text1 = (char*)malloc(2000);
    char* text2 = (char*)malloc(2000);
    if (scanf("%s %s", text1, text2) != 2) {
        printf("0\n");
        return 0;
    }
    printf("%d\n", longestCommonSubsequence(text1, text2));
    free(text1);
    free(text2);
    return 0;
}
```
