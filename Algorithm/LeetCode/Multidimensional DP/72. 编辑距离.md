# [72. 编辑距离](https://leetcode.cn/problems/edit-distance/)

- 🟡 **难度**：中等
- 🗺️ **分类**：多维动态规划
- 🏷️ **标签**：`字符串`、`动态规划`

## 题目描述

给你两个单词 `word1` 和 `word2`， *请返回将 `word1` 转换成 `word2` 所使用的最少操作数*  。

你可以对一个单词进行如下三种操作：
- 插入一个字符
- 删除一个字符
- 替换一个字符

**示例 1：**

```
输入：word1 = "horse", word2 = "ros"
输出：3
解释：
horse -> rorse (将 'h' 替换为 'r')
rorse -> rose (删除 'r')
rose -> ros (删除 'e')
```

**示例 2：**

```
输入：word1 = "intention", word2 = "execution"
输出：5
解释：
intention -> inention (删除 't')
inention -> enention (将 'i' 替换为 'e')
enention -> exention (将 'n' 替换为 'x')
exention -> exection (将 'n' 替换为 'c')
exection -> execution (插入 'u')
```

**提示：**
- `0 <= word1.length, word2.length <= 500`
- `word1` 和 `word2` 由小写英文字母组成

## 思路辨析：同 1143 的骨架，只换转移方程

状态定义与 1143 一字不差：`dp[i][j]` = `word1` **前 i 个字符**变成 `word2` **前 j 个字符**的最少操作数。区别只在转移——LSC 配"+1 取 max"，这里配"三种操作取 min"。

转移的推导靠**枚举最后一步**（"尾巴账本"）：最优方案的最后一步操作完成后，两个串的尾巴必然对齐，而尾巴的处理方式只有四种——

| 最后一步 | 尾巴处理 | 剩下子问题 | 式子 |
|---|---|---|---|
| 删 `t1` 尾巴 | `i` 退一格 | 前 i-1 × 前 j | `dp[i-1][j] + 1` |
| 插 `t2` 尾巴 | `j` 退一格 | 前 i × 前 j-1 | `dp[i][j-1] + 1` |
| 替换尾巴 | 双双退一格 | 前 i-1 × 前 j-1 | `dp[i-1][j-1] + 1` |
| 尾巴本就相等 | 双双退一格（免费） | 前 i-1 × 前 j-1 | `dp[i-1][j-1]` |

```
dp[i][j] = min(三操作 + 1 各自的子问题)     尾巴相等时另有免费分支 dp[i-1][j-1]
```

注意"插入"对应 `dp[i][j-1]` 最易混：新插的字符就是 `word2[j-1]` 本尊，补上后 `t2` 尾巴使命完成——**谁的尾巴被处理，谁的维度退一格**。

基准：哨兵语义下 `dp[0][j] = j`（空串 → 前 j 个字符：全插入）、`dp[i][0] = i`（→ 空串：全删除）——**边界是 i、j 本身，与字符比较无关**（对比 1143 边界是 0/1 可用首现位置特化，这里没有捷径）。

三个易错点（都踩过）：

1. **转移漏"替换"分支**：只写插/删时，`"ab"` → `"cd"` 只能得 3（正确 2，两次替换）——每个不匹配的字符对都需要"原地改写"选项；
2. **边界逐位比较字符**：`dp[2][0]`（`"aba"` → 空串）应为 2，"匹配到一次就停止累加"的写法会得 1——边界比较对象是**空串**，不存在字符匹配；
3. **返回 `dp[n-1][m-1]`**：哨兵版答案在右下角 `dp[n][m]`，少一圈等于"两串各扔一个字符"的距离（`"horse"/"ros"` 会返回 2 而非 3）。

## 题解一：哨兵版二维 DP（O(m·n) 时间 / 空间）

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m·n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        // dp[i][j]：word1 前 i 个字符 → word2 前 j 个字符的最少操作数
        // 哨兵版：第 0 行/列为空串基准
        int[][] dp = new int[n + 1][m + 1];
        for (int i = 0; i <= n; i++) {
            dp[i][0] = i; // → 空串：全删除
        }
        for (int j = 0; j <= m; j++) {
            dp[0][j] = j; // 空串 → ：全插入
        }
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[i][j] = dp[i - 1][j - 1];            // 尾巴免费对齐
                } else {
                    int replace = dp[i - 1][j - 1] + 1;     // 替换：双双退
                    int delete = dp[i - 1][j] + 1;          // 删除：i 退
                    int insert = dp[i][j - 1] + 1;          // 插入：j 退
                    dp[i][j] = Math.min(replace, Math.min(delete, insert));
                }
            }
        }
        return dp[n][m]; // 答案在哨兵右下角
    }

    public static void main(String[] args) {
        // ACM 输入：两行，各一个单词
        Scanner sc = new Scanner(System.in);
        String word1 = sc.nextLine().trim();
        String word2 = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().minDistance(word1, word2));
        sc.close();
    }
}
```

```python
import sys


class Solution:
    def minDistance(self, word1: str, word2: str) -> int:
        n, m = len(word1), len(word2)
        # dp[i][j]：word1 前 i 个 → word2 前 j 个的最少操作数；第 0 行/列为空串基准
        dp = [[0] * (m + 1) for _ in range(n + 1)]
        for i in range(n + 1):
            dp[i][0] = i  # → 空串：全删除
        for j in range(m + 1):
            dp[0][j] = j  # 空串 → ：全插入
        for i in range(1, n + 1):
            for j in range(1, m + 1):
                if word1[i - 1] == word2[j - 1]:
                    dp[i][j] = dp[i - 1][j - 1]  # 尾巴免费对齐
                else:

                                       dp[i - 1][j],       # 删除
                                       dp[i][j - 1])       # 插入
        return dp[n][m]
```

```cpp
#include <algorithm>

class Solution {
public:
    int minDistance(string word1, string word2) {

        vector<vector<int>> dp(n + 1, vector<int>(m + 1, 0));

            dp[0][j] = j; // 空串 → ：全插入
        }
        for (int i = 1; i <= n; i++) {
            for (int j = 1; j <= m; j++) {
                if (word1[i - 1] == word2[j - 1]) {
                    dp[i][j] = dp[i - 1][j - 1]; // 尾巴免费对齐
                } else {
                    dp[i][j] = 1 + min({dp[i - 1][j - 1],  // 替换
                                        dp[i - 1][j],      // 删除
                                        dp[i][j - 1]});    // 插入
                }
            }
        }
        return dp[n][m];
    }
};
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

int minDistance(char* word1, char* word2) {
    int n = strlen(word1), m = strlen(word2);
    int** dp = (int**)malloc((n + 1) * sizeof(int*));
    for (int i = 0; i <= n; i++) {
        dp[i] = (int*)malloc((m + 1) * sizeof(int));
        dp[i][0] = i; // → 空串：全删除
    }
    for (int j = 0; j <= m; j++) {
        dp[0][j] = j; // 空串 → ：全插入
    }
    for (int i = 1; i <= n; i++) {
        for (int j = 1; j <= m; j++) {
            if (word1[i - 1] == word2[j - 1]) {
                dp[i][j] = dp[i - 1][j - 1]; // 尾巴免费对齐
            } else {
                int rep = dp[i - 1][j - 1] + 1; // 替换
                int del = dp[i - 1][j] + 1;     // 删除
                int ins = dp[i][j - 1] + 1;     // 插入
                int mn = rep < del ? rep : del;
                dp[i][j] = mn < ins ? mn : ins;
            }
        }
    }
    int ans = dp[n][m];
    for (int i = 0; i <= n; i++) {
        free(dp[i]);
    }
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：两行，各一个单词
    char* word1 = (char*)malloc(600);
    char* word2 = (char*)malloc(600);
    if (scanf("%s %s", word1, word2) != 2) {
        word2[0] = '\0'; // 缺第二个词按空串处理
    }
    printf("%d\n", minDistance(word1, word2));
    free(word1);
    free(word2);
    return 0;
}
```

## 题解二：一维滚动数组（O(n) 空间）

转移依赖左上三格，压掉行维度。关键细节：相等/替换分支要用的 `dp[i-1][j-1]` 会被本轮覆盖，需用变量 `prev` 在覆盖前暂存——`prev` 随 `j` 逐列滚动，始终等于"左上角旧值"。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int minDistance(String word1, String word2) {
        int n = word1.length(), m = word2.length();
        int[] dp = new int[m + 1];
        for (int j = 0; j <= m; j++) {
            dp[j] = j; // 第 0 行：空串 → 前 j 个字符
        }
        for (int i = 1; i <= n; i++) {
            int prev = dp[0]; // prev = dp[i-1][j-1]（左上旧值）
            dp[0] = i;        // dp[i][0] = i：全删除
            for (int j = 1; j <= m; j++) {
                int tmp = dp[j]; // 覆盖前暂存 dp[i-1][j]，它是下一列的左上
                if (word1.charAt(i - 1) == word2.charAt(j - 1)) {
                    dp[j] = prev; // 尾巴免费对齐
                } else {
                    int rep = prev + 1;          // dp[i-1][j-1] + 1
                    int del = dp[j] + 1;         // dp[i-1][j] + 1（旧值）
                    int ins = dp[j - 1] + 1;     // dp[i][j-1] + 1（新值）
                    dp[j] = Math.min(rep, Math.min(del, ins));
                }
                prev = tmp;
            }
        }
        return dp[m];
    }

    public static void main(String[] args) {
        // ACM 输入：两行，各一个单词
        Scanner sc = new Scanner(System.in);
        String word1 = sc.nextLine().trim();
        String word2 = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().minDistance(word1, word2));
        sc.close();
    }
}
```
