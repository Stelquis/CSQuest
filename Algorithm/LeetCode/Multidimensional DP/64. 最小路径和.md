# [64. 最小路径和](https://leetcode.cn/problems/minimum-path-sum/)

- 🟡 **难度**：中等
- 🗺️ **分类**：多维动态规划
- 🏷️ **标签**：`数组`、`动态规划`、`矩阵`

## 题目描述

给定一个包含非负整数的 `m x n` 网格 `grid` ，请找出一条从左上角到右下角的路径，使得路径上的数字总和为最小。

**说明：** 每次只能向下或者向右移动一步。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/11/05/minpath.jpg)

```
输入：grid = [[1,3,1],[1,5,1],[4,2,1]]
输出：7
解释：因为路径 1→3→1→1→1 的总和最小。
```

**示例 2：**

```
输入：grid = [[1,2,3],[4,5,6]]
输出：12
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 200`
- `0 <= grid[i][j] <= 200`

## 与 62. 不同路径 对照着看

同样的"只能向右/向下"网格，只换了一处：格子上的数字有**代价**，聚合从"数路径条数"（加法计数）变成"找路径最小和"（取 min）。转移骨架完全一致：

```
62：dp[i][j] = dp[i-1][j]  +  dp[i][j-1]        （上方 + 左方）
64：dp[i][j] = grid[i][j]  +  min(dp[i-1][j], dp[i][j-1])   （本格代价 + 上/左取小）
```

两个新细节：

- **边界不再是全 1**：首行/首列只有一条路，路径和是**前缀累加**（`dp[0][j] = dp[0][j-1] + grid[0][j]`）；
- 权重非负 + 每步只增 → 转移是 DAG 上的单源最短路特例，但网格 DP 按行列扫描即可，无需堆（Dijkstra 属于有任意方向移动的版本）。

## 题解一：二维 DP（O(m·n)）

- `dp[i][j]` = 从 `(0,0)` 走到 `(i,j)` 的最小路径和，`dp[0][0] = grid[0][0]`
- 转移：`dp[i][j] = grid[i][j] + min(dp[i-1][j], dp[i][j-1])`
- 答案：`dp[m-1][n-1]`

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(m·n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[][] dp = new int[m][n];
        dp[0][0] = grid[0][0];
        for (int j = 1; j < n; j++) {
            dp[0][j] = dp[0][j - 1] + grid[0][j]; // 首行：前缀累加
        }
        for (int i = 1; i < m; i++) {
            dp[i][0] = dp[i - 1][0] + grid[i][0]; // 首列：前缀累加
        }
        for (int i = 1; i < m; i++) {
            for (int j = 1; j < n; j++) {
                dp[i][j] = grid[i][j] + Math.min(dp[i - 1][j], dp[i][j - 1]);
            }
        }
        return dp[m - 1][n - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m 和 n，随后 m 行每行 n 个整数
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        System.out.println(new Solution().minPathSum(grid));
        sc.close();
    }
}
```

class Solution:
    def minPathSum(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        dp = [[0] * n for _ in range(m)]
        dp[0][0] = grid[0][0]

            dp[0][j] = dp[0][j - 1] + grid[0][j]  # 首行：前缀累加
        for i in range(1, m):
            dp[i][0] = dp[i - 1][0] + grid[i][0]  # 首列：前缀累加
        for i in range(1, m):
            for j in range(1, n):
                dp[i][j] = grid[i][j] + min(dp[i - 1][j], dp[i][j - 1])

#include <stdio.h>
#include <stdlib.h>

int minPathSum(int** grid, int m, int n) {
    int** dp = (int**)malloc(m * sizeof(int*));
    for (int i = 0; i < m; i++) {
        dp[i] = (int*)malloc(n * sizeof(int));
    }
    dp[0][0] = grid[0][0];
    for (int j = 1; j < n; j++) {
        dp[0][j] = dp[0][j - 1] + grid[0][j]; // 首行：前缀累加
    }
    for (int i = 1; i < m; i++) {
        dp[i][0] = dp[i - 1][0] + grid[i][0]; // 首列：前缀累加
    }
    for (int i = 1; i < m; i++) {
        for (int j = 1; j < n; j++) {
            int up = dp[i - 1][j], left = dp[i][j - 1];
            dp[i][j] = grid[i][j] + (up < left ? up : left);
        }
    }
    int ans = dp[m - 1][n - 1];
    for (int i = 0; i < m; i++) {
        free(dp[i]);
    }
    free(dp);
    return ans;
}

## 题解二：一维滚动数组（O(n) 空间）

压维套路与 62 完全一致，且这题**升序扫描恰好正确**：更新 `dp[j]` 时，旧 `dp[j]` 是上一行的值（当"上方"），新写的 `dp[j-1]` 是本行的值（当"左方"），`min` 里各取所需：

- 首行先做前缀累加装进一维数组；
- 之后每行：先修 `dp[0] += grid[i][0]`（首列累加），再从左到右 `dp[j] = grid[i][j] + min(dp[j], dp[j-1])`。

变体说明：还可以**原地修改 `grid`**（把 dp 直接写回输入矩阵），额外空间 O(1)，但副作用是破坏输入数据——LeetCode 允许，工程中要看接口约定。

- 时间复杂度：`O(m·n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int minPathSum(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        int[] dp = new int[n];
        dp[0] = grid[0][0];
        for (int j = 1; j < n; j++) {
            dp[j] = dp[j - 1] + grid[0][j]; // 首行：前缀累加
        }
        for (int i = 1; i < m; i++) {
            dp[0] += grid[i][0]; // 首列累加：上方旧值 + 本格
            for (int j = 1; j < n; j++) {
                dp[j] = grid[i][j] + Math.min(dp[j], dp[j - 1]); // 上方旧值 / 左方新值
            }
        }
        return dp[n - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m 和 n，随后 m 行每行 n 个整数
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        System.out.println(new Solution().minPathSum(grid));
        sc.close();
    }
}
```
