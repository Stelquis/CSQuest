# [48. 旋转图像](https://leetcode.cn/problems/rotate-image/)

- 🟡 **难度**：中等
- 🔲 **分类**：矩阵
- 🏷️ **标签**：`数组`、`数学`、`矩阵`

## 题目描述

给定一个 *n* × *n* 的二维矩阵 `matrix` 表示一个图像。请你将图像顺时针旋转 90 度。

你必须在 **[原地](https://baike.baidu.com/item/%E5%8E%9F%E5%9C%B0%E7%AE%97%E6%B3%95)** 旋转图像，这意味着你需要直接修改输入的二维矩阵。**请不要** 使用另一个矩阵来旋转图像。

**示例 1：**

![](https://assets.leetcode.com/uploads/2020/08/28/mat1.jpg)

```
输入：matrix = [[1,2,3],[4,5,6],[7,8,9]]
输出：[[7,4,1],[8,5,2],[9,6,3]]
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2020/08/28/mat2.jpg)

```
输入：matrix = [[5,1,9,11],[2,4,8,10],[13,3,6,7],[15,14,12,16]]
输出：[[15,13,2,5],[14,3,4,1],[12,6,8,9],[16,7,10,11]]
```

**提示：**
- `n == matrix.length == matrix[i].length`
- `1 <= n <= 20`
- `-1000 <= matrix[i][j] <= 1000`

## 题解：副对角线翻转 + 上下翻转

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public void rotate(int[][] matrix) {
        int n=matrix.length;
        // 先副对角线翻转：(i,j) 与 (n-1-j,n-1-i) 互换（左上角与右下角互换）
        // j 上界 n-1-i 保证每对元素只交换一次（伙伴行 n-1-j 恒大于 i）
        for(int i=0;i<n;i++){
            for(int j=0;j<n-1-i;j++){
                swap(matrix,i,j,n-1-j,n-1-i);
            }
        }
        // 然后上下翻转：前一半行与后一半行对应互换
        for(int i=0;i<n/2;i++){
            for(int j=0;j<n;j++){
                swap(matrix,i,j,n-1-i,j);
            }
        }
    }

    public static void swap(int[][] matrix,int i,int j,int k,int l){
        int temp = matrix[i][j];
        matrix[i][j] = matrix[k][l];
        matrix[k][l] = temp;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，接下来 n 行每行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[][] matrix = new int[n][n];
        for (int i = 0; i < n; i++) {
            for (int j = 0; j < n; j++) {
                matrix[i][j] = sc.nextInt();
            }
        }
        new Solution().rotate(matrix);
        for (int i = 0; i < n; i++) {
            StringBuilder sb = new StringBuilder();
            for (int j = 0; j < n; j++) {
                if (j > 0) sb.append(' ');
                sb.append(matrix[i][j]);
            }
            System.out.println(sb);
        }
        sc.close();
    }
}
```

## 题解一：副对角线翻转 + 上下翻转

顺时针旋转 90° 的映射 `(i,j) → (j, n-1-i)` 可拆成两步原地变换复合：先副对角线翻转 `(i,j) → (n-1-j, n-1-i)`，再上下翻转 `(i,j) → (n-1-i, j)`，复合后 `(i,j) → (j, n-1-i)` 恰为顺时针 90°。

注意第一步互换的双方是 `(i,j)` 与 `(n-1-j, n-1-i)`，行列**交叉**计算；`j` 的上界 `n-1-i` 保证每对元素只交换一次，且副对角线上的元素原地不动。

### ☕ Java

```java
import java.util.Scanner;

class Solution {
    public void rotate(int[][] matrix) {
        int n=matrix.length;
        // 先副对角线翻转：(i,j) 与 (n-1-j,n-1-i) 互换（左上角与右下角互换）
        // j 上界 n-1-i 保证每对元素只交换一次（伙伴行 n-1-j 恒大于 i）
        for(int i=0;i<n;i++){
            for(int j=0;j<n-1-i;j++){
                swap(matrix,i,j,n-1-j,n-1-i);
            }
        }
        // 然后上下翻转：前一半行与后一半行对应互换
        for(int i=0;i<n/2;i++){
            for(int j=0;j<n;j++){
                swap(matrix,i,j,n-1-i,j);
            }
        }
    }

    public static void swap(int[][] matrix,int i,int j,int k,int l){
        int temp = matrix[i][j];
        matrix[i][j] = matrix[k][l];
        matrix[k][l] = temp;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，接下来 n 行每行 n 个整数
        Scanner sc = new Scanner(System.in);

            System.out.println(sb);

    }
}
```
