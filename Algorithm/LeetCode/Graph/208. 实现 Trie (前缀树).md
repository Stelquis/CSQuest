# [208. 实现 Trie (前缀树)](https://leetcode.cn/problems/implement-trie-prefix-tree/)

- 🟡 **难度**：中等
- 🕸️ **分类**：图论
- 🏷️ **标签**：`设计`、`字典树`、`哈希表`、`字符串`

## 题目描述

**[Trie](https://baike.baidu.com/item/字典树/9825209?fr=aladdin)**（发音类似 "try"）或者说 **前缀树** 是一种树形数据结构，用于高效地存储和检索字符串数据集中的键。这一数据结构有相当多的应用情景，例如自动补全和拼写检查。

请你实现 Trie 类：
- `Trie()` 初始化前缀树对象。
- `void insert(String word)` 向前缀树中插入字符串 `word` 。
- `boolean search(String word)` 如果字符串 `word` 在前缀树中，返回 `true`（即，在检索之前已经插入）；否则，返回 `false` 。
- `boolean startsWith(String prefix)` 如果之前已经插入的字符串 `word` 的前缀之一为 `prefix` ，返回 `true` ；否则，返回 `false` 。

**示例：**

```
输入
["Trie", "insert", "search", "search", "startsWith", "insert", "search"]
[[], ["apple"], ["apple"], ["app"], ["app"], ["app"], ["app"]]
输出
[null, null, true, false, true, null, true]

解释
Trie trie = new Trie();
trie.insert("apple");
trie.search("apple");   // 返回 True
trie.search("app");     // 返回 False
trie.startsWith("app"); // 返回 True
trie.insert("app");
trie.search("app");     // 返回 True
```

**提示：**
- `1 <= word.length, prefix.length <= 2000`
- `word` 和 `prefix` 仅由小写英文字母组成
- `insert`、`search` 和 `startsWith` 调用次数 **总计** 不超过 `3 * 10^4` 次

## 题解：前缀树（每个节点一个 26 槽数组）

### 为什么需要 Trie

用 `HashSet<String>` 存所有单词，`insert` / `search` 是 `O(L)`，但 **`startsWith(prefix)` 没辙**——哈希表没有"前缀"概念，只能把每个单词拿出来逐个比对，退化成 `O(n · L)`。Trie 把字符串按**公共前缀合并**成一棵树，于是三个操作**全是 `O(L)`，与已存单词数无关**。

### 结构：一个节点 = 26 槽数组 + `isEnd`

```
class TrieNode:
    children : TrieNode[26]     // 下标 c - 'a' → 对应的子节点（null 表示无此路）
    isEnd    : boolean          // 从根走到这里，是否是一个被插入过的完整单词
```

整棵树只有**一种节点类型**——所谓"叶子"就是 `children` 全为 `null` 的节点，是**状态**而非**类型**，不需要单独的"叶子类"。`null` 就是多叉树的天然末端。

**关键洞察：** 26 槽是"**潜在位置**"，不是"26 个孩子"。每个槽要么 `null`，要么指向一个同构的子节点。因为题目限定**只有小写字母**，`c - 'a'` 恰好落在 `0..25`，定长数组是最高效的表示。

### `isEnd` 是灵魂：区分"路径存在"和"完整单词"

插入 `"apple"` 后，路径 `a→p→p` 是存在的，但 `"app"` 从没被插入过。怎么区分？靠 `isEnd`：

```
root ─a─► A ─p─► P ─p─► PP(isEnd) ─l─► L ─e─► E(isEnd)
                          ↑                      ↑
                       "app" 终点            "apple" 终点
```

| 查询 | 走法 | 结果 |
|---|---|---|
| `search("app")`（只插过 apple） | 能走到 `PP`，但 `PP.isEnd == false` | `false` |
| `startsWith("app")` | 能走到 `PP` 即可 | `true` |

**`search` 与 `startsWith` 的唯一区别就在结尾**：前者 `return node.isEnd`，后者 `return true`。

### 三个操作

三个方法前半段**完全一样**——"从根出发逐字符走"，差别只在两处：**遇到 `null` 怎么办**、**走完返回什么**。

```
insert(word):
    node = root
    for c in word:
        idx = c - 'a'
        if node.children[idx] == null:  node.children[idx] = new TrieNode()   // 缺路 → 修路
        node = node.children[idx]
    node.isEnd = true                                                          // 终点标记

search(word):
    node = root
    for c in word:
        idx = c - 'a'
        if node.children[idx] == null:  return false                           // 路不存在 → 查不到
        node = node.children[idx]
    return node.isEnd                                                          // 必须是完整单词

startsWith(prefix):
    node = root
    for c in prefix:
        idx = c - 'a'
        if node.children[idx] == null:  return false
        node = node.children[idx]
    return true                                                                // 前缀存在即可
```

**为什么同一句 `children[idx] == null`，`insert` 要新建而 `search` 要失败？** 因为使命不同：`insert` 是"**施工队**"，要把单词存进去，缺路就得造；`search` / `startsWith` 是"**访客**"，只查不改，路不存在就是查不到——**查询绝不允许修改数据结构**。

示例操作序列的演化：

```
insert("apple")     → 建 a-p-p-l-e 五个节点，E.isEnd = true
search("apple")     → 走到 E，E.isEnd = true                                  → true
search("app")       → 走到 PP，PP.isEnd = false（app 还没插过）                → false
startsWith("app")   → 走到 PP 即可                                            → true
insert("app")       → a-p-p 已存在，复用不新建，仅 PP.isEnd = true
search("app")       → 走到 PP，PP.isEnd = true                                → true
```

- 时间复杂度：每个操作 `O(L)`（`L` 为串长），与已存单词数无关
- 空间复杂度：`O(总字符数 × 26)`，最坏（无公共前缀）每节点固定占 26 个引用

**对比 207 / 994**：207 课程表是把"先修关系"建成**有向图**判环；994 是网格上的多源 BFS；本题是**字符串的前缀共享树**——虽然都叫"图/树"，但 Trie 的边是**字符**、路径是**字符串**，本质是"用空间换前缀查询时间"。

**易错点**：

1. **`root` 必须是字段，不能写成构造函数里的局部变量**：`TrieNode root = new TrieNode();` 写在构造函数里只是临时变量，构造函数一返回就没了，后面的方法会"找不到符号"。应在类里声明字段、在构造函数里赋值；
2. **数组槽是 `null` 不是空节点**：`new TrieNode[26]` 只给 26 个 `null` 引用，用到哪个才 `new` 哪个，别以为自动建好了；
3. **`insert` 与 `search` 对 `null` 处理相反**（造路 vs 失败），别抄错；
4. **`search` 与 `startsWith` 结尾不同**（看 `isEnd` vs 直接 `true`）；
5. 下标用 `c - 'a'`（仅小写字母时成立）；若有大小写/数字，得改用 `Map<Character, TrieNode>`。

**备注**：两种等价实现——① **`Map<Character, TrieNode>` 当 children**：按需分配、支持任意字符集，适合字母表大或稀疏的场景；② **全局静态数组**（`int[MAXN][26]` + 节点计数器）：无对象开销、缓存友好，竞赛里处理更大规模时常用。本题只有小写字母，定长 `TrieNode[26]` 最直观。应用上，Trie 是**自动补全、拼写检查、IP 路由最长前缀匹配、AC 自动机**等的基础。

### ☕ Java

```java
import java.util.Scanner;

class Trie {
    TrieNode root;

    public Trie() {
        root = new TrieNode();
    }

    public void insert(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                node.children[idx] = new TrieNode();   // 缺路 → 修路
            }
            node = node.children[idx];
        }
        node.isEnd = true;                             // 终点标记为完整单词
    }

    public boolean search(String word) {
        TrieNode node = root;
        for (char c : word.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                return false;                          // 路不存在 → 查不到
            }
            node = node.children[idx];
        }
        return node.isEnd;                             // 必须是完整单词
    }

    public boolean startsWith(String prefix) {
        TrieNode node = root;
        for (char c : prefix.toCharArray()) {
            int idx = c - 'a';
            if (node.children[idx] == null) {
                return false;
            }
            node = node.children[idx];
        }
        return true;                                   // 前缀存在即可，不看 isEnd
    }
}

public class Solution {
    public static void main(String[] args) {
        // ACM 输入：第一行操作数 n，接下来 n 行每行为
        //   insert word / search word / startsWith prefix
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        Trie trie = new Trie();
        StringBuilder sb = new StringBuilder();
        for (int i = 0; i < n; i++) {
            String op = sc.next();
            String arg = sc.next();
            if (op.equals("insert")) {
                trie.insert(arg);
            } else if (op.equals("search")) {
                sb.append(trie.search(arg)).append('\n');
            } else {                                   // startsWith
                sb.append(trie.startsWith(arg)).append('\n');
            }
        }
        System.out.print(sb);
        sc.close();
    }
}

// 单文件运行时入口类需在前，故自定义结构 TrieNode 置于 Solution 之后
class TrieNode {
    TrieNode[] children = new TrieNode[26];   // 26 个槽位，默认全 null
    boolean isEnd;                            // 到此是否为完整单词
}
```

### 🐍 Python

```python
import sys


class TrieNode:
    __slots__ = ("children", "is_end")

    def __init__(self):
        self.children = [None] * 26     # 26 个槽位，默认全 None
        self.is_end = False             # 到此是否为完整单词


class Trie:
    def __init__(self):
        self.root = TrieNode()

    def insert(self, word: str) -> None:
        node = self.root
        for c in word:
            idx = ord(c) - ord('a')
            if node.children[idx] is None:
                node.children[idx] = TrieNode()   # 缺路 → 修路
            node = node.children[idx]
        node.is_end = True                        # 终点标记为完整单词

    def search(self, word: str) -> bool:
        node = self.root
        for c in word:
            idx = ord(c) - ord('a')
            if node.children[idx] is None:
                return False                      # 路不存在 → 查不到
            node = node.children[idx]
        return node.is_end                        # 必须是完整单词

    def starts_with(self, prefix: str) -> bool:
        node = self.root
        for c in prefix:
            idx = ord(c) - ord('a')
            if node.children[idx] is None:
                return False
            node = node.children[idx]
        return True                               # 前缀存在即可


def main():
    # ACM 输入：第一行操作数 n，接下来 n 行每行为
    #   insert word / search word / startsWith prefix
    data = sys.stdin.read().split()
    n = int(data[0])
    idx = 1
    trie = Trie()
    out = []
    for _ in range(n):
        op = data[idx]
        arg = data[idx + 1]
        idx += 2
        if op == "insert":
            trie.insert(arg)
        elif op == "search":
            out.append("true" if trie.search(arg) else "false")
        else:                                     # startsWith
            out.append("true" if trie.starts_with(arg) else "false")
    print("\n".join(out))


if __name__ == "__main__":
    main()
```

```cpp
            children[i] = nullptr;          // 26 个槽位默认空指针

    }

        TrieNode* node = root;
        for (char c : word) {

            if (node->children[idx] == nullptr) {
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>
#include <stdbool.h>

typedef struct TrieNode {
    struct TrieNode *children[26];   /* 26 个槽位，默认 NULL */
    bool isEnd;                      /* 到此是否为完整单词 */
} TrieNode;

typedef struct {
    TrieNode *root;
} Trie;

static TrieNode *newNode(void) {
    return (TrieNode *)calloc(1, sizeof(TrieNode));   /* children 全 NULL，isEnd = false */
}

Trie *trieCreate(void) {
    Trie *t = (Trie *)malloc(sizeof(Trie));
    t->root = newNode();
    return t;
}

void trieInsert(Trie *t, char *word) {
    TrieNode *node = t->root;
    for (int i = 0; word[i] != '\0'; i++) {
        int idx = word[i] - 'a';
        if (node->children[idx] == NULL) {
            node->children[idx] = newNode();          /* 缺路 → 修路 */
        }
        node = node->children[idx];
    }
    node->isEnd = true;                               /* 终点标记为完整单词 */
}

bool trieSearch(Trie *t, char *word) {
    TrieNode *node = t->root;
    for (int i = 0; word[i] != '\0'; i++) {
        int idx = word[i] - 'a';
        if (node->children[idx] == NULL) {
            return false;                             /* 路不存在 → 查不到 */
        }
        node = node->children[idx];
    }
    return node->isEnd;                               /* 必须是完整单词 */
}

bool trieStartsWith(Trie *t, char *prefix) {
    TrieNode *node = t->root;
    for (int i = 0; prefix[i] != '\0'; i++) {
        int idx = prefix[i] - 'a';
        if (node->children[idx] == NULL) {
            return false;
        }
        node = node->children[idx];
    }
    return true;                                      /* 前缀存在即可 */
}

static void freeNode(TrieNode *node) {
    if (node == NULL) {
        return;
    }
    for (int i = 0; i < 26; i++) {
        freeNode(node->children[i]);
    }
    free(node);
}

void trieFree(Trie *t) {
    freeNode(t->root);
    free(t);
}

int main(void) {
    /* ACM 输入：第一行操作数 n，接下来 n 行每行为
       insert word / search word / startsWith prefix */
    int n;
    if (scanf("%d", &n) != 1) {
        return 0;
    }
    Trie *trie = trieCreate();
    char op[16], arg[2048];
    for (int i = 0; i < n; i++) {
        scanf("%s %s", op, arg);
        if (strcmp(op, "insert") == 0) {
            trieInsert(trie, arg);
        } else if (strcmp(op, "search") == 0) {
            printf("%s\n", trieSearch(trie, arg) ? "true" : "false");
        } else {                                      /* startsWith */
            printf("%s\n", trieStartsWith(trie, arg) ? "true" : "false");
        }
    }
    trieFree(trie);
    return 0;
}
```
