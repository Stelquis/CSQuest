# [207. 课程表](https://leetcode.cn/problems/course-schedule/)

- 🟡 **难度**：中等
- 🕸️ **分类**：图论
- 🏷️ **标签**：`深度优先搜索`、`广度优先搜索`、`图`、`拓扑排序`、`有向无环图`

## 题目描述

你这个学期必须选修 `numCourses` 门课程，记为 `0` 到 `numCourses - 1` 。

在选修某些课程之前需要一些先修课程。 先修课程按数组 `prerequisites` 给出，其中 `prerequisites[i] = [a_i, b_i]` ，表示如果要学习课程 `a_i` 则 **必须** 先学习课程  `b_i`_ 。
- 例如，先修课程对 `[0, 1]` 表示：想要学习课程 `0` ，你需要先完成课程 `1` 。

请你判断是否可能完成所有课程的学习？如果可以，返回 `true` ；否则，返回 `false` 。

**示例 1：**

```
输入：numCourses = 2, prerequisites = [[1,0]]
输出：true
解释：总共有 2 门课程。学习课程 1 之前，你需要完成课程 0 。这是可能的。
```

**示例 2：**

```
输入：numCourses = 2, prerequisites = [[1,0],[0,1]]
输出：false
解释：总共有 2 门课程。学习课程 1 之前，你需要先完成​课程 0 ；并且学习课程 0 之前，你还应先完成课程 1 。这是不可能的。
```

**提示：**
- `1 <= numCourses <= 2000`
- `0 <= prerequisites.length <= 5000`
- `prerequisites[i].length == 2`
- `0 <= a_i, b_i < numCourses`
- `prerequisites[i]` 中的所有课程对 **互不相同**

## 题解：Kahn 拓扑排序（BFS 判环）

### 建模：先修关系 ⇔ 有向边

把课程看成**顶点**，先修关系看成**有向边**：对 `[a, b]`（学 `a` 前先学 `b`），画一条 **`b → a`**（**先修指向后修**，沿箭头走即"学习顺序"）。那么：

> **能否完成所有课程 ⟺ 这个有向图是否为 DAG（有向无环图）。**

**为什么？** 如果图里有环（如示例 2 的 `0 → 1 → 0`），意味着"学 1 要先学 0，学 0 又要先学 1"——环上课程互相要求对方先修，谁都无法先学，永远理不清。反之若为 DAG，总能排出拓扑序，即一个合法学习顺序。

### 建图：邻接表（只存出边）+ 入度数组

数据规模 `V <= 2000`、`E <= 5000`，是**稀疏图**，用邻接表 `O(V + E)`，而非 `O(V²)` 的邻接矩阵。

```
List<List<Integer>> adj = new ArrayList<>();
for (int i = 0; i < numCourses; i++) adj.add(new ArrayList<>());   // 每门课一个空邻居表（别漏！）
int[] inDegree = new int[numCourses];
for (int[] p : prerequisites) {
    int a = p[0], b = p[1];
    adj.get(b).add(a);    // 边 b -> a：学完 b 解锁 a，故 a 进 b 的邻居表
    inDegree[a]++;        // a 多一门先修
}
```

有向图**只加一个方向**（不像无向图要双向），因此邻接表只反映"**出边**"——`adj[i].size()` 是**出度**，**入度必须自己统计**，这正是 `inDegree[]` 的作用。

### Kahn 算法四步

```
① 统计每个点的入度 inDegree[v] = "还有几门先修没学"
② 把所有 inDegree == 0 的点（没先修、能立刻学）入队
③ while 队列非空:
      出队 u 并计入 studied（出队 = 学完这门课）
      for 每个 u 的后继 v:
          inDegree[v]--            // u 学完，v 少一门先修
          if inDegree[v] == 0: 入队 v
④ return studied == numCourses
```

**判环原理**：环上的点，入度**永远不会降到 0**（环内互相依赖），于是它们**永远进不了队列**，`studied` 也永远凑不满 `numCourses`。所以 `studied == numCourses` ⇔ 无环。

**无需额外的 `visited` 数组**：一门课只有当它的入度**从 1 减到 0 的那一刻**才入队一次；入度是单调递减的，所以每门课**最多入队一次、出队一次**，不会重复。"已学"这件事被完全编码进了 `inDegree` 与队列里。

两个示例的推演：

```
示例 1  [[1,0]]                    示例 2  [[1,0],[0,1]]
  adj = [[1],[]]                     adj = [[1],[0]]
  inDegree = [0,1]                   inDegree = [1,1]
  初始队列 = [0]（课程 0 无先修）      初始队列 = []（没有入度 0 的点！）
  学完 0：studied=1，后继 1 入度→0，入队     while 一次都不进循环
  学完 1：studied=2，无后继             studied = 0 ≠ 2
  studied = 2 == numCourses → true    → false（环上的点排不进来）
```

- 时间复杂度：`O(V + E)`，建图与每个点、每条边各处理常数次
- 空间复杂度：`O(V + E)`，邻接表与入度数组（队列最多 `V` 个元素）

**对比 200 / 994**：200 岛屿数量在**无向**网格上求连通块（DFS 即可）；994 腐烂的橘子是**多源 BFS** 求距离层次；本题是**有向图**上求"是否存在拓扑序"，即**判环**——Kahn 用"入度归零"的消费式推进来判，天然顺带得到一个拓扑序。

**易错点**：

1. **边方向写反**：`[a,b]` 是 `b→a`，故 `adj.get(b).add(a)`、`inDegree[a]++`，不是反过来；
2. **忘记初始化每个邻居表**：`for (...) adj.add(new ArrayList<>())` 漏了，`adj.get(b)` 立刻越界；
3. **有向图忘了统计入度**：邻接表只有出边，入度必须单独数；
4. **判据写错**：应是 `studied == numCourses`（全部排完）；写成 `> 0` 之类无意义；
5. **队列用栈**：拓扑序要求 FIFO 的队列（`ArrayDeque`），用栈会退化。

**备注**：另一条**路线 A：DFS + 三色标记**——给每个点状态 `0 未访问 / 1 正在递归链上 / 2 已完成`，DFS 时若走到状态为 `1` 的点，说明撞回当前递归链的祖先 → 有环。它需要区分 `1` 和 `2`：只有"在**当前**这条链上"的点才是环，一条早已走完的链上再碰到无害。相比之下，**Kahn 不需要状态数组**，判环逻辑更直白；DFS 的优点是可以顺手求出具体拓扑序（后序遍历逆序）与强连通分量等。两条路线都能判环，按题意择优即可。

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.ArrayList;
import java.util.Deque;
import java.util.List;
import java.util.Scanner;

class Solution {
    public boolean canFinish(int numCourses, int[][] prerequisites) {
        // ① 建图：邻接表（只存出边）+ 入度数组
        List<List<Integer>> adj = new ArrayList<>();
        for (int i = 0; i < numCourses; i++) {
            adj.add(new ArrayList<>());
        }
        int[] inDegree = new int[numCourses];
        for (int[] p : prerequisites) {
            int a = p[0], b = p[1];   // [a, b]：学 a 前先学 b
            adj.get(b).add(a);        // 边 b -> a（先修指向后修）
            inDegree[a]++;            // a 多一门先修
        }

        // ② 入度为 0（没先修）的课先入队
        Deque<Integer> queue = new ArrayDeque<>();
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                queue.add(i);
            }
        }

        // ③ 逐门"学"：学完 u，把后继 v 的入度 -1，归零则入队
        int studied = 0;
        while (!queue.isEmpty()) {
            int u = queue.poll();
            studied++;
            for (int v : adj.get(u)) {
                if (--inDegree[v] == 0) {
                    queue.add(v);
                }
            }
        }

        // ④ 全部学完 ⇔ 无环（DAG）
        return studied == numCourses;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 numCourses E，接下来 E 行每行 a b（[a,b] 表示学 a 前先学 b）
        Scanner sc = new Scanner(System.in);
        int numCourses = sc.nextInt();
        int e = sc.nextInt();
        int[][] prerequisites = new int[e][2];
        for (int i = 0; i < e; i++) {
            prerequisites[i][0] = sc.nextInt();
            prerequisites[i][1] = sc.nextInt();
        }
        System.out.println(new Solution().canFinish(numCourses, prerequisites));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from collections import deque
from typing import List


class Solution:
    def canFinish(self, numCourses: int, prerequisites: List[List[int]]) -> bool:
        # ① 建图：邻接表（只存出边）+ 入度数组
        adj: List[List[int]] = [[] for _ in range(numCourses)]
        in_degree = [0] * numCourses
        for a, b in prerequisites:          # [a, b]：学 a 前先学 b
            adj[b].append(a)                # 边 b -> a
            in_degree[a] += 1               # a 多一门先修

        # ② 入度为 0 的课先入队
        queue = deque(i for i in range(numCourses) if in_degree[i] == 0)

        # ③ 逐门"学"
        studied = 0
        while queue:
            u = queue.popleft()
            studied += 1
            for v in adj[u]:
                in_degree[v] -= 1
                if in_degree[v] == 0:
                    queue.append(v)

        # ④ 全部学完 ⇔ 无环
        return studied == numCourses


if __name__ == "__main__":
    # ACM 输入：第一行 numCourses E，接下来 E 行每行 a b
    data = sys.stdin.read().split()
    idx = 0
    num_courses = int(data[idx]); idx += 1
    e = int(data[idx]); idx += 1
    pre = []
    for _ in range(e):
        a = int(data[idx]); b = int(data[idx + 1]); idx += 2
        pre.append([a, b])
    print("true" if Solution().canFinish(num_courses, pre) else "false")
```

### ➕ C++

```cpp
#include <vector>
#include <queue>
#include <iostream>
using namespace std;

class Solution {
public:
    bool canFinish(int numCourses, vector<vector<int>>& prerequisites) {
        // ① 建图：邻接表（只存出边）+ 入度数组
        vector<vector<int>> adj(numCourses);
        vector<int> inDegree(numCourses, 0);
        for (auto& p : prerequisites) {
            int a = p[0], b = p[1];   // [a, b]：学 a 前先学 b
            adj[b].push_back(a);      // 边 b -> a
            inDegree[a]++;            // a 多一门先修
        }

        // ② 入度为 0 的课先入队
        queue<int> q;
        for (int i = 0; i < numCourses; i++) {
            if (inDegree[i] == 0) {
                q.push(i);
            }
        }

        // ③ 逐门"学"
        int studied = 0;
        while (!q.empty()) {
            int u = q.front();
            q.pop();
            studied++;
            for (int v : adj[u]) {
                if (--inDegree[v] == 0) {
                    q.push(v);
                }
            }
        }

        // ④ 全部学完 ⇔ 无环
        return studied == numCourses;
    }
};

int main() {
    // ACM 输入：第一行 numCourses E，接下来 E 行每行 a b
    int numCourses, e;
    cin >> numCourses >> e;
    vector<vector<int>> prerequisites(e, vector<int>(2));
    for (int i = 0; i < e; i++) {
        cin >> prerequisites[i][0] >> prerequisites[i][1];
    }
    cout << (Solution().canFinish(numCourses, prerequisites) ? "true" : "false") << "\n";
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <stdbool.h>

bool canFinish(int numCourses, int **prerequisites, int prerequisitesSize,
               int *prerequisitesColSize) {
    int V = numCourses, E = prerequisitesSize;
    int *inDegree = (int *)calloc(V, sizeof(int));
    int *outDeg = (int *)calloc(V, sizeof(int));

    for (int i = 0; i < E; i++) {
        int a = prerequisites[i][0], b = prerequisites[i][1];   /* [a,b]: 学 a 前先学 b */
        outDeg[b]++;                                            /* 边 b -> a */
        inDegree[a]++;
    }

    /* CSR 邻接表：start[i] 为点 i 的出边在 to[] 中的起始下标 */
    int *start = (int *)malloc((V + 1) * sizeof(int));
    start[0] = 0;
    for (int i = 0; i < V; i++) {
        start[i + 1] = start[i] + outDeg[i];
    }
    int *to = (int *)malloc((E > 0 ? E : 1) * sizeof(int));
    int *cursor = (int *)malloc(V * sizeof(int));
    for (int i = 0; i < V; i++) {
        cursor[i] = start[i];
    }
    for (int i = 0; i < E; i++) {
        int a = prerequisites[i][0], b = prerequisites[i][1];
        to[cursor[b]++] = a;                                    /* b 的邻居表里放 a */
    }

    /* Kahn */
    int *queue = (int *)malloc((V > 0 ? V : 1) * sizeof(int));
    int head = 0, tail = 0;
    for (int i = 0; i < V; i++) {
        if (inDegree[i] == 0) {
            queue[tail++] = i;
        }
    }
    int studied = 0;
    while (head < tail) {
        int u = queue[head++];
        studied++;
        for (int k = start[u]; k < start[u + 1]; k++) {
            int v = to[k];
            if (--inDegree[v] == 0) {
                queue[tail++] = v;
            }
        }
    }

    int ok = (studied == V);
    free(inDegree);
    free(outDeg);
    free(start);
    free(to);
    free(cursor);
    free(queue);
    return ok;
}

int main(void) {
    /* ACM 输入：第一行 numCourses E，接下来 E 行每行 a b */
    int numCourses, E;
    if (scanf("%d %d", &numCourses, &E) != 2) {
        return 0;
    }
    int **pre = (int **)malloc((E > 0 ? E : 1) * sizeof(int *));
    int *col = (int *)malloc((E > 0 ? E : 1) * sizeof(int));
    for (int i = 0; i < E; i++) {
        pre[i] = (int *)malloc(2 * sizeof(int));
        scanf("%d %d", &pre[i][0], &pre[i][1]);
        col[i] = 2;
    }
    printf("%s\n", canFinish(numCourses, pre, E, col) ? "true" : "false");
    for (int i = 0; i < E; i++) {
        free(pre[i]);
    }
    free(pre);
    free(col);
    return 0;
}
```
