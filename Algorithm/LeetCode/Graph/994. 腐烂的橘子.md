# [994. 腐烂的橘子](https://leetcode.cn/problems/rotting-oranges/)

- 🟡 **难度**：中等
- 🕸️ **分类**：图论
- 🏷️ **标签**：`广度优先搜索`、`数组`、`矩阵`

## 题目描述

在给定的 `m x n` 网格 `grid` 中，每个单元格可以有以下三个值之一：
- 值 `0` 代表空单元格；
- 值 `1` 代表新鲜橘子；
- 值 `2` 代表腐烂的橘子。

每分钟，腐烂的橘子 **周围 4 个方向上相邻** 的新鲜橘子都会腐烂。

返回 *直到单元格中没有新鲜橘子为止所必须经过的最小分钟数。如果不可能，返回 `-1`* 。

**示例 1：**

![](https://assets.leetcode.cn/aliyun-lc-upload/uploads/2019/02/16/oranges.png)

```
输入：grid = [[2,1,1],[1,1,0],[0,1,1]]
输出：4
```

**示例 2：**

```
输入：grid = [[2,1,1],[0,1,1],[1,0,1]]
输出：-1
解释：左下角的橘子（第 2 行， 第 0 列）永远不会腐烂，因为腐烂只会发生在 4 个方向上。
```

**示例 3：**

```
输入：grid = [[0,2]]
输出：0
解释：因为 0 分钟时已经没有新鲜橘子了，所以答案就是 0 。
```

**提示：**
- `m == grid.length`
- `n == grid[i].length`
- `1 <= m, n <= 10`
- `grid[i][j]` 仅为 `0`、`1` 或 `2`

## 题解：多源 BFS（层序扩散）

### 两个关键认识

**① 是"多源同时扩散"，不是"单源"搜索。** 题面说"每分钟，**所有**腐烂橘子周围的新鲜橘子都会腐烂"——多个源头**同时**向外扩。所以不能像 79 单词搜索那样从一个起点搜到底；正确做法是**一开始就把所有腐烂橘子一起塞进队列**，让 BFS 的"波前"自然对应"每分钟同时扩散一圈"。

**② 答案 = 所有新鲜橘子到最近腐烂源的**距离最大值**。** 因为腐烂时间 = 到最近腐烂源的最短步数，而题目问的是"直到没有新鲜橘子为止"，也就是**最后一个**腐烂的时刻，即这些距离里的 **max**。求"最短距离"，正是 **BFS** 的拿手好戏（逐层扩散，层号 = 距离）；DFS 一头扎到底，算出的不保证最短。

于是整个算法分两段：

```
第一段（预处理）: 遍历网格，所有 2 入队；统计新鲜橘子数 fresh
第二段（层序 BFS）:
    每分钟处理"当前队列里这一批"橘子——
        size = 队列长度          ← 先拍照，锁定本批
        弹出 size 个，逐个看四个邻居：
            若是新鲜 → 变烂、fresh--、入队（留给下一分钟）、spread = true
        若本轮真的感染了东西（spread）→ 分钟数 +1
第三段（判定）: fresh == 0 ? 分钟数 : -1
```

### 三处必须想清楚的地方

**1. `size = queue.size()` 必须先"拍照"。** `for` 循环体里会往队列 `add` 新橘子，若写成 `k < queue.size()`，队列边循环边长，这一轮就把"下一分钟该处理的"也顺手处理了，**层次（时间）就塌了**。先把长度固定进 `size`，才能保证"这一轮只处理当前这批"。

**2. 分钟数只在"真的感染了"时才 +1（`spread` 标志）。** 某一批橘子四个邻居全不是新鲜时（例如最后一轮、或示例 3 的唯一那颗），这一轮**不该**算一分钟。用 `spread` 兜住，示例 3 才能得到 `0` 而不是 `1`。

**3. 队列空 = 波前熄灭 = 扩散结束。** 队列里装的语义是"已烂、还没向外试探过的橘子"；每个橘子在它变烂那一刻入队**一次**，被 `poll` 弹出后**不再回队**（`grid[ni][nj] == 1` 已不成立）。所以每个格子最多入队一次 → 队列必空，不会死循环。**但"队列空"只说明"能扩的扩完了"，不代表"全烂了"**——是否有够不到的新鲜橘子，由 `fresh` 判定：`fresh == 0` 成功，否则 `-1`（示例 2 左下角被 `0` 隔离的那颗）。

示例 1 的逐分钟波前（示例 1 网格：`[[2,1,1],[1,1,0],[0,1,1]]`）：

```
第 0 分钟   (0,0)                    ← 初始腐烂（第 0 批）
第 1 分钟   (0,1) (1,0)
第 2 分钟   (0,2) (1,1)
第 3 分钟   (2,1)
第 4 分钟   (2,2)                    ← 最后一颗新鲜变烂，收工 → 返回 4
            (随后还会弹一次 (2,2)，但它没感染到任何东西，spread=false，分钟数不再增)
```

- 时间复杂度：`O(m · n)`，每个格子最多入队、出队一次，邻居检查 `O(1)`
- 空间复杂度：`O(m · n)`，队列最坏装满网格

**对比 200 / 79**：都是网格（矩阵）上的搜索。200 岛屿数量用 **DFS** 因为只关心"连通块个数"，不关心距离；79 单词搜索是**单源**回溯找一条路；本题是**多源 BFS**，要的正是"距离/时间"的**层次**——所以非 BFS 不可。

**易错点**：

1. **用栈（LIFO）而非队列（FIFO）**：栈会让"远的先处理"，时间层次错乱。Java 用 `ArrayDeque`（别用 `Stack`）；
2. **忘记给 `size` 拍照**，写成 `k < queue.size()`，把下一分钟的也处理了；
3. **把弹出的橘子重新入队**，导致队列永不空、死循环；
4. **分钟数无条件 `+1`**，没加 `spread` 判断，示例 3 会错成 `1`；
5. **判定用错基准**：要判"是否全烂"，基准必须是"**初始新鲜数**"（每感染一个就 `fresh--`，末看是否为 0），而不是"初始腐烂数"——腐烂的是"传染源"，不是"待办清单"。

**备注**：等价的计数写法（本题实现用的是减法派）——**加法派**：不维护 `fresh`，而是维护"已处理的橘子数"（每轮 `已处理 += size`）或"已烂总数"，最终与"网格中非空格子总数"比较，相等即全烂，否则 `-1`，二者等价。此外也可在队列里存 `(i, j, time)`，每感染一个就记 `time + 1`，最后取所有时间的最大值，同样正确——但层序 BFS 的"按 `size` 分批"是最贴近直觉的写法。

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

class Solution {
    public int orangesRotting(int[][] grid) {
        int m = grid.length, n = grid[0].length;
        Deque<int[]> queue = new ArrayDeque<>();
        int fresh = 0;

        // 多源：所有腐烂橘子一起入队，同时统计新鲜橘子数
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    queue.add(new int[]{i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        int minutes = 0;
        int[][] dirs = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        while (!queue.isEmpty()) {
            int size = queue.size();            // 先拍照：本批 = 当前这一分钟
            boolean spread = false;             // 本轮有没有感染到新的
            for (int k = 0; k < size; k++) {
                int[] cur = queue.poll();
                int i = cur[0], j = cur[1];
                for (int[] d : dirs) {
                    int ni = i + d[0], nj = j + d[1];
                    if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                        grid[ni][nj] = 2;       // 变烂
                        fresh--;                // 待办 -1
                        queue.add(new int[]{ni, nj});
                        spread = true;
                    }
                }
            }
            if (spread) {                       // 只有真感染了才算一分钟
                minutes++;
            }
        }
        return fresh == 0 ? minutes : -1;       // 还有新鲜 → 够不到
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 m n，接下来 m 行每行 n 个整数
        Scanner sc = new Scanner(System.in);
        int m = sc.nextInt();
        int n = sc.nextInt();
        int[][] grid = new int[m][n];
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                grid[i][j] = sc.nextInt();
            }
        }
        System.out.println(new Solution().orangesRotting(grid));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from collections import deque
from typing import List


class Solution:
    def orangesRotting(self, grid: List[List[int]]) -> int:
        m, n = len(grid), len(grid[0])
        queue = deque()
        fresh = 0

        # 多源：所有腐烂橘子一起入队，同时统计新鲜橘子数
        for i in range(m):
            for j in range(n):
                if grid[i][j] == 2:
                    queue.append((i, j))
                elif grid[i][j] == 1:
                    fresh += 1

        minutes = 0
        dirs = [(-1, 0), (1, 0), (0, -1), (0, 1)]
        while queue:
            size = len(queue)               # 先拍照：本批 = 当前这一分钟
            spread = False                  # 本轮有没有感染到新的
            for _ in range(size):
                i, j = queue.popleft()
                for di, dj in dirs:
                    ni, nj = i + di, j + dj
                    if 0 <= ni < m and 0 <= nj < n and grid[ni][nj] == 1:
                        grid[ni][nj] = 2    # 变烂
                        fresh -= 1          # 待办 -1
                        queue.append((ni, nj))
                        spread = True
            if spread:                      # 只有真感染了才算一分钟
                minutes += 1

        return minutes if fresh == 0 else -1


if __name__ == "__main__":
    # ACM 输入：第一行 m n，接下来 m 行每行 n 个整数
    data = sys.stdin.read().split()
    m, n = int(data[0]), int(data[1])
    vals = list(map(int, data[2:]))
    grid = [vals[i * n:(i + 1) * n] for i in range(m)]
    print(Solution().orangesRotting(grid))
```

```cpp
#include <vector>
#include <queue>
#include <iostream>

class Solution {
public:
    int orangesRotting(vector<vector<int>>& grid) {
        int m = (int)grid.size(), n = (int)grid[0].size();
        queue<pair<int, int>> q;
        int fresh = 0;

        // 多源：所有腐烂橘子一起入队，同时统计新鲜橘子数
        for (int i = 0; i < m; i++) {
            for (int j = 0; j < n; j++) {
                if (grid[i][j] == 2) {
                    q.push({i, j});
                } else if (grid[i][j] == 1) {
                    fresh++;
                }
            }
        }

        int minutes = 0;
        int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
        while (!q.empty()) {
            int size = (int)q.size();           // 先拍照：本批 = 当前这一分钟
            bool spread = false;                // 本轮有没有感染到新的
            for (int k = 0; k < size; k++) {
                int i = q.front().first, j = q.front().second;
                q.pop();
                for (int d = 0; d < 4; d++) {
                    int ni = i + dirs[d][0], nj = j + dirs[d][1];

                        grid[ni][nj] = 2;       // 变烂
                        fresh--;                // 待办 -1
                        q.push({ni, nj});
                        spread = true;
                    }
                }
            }
            if (spread) {                       // 只有真感染了才算一分钟
                minutes++;
            }
        }
        return fresh == 0 ? minutes : -1;       // 还有新鲜 → 够不到
    }
};
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int orangesRotting(int **grid, int gridSize, int *gridColSize) {
    int m = gridSize, n = gridColSize[0];
    int total = m * n;
    /* 手写队列：每个格子最多入队一次，故容量 m * n 足够 */
    int *qi = (int *)malloc(total * sizeof(int));
    int *qj = (int *)malloc(total * sizeof(int));
    int head = 0, tail = 0;
    int fresh = 0;

    for (int i = 0; i < m; i++) {
        for (int j = 0; j < n; j++) {
            if (grid[i][j] == 2) {              /* 多源入队 */
                qi[tail] = i;
                qj[tail] = j;
                tail++;
            } else if (grid[i][j] == 1) {
                fresh++;
            }
        }
    }

    int minutes = 0;
    int dirs[4][2] = {{-1, 0}, {1, 0}, {0, -1}, {0, 1}};
    while (head < tail) {
        int size = tail - head;                 /* 先拍照：本批 = 当前这一分钟 */
        int spread = 0;                         /* 本轮有没有感染到新的 */
        for (int k = 0; k < size; k++) {
            int i = qi[head], j = qj[head];
            head++;
            for (int d = 0; d < 4; d++) {
                int ni = i + dirs[d][0], nj = j + dirs[d][1];
                if (ni >= 0 && ni < m && nj >= 0 && nj < n && grid[ni][nj] == 1) {
                    grid[ni][nj] = 2;           /* 变烂 */
                    fresh--;                    /* 待办 -1 */
                    qi[tail] = ni;
                    qj[tail] = nj;
                    tail++;
                    spread = 1;
                }
            }
        }
        if (spread) {                           /* 只有真感染了才算一分钟 */
            minutes++;
        }
    }

    free(qi);
    free(qj);
    return fresh == 0 ? minutes : -1;           /* 还有新鲜 → 够不到 */
}

int main(void) {
    /* ACM 输入：第一行 m n，接下来 m 行每行 n 个整数 */
    int m, n;
    if (scanf("%d %d", &m, &n) != 2) {
        return 0;
    }
    int **grid = (int **)malloc(m * sizeof(int *));
    int *colSizes = (int *)malloc(m * sizeof(int));
    for (int i = 0; i < m; i++) {
        grid[i] = (int *)malloc(n * sizeof(int));
        colSizes[i] = n;
        for (int j = 0; j < n; j++) {
            scanf("%d", &grid[i][j]);
        }
    }
    printf("%d\n", orangesRotting(grid, m, colSizes));
    for (int i = 0; i < m; i++) {
        free(grid[i]);
    }
    free(grid);
    free(colSizes);
    return 0;
}
```
