# [394. 字符串解码](https://leetcode.cn/problems/decode-string/)

- 🟡 **难度**：中等
- 📚 **分类**：栈
- 🏷️ **标签**：`栈`、`递归`、`字符串`

## 题目描述

给定一个经过编码的字符串，返回它解码后的字符串。

编码规则为: `k[encoded_string]`，表示其中方括号内部的 `encoded_string` 正好重复 `k` 次。注意 `k` 保证为正整数。

你可以认为输入字符串总是有效的；输入字符串中没有额外的空格，且输入的方括号总是符合格式要求的。

此外，你可以认为原始数据不包含数字，所有的数字只表示重复的次数 `k` ，例如不会出现像 `3a` 或 `2[4]` 的输入。

测试用例保证输出的长度不会超过 `10^5`。

**示例 1：**

```
输入：s = "3[a]2[bc]"
输出："aaabcbc"
```

**示例 2：**

```
输入：s = "3[a2[c]]"
输出："accaccacc"
```

**示例 3：**

```
输入：s = "2[abc]3[cd]ef"
输出："abcabccdcdcdef"
```

**示例 4：**

```
输入：s = "abc3[cd]xyz"
输出："abccdcdcdxyz"
```

**提示：**
- `1 <= s.length <= 30`
- `s` 由小写英文字母、数字和方括号 `'[]'` 组成
- `s` 保证是一个 **有效** 的输入。
- `s` 中所有整数的取值范围为 `[1, 300]`

## 题解一：反复展开最内层括号（直观模拟）

思路：**每一轮只展开"最内层"的一对括号，替换掉，重复到没有 `[` 为止。**

为什么"最内层"好找？因为括号是嵌套的，从左往右看到的**第一个 `]`** 必然是最内层的右括号；它配对的 `[` 就是它**左边最近的**那个 `[`。这对括号里不会再嵌括号。

每轮四步：

1. `r` = 第一个 `]` 的位置；
2. `l` = `r` 左边最近的 `[` 的位置（配对）；
3. 从 `l - 1` 向左读出倍数 `k`（支持多位）；
4. 把 `k[...]` 整段换成 `括号内容 × k`，拼回字符串。

关键优势：**每一轮都在"当前字符串"上重新定位**，所以字符串变长变短都不会有坐标漂移；多位数、嵌套也天然成立。

- 时间复杂度：最坏 `O(n^2)`（每轮重建整串，`n` 为编码串长度）
- 空间复杂度：`O(m)`，`m` 为解码结果长度

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public String decodeString(String s) {
        while (s.indexOf('[') != -1) {              // 还有没展开的括号就继续
            int r = s.indexOf(']');                 // 第一个 ']' = 最内层右括号
            int l = s.lastIndexOf('[', r);          // 配对的 '[' = 左边最近的 '['
            int d = l - 1;                          // 向左读出倍数（可多位）
            while (d >= 0 && Character.isDigit(s.charAt(d))) {
                d--;
            }
            int k = Integer.parseInt(s.substring(d + 1, l));
            String inside = s.substring(l + 1, r);  // 括号内内容
            s = s.substring(0, d + 1) + inside.repeat(k) + s.substring(r + 1);
        }
        return s;
    }

    public static void main(String[] args) {
        // ACM 输入：一行编码字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(new Solution().decodeString(s));
        sc.close();
    }
}
```

```python
import sys


class Solution:
    def decodeString(self, s: str) -> str:
        while '[' in s:
            r = s.index(']')                    # 第一个 ']' = 最内层右括号
            l = s.rfind('[', 0, r + 1)          # 配对的 '[' = 左边最近的 '['
            d = l - 1                           # 向左读出倍数（可多位）
            while d >= 0 and s[d].isdigit():
                d -= 1
            k = int(s[d + 1:l])
            inside = s[l + 1:r]                 # 括号内内容
            s = s[:d + 1] + inside * k + s[r + 1:]
        return s
```

### ➕ C++

```cpp
#include <cctype>
#include <string>
#include <iostream>
using namespace std;

class Solution {
public:
    string decodeString(string s) {
        while (s.find('[') != string::npos) {
            size_t r = s.find(']');                 // 第一个 ']' = 最内层右括号
            size_t l = s.rfind('[', r);             // 配对的 '[' = 左边最近的 '['
            int d = (int)l - 1;                     // 向左读出倍数（可多位）
            while (d >= 0 && isdigit((unsigned char)s[d])) {
                d--;
            }
            size_t start = (size_t)(d + 1);
            int k = stoi(s.substr(start, l - start));
            string inside = s.substr(l + 1, r - l - 1);   // 括号内内容
            string rep;
            for (int t = 0; t < k; t++) {
                rep += inside;
            }
            s = s.substr(0, start) + rep + s.substr(r + 1);
        }
        return s;
    }
};

int main() {
    // ACM 输入：一行编码字符串
    string s;
    cin >> s;
    cout << Solution().decodeString(s) << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

char* decodeString(char* s) {
    int len = (int)strlen(s);
    char* buf = (char*)malloc(len + 1);
    strcpy(buf, s);
    while (strchr(buf, '[') != NULL) {
        char* rb = strchr(buf, ']');                 /* 第一个 ']' = 最内层右括号 */
        int r = (int)(rb - buf);
        int l = -1;                                  /* 配对的 '[' = 左边最近的 '[' */
        for (int i = r - 1; i >= 0; i--) {
            if (buf[i] == '[') { l = i; break; }
        }
        int d = l - 1;                               /* 向左读出倍数（可多位） */
        while (d >= 0 && buf[d] >= '0' && buf[d] <= '9') d--;
        int start = d + 1;
        int k = 0;
        for (int i = start; i < l; i++) k = k * 10 + (buf[i] - '0');
        int insideLen = r - l - 1;                   /* 括号内内容长度 */
        int suffixLen = (int)strlen(buf) - (r + 1);
        int newLen = start + insideLen * k + suffixLen;
        char* nb = (char*)malloc(newLen + 1);
        memcpy(nb, buf, start);                      /* 前缀 */
        int pos = start;
        for (int t = 0; t < k; t++) {                /* 内容重复 k 次 */
            memcpy(nb + pos, buf + l + 1, insideLen);
            pos += insideLen;
        }
        memcpy(nb + pos, buf + r + 1, suffixLen);    /* 后缀 */
        nb[newLen] = '\0';
        free(buf);
        buf = nb;
    }
    return buf;
}

int main(void) {
    /* ACM 输入：一行编码字符串 */
    char s[64];
    if (scanf("%63s", s) != 1) {
        return 0;
    }
    char* res = decodeString(s);
    printf("%s\n", res);
    free(res);
    return 0;
}
```

## 题解二：栈（一遍扫描，增量构造）

换个更高效的模型：**不碰中间，只往当前层尾部追加**，用两个栈维护"进入每一层时的现场"。

- `countStack`：每层的倍数 `k`；
- `strStack`：进入该层**之前**已经拼好的前缀；
- `cur`：当前层正在拼的串。

一遍扫描四个分支：

- **数字**：`k = k * 10 + digit`，累积出多位倍数；
- **`[`**：把 `(k, 前缀 cur)` 压栈，然后 `cur` 清空、`k` 清零，开始新一层；
- **`]`**：弹出 `(k, 前缀)`，令 `cur = 前缀 + 本层内容 × k`，即把本层结果接回上一层；
- **字母**：直接 `cur` 追加。

因为全程只在尾部 `append`，不存在"中间替换 / 下标漂移"，嵌套也由栈自然处理。

- 时间复杂度：`O(m)`，`m` 为解码结果长度（每个字符只在 append 时被复制）
- 空间复杂度：`O(m)`

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public String decodeString(String s) {
        Deque<Integer> countStack = new ArrayDeque<>();   // 每层的倍数 k
        Deque<String> strStack = new ArrayDeque<>();      // 进本层前已拼好的前缀
        StringBuilder cur = new StringBuilder();          // 当前层正在拼的串
        int k = 0;
        for (char c : s.toCharArray()) {
            if (c >= '0' && c <= '9') {
                k = k * 10 + (c - '0');                   // 累积多位数字
            } else if (c == '[') {
                countStack.push(k);
                strStack.push(cur.toString());
                cur.setLength(0);
                k = 0;
            } else if (c == ']') {
                int repeat = countStack.pop();
                StringBuilder expanded = new StringBuilder(strStack.pop());
                for (int i = 0; i < repeat; i++) {
                    expanded.append(cur);
                }
                cur = expanded;
            } else {
                cur.append(c);
            }
        }
        return cur.toString();
    }

    public static void main(String[] args) {
        // ACM 输入：一行编码字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(new Solution().decodeString(s));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys


class Solution:
    def decodeString(self, s: str) -> str:
        count_stack = []          # 每层的倍数 k
        str_stack = []            # 进本层前已拼好的前缀
        cur = []                  # 当前层正在拼的字符列表
        k = 0
        for c in s:
            if c.isdigit():
                k = k * 10 + int(c)                     # 累积多位数字
            elif c == '[':
                count_stack.append(k)
                str_stack.append(''.join(cur))
                cur = []
                k = 0
            elif c == ']':
                repeat = count_stack.pop()
                prefix = str_stack.pop()
                cur = [prefix + ''.join(cur) * repeat]  # 本层结果接回上一层
            else:
                cur.append(c)
        return ''.join(cur)


if __name__ == "__main__":
    # ACM 输入：一行编码字符串
    s = sys.stdin.read().strip()
    print(Solution().decodeString(s))
```

### ➕ C++

```cpp
#include <cctype>
#include <string>
#include <stack>
#include <iostream>
using namespace std;

class Solution {
public:
    string decodeString(string s) {
        stack<int> countStack;          // 每层的倍数 k
        stack<string> strStack;         // 进本层前已拼好的前缀
        string cur;                     // 当前层正在拼的串
        int k = 0;
        for (char c : s) {
            if (isdigit((unsigned char)c)) {
                k = k * 10 + (c - '0'); // 累积多位数字
            } else if (c == '[') {
                countStack.push(k);
                strStack.push(cur);
                cur.clear();
                k = 0;
            } else if (c == ']') {
                int repeat = countStack.top();
                countStack.pop();
                string prefix = strStack.top();
                strStack.pop();
                string expanded = prefix;
                for (int i = 0; i < repeat; i++) {
                    expanded += cur;
                }
                cur = expanded;
            } else {
                cur += c;
            }
        }
        return cur;
    }
};

int main() {
    // ACM 输入：一行编码字符串
    string s;
    cin >> s;
    cout << Solution().decodeString(s) << endl;
    return 0;
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

static char* dupStr(const char* s) {
    char* p = (char*)malloc(strlen(s) + 1);
    strcpy(p, s);
    return p;
}

char* decodeString(char* s) {
    int countStack[64], ctop = 0;        /* 每层的倍数 k */
    char* strStack[64]; int stop = 0;    /* 进本层前已拼好的前缀 */
    char* cur = dupStr("");              /* 当前层正在拼的串 */
    int cap = 1, len = 0;                /* cur 的容量与长度（不含结尾 '\0'） */
    int k = 0;

    for (int i = 0; s[i] != '\0'; i++) {
        char c = s[i];
        if (c >= '0' && c <= '9') {
            k = k * 10 + (c - '0');               /* 累积多位数字 */
        } else if (c == '[') {
            countStack[ctop++] = k;
            strStack[stop++] = cur;               /* 前缀入栈（转交所有权） */
            cur = dupStr("");
            cap = 1;
            len = 0;
            k = 0;
        } else if (c == ']') {
            int repeat = countStack[--ctop];
            char* prefix = strStack[--stop];
            int plen = (int)strlen(prefix);
            int newLen = plen + len * repeat;
            char* nb = (char*)malloc(newLen + 1);
            memcpy(nb, prefix, plen);
            int pos = plen;
            for (int t = 0; t < repeat; t++) {    /* 本层内容重复 k 次接上去 */
                memcpy(nb + pos, cur, len);
                pos += len;
            }
            nb[newLen] = '\0';
            free(prefix);
            free(cur);
            cur = nb;
            cap = newLen + 1;
            len = newLen;
        } else {
            if (len + 1 >= cap) {                 /* 普通字母：追加到 cur */
                cap = cap * 2 + 1;
                cur = (char*)realloc(cur, cap);
            }
            cur[len++] = c;
            cur[len] = '\0';
        }
    }
    return cur;
}

int main(void) {
    /* ACM 输入：一行编码字符串 */
    char s[64];
    if (scanf("%63s", s) != 1) {
        return 0;
    }
    char* res = decodeString(s);
    printf("%s\n", res);
    free(res);
    return 0;
}
```
