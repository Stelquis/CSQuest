# [20. 有效的括号](https://leetcode.cn/problems/valid-parentheses/)

- 🟢 **难度**：简单
- 📚 **分类**：栈
- 🏷️ **标签**：`栈`、`字符串`、`括号序列`

## 题目描述

给定一个只包括 `'('`，`')'`，`'{'`，`'}'`，`'['`，`']'` 的字符串 `s` ，判断字符串是否有效。

有效字符串需满足：
- 左括号必须用相同类型的右括号闭合。
- 左括号必须以正确的顺序闭合。
- 每个右括号都有一个对应的相同类型的左括号。

**示例 1：**

**输入：** s = "()"

**输出：** true

**示例 2：**

**输入：** s = "()[]{}"

**输出：** true

**示例 3：**

**输入：** s = "(]"

**输出：** false

**示例 4：**

**输入：** s = "([])"

**输出：** true

**示例 5：**

**输入：** s = "([)]"

**输出：** false

**提示：**
- `1 <= s.length <= 10^4`
- `s` 仅由括号 `'()[]{}'` 组成

## 题解一：栈（逐个类型比对）

括号匹配天然满足"后进先出"：**最后出现的左括号，必须最先被闭合**，这正是栈的语义。

从左到右扫描：

- 遇到**左括号** → 入栈；
- 遇到**右括号** → 若栈为空，说明这是"多余的右括号"，直接 `false`；否则弹出栈顶，检查二者是否为同一类型，不匹配则 `false`。

扫描结束后，栈必须为空（否则还剩未闭合的"多余的左括号"）。

两个关键点：**弹出前先判空**（对应多余右括号）、**结束后判空**（对应多余左括号）。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，最坏全是左括号

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(' || c == '[' || c == '{') {
                stack.push(c);                  // 左括号直接入栈
            } else {
                if (stack.isEmpty()) {
                    return false;               // 多余的右括号
                }
                char top = stack.pop();
                if (c == ')' && top != '(') return false;
                if (c == ']' && top != '[') return false;
                if (c == '}' && top != '{') return false;
            }
        }
        return stack.isEmpty();                 // 左括号必须全部闭合
    }

    public static void main(String[] args) {
        // ACM 输入：一行括号字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(new Solution().isValid(s) ? "true" : "false");
        sc.close();
    }
}
```

### ⚙️ C

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>
#include <string.h>

bool isValid(char* s) {
    int n = (int)strlen(s);
    char* stack = (char*)malloc(n * sizeof(char));   // 手写栈：数组 + top
    int top = 0;                                      // top == 0 表示空栈
    for (int i = 0; i < n; i++) {
        char c = s[i];
        if (c == '(' || c == '[' || c == '{') {
            stack[top++] = c;                         // 左括号入栈
        } else {
            if (top == 0) {                           // 多余的右括号
                free(stack);
                return false;
            }
            char t = stack[--top];
            if ((c == ')' && t != '(') ||
                (c == ']' && t != '[') ||
                (c == '}' && t != '{')) {
                free(stack);
                return false;
            }
        }
    }
    bool ok = (top == 0);                             // 左括号必须全部闭合
    free(stack);
    return ok;
}

int main(void) {
    // ACM 输入：一行括号字符串
    char s[10005];
    if (scanf("%10004s", s) != 1) {
        return 0;
    }
    printf("%s\n", isValid(s) ? "true" : "false");
    return 0;
}
```

## 题解二：栈（预存期望的右括号）

换个技巧：遇到左括号时，**不压它本身，而是直接压入它"期望匹配的右括号"**。

这样一来，遇到任意右括号时，只需判断"栈顶是否恰好等于当前字符"即可，省去了逐个类型的 `if` 比对——匹配关系的三选一被提前转移到了入栈那一刻。

- 遇到 `(` / `[` / `{` → 压入 `)` / `]` / `}`；
- 遇到右括号 → 栈空 或 弹出值与当前字符不等 → `false`；
- 结束后栈必须为空。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public boolean isValid(String s) {
        Deque<Character> stack = new ArrayDeque<>();
        for (char c : s.toCharArray()) {
            if (c == '(') {
                stack.push(')');                // 压入期望匹配的右括号
            } else if (c == '[') {
                stack.push(']');
            } else if (c == '{') {
                stack.push('}');
            } else {
                if (stack.isEmpty() || stack.pop() != c) {
                    return false;               // 多余或不匹配
                }
            }
        }
        return stack.isEmpty();
    }

    public static void main(String[] args) {
        // ACM 输入：一行括号字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.next();
        System.out.println(new Solution().isValid(s) ? "true" : "false");
        sc.close();
    }
}
```
