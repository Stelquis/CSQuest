# [84. 柱状图中最大的矩形](https://leetcode.cn/problems/largest-rectangle-in-histogram/)

- 🔴 **难度**：困难
- 📚 **分类**：栈
- 🏷️ **标签**：`栈`、`数组`、`单调栈`、`区间最值查询`

## 题目描述

给定 *n* 个非负整数，用来表示柱状图中各个柱子的高度。每个柱子彼此相邻，且宽度为 1 。

求在该柱状图中，能够勾勒出来的矩形的最大面积。

**示例 1:**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram.jpg)

```
输入：heights = [2,1,5,6,2,3]
输出：10
解释：最大的矩形为图中红色区域，面积为 10
```

**示例 2：**

![](https://assets.leetcode.com/uploads/2021/01/04/histogram-1.jpg)

```
输入： heights = [2,4]
输出： 4
```

**提示：**
- `1 <= heights.length <=10^5`
- `0 <= heights[i] <= 10^4`

## 题解一：两趟单调栈（先求左右第一个更矮）

核心转换：对每根柱子 `i`（高 `h = heights[i]`），它能撑起的矩形宽度 = **它左右两边第一个"严格更矮"的柱子之间的跨度**：

```
面积[i] = h * (右边界位置 - 左边界位置 - 1)
```

（等高的柱子挡不住它，可以并进来，所以找的是**严格更矮**。）

用两个**递增栈**（存下标）分别求出左右边界：

- **第一趟（从左往右）**：求 `left[i]` = 左边第一个更矮的位置，没有记 `-1`。做法是「把栈里比当前高/等高的都弹掉」，剩下的栈顶就是答案。
- **第二趟（从右往左）**：方向反过来，求 `right[i]` = 右边第一个更矮的位置，没有记 `n`。

最后对每根柱子算一次面积取最大。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        int[] left = new int[n];        // left[i] = 左边第一个更矮的位置，没有记 -1
        int[] right = new int[n];       // right[i] = 右边第一个更矮的位置，没有记 n
        Deque<Integer> stack = new ArrayDeque<>();   // 存下标，高度递增

        for (int i = 0; i < n; i++) {
            while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
                stack.pop();
            }
            left[i] = stack.isEmpty() ? -1 : stack.peek();
            stack.push(i);
        }
        stack.clear();
        for (int i = n - 1; i >= 0; i--) {
            while (!stack.isEmpty() && heights[stack.peek()] >= heights[i]) {
                stack.pop();
            }
            right[i] = stack.isEmpty() ? n : stack.peek();
            stack.push(i);
        }

        int ans = 0;
        for (int i = 0; i < n; i++) {
            ans = Math.max(ans, heights[i] * (right[i] - left[i] - 1));
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] heights = new int[n];
        for (int i = 0; i < n; i++) {
            heights[i] = sc.nextInt();
        }
        System.out.println(new Solution().largestRectangleArea(heights));
        sc.close();
    }
}
```

```python
import sys
from typing import List


class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:
        n = len(heights)
        left = [0] * n        # left[i] = 左边第一个更矮的位置，没有记 -1
        right = [0] * n       # right[i] = 右边第一个更矮的位置，没有记 n
        stack = []            # 存下标，高度递增

        for i in range(n):
            while stack and heights[stack[-1]] >= heights[i]:
                stack.pop()
            left[i] = -1 if not stack else stack[-1]
            stack.append(i)

        stack = []
        for i in range(n - 1, -1, -1):
            while stack and heights[stack[-1]] >= heights[i]:
                stack.pop()
            right[i] = n if not stack else stack[-1]
            stack.append(i)

        ans = 0
        for i in range(n):
            ans = max(ans, heights[i] * (right[i] - left[i] - 1))
        return ans
```

```c
#include <stdio.h>
#include <stdlib.h>

int largestRectangleArea(int* heights, int heightsSize) {
    int n = heightsSize;
    int* left = (int*)malloc(n * sizeof(int));    /* 左边第一个更矮的位置 */
    int* right = (int*)malloc(n * sizeof(int));   /* 右边第一个更矮的位置 */
    int* stack = (int*)malloc(n * sizeof(int));   /* 存下标，高度递增 */
    int top = 0;

    for (int i = 0; i < n; i++) {
        while (top > 0 && heights[stack[top - 1]] >= heights[i]) {
            top--;
        }
        left[i] = (top == 0) ? -1 : stack[top - 1];
        stack[top++] = i;
    }
    top = 0;
    for (int i = n - 1; i >= 0; i--) {
        while (top > 0 && heights[stack[top - 1]] >= heights[i]) {
            top--;
        }
        right[i] = (top == 0) ? n : stack[top - 1];
        stack[top++] = i;
    }

    int ans = 0;
    for (int i = 0; i < n; i++) {
        int area = heights[i] * (right[i] - left[i] - 1);
        if (area > ans) {
            ans = area;
        }
    }
    free(left);
    free(right);
    free(stack);
    return ans;
}
```

## 题解二：一趟单调栈 + 两端哨兵

上一版要扫两遍、开两个数组。其实**一遍就能同时拿到左右边界**：

用高度**递增**的栈（存下标，两端各补一个高度 `0` 的哨兵）。遍历时，一旦遇到**比栈顶更矮**的柱子 `i`：

- 弹出栈顶 `cur`：`i` 就是它的**右边界**；
- 弹掉后**露出的新栈顶**就是它的**左边界**；
- 于是当场算出 `cur` 的宽 = `i - 新栈顶 - 1`，面积 = `heights[cur] * 宽`。

一句话：**"谁把我顶出来，谁就是我的右边界；弹掉我之后露出的那根，就是我的左边界。"**

两端哨兵（高度 0）保证：

- 每根真实柱子最终都会被顶出来，不留遗漏；
- 栈永远非空，弹出的柱子必有左边界，**免去一切特判**。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public int largestRectangleArea(int[] heights) {
        int n = heights.length;
        int[] nums = new int[n + 2];          // 两端补高度 0 的哨兵
        nums[0] = 0;
        nums[n + 1] = 0;
        for (int i = 1; i <= n; i++) {
            nums[i] = heights[i - 1];
        }

        int ans = 0;
        Deque<Integer> stack = new ArrayDeque<>();   // 存下标，高度递增
        for (int i = 0; i <= n + 1; i++) {
            while (!stack.isEmpty() && nums[stack.peek()] > nums[i]) {
                int h = nums[stack.pop()];           // 被顶出来的柱子
                int w = i - stack.peek() - 1;        // 新栈顶就是它的左边界
                ans = Math.max(ans, h * w);
            }
            stack.push(i);
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：第一行 n，第二行 n 个整数
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        int[] heights = new int[n];
        for (int i = 0; i < n; i++) {
            heights[i] = sc.nextInt();
        }
        System.out.println(new Solution().largestRectangleArea(heights));
        sc.close();
    }
}
```

```python
import sys
from typing import List


class Solution:
    def largestRectangleArea(self, heights: List[int]) -> int:

            stack.append(i)
```

```cpp
#include <vector>
#include <iostream>
using namespace std;

class Solution {
public:
    int largestRectangleArea(vector<int>& heights) {
        vector<int> nums;                    // 两端补高度 0 的哨兵
        nums.push_back(0);
        for (int h : heights) nums.push_back(h);
        nums.push_back(0);

        int ans = 0;
        vector<int> stack;                   // 存下标，高度递增
        for (int i = 0; i < (int)nums.size(); i++) {
            while (!stack.empty() && nums[stack.back()] > nums[i]) {
                int cur = nums[stack.back()];   // 被顶出来的柱子
                stack.pop_back();
                ans = max(ans, cur * (i - stack.back() - 1));   // 新栈顶即左边界
            }
            stack.push_back(i);
        }
        return ans;
    }
};
```

```c
#include <stdio.h>
#include <stdlib.h>

int largestRectangleArea(int* heights, int heightsSize) {
    int n = heightsSize;
    int m = n + 2;
    int* nums = (int*)malloc(m * sizeof(int));    /* 两端补高度 0 的哨兵 */
    nums[0] = 0;
    nums[n + 1] = 0;
    for (int i = 1; i <= n; i++) {
        nums[i] = heights[i - 1];
    }

    int* stack = (int*)malloc(m * sizeof(int));   /* 存下标，高度递增 */
    int top = 0;
    int ans = 0;
    for (int i = 0; i < m; i++) {
        while (top > 0 && nums[stack[top - 1]] > nums[i]) {
            int cur = nums[stack[--top]];         /* 被顶出来的柱子 */
            int w = i - stack[top - 1] - 1;       /* 新栈顶即左边界 */
            int area = cur * w;
            if (area > ans) {
                ans = area;
            }
        }
        stack[top++] = i;
    }
    free(nums);
    free(stack);
    return ans;
}

int main(void) {
    /* ACM 输入：第一行 n，第二行 n 个整数 */

    if (scanf("%d", &n) != 1) {
        return 0;
    }
    int* heights = (int*)malloc(n * sizeof(int));
    for (int i = 0; i < n; i++) {
        scanf("%d", &heights[i]);
    }
    printf("%d\n", largestRectangleArea(heights, n));
    free(heights);
    return 0;
}
```
