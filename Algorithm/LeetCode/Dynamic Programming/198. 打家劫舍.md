# [198. 打家劫舍](https://leetcode.cn/problems/house-robber/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`数组`、`动态规划`

## 题目描述

你是一个专业的小偷，计划偷窃沿街的房屋。每间房内都藏有一定的现金，影响你偷窃的唯一制约因素就是相邻的房屋装有相互连通的防盗系统，**如果两间相邻的房屋在同一晚上被小偷闯入，系统会自动报警**。

给定一个代表每个房屋存放金额的非负整数数组，计算你 **不触动警报装置的情况下** ，一夜之内能够偷窃到的最高金额。

**示例 1：**

```
输入：[1,2,3,1]
输出：4
解释：偷窃 1 号房屋 (金额 = 1) ，然后偷窃 3 号房屋 (金额 = 3)。
     偷窃到的最高金额 = 1 + 3 = 4 。
```

**示例 2：**

```
输入：[2,7,9,3,1]
输出：12
解释：偷窃 1 号房屋 (金额 = 2), 偷窃 3 号房屋 (金额 = 9)，接着偷窃 5 号房屋 (金额 = 1)。
     偷窃到的最高金额 = 2 + 9 + 1 = 12 。
```

**提示：**
- `1 <= nums.length <= 100`
- `0 <= nums[i] <= 400`

## 题解一：动态规划（dp 数组）

状态定义：`dp[i]` = **考虑前 `i+1` 间房**（下标 `0..i`）能偷到的最大金额。对第 `i` 间房只有两种选择：

- **不偷**：结果就是 `dp[i-1]`（前 `i` 间房的最优不变）
- **偷**：第 `i-1` 间必须不偷，收益 = `nums[i] + dp[i-2]`

转移方程：`dp[i] = max(dp[i-1], nums[i] + dp[i-2])`，初始 `dp[0] = nums[0]`、`dp[1] = max(nums[0], nums[1])`。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，dp 数组

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int rob(int[] nums) {
        if (nums.length == 1) {
            return nums[0];
        }
        int[] dp = new int[nums.length];
        dp[0] = nums[0];
        dp[1] = Math.max(nums[0], nums[1]);
        for (int i = 2; i < nums.length; i++) {
            // 不偷第 i 间 / 偷第 i 间（则第 i-1 间必不偷）
            dp[i] = Math.max(dp[i - 1], nums[i] + dp[i - 2]);
        }
        return dp[nums.length - 1];
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的房屋金额
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().rob(nums));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        if len(nums) == 1:
            return nums[0]
        dp = [0] * len(nums)
        dp[0] = nums[0]
        dp[1] = max(nums[0], nums[1])
        for i in range(2, len(nums)):
            dp[i] = max(dp[i - 1], nums[i] + dp[i - 2])
        return dp[-1]


if __name__ == "__main__":
    # ACM 输入：一行空格分隔的房屋金额
    nums = [int(x) for x in sys.stdin.read().split()]
    print(Solution().rob(nums))
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int rob(int* nums, int n) {
    if (n == 1) {
        return nums[0];
    }
    int* dp = (int*)malloc(n * sizeof(int));
    dp[0] = nums[0];
    dp[1] = nums[0] > nums[1] ? nums[0] : nums[1];
    for (int i = 2; i < n; i++) {
        int skip = dp[i - 1];
        int take = nums[i] + dp[i - 2];
        dp[i] = skip > take ? skip : take;
    }
    int ans = dp[n - 1];
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：一行空格分隔的房屋金额
    int* nums = (int*)malloc(1000 * sizeof(int));
    int n = 0;
    while (n < 1000 && scanf("%d", &nums[n]) == 1) {
        n++;
    }
    printf("%d\n", rob(nums, n));
    free(nums);
    return 0;
}
```

## 题解二：滚动变量（空间压缩到 O(1)）

观察转移方程：`dp[i]` 只依赖 `dp[i-1]` 和 `dp[i-2]`，因此整条 dp 数组可以压成两个变量——`prev2`（dp[i-2]）、`prev1`（dp[i-1]），每轮向前滚动。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int rob(int[] nums) {
        int prev2 = 0;      // dp[i-2]
        int prev1 = 0;      // dp[i-1]
        for (int x : nums) {
            int cur = Math.max(prev1, x + prev2);
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的房屋金额
        Scanner sc = new Scanner(System.in);
        int prev2 = 0, prev1 = 0;
        while (sc.hasNextInt()) {
            int x = sc.nextInt();
            int cur = Math.max(prev1, x + prev2);
            prev2 = prev1;
            prev1 = cur;
        }
        System.out.println(prev1);
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from typing import List


class Solution:
    def rob(self, nums: List[int]) -> int:
        prev2, prev1 = 0, 0          # dp[i-2], dp[i-1]
        for x in nums:
            prev2, prev1 = prev1, max(prev1, x + prev2)
        return prev1
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int rob(int* nums, int n) {
    int prev2 = 0, prev1 = 0;    // dp[i-2], dp[i-1]
    for (int i = 0; i < n; i++) {
        int take = prev2 + nums[i];              // 偷第 i 间
        int cur = take > prev1 ? take : prev1;   // 与不偷比较
        prev2 = prev1;
        prev1 = cur;
    }
    return prev1;
}

int main(void) {
    // ACM 输入：一行空格分隔的房屋金额
    int* nums = (int*)malloc(1000 * sizeof(int));
    int n = 0;
    while (n < 1000 && scanf("%d", &nums[n]) == 1) {
        n++;
    }
    printf("%d\n", rob(nums, n));
    free(nums);
    return 0;
}
```
