# [279. 完全平方数](https://leetcode.cn/problems/perfect-squares/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`广度优先搜索`、`数学`、`动态规划`、`背包问题`、`完全背包`

## 题目描述

给你一个整数 `n` ，返回 *和为 `n` 的完全平方数的最少数量* 。

**完全平方数** 是一个整数，其值等于另一个整数的平方；换句话说，其值等于一个整数自乘的积。例如，`1`、`4`、`9` 和 `16` 都是完全平方数，而 `3` 和 `11` 不是。

**示例 1：**

```
输入：n = 12
输出：3 
解释：12 = 4 + 4 + 4
```

**示例 2：**

```
输入：n = 13
输出：2
解释：13 = 4 + 9
```

**提示：**
- `1 <= n <= 10^4`

## 题解一：完全背包（动态规划）

把每个平方数 `j²`（`j² ≤ n`）看成一种**数量不限的物品**（完全背包），`n` 是背包容量，每用一个平方数代价 +1，求最小代价。

状态与转移：

- `dp[i]` = 凑出 `i` 所需的最少平方数个数，`dp[0] = 0`
- `dp[i] = min(dp[i - j²] + 1)`，对所有 `j² ≤ i`

重复使用同一平方数**不需要任何特殊机制**——"枚举最后一个平方数"的分解方式天然允许：`12 = 4+4+4` 通过 `dp[8] + 1` 找到，而 `dp[8] = 2` 又来自 `dp[4] + 1`。

附带收益：`j = 1` 恒可选，`dp[i]` 永远有限（`dp[i] ≥ dp[i-1]`），因此 `dp[i - j²] + 1` 不会发生 `MAX_VALUE` 溢出，无需额外守卫。

- 时间复杂度：`O(n·√n)`，外层 n，内层枚举 j² ≤ i 共 √n 个
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int numSquares(int n) {
        // dp[i] 表示和为 i 的最少完全平方数个数
        int[] dp = new int[n + 1];
        dp[0] = 0;
        for (int i = 1; i <= n; i++) {
            dp[i] = Integer.MAX_VALUE;
            for (int j = 1; j * j <= i; j++) {
                // j = 1 恒可选，dp[i - j*j] 恒有限，无溢出风险
                dp[i] = Math.min(dp[i], dp[i - j * j] + 1);
            }
        }
        return dp[n];
    }

    public static void main(String[] args) {
        // ACM 输入：一个整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(new Solution().numSquares(n));
        sc.close();
    }
}
```

import sys


class Solution:
    def numSquares(self, n: int) -> int:
        # dp[i] 表示和为 i 的最少完全平方数个数
        dp = [0] + [float('inf')] * n
        for i in range(1, n + 1):
            j = 1
            while j * j <= i:
                dp[i] = min(dp[i], dp[i - j * j] + 1)
                j += 1
        return dp[n]

int numSquares(int n) {
    int* dp = (int*)malloc((n + 1) * sizeof(int));
    dp[0] = 0;
    for (int i = 1; i <= n; i++) {
        dp[i] = INT_MAX;
        for (int j = 1; j * j <= i; j++) {
            // j = 1 恒可选，dp[i - j*j] 恒有限，无溢出风险
            if (dp[i - j * j] + 1 < dp[i]) {
                dp[i] = dp[i - j * j] + 1;
            }
        }
    }
    int ans = dp[n];
    free(dp);
    return ans;
}

## 题解二：数学（四平方定理，O(√n)）

两条数论定理直接锁定答案范围：

- **拉格朗日四平方定理**：任何正整数都能表示为 **至多 4 个**完全平方数之和 → 答案只能是 1、2、3、4
- **勒让德三平方定理**：当且仅当 `n = 4^a · (8b + 7)` 时，n **无法**用 3 个平方数表示 → 此时答案是 4

于是按 `1 → 2 → 4 → 3` 的顺序判定（3 无需计算，四平方定理兜底）：

1. `n` 本身是完全平方数 → **1**（O(1)）
2. 剥离所有因子 4 后余数为 `8b+7` → **4**（O(log n)）
3. 枚举 `k`，若 `n - k²` 是完全平方数 → **2**（O(√n)）
4. 以上皆否 → **3**

- 时间复杂度：`O(√n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int numSquares(int n) {
        // ① 勒让德判定：n = 4^a * (8b+7) 形式 → 答案为 4
        int m = n;
        while (m % 4 == 0) {
            m /= 4;
        }
        if (m % 8 == 7) {
            return 4;
        }
        // ② 答案为 1：n 本身是完全平方数
        if (isSquare(n)) {
            return 1;
        }
        // ③ 答案为 2：存在 k 使 n - k² 为完全平方数
        for (int k = 1; k * k < n; k++) {
            if (isSquare(n - k * k)) {
                return 2;
            }
        }
        // ④ 四平方定理兜底：答案为 3
        return 3;
    }

    // 完全平方判定（避免浮点误差：先取平方根再回代验证）
    public static boolean isSquare(int x) {
        int r = (int) Math.sqrt(x);
        return r * r == x;
    }

    public static void main(String[] args) {
        // ACM 输入：一个整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(new Solution().numSquares(n));
        sc.close();
    }
}
```

### 🐍 Python

```python
import math
import sys


class Solution:
    def numSquares(self, n: int) -> int:
        # ① 勒让德判定：n = 4^a * (8b+7) 形式 → 答案为 4
        m = n
        while m % 4 == 0:
            m //= 4
        if m % 8 == 7:
            return 4
        # ② 答案为 1：n 本身是完全平方数
        r = math.isqrt(n)
        if r * r == n:
            return 1
        # ③ 答案为 2：存在 k 使 n - k² 为完全平方数
        k = 1
        while k * k < n:
            r = math.isqrt(n - k * k)
            if r * r == n - k * k:
                return 2
            k += 1
        # ④ 四平方定理兜底：答案为 3
        return 3


if __name__ == "__main__":
    # ACM 输入：一个整数 n
    n = int(sys.stdin.read().split()[0])
    print(Solution().numSquares(n))
```
