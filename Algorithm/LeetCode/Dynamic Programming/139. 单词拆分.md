# [139. 单词拆分](https://leetcode.cn/problems/word-break/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`字典树`、`记忆化`、`数组`、`哈希表`、`字符串`、`动态规划`、`Brute-Force Search`

## 题目描述

给你一个字符串 `s` 和一个字符串列表 `wordDict` 作为字典。如果可以利用字典中出现的一个或多个单词拼接出 `s` 则返回 `true`。

**注意：** 不要求字典中出现的单词全部都使用，并且字典中的单词可以重复使用。

**示例 1：**

```
输入: s = "leetcode", wordDict = ["leet", "code"]
输出: true
解释: 返回 true 因为 "leetcode" 可以由 "leet" 和 "code" 拼接成。
```

**示例 2：**

```
输入: s = "applepenapple", wordDict = ["apple", "pen"]
输出: true
解释: 返回 true 因为 "applepenapple" 可以由 "apple" "pen" "apple" 拼接成。
     注意，你可以重复使用字典中的单词。
```

**示例 3：**

```
输入: s = "catsandog", wordDict = ["cats", "dog", "sand", "and", "cat"]
输出: false
```

**提示：**
- `1 <= s.length <= 300`
- `1 <= wordDict.length <= 1000`
- `1 <= wordDict[i].length <= 20`
- `s` 和 `wordDict[i]` 仅由小写英文字母组成
- `wordDict` 中的所有字符串 **互不相同**

## 题解一：动态规划（前缀可达性，O(n·m·L)）

状态定义与转移：

- `dp[i]` = 前缀 `s[0..i)` 能否被字典拼出，`dp[0] = true`（空串天然可拼）
- `dp[i] = OR( dp[i - |w|] && s[i-|w|..i) == w )`，对所有词 `w`

思路是"枚举前缀的**最后一个单词**"：若 `s[0..i)` 可拼，其最后一个词必是某个 `w`，剩余前缀 `s[0..i-|w|)` 也必须可拼。**只有 `dp[j] == true` 的位置才有资格做起跳板**延伸到更远的 `i`。

要点：

- boolean 型 DP 没有"无穷大哨兵"问题，true/false 天然封闭于 OR/AND，`dp[0]` 就是基准
- 内层枚举字典词，`startsWith(word, i - len)` 匹配词尾；命中即 `break`（存在性题，一种拼法足矣）
- **`i` 必须做外层（排列型）**：单词按顺序拼接，与 322 的"求排列数必须金额在外层"同理。反例：`s = "abc"`、`dict = ["bc", "a"]`，若词做外层会先处理 `"bc"`（此时 `dp[1]` 还是 false），再处理 `"a"` 后不再回头，`dp[3]` 漏判为 false
- 复杂度优化：内层改为枚举切分点 `j ∈ [i-L, i)`（L 为最大词长 ≤ 20），字典装 `HashSet` 查询，得 `O(n·L²)`

- 时间复杂度：`O(n·m·L)`，n = |s|，m = 词数，L = 最大词长
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    public boolean wordBreak(String s, List<String> wordDict) {
        int n = s.length();
        boolean[] dp = new boolean[n + 1];
        dp[0] = true; // 空串可拼
        for (int i = 1; i <= n; i++) {
            for (String word : wordDict) {
                int len = word.length();
                // 起跳板可拼 && 这个词正好踩满词尾
                if (len <= i && dp[i - len] && s.startsWith(word, i - len)) {
                    dp[i] = true;
                    break; // 存在性问题，一种拼法足矣
                }
            }
        }
        return dp[n];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行字符串 s，第二行空格分隔的字典单词
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().trim();
        List<String> dict = new ArrayList<>();
        while (sc.hasNext()) {
            dict.add(sc.next());
        }
        System.out.println(new Solution().wordBreak(s, dict));
        sc.close();
    }
}
```

## 题解二：记忆化搜索（自顶向下，O(n·m·L)）

与题解一互为镜像的写法。状态：`dfs(start)` = **后缀** `s[start..n)` 能否被拼出。

从暴力 DFS 出发的两步改造：

1. **观察重复**：`dfs(start)` 的答案只由 `start` 决定，与"如何走到 `start`"无关（无后效性）。搜索树上不同路径会反复访问同一 `start`（例：`"aaaab"` 配 `["a","aa","aaa"]`，`dfs(2)`、`dfs(3)` 被多次重复计算）；
2. **加缓存**：`memo[start]` 存"该位置算过没有、答案是什么"，命中直接返回，指数塌缩为每个状态至多完整计算一次。

两个易踩的坑：

- **`false` 也必须缓存**："从 start 拼不出来"这个否定结论同样能免掉一整棵子树，只缓存 `true` 最坏仍爆炸；用 `Boolean` 包装类型借 `null` 表示"未计算"
- 成功短路保留：`dfs` 返回 `true` 时沿调用链原样上抛，同层未试的词与其余分支全部作废——存在性问题第一个完整组合即定答案

与题解一的镜像关系：`dp[0] = true` ↔ `dfs(n) = true`；`dp[i - len]`（回看前缀）↔ `dfs(start + len)`（前探后缀）；两版计算的是同一张表，复杂度相同。

- 时间复杂度：`O(n·m·L)`
- 空间复杂度：`O(n)`，memo 数组 + 递归栈

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    static String s;
    static List<String> dict;
    static Boolean[] memo; // null=未计算

    public boolean wordBreak(String s, List<String> wordDict) {
        Solution.s = s;
        dict = wordDict;
        memo = new Boolean[s.length()];
        return dfs(0);
    }

    // dfs(start)：后缀 s[start..n) 能否被字典拼出
    public static boolean dfs(int start) {
        if (start == s.length()) {
            return true; // 串吃光了
        }
        if (memo[start] != null) {
            return memo[start]; // 算过，直接抄答案
        }
        for (String word : dict) {
            if (s.startsWith(word, start) && dfs(start + word.length())) {
                return memo[start] = true; // 成功短路，沿途上抛
            }
        }
        return memo[start] = false; // 失败结论同样要缓存
    }

    public static void main(String[] args) {
        // ACM 输入：第一行字符串 s，第二行空格分隔的字典单词
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().trim();
        List<String> dict = new ArrayList<>();
        while (sc.hasNext()) {
            dict.add(sc.next());
        }
        System.out.println(new Solution().wordBreak(s, dict));
        sc.close();
    }
}
```

```cpp
#include <iostream>
#include <sstream>
#include <string>
#include <vector>
using namespace std;

class Solution {
public:
    string s;
    vector<string> dict;
    vector<int> memo; // -1=未计算, 0=否, 1=是

    // dfs(start)：后缀 s[start..n) 能否被字典拼出
    bool dfs(int start) {
        if (start == (int)s.size()) {

        dict = wordDict;
        memo.assign(this->s.size(), -1);
        return dfs(0);
```

## 题解三：暴力 DFS（回溯 + 成功短路，指数级，会超时）

记忆化的骨架，也是理解本题搜索结构的起点。以**字典词为匹配单元**：每层拿全部词典对当前开头做 `startsWith`，命中就"摘掉"（下标右移，不真删串）递归剩余部分。

两条纪律缺一不可：

- **失败必须回溯**：同一开头常有多词命中（如 `"a"` 与 `"ab"` 共享前缀），必须逐个开分支都试完才能下失败结论。反例：`s = "ab"`、`dict = ["a", "ab"]`，若匹配到 `"a"` 就一路走到底（贪心），剩 `"b"` 无人能吃，误报 false——漏掉了 `"ab"` 整词这条路。任何贪心规则（优先最长、按字典序）都不安全：本轮选词是否正确取决于剩余串未来能否拼出
- **成功立刻短路**：题目只问存在性，第一个彻底匹配的组合出现即返回 true，沿途上抛清场；但若题目改为输出**所有**拆分方案（140. 单词拆分 II），则必须搜完整棵树，无法短路

超时根源：搜索树指数级——最坏 `s = "aaaa…a"` 配 `["a","aa","aaa"]`，每个位置 3 个分支，而重复的 `dfs(start)` 各自带一整棵子树。它本身不可提交，价值在于暴露"同 `start` 反复计算"这一结构，引出题解二的记忆化。

- 时间复杂度：指数级，最坏 `O(m^n)` 量级
- 空间复杂度：`O(n)`，递归栈

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    static String s;
    static List<String> dict;

    public boolean wordBreak(String s, List<String> wordDict) {
        Solution.s = s;
        dict = wordDict;
        return dfs(0);
    }

    // 每层：字典挨个比对开头，命中就"摘掉"（下标右移）递归剩余部分
    public static boolean dfs(int start) {
        if (start == s.length()) {
            return true; // 串吃光了
        }
        for (String word : dict) {
            if (s.startsWith(word, start) && dfs(start + word.length())) {
                return true; // 成功短路：第一个完整组合即定答案
            }
            // 此路失败 → for 自动换下一个词（这就是回溯）
        }
        return false; // 全部词试完仍无解
    }

    public static void main(String[] args) {
        // ACM 输入：第一行字符串 s，第二行空格分隔的字典单词
        Scanner sc = new Scanner(System.in);
        String s = sc.nextLine().trim();

            dict.add(sc.next());
        }
        System.out.println(new Solution().wordBreak(s, dict));
        sc.close();
    }
}
```
