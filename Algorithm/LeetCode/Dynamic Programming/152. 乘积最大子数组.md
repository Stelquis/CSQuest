# [152. 乘积最大子数组](https://leetcode.cn/problems/maximum-product-subarray/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`数组`、`动态规划`

## 题目描述

给你一个整数数组 `nums` ，请你找出数组中乘积最大的非空连续 子数组（该子数组中至少包含一个数字），并返回该子数组所对应的乘积。

测试用例的答案是一个 **32-位** 整数。

**请注意**，一个只包含一个元素的数组的乘积是这个元素的值。

**示例 1:**

```
输入: nums = [2,3,-2,4]
输出: 6
解释: 子数组 [2,3] 有最大乘积 6。
```

**示例 2:**

```
输入: nums = [-2,0,-1]
输出: 0
解释: 结果不能为 2, 因为 [-2,-1] 不是子数组。
```

**提示:**
- `1 <= nums.length <= 2 * 10^4`
- `-10 <= nums[i] <= 10`
- `nums` 的任何子数组的乘积都 **保证** 是一个 **32-位** 整数

## 核心辨析：为什么不能像「53. 最大子数组和」那样只记最大

`53` 的转移 `dp[i] = max(dp[i-1] + x, x)` 用单一状态就够——加法里大加大只会更大。**乘法不同：乘以负数，大小互换**（负负得正）。"以 i 结尾的最大乘积"在遇到负数时可能瞬间作废，而"以 i 结尾的**最小**乘积"（一个很负的数）乘上负数反而爆成最大值。

单状态写法的反例 `nums = [-2, 3, -4]`（正确答案 `(-2)×3×(-4) = 24`）：

```
dp[0] = -2
dp[1] = max(-2×3, 3) = 3      ← 最小值 -6 被 max 扔掉了！
dp[2] = max(3×(-4), -4) = -4  ← 无从知道 -6 × -4 = 24
返回 3 ✗                       正确答案 24
```

第 1 步的 `-6` 是"潜力股"：当前最小，但一旦后面冒出负数就翻身。所以每个位置必须**记两本账**：最大、最小。

## 题解一：max/min 双状态 DP（O(n) 时间 / O(n) 空间）

状态定义：

- `maxDp[i]` = 以 `nums[i]` 结尾的连续子数组的**最大**乘积
- `minDp[i]` = 以 `nums[i]` 结尾的连续子数组的**最小**乘积

转移——三种来历各算一遍，大的进 max 账、小的进 min 账：

1. `nums[i]` 自起炉灶（子数组必须连续，前面的可以不接）
2. `maxDp[i-1] × nums[i]`（接在最大值后面，`x` 为正时的希望）
3. `minDp[i-1] × nums[i]`（接在最小值后面，**`x` 为负时的希望**）

要点：

- max 与 min 的转移**互相引用**，但都只依赖 `i-1` → 同一轮先算好两个候选再写入，互不污染
- 答案取 `maxDp` 全表最大（最大乘积子数组可以在任意位置结尾）

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int maxProduct(int[] nums) {
        int[] maxDp = new int[nums.length];
        int[] minDp = new int[nums.length];
        maxDp[0] = minDp[0] = nums[0];
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            int byMax = maxDp[i - 1] * x; // 接最大值
            int byMin = minDp[i - 1] * x; // 接最小值（负负得正的希望）
            maxDp[i] = Math.max(x, Math.max(byMax, byMin));
            minDp[i] = Math.min(x, Math.min(byMax, byMin));
            ans = Math.max(ans, maxDp[i]);
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的整数
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().maxProduct(nums));
        sc.close();
    }
}
```

```python
import sys
from typing import List


class Solution:
    def maxProduct(self, nums: List[int]) -> int:
        maxDp = [0] * len(nums)
        minDp = [0] * len(nums)
        maxDp[0] = minDp[0] = nums[0]
        ans = nums[0]
        for i in range(1, len(nums)):
            x = nums[i]
            byMax = maxDp[i - 1] * x  # 接最大值
            byMin = minDp[i - 1] * x  # 接最小值（负负得正的希望）
            maxDp[i] = max(x, byMax, byMin)
            minDp[i] = min(x, byMax, byMin)
            ans = max(ans, maxDp[i])
        return ans
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int maxProduct(int* nums, int numsSize) {
    int* maxDp = (int*)malloc(numsSize * sizeof(int));
    int* minDp = (int*)malloc(numsSize * sizeof(int));
    maxDp[0] = minDp[0] = nums[0];
    int ans = nums[0];
    for (int i = 1; i < numsSize; i++) {
        int x = nums[i];
        int byMax = maxDp[i - 1] * x; // 接最大值
        int byMin = minDp[i - 1] * x; // 接最小值（负负得正的希望）
        maxDp[i] = x > byMax ? x : byMax;
        if (byMin > maxDp[i]) {
            maxDp[i] = byMin;
        }
        minDp[i] = x < byMin ? x : byMin;
        if (byMax < minDp[i]) {
            minDp[i] = byMax;
        }
        if (maxDp[i] > ans) {
            ans = maxDp[i];
        }
    }
    free(maxDp);
    free(minDp);
    return ans;
}

int main(void) {
    // ACM 输入：一行空格分隔的整数
    int* nums = (int*)malloc(20000 * sizeof(int));
    int n = 0;
    while (n < 20000 && scanf("%d", &nums[n]) == 1) {
        n++;
    }
    printf("%d\n", maxProduct(nums, n));
    free(nums);
    return 0;
}
```

## 题解二：滚动变量（O(1) 空间）

两个状态都只依赖 `i-1` → 双数组压成两个变量。**关键细节：先算好两个候选、再统一滚动赋值**——若先把 `maxEnd` 更新掉，`minEnd` 的转移用到的就是本轮新值，等于"同一轮污染"（类比 0/1 背包压维必须倒序的道理：转移读到的必须是上一轮的旧值）。

验证 `[-2, 3, -4]`：

```
i=1（x=3）：候选 = 3, -2×3=-6, -6 → maxEnd=3, minEnd=-6   ← -6 进小账本
i=2（x=-4）：候选 = -4, 3×(-4)=-12, (-6)×(-4)=24
             maxEnd=24 ✓
答案 24 ✓
```

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int maxProduct(int[] nums) {
        int maxEnd = nums[0]; // 以当前位置结尾的最大乘积
        int minEnd = nums[0]; // 以当前位置结尾的最小乘积
        int ans = nums[0];
        for (int i = 1; i < nums.length; i++) {
            int x = nums[i];
            // 先算候选：两个转移互相引用，必须基于上一轮的旧值
            int candMax = Math.max(x, Math.max(maxEnd * x, minEnd * x));
            int candMin = Math.min(x, Math.min(maxEnd * x, minEnd * x));
            maxEnd = candMax; // 再滚动
            minEnd = candMin;
            ans = Math.max(ans, maxEnd);
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的整数
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().maxProduct(nums));
        sc.close();
    }
}
```
