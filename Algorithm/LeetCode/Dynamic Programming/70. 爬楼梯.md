# [70. 爬楼梯](https://leetcode.cn/problems/climbing-stairs/)

- 🟢 **难度**：简单
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`记忆化`、`数学`、`动态规划`

## 题目描述

假设你正在爬楼梯。需要 `n` 阶你才能到达楼顶。

每次你可以爬 `1` 或 `2` 个台阶。你有多少种不同的方法可以爬到楼顶呢？

**示例 1：**

```
输入：n = 2
输出：2
解释：有两种方法可以爬到楼顶。
1. 1 阶 + 1 阶
2. 2 阶
```

**示例 2：**

```
输入：n = 3
输出：3
解释：有三种方法可以爬到楼顶。
1. 1 阶 + 1 阶 + 1 阶
2. 1 阶 + 2 阶
3. 2 阶 + 1 阶
```

**提示：**
- `1 <= n <= 45`

## 题解一：记忆化递归（自顶向下）

最后一步只能是「跨 1 阶」或「跨 2 阶」，因此到达第 `n` 阶的方法数 = 到达第 `n-1` 阶的方法数 + 到达第 `n-2` 阶的方法数 —— 即斐波那契式递推。朴素递归会重复求解同一子问题（指数级），用备忘录数组把每个 `f(i)` 只算一次。

- 时间复杂度：`O(n)`，每个状态只计算一次
- 空间复杂度：`O(n)`，备忘录 + `O(n)` 递归栈

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int climbStairs(int n) {
        int[] memo = new int[n + 1];
        return dfs(n, memo);
    }

    public static int dfs(int n, int[] memo) {
        if (n <= 2) {
            return n;               // f(1)=1, f(2)=2
        }
        if (memo[n] != 0) {
            return memo[n];         // 已算过，直接取用
        }
        memo[n] = dfs(n - 1, memo) + dfs(n - 2, memo);
        return memo[n];
    }

    public static void main(String[] args) {
        // ACM 输入：一个整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(new Solution().climbStairs(n));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys
from functools import lru_cache


class Solution:
    def climbStairs(self, n: int) -> int:
        @lru_cache(maxsize=None)
        def dfs(i: int) -> int:
            if i <= 2:
                return i                # f(1)=1, f(2)=2
            return dfs(i - 1) + dfs(i - 2)

        return dfs(n)


if __name__ == "__main__":
    # ACM 输入：一个整数 n
    n = int(sys.stdin.read().split()[0])
    print(Solution().climbStairs(n))
```

int dfs(int n) {
    if (n <= 2) {
        return n;                   // f(1)=1, f(2)=2
    }

        return memo[n];             // 已算过，直接取用

int climbStairs(int n) {

## 题解二：迭代递推（自底向上，滚动变量）

把递推式从小往大算：`f(i) = f(i-1) + f(i-2)`。由于每步只依赖前两个状态，用两个变量滚动即可，无需数组。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(1)`，只保留前两项

> 进阶方向：递推式是标准斐波那契，可用「矩阵快速幂」把复杂度降到 `O(log n)`，或直接用通项公式（浮点误差需谨慎）。

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int climbStairs(int n) {
        if (n <= 2) {
            return n;
        }
        int prev2 = 1;              // f(1)
        int prev1 = 2;              // f(2)
        for (int i = 3; i <= n; i++) {
            int cur = prev1 + prev2;
            prev2 = prev1;
            prev1 = cur;
        }
        return prev1;
    }

    public static void main(String[] args) {
        // ACM 输入：一个整数 n
        Scanner sc = new Scanner(System.in);
        int n = sc.nextInt();
        System.out.println(new Solution().climbStairs(n));
        sc.close();
    }
}
```

### 🐍 Python

```python
import sys


class Solution:
    def climbStairs(self, n: int) -> int:
        if n <= 2:
            return n
        prev2, prev1 = 1, 2          # f(1), f(2)
        for _ in range(3, n + 1):
            prev2, prev1 = prev1, prev1 + prev2
        return prev1


if __name__ == "__main__":
    # ACM 输入：一个整数 n
    n = int(sys.stdin.read().split()[0])
    print(Solution().climbStairs(n))
```
