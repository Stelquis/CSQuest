# [322. 零钱兑换](https://leetcode.cn/problems/coin-change/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`广度优先搜索`、`数组`、`动态规划`、`背包问题`、`完全背包`

## 题目描述

给你一个整数数组 `coins` ，表示不同面额的硬币；以及一个整数 `amount` ，表示总金额。

计算并返回可以凑成总金额所需的 **最少的硬币个数** 。如果没有任何一种硬币组合能组成总金额，返回 `-1` 。

你可以认为每种硬币的数量是无限的。

**示例 1：**

```
输入：coins = [1, 2, 5], amount = 11
输出：3 
解释：11 = 5 + 5 + 1
```

**示例 2：**

```
输入：coins = [2], amount = 3
输出：-1
```

**示例 3：**

```
输入：coins = [1], amount = 0
输出：0
```

**提示：**
- `1 <= coins.length <= 12`
- `1 <= coins[i] <= 2^31 - 1`
- `0 <= amount <= 10^4`

## 题解一：外层枚举金额（正向递推，O(n·amount)）

状态定义与转移：

- `dp[i]` = 凑出金额 `i` 所需的最少硬币数，`dp[0] = 0`
- `dp[i] = min(dp[i - coin] + 1)`，对所有 `coin ≤ i` 且 `dp[i - coin]` 可达

思路是"**枚举最后一枚硬币**"：任一最优方案去掉最后一枚 `coin` 后，剩余部分恰是 `i - coin` 的最优方案。由于 `coin > 0`，状态图（节点为金额 `0..amount`，边为 `i - coin → i`）中所有边都从小金额指向大金额，是 **DAG**——`i` 升序扫描就是拓扑序，计算 `dp[i]` 时所有依赖（更小金额）都已就绪，一次遍历即可。

哨兵 `INF = amount + 1`：

- 可行答案至多 `amount` 枚（全用 1 元），`amount + 1` 严格大于一切真解，可安全表示"不可达"
- `INF + 1` 不溢出，不可达前驱即使参与转移，`min` 也永远选不中它——守卫 `dp[i - coin] != INF` 只是加速而非正确性前提（对比：若填 `Integer.MAX_VALUE`，加 1 会溢出为负数污染结果，守卫就变成必需）

- 时间复杂度：`O(n·amount)`，n 为硬币种数
- 空间复杂度：`O(amount)`

### ☕ Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        int INF = amount + 1; // 可行答案上界 + 1：严格大于一切真解，且加 1 不溢出
        Arrays.fill(dp, INF);
        dp[0] = 0;
        // 外层枚举金额：转移只依赖更小金额，升序即拓扑序
        for (int i = 1; i <= amount; i++) {
            for (int coin : coins) {
                if (coin <= i && dp[i - coin] != INF) {
                    dp[i] = Math.min(dp[i], dp[i - coin] + 1);
                }
            }
        }
        return dp[amount] == INF ? -1 : dp[amount];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行空格分隔的硬币面额，第二行总金额
        Scanner sc = new Scanner(System.in);
        String[] parts = sc.nextLine().trim().split("\\s+");
        int[] coins = new int[parts.length];
        for (int i = 0; i < coins.length; i++) {
            coins[i] = Integer.parseInt(parts[i]);
        }
        int amount = sc.nextInt();
        System.out.println(new Solution().coinChange(coins, amount));
        sc.close();
    }
}
```

```python
class Solution:
    def coinChange(self, coins: List[int], amount: int) -> int:
        INF = amount + 1  # 可行答案上界 + 1：严格大于一切真解，且加 1 不溢出
```

```c
#include <stdio.h>
#include <stdlib.h>

int coinChange(int* coins, int coinsSize, int amount) {
    int INF = amount + 1; // 可行答案上界 + 1：严格大于一切真解，且加 1 不溢出
    int* dp = (int*)malloc((amount + 1) * sizeof(int));
    for (int i = 0; i <= amount; i++) {
        dp[i] = INF;
    }
    dp[0] = 0;
    // 外层枚举金额：转移只依赖更小金额，升序即拓扑序
    for (int i = 1; i <= amount; i++) {
        for (int j = 0; j < coinsSize; j++) {
            if (coins[j] <= i && dp[i - coins[j]] != INF) {
                if (dp[i - coins[j]] + 1 < dp[i]) {
                    dp[i] = dp[i - coins[j]] + 1;
                }
            }
        }
    }
    int ans = dp[amount] == INF ? -1 : dp[amount];
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：第一行空格分隔的硬币面额，第二行总金额
    int* coins = (int*)malloc(1000 * sizeof(int));
    int n = 0, amount;
    char c;
    while (n < 1000 && scanf("%d", &coins[n]) == 1) {
        n++;
        c = getchar();
        if (c == '\n' || c == EOF) {
            break;
        }
    }
    if (scanf("%d", &amount) != 1) {
        amount = 0;
    }
    printf("%d\n", coinChange(coins, n, amount));
    free(coins);
    return 0;
}
```

## 题解二：外层枚举硬币（经典完全背包，O(n·amount)）

把每种硬币看成一**数量不限的物品**（完全背包），`amount` 是背包容量，每用一枚硬币代价 +1，求最小代价：

- 外层枚举物品 `coin`，内层枚举容量 `i` 且**升序**：升序保证计算 `dp[i]` 时 `dp[i - coin]` 可能已包含当前硬币，即同一硬币可重复使用
- 面额 `> amount` 的硬币直接跳过，规避内层循环的边界问题（面额可达 `2^31 - 1`）
- 同样用 `INF = amount + 1` 作哨兵，`INF + 1` 不溢出，无需可达性守卫

两种循环顺序为何都对：本题求"最少枚数"（组合型），答案只与每种硬币用了几枚有关，与拼凑顺序无关；转移是对称的 `min`，两种枚举顺序覆盖的依赖集合完全一致，结果相同。对比同类题记忆：

- 求**组合**数（518. 零钱兑换 II）：必须硬币在外层，避免把同一组硬币的不同排列重复计数
- 求**排列**数（377. 组合总和 IV）：必须金额在外层，让不同顺序各计一次

- 时间复杂度：`O(n·amount)`
- 空间复杂度：`O(amount)`

### ☕ Java

```java
import java.util.Arrays;
import java.util.Scanner;

public class Solution {
    public int coinChange(int[] coins, int amount) {
        int[] dp = new int[amount + 1];
        int INF = amount + 1; // 可行答案上界 + 1：严格大于一切真解，且加 1 不溢出
        Arrays.fill(dp, INF);
        dp[0] = 0;
        // 外层枚举硬币，内层容量升序：dp[i-coin] 可能已含当前硬币，即同一硬币可重复使用
        for (int coin : coins) {
            if (coin > amount) {
                continue; // 面额超过目标金额（面额可达 2^31-1），直接跳过
            }
            for (int i = coin; i <= amount; i++) {
                dp[i] = Math.min(dp[i], dp[i - coin] + 1);
            }
        }
        return dp[amount] == INF ? -1 : dp[amount];
    }

    public static void main(String[] args) {
        // ACM 输入：第一行空格分隔的硬币面额，第二行总金额
        Scanner sc = new Scanner(System.in);
        String[] parts = sc.nextLine().trim().split("\\s+");
        int[] coins = new int[parts.length];
        for (int i = 0; i < coins.length; i++) {
            coins[i] = Integer.parseInt(parts[i]);
        }
        int amount = sc.nextInt();
        System.out.println(new Solution().coinChange(coins, amount));
        sc.close();
    }
}
```
