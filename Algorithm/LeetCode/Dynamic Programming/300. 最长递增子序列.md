# [300. 最长递增子序列](https://leetcode.cn/problems/longest-increasing-subsequence/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`数组`、`二分查找`、`动态规划`、`最长上升子序列`

## 题目描述

给你一个整数数组 `nums` ，找到其中最长严格递增子序列的长度。

**子序列** 是由数组派生而来的序列，删除（或不删除）数组中的元素而不改变其余元素的顺序。例如，`[3,6,2,7]` 是数组 `[0,3,1,6,2,2,7]` 的子序列。

**示例 1：**

```
输入：nums = [10,9,2,5,3,7,101,18]
输出：4
解释：最长递增子序列是 [2,3,7,101]，因此长度为 4 。
```

**示例 2：**

```
输入：nums = [0,1,0,3,2,3]
输出：4
```

**示例 3：**

```
输入：nums = [7,7,7,7,7,7,7]
输出：1
```

**提示：**
- `1 <= nums.length <= 2500`
- `-10^4 <= nums[i] <= 10^4`

**进阶：**
- 你能将算法的时间复杂度降低到 `O(n log(n))` 吗?

## 题解一：动态规划（O(n²)）

状态定义与转移：

- `dp[i]` = **以 `nums[i]` 结尾**的最长严格递增子序列长度，初值 `1`（元素自身）
- `dp[i] = max(dp[j] + 1)`，对所有 `j < i` 且 `nums[j] < nums[i]`；无合法前驱则保持 `1`
- 答案 = **全表最大值**（LIS 可以在任意位置结尾，不以最后一个元素为终点）

转移只依赖更小的 `j`，外层升序即拓扑序（与 322/416 的循环方向分析同理）。

### 三个易错点（都踩过）

1. **前驱不能选"离 i 最近的那个小元素"**——链长与距离无关。反例 `nums = [2, 3, 1, 4]`：以 4 结尾的最优前驱是下标 1 的 `3`（`dp=2`，链 `[2,3,4]`）；但离 4 最近的小元素是下标 2 的 `1`——它是"新低"（前面没有比它小的，`dp=1`），接上去只得长度 2。**`dp` 值跳来跳去没有单调性，必须全量扫描取 `max`，不能提前 `break`**；
2. **无合法前驱时保持初值 1**，不能错误地兜底成 `dp[0] + 1`。反例 `nums = [2, 1]`：`1` 前面没有更小的元素，`dp[1]` 应为 1，若兜底会得到 2；
3. **返回全表 max 而非 `dp[n-1]`**。反例 `nums = [1, 2, 3, 1]`：`dp = [1, 2, 3, 1]`，答案 3 在中间。

- 时间复杂度：`O(n²)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int lengthOfLIS(int[] nums) {
        // dp[i]：以 nums[i] 结尾的最长严格递增子序列长度
        int[] dp = new int[nums.length];
        java.util.Arrays.fill(dp, 1); // 元素自身就是长度 1
        for (int i = 1; i < nums.length; i++) {
            for (int j = 0; j < i; j++) { // 全量扫描合法前驱，不 break
                if (nums[j] < nums[i]) {
                    dp[i] = Math.max(dp[i], dp[j] + 1);
                }
            }
        }
        int ans = 0;
        for (int x : dp) { // LIS 可在任意位置结尾，取全表 max
            ans = Math.max(ans, x);
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的整数
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().lengthOfLIS(nums));
        sc.close();
    }
}
```

### ⚙️ C

```c
#include <stdio.h>
#include <stdlib.h>

int lengthOfLIS(int* nums, int numsSize) {
    // dp[i]：以 nums[i] 结尾的最长严格递增子序列长度
    int* dp = (int*)malloc(numsSize * sizeof(int));
    for (int i = 0; i < numsSize; i++) {
        dp[i] = 1; // 元素自身就是长度 1
    }
    for (int i = 1; i < numsSize; i++) {
        for (int j = 0; j < i; j++) { // 全量扫描合法前驱，不 break
            if (nums[j] < nums[i] && dp[j] + 1 > dp[i]) {
                dp[i] = dp[j] + 1;
            }
        }
    }
    int ans = 0;
    for (int i = 0; i < numsSize; i++) { // 全表 max
        if (dp[i] > ans) {
            ans = dp[i];
        }
    }
    free(dp);
    return ans;
}

int main(void) {
    // ACM 输入：一行空格分隔的整数
    int* nums = (int*)malloc(10000 * sizeof(int));
    int n = 0;
    while (n < 10000 && scanf("%d", &nums[n]) == 1) {
        n++;
    }
    printf("%d\n", lengthOfLIS(nums, n));
    free(nums);
    return 0;
}
```

## 题解二：贪心 + 二分（O(n log n)）

核心数据结构：`tails[k]` = **所有长度为 `k+1` 的递增子序列中，最小的结尾值**。

- 单调性：`tails` 严格递增。反证：若 `a < b` 且 `tails[a] ≥ tails[b]`，把长度 `b+1` 的子序列截掉头部若干元素即可得到长度 `a+1`、结尾 ≤ `tails[b]` 的子序列，与 `tails[a]` 的最小性矛盾；
- 处理每个 `num`：二分找 `tails` 中**第一个 `≥ num`** 的位置——
  - 找到：**替换**之。同长度子序列的结尾变得更小，给后续元素留出更多"续上"的机会；已有长度不变；
  - 越界（`num` 比所有结尾都大）：**追加**，LIS 长度 +1；
- 答案 = `tails` 的长度。

两个关键认知：

- **`tails` 不是某个真实的 LIS**，中间元素可能来自不同子序列的拼接，但它的**长度**恰好等于 LIS 长度；
- 严格递增用**下界二分**（第一个 `≥ num`，相等也替换、不延长）；若题目改成最长**非严格**递增子序列（允许相等），改用上界二分（第一个 `> num`）即可。

- 时间复杂度：`O(n log n)`
- 空间复杂度：`O(n)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int lengthOfLIS(int[] nums) {
        // tails[k]：所有长度为 k+1 的递增子序列中最小的结尾值（严格递增）
        int[] tails = new int[nums.length];
        int size = 0;
        for (int num : nums) {
            // 下界二分：找第一个 >= num 的位置
            int lo = 0, hi = size;
            while (lo < hi) {
                int mid = (lo + hi) >>> 1;
                if (tails[mid] < num) {
                    lo = mid + 1;
                } else {
                    hi = mid;
                }
            }
            tails[lo] = num; // 替换（同长度结尾更小）或追加（lo == size）
            if (lo == size) {
                size++;
            }
        }
        return size;
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的整数
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().lengthOfLIS(nums));
        sc.close();
    }
}
```

### 🐍 Python

```python
import bisect
import sys
from typing import List


class Solution:
    def lengthOfLIS(self, nums: List[int]) -> int:
        # tails[k]：所有长度为 k+1 的递增子序列中最小的结尾值（严格递增）
        tails: List[int] = []
        for num in nums:
            i = bisect.bisect_left(tails, num)  # 下界二分：第一个 >= num
            if i == len(tails):
                tails.append(num)  # 追加，LIS 长度 +1
            else:
                tails[i] = num  # 替换，同长度结尾更小
        return len(tails)


if __name__ == "__main__":
    # ACM 输入：一行空格分隔的整数
    nums = [int(x) for x in sys.stdin.read().split()]
    print(Solution().lengthOfLIS(nums))
```

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

class Solution {
public:
    int lengthOfLIS(vector<int>& nums) {
        // tails[k]：所有长度为 k+1 的递增子序列中最小的结尾值（严格递增）
        vector<int> tails;
        for (int num : nums) {
            auto it = lower_bound(tails.begin(), tails.end(), num); // 下界二分
            if (it == tails.end()) {
                tails.push_back(num); // 追加，LIS 长度 +1
            } else {
                *it = num; // 替换，同长度结尾更小
            }
        }
        return tails.size();
    }
};
```

```c
#include <stdio.h>
#include <stdlib.h>

int lengthOfLIS(int* nums, int numsSize) {
    // tails[k]：所有长度为 k+1 的递增子序列中最小的结尾值（严格递增）
    int* tails = (int*)malloc(numsSize * sizeof(int));
    int size = 0;
    for (int i = 0; i < numsSize; i++) {
        // 下界二分：找第一个 >= nums[i] 的位置

                hi = mid;
            }

        tails[lo] = nums[i]; // 替换或追加
        if (lo == size) {
            size++;
        }
    }
    int ans = size;
    free(tails);
    return ans;
}
```
