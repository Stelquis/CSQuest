# [32. 最长有效括号](https://leetcode.cn/problems/longest-valid-parentheses/)

- 🔴 **难度**：困难
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`栈`、`字符串`、`动态规划`、`括号序列`

## 题目描述

给你一个只包含 `'('` 和 `')'` 的字符串，找出最长有效（格式正确且连续）括号 子串 的长度。

左右括号匹配，即每个左括号都有对应的右括号将其闭合的字符串是格式正确的，比如 `"(()())"`。

**示例 1：**

```
输入：s = "(()"
输出：2
解释：最长有效括号子串是 "()"
```

**示例 2：**

```
输入：s = ")()())"
输出：4
解释：最长有效括号子串是 "()()"
```

**示例 3：**

```
输入：s = ""
输出：0
```

**提示：**
- `0 <= s.length <= 3 * 10^4`
- `s[i]` 为 `'('` 或 `')'`

## 思路辨析：dp 的语义必须落在"以 i 结尾"

用栈配对 + dp 记录的直觉是对的，但 dp 若定义为"**从开头到 i 累计的有效括号数量**"会踩两个雷：

1. **累计量丢失"连续"语义**：配对之间可以隔着没配上的字符。反例 `s = "()(()"`：配了两对共 4 字符，但中间的 `'('`（下标 2）是断点，最长**连续**有效段只有 2——累计量把散落的对乱加成一段；
2. **连续段会合并**：`s = "()()"` 处理到下标 3 时新配的对只有 2 长，但它与前面的 `(0,1)` 紧挨着，真答案 4——需要"向前跳着合并"的能力。

修正：`dp[i]` 定义为**以 i 结尾**的最长有效括号子串长度（断点处自然为 0）。栈负责告诉你"配对的另一半在哪"，`dp[j-1]` 负责把紧挨的旧段接上——查表相加即可，"隔开合不上、紧挨就接上"由 `dp[j-1]` 是否为 0 自动决定。

## 题解一：栈 + dp 混血（O(n) 时间 / O(n) 空间）

栈的定义：

- **栈里存下标**，不存字符——配对时需要知道 `j` 是几，公式才算得动
- 栈中成员只有两种**身份**：真 `'('` 的下标（配对候选）、断点哨兵的下标（初始 `-1`，以及配不上的 `')'` 的下标）
- 哨兵语义：栈底永远垫着"最后一个无法匹配的位置"

转移（`dp[i]` = 以 i 结尾的最长有效长度）：

- `s[i] == '('`：下标进栈，`dp[i] = 0`
- `s[i] == ')'`：弹出 `num`——
  - 若 `num == -1` 或 `s[num] == ')'`（弹到哨兵，配不上）：把 `i` 压回去当**新断点**，`dp[i] = 0`
  - 否则配对成功：`dp[i] = (i - num + 1) + (num > 0 ? dp[num-1] : 0)`

三个易错点（都踩过）：

1. **`dp[num-1]` 越界**：配对的 `'('` 在下标 0 时 `num = 0`，`dp[-1]` 直接崩溃（输入 `"()"` 即触发）→ 必须 `num > 0` 才查表，否则加 0；
2. **哨兵身份不能用 `num == -1` 判定**：断点会被替换，哨兵不再是 -1，后续 `')'` 弹到它会误当配对。区分身份靠**反查字符**：`s[num] == '('` 是真候选，`s[num] == ')'` 是断点（`-1` 无字符可查，单独特判）；
3. **答案是全表 max 而非 `dp[n-1]`**：最长段可以在任意位置结尾。反例 `s = "()("`：`dp = [0, 2, 0]`，返回 `dp[2]` 得 0。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，dp 数组 + 栈

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public int longestValidParentheses(String s) {
        // dp[i]：以 i 结尾的最长有效括号子串长度
        int[] dp = new int[s.length()];
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 垫底哨兵
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
                dp[i] = 0;
            } else {
                int num = stack.poll();
                if (num == -1 || s.charAt(num) == ')') {
                    // 弹到哨兵：配不上，i 成为新断点
                    stack.push(i);
                    dp[i] = 0;
                } else {
                    // 配对成功：本对长度 + 紧挨前段合并
                    dp[i] = i - num + 1 + (num > 0 ? dp[num - 1] : 0);
                }
                ans = Math.max(ans, dp[i]);
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行括号字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestValidParentheses(s));
        sc.close();
    }
}
```

## 题解二：纯栈（不开 dp 数组，O(n) 时间 / O(n) 空间）

把"合并"藏进哨兵语义里。栈同样存下标 + 垫底 `-1`，但**不配对长度、只维护边界**：

- `'('` 下标进栈；
- `')'` 弹出后：栈空 → 当前 `')'` 是新断点，压回去；栈不空 → **`i - stack.peek()` 就是答案候选**。

为什么不用 `dp[j-1]`：弹出配对 `'('` 后，栈顶（`peek`）恰好是"这段有效串左边界的左邻"——要么是断点，要么是上一段有效串的结尾。`i - peek` 一步就把"本对长度 + 前面所有紧挨的段"算完了，`dp` 的合并职责被 `peek` 的语义天然吸收。

对照 `s = "()"`：`i=1` 弹出 `0`，栈顶 `-1`，长度 `1 - (-1) = 2` ✓。

- 时间复杂度：`O(n)`
- 空间复杂度：`O(n)`，仅栈

### ☕ Java

```java
import java.util.ArrayDeque;
import java.util.Deque;
import java.util.Scanner;

public class Solution {
    public int longestValidParentheses(String s) {
        Deque<Integer> stack = new ArrayDeque<>();
        stack.push(-1); // 哨兵：最后一个无法匹配的位置
        int ans = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                stack.push(i);
            } else {
                stack.poll();
                if (stack.isEmpty()) {
                    stack.push(i); // 新断点
                } else {
                    ans = Math.max(ans, i - stack.peek()); // 左边界左邻到 i 的距离
                }
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行括号字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestValidParentheses(s));
        sc.close();
    }
}
```

## 题解三：正反双计数（O(n) 时间 / O(1) 空间）

不需要任何辅助结构，只用两个计数器 `left`（`'('` 个数）、`right`（`')'` 个数）：

- **正向扫**：`left == right` → 当前窗口有效，候选 `2 * right`；`right > left` → 右括号过剩，有效段断开，**双归零**重新开始；
- **反向扫**：`left == right` → 候选 `2 * left`；`left > right` → 双归零；
- 答案取两遍的最大值。

为什么必须扫两遍：正向只会因"右括号过剩"断开，**左括号悬空的段永远等不到闭合**，被漏记——反例 `"(()"`，正向扫全程 `left > right`，什么都记不到；反向扫时视角翻转，"右括号悬空"的段（`"()"`）反而能被正常计数。两遍各管一种悬空，取最大即完备。

- 时间复杂度：`O(n)`，两遍扫描
- 空间复杂度：`O(1)`

### ☕ Java

```java
import java.util.Scanner;

public class Solution {
    public int longestValidParentheses(String s) {
        int ans = 0;
        // 正向：右括号过剩才断开，漏"左括号悬空"的段
        int left = 0, right = 0;
        for (int i = 0; i < s.length(); i++) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            if (left == right) {
                ans = Math.max(ans, 2 * right);
            } else if (right > left) {
                left = right = 0;
            }
        }
        // 反向：左括号过剩才断开，补上正向漏掉的段
        left = right = 0;
        for (int i = s.length() - 1; i >= 0; i--) {
            if (s.charAt(i) == '(') {
                left++;
            } else {
                right++;
            }
            if (left == right) {
                ans = Math.max(ans, 2 * left);
            } else if (left > right) {
                left = right = 0;
            }
        }
        return ans;
    }

    public static void main(String[] args) {
        // ACM 输入：一行括号字符串
        Scanner sc = new Scanner(System.in);
        String s = sc.hasNextLine() ? sc.nextLine().trim() : "";
        System.out.println(new Solution().longestValidParentheses(s));
        sc.close();
    }
}
```

```python
import sys


class Solution:
    def longestValidParentheses(self, s: str) -> int:
        ans = 0

        # 正向：右括号过剩才断开，漏"左括号悬空"的段
        left = right = 0
        for ch in s:

                left += 1
            else:
                right += 1

            elif right > left:

        for ch in reversed(s):
            if ch == '(':
                left += 1
            else:
                right += 1
            if left == right:
                ans = max(ans, 2 * left)
            elif left > right:
                left = right = 0

        return ans
```

```cpp
#include <algorithm>
#include <iostream>
#include <string>
using namespace std;

class Solution {
public:
    int longestValidParentheses(string s) {
        int ans = 0;
        // 正向：右括号过剩才断开，漏"左括号悬空"的段
        int left = 0, right = 0;
        for (char ch : s) {
            ch == '(' ? left++ : right++;
            if (left == right) {
                ans = max(ans, 2 * right);
            } else if (right > left) {
                left = right = 0;
            }
        }
        // 反向：左括号过剩才断开，补上正向漏掉的段
        left = right = 0;
        for (auto it = s.rbegin(); it != s.rend(); ++it) {
            *it == '(' ? left++ : right++;
            if (left == right) {
                ans = max(ans, 2 * left);
            } else if (left > right) {
                left = right = 0;
            }
        }
        return ans;
    }
};

    // ACM 输入：一行括号字符串
    string s;
    getline(cin, s);
    cout << Solution().longestValidParentheses(s) << endl;
    return 0;
}
```
