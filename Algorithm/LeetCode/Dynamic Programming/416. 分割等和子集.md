# [416. 分割等和子集](https://leetcode.cn/problems/partition-equal-subset-sum/)

- 🟡 **难度**：中等
- 🧩 **分类**：动态规划
- 🏷️ **标签**：`数组`、`动态规划`、`背包问题`、`0-1 背包`

## 题目描述

给你一个 **只包含正整数** 的 **非空** 数组 `nums` 。请你判断是否可以将这个数组分割成两个子集，使得两个子集的元素和相等。

**示例 1：**

```
输入：nums = [1,5,11,5]
输出：true
解释：数组可以分割成 [1, 5, 5] 和 [11] 。
```

**示例 2：**

```
输入：nums = [1,2,3,5]
输出：false
解释：数组不能分割成两个元素和相等的子集。
```

**提示：**
- `1 <= nums.length <= 200`
- `1 <= nums[i] <= 100`

## 转化：分割问题 → 0/1 背包可行性

两个子集和相等 ⟺ 存在一个子集和恰好为 `target = sum / 2`（另一半自动成立）。于是：

- 物品 = `nums[i]`，**每件至多选一次**（0/1 背包）
- 容量 = `target`，求"**恰好装满**是否可能"（boolean 可行性，不求最大价值）
- `sum` 为奇数直接 `false`——数学上不可能平分

## 题解一：0/1 背包·二维 DP（教学版，O(n·target)）

状态定义与转移（第 k 件物品只有选/不选两种命运，且都只依赖**上一行**）：

- `dp[k][i]` = 只用前 `k` 件物品，能否恰好凑出和 `i`，`dp[0][0] = true`
- `dp[k][i] = dp[k-1][i]`（不选）`|| dp[k-1][i - nums[k-1]]`（选，要求 `i ≥ num`）

手推示例（`nums = [2, 3]`，`target = 5`）：

```
           i=0    i=1    i=2    i=3    i=4    i=5
k=0         T      F      F      F      F      F
k=1 (num=2) T      F      T      F      F      F
k=2 (num=3) T      F      T      T      F      T   ← dp[1][5] || dp[1][2] → true ✓
```

要点：

- **行与行天然隔离**：算第 `k` 行只读第 `k-1` 行，行内怎么填、什么顺序填都无所谓——"不倒序"在二维里根本不是问题
- "不选"分支负责把上一行的成果**原样继承**下来（如 `dp[2][2]` 直接来自 `dp[1][2]`）
- `dp[k][0]` 经"不选"分支自动从 `dp[0][0] = true` 继承，无需单独初始化

- 时间复杂度：`O(n·target)`
- 空间复杂度：`O(n·target)`

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }
        if (sum % 2 == 1) {
            return false; // 奇数不可能平分
        }
        int target = sum / 2;
        int n = nums.length;
        boolean[][] dp = new boolean[n + 1][target + 1];
        dp[0][0] = true; // 0 件物品凑出 0
        for (int k = 1; k <= n; k++) {
            int num = nums[k - 1];
            for (int i = 0; i <= target; i++) {
                dp[k][i] = dp[k - 1][i]; // 不选第 k 件
                if (i >= num) {
                    dp[k][i] |= dp[k - 1][i - num]; // 选第 k 件
                }
            }
        }
        return dp[n][target];
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的正整数
        Scanner sc = new Scanner(System.in);
        List<Integer> list = new ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().canPartition(nums));
        sc.close();
    }
}
```

```python
        if total % 2 == 1:

        return dp[n][target]
```

```c
#include <stdbool.h>
#include <stdio.h>
#include <stdlib.h>

bool canPartition(int* nums, int numsSize) {
    int sum = 0;
    for (int i = 0; i < numsSize; i++) {
        sum += nums[i];
    }
    if (sum % 2 == 1) {
        return false; // 奇数不可能平分
    }
    int target = sum / 2;
    bool** dp = (bool**)malloc((numsSize + 1) * sizeof(bool*));
    for (int k = 0; k <= numsSize; k++) {
        dp[k] = (bool*)calloc(target + 1, sizeof(bool));
    }
    dp[0][0] = true; // 0 件物品凑出 0
    for (int k = 1; k <= numsSize; k++) {
        int num = nums[k - 1];
        for (int i = 0; i <= target; i++) {
            dp[k][i] = dp[k - 1][i]; // 不选第 k 件
            if (i >= num && dp[k - 1][i - num]) {
                dp[k][i] = true; // 选第 k 件
            }
        }
```

## 题解二：0/1 背包·一维倒序滚动（标准解，O(n·target) 时间 / O(target) 空间）

二维表只有相邻两行参与运算、且行内依赖只朝左（`dp[k-1][i]` 与 `dp[k-1][i-num]` 都在 `i` 及更左）→ 可以把"行"压掉，用一个一维数组滚动复用：

- 原地覆盖后，转移要读的必须是**本轮覆盖之前的旧值**（等价于二维的上一行）
- **倒序扫描**保证这一点：本轮已覆盖的位置全在 `i` 右侧，依赖的 `i`、`i-num` 全在左侧未开发区
- 升序则读到本轮新值 → 物品被接力复用，恰好退化成完全背包——**内层方向就是 0/1 与完全背包的分水岭**（对比 322 零钱兑换的内层升序）

两个隐藏简化：

- "不选"分支免费：`dp[i]` 不动即自动继承旧值，只需补"选"分支 `dp[i] |= dp[i - num]`
- 内层下界取 `num`：`i < num` 的位置连"选它"的资格都没有，原样继承即可不扫

剪枝（同 139 的成功短路）：

- **单件超重**：`num > target` 直接 `false`
- **提前返回**：某轮结束后 `dp[target]` 为 true，剩余物品不必再看

- 时间复杂度：`O(n·target)`
- 空间复杂度：`O(target)`

### ☕ Java

```java
import java.util.ArrayList;
import java.util.List;
import java.util.Scanner;

public class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }
        if (sum % 2 == 1) {
            return false; // 奇数不可能平分
        }
        int target = sum / 2;
        boolean[] dp = new boolean[target + 1];
        dp[0] = true; // 空集凑出 0
        for (int num : nums) {                          // 外层：物品，一件只轮到一次
            if (num > target) {
                return false; // 单件超重，直接无解
            }
            for (int i = target; i >= num; i--) {       // 内层：容量【倒序】保旧值
                dp[i] = dp[i] || dp[i - num];
            }
            if (dp[target]) {
                return true; // 成功短路
            }
        }
        return dp[target];
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的正整数
        Scanner sc = new Scanner(System.in);
        List<Integer> list = new ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().canPartition(nums));
        sc.close();
    }
}
```

## 题解三：位运算 bitset（O(n·target / 64)）

boolean dp 本质是一个 0/1 位串，转移可以整体完成：

```
dp_new = dp_old | (dp_old << num)
```

含义：每个已可达的和 `i`，选上当前物品后 `i + num` 也可达；`<< num` 产生的是**旧表的副本**，OR 回来时新值不会接力参与同一轮转移——位运算天然满足 0/1 语义（相当于内层倒序的并行版）。一个机器字并行处理 64 个状态，时间与空间各再除以 64。

注意天花板：子集和问题是 **NP 完全**的，`O(n·target)` 是伪多项式复杂度；bitset、前缀截断、早停这类常数优化之后，基本就是该模型的性能极限，不要期待多项式时间精确算法。

- 时间复杂度：`O(n·target / 64)`
- 空间复杂度：`O(target / 64)`

### ☕ Java

```java
import java.math.BigInteger;
import java.util.Scanner;

public class Solution {
    public boolean canPartition(int[] nums) {
        int sum = 0;
        for (int x : nums) {
            sum += x;
        }
        if (sum % 2 == 1) {
            return false; // 奇数不可能平分
        }
        BigInteger bits = BigInteger.ONE; // 第 0 位 = 1：空集凑出 0
        for (int num : nums) {
            bits = bits.or(bits.shiftLeft(num)); // dp |= dp << num
        }
        return bits.testBit(sum / 2);
    }

    public static void main(String[] args) {
        // ACM 输入：一行空格分隔的正整数
        Scanner sc = new Scanner(System.in);
        java.util.List<Integer> list = new java.util.ArrayList<>();
        while (sc.hasNextInt()) {
            list.add(sc.nextInt());
        }
        int[] nums = new int[list.size()];
        for (int i = 0; i < nums.length; i++) {
            nums[i] = list.get(i);
        }
        System.out.println(new Solution().canPartition(nums));
        sc.close();
    }
}
```

### ⚙️ C

```c
#include <stdbool.h>
#include <stdint.h>
#include <stdio.h>
#include <stdlib.h>

bool canPartition(int* nums, int numsSize) {
    int sum = 0;
    for (int i = 0; i < numsSize; i++) {
        sum += nums[i];
    }
    if (sum % 2 == 1) {
        return false; // 奇数不可能平分
    }
    int target = sum / 2;
    int words = target / 64 + 1;
    uint64_t* bits = (uint64_t*)calloc(words, sizeof(uint64_t));
    bits[0] = 1; // 第 0 位 = 1：空集凑出 0
    for (int k = 0; k < numsSize; k++) {
        int num = nums[k];
        int sw = num / 64, sb = num % 64;
        // dp |= dp << num：字序倒着做，低位字尚未更新 → 读到的都是旧值（0/1 语义）
        for (int w = words - 1; w >= 0; w--) {
            uint64_t shifted = 0;
            if (w - sw >= 0) {
                shifted = bits[w - sw] << sb;
                if (sb != 0 && w - sw - 1 >= 0) {
                    shifted |= bits[w - sw - 1] >> (64 - sb); // 带上低位字的溢出位
                }
            }
            bits[w] |= shifted;
        }
    }
    bool ans = (bits[target / 64] >> (target % 64)) & 1;
    free(bits);
    return ans;
}

int main(void) {
    // ACM 输入：一行空格分隔的正整数
    int* nums = (int*)malloc(1000 * sizeof(int));
    int n = 0;
    while (n < 1000 && scanf("%d", &nums[n]) == 1) {
        n++;
    }
    printf("%s\n", canPartition(nums, n) ? "true" : "false");
    free(nums);
    return 0;
}
```
