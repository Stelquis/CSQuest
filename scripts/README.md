# 🛠️ scripts

本目录管理 **CNB 容器环境初始化** 与 **仓库同步维护** 的 shell 脚本。

---

## 📚 目录内容

| 脚本                       | 用途                                                          |
| -------------------------- | ------------------------------------------------------------- |
| `init-codebuddy.sh`      | 安装 CodeBuddy Code CLI，可选取消 CNB 自动登录，进入登录引导  |
| `init-atomcode.sh`       | AtomCode AI 助手一键「安装 → 登录 → 启动」，已装自动跳过    |
| `init-claude.sh`         | 生成 Claude Code CLI 配置（API Key / Base URL / 模型）        |
| `init-codex.sh`          | 生成 CodeX CLI 配置（同上模式）                               |
| `init-jupyterlab.sh`     | 安装并配置 JupyterLab（单用户免密，默认端口 8888）            |
| `init-bigdata-env.sh`    | 配置 Java/Spark/Scala/SBT，版本自动检测                       |
| `init-blockchain-env.sh` | 区块链系列实验环境（Python cryptography / Solidity Hardhat）  |
| `sync-to-gitee.sh`       | 将 main 分支快照同步到 Gitee（运行时输入私人令牌）            |
| `sync-to-github.sh`      | 将 main 分支快照同步到 GitHub（依赖`gh` CLI，自动推断仓库） |

统一运行方式：`bash scripts/<脚本名>`，均在 CNB 容器内直接执行。

---

## 📏 Bash 脚本编写规范

脚本按此起手，存量脚本整治时对照检查。

### 结构

- `set -euo pipefail` 严格模式；
- 头部注释写清**职责与用法**，正文由若干单一职责的函数 + `main` 入口组成；
- 多调用方式用 `main` 内 `case` 分发；只有一种方式则不预留分支。

### 变量

- 变量一律加双引号，函数内 `local`，全局只放 `readonly` 常量；
- 条件用 `[[ ]]`，算术用 `(( ))`。

### 配置

- 同一信息只写一份，衍生内容（规则、哨兵）由事实来源生成或直接落地，不重复维护；
- 配置以**实测环境**为准，不凭猜测防御；过期配置及时删除；
- 只用一次的值直接内联，不为它建常量。

### 精简

- **默认最小化**：分支、常量、配置、备份、辅助函数，只为当前真实需求存在，"以防万一"的一律不加；
- 注释只写代码说不清的信息，不复述代码；打印只保留执行结果必需的内容；
- 需求消失时同步删除（如子命令、备份、环境变量），不留"以后可能用到"的存量；
- 复用与封装等出现第二次使用时再引入。

### 输出与交互

- 只打印**结果、错误、交互提示**三类；错误走 stderr 并附补救方式；
- 选择提示用 `[Y/n]`，回车等于默认项；
- 外部命令自带输出的，不再包一层提示。

### 副作用

- 改系统文件优先"注释"而非"删除"，保持可回滚；
- 删除类操作先确认目标真实存在，再做正确性校验（如按内容识别），备份按需取舍。

### 验证

- 改完必过：`bash -n` 语法检查 → （可用则 `shellcheck`）→ **逐条路径实测**；
- 涉及系统文件的测试用临时文件模拟，不动真实环境；
- 怀疑配置无用时，先在真实环境取证确认，再删。
