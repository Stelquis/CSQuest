# 计算机网络知识总结

## 核心矛盾链

```
两台计算机要传数据
    → 物理层：比特怎么变信号？（编码/调制）
    → 链路层：相邻节点怎么可靠传？（成帧/差错控制/流量控制/MAC）
    → 网络层：数据从源到目的地走哪条路？（IP 寻址/路由）
    → 传输层：数据可靠送到目标进程？（TCP 可靠传输/拥塞控制）
    → 应用层：用户要什么服务？（HTTP/DNS/SMTP/FTP）
```

## 各层 PDU 名称

| 层 | PDU 名称 | 典型设备 |
| :--- | :--- | :--- |
| 应用层 | 报文（Message） | 应用层网关 |
| 传输层 | 段（Segment） | 四层交换机 |
| 网络层 | 数据报（Datagram）/ 分组（Packet） | 路由器 |
| 数据链路层 | 帧（Frame） | 交换机/网桥 |
| 物理层 | 比特流（Bit stream） | 中继器/集线器 |

## 必背公式

- **奈氏准则（无噪声）**：最大码元率 = 2W (Baud)
- **香农公式（有噪声）**：C = W log₂(1+S/N) (bit/s)
- **最短帧长（CSMA/CD）** = 2 × τ × 传输速率
- **发送窗口** = min(拥塞窗口, 接收窗口)
- **子网最大主机数** = 2^h - 2

## 易错点

1. 奈氏 vs 香农：奈氏无噪声，香农有噪声
2. CRC 是检错不是纠错
3. IP 分片偏移量单位是 8 字节
4. TCP 超时 cwnd=1；3 个冗余 ACK 快重传+快恢复
5. 后退 N 帧一错全重传，选择重传只重传错的
