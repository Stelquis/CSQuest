# 数据结构关系图谱

> 用 mermaid 具象化考纲各数据结构之间的关系——逻辑结构、存储结构、查找/排序演化链、遍历接口、跨章缝合点。

---

## 1. 逻辑结构：约束逐层收紧的光谱

```mermaid
flowchart TB
    subgraph ONE["第 1 层 · 集合"]
        A["集合结构<br/>元素间除同属一个集合外无任何关系<br/>例：字典查重、判定是否互斥"]
    end
    subgraph TWO["第 2 层 · 线性结构"]
        B["线性结构<br/>元素之间一对一（前驱唯一·后继唯一）<br/>例：线性表、串、数组"]
    end
    subgraph THREE["第 3 层 · 树形结构"]
        C["树形结构<br/>元素之间一对多（1 个后继可有多棵子树）<br/>例：树、二叉树、堆、并查集"]
    end
    subgraph FOUR["第 4 层 · 图形结构"]
        D["图形结构<br/>元素之间多对多（前驱后继均不唯一）<br/>例：图、网（带权图）"]
    end

    A == 加上一条前后继关系 ==> B
    B == 放开后继唯一限制-一变多 ==> C
    C == 放开前驱唯一限制-多对多 ==> D

    B -. 加约束：只允许一端操作 .-> S["栈<br/>= 一端受限的线性表<br/>换来：进栈出栈 O(1)"]
    B -. 加约束：一端进一端出 .-> Q["队列<br/>= 两端受限的线性表<br/>换来：FIFO 公平顺序"]
    B -. 加约束：元素限定为字符 .-> STR["串<br/>= 内容受限的线性表<br/>换来：可研究模式匹配 KMP"]
    B -. 推广：元素本身也是向量 .-> ARR["数组<br/>= 线性表的元素推广<br/>换来：多维地址计算"]

    C -. 树的退化形态：每结点至多 2 个孩子且有序 .-> BT["二叉树<br/>= 度≤2 且有序的树<br/>换来：可编号可顺序存储"]
    D -. 图的特例：连通且无环 .-> TREE["树<br/>= 无环连通图<br/>图的生成树是包含全部顶点的树"]

    style A fill:#e8f5e9
    style B fill:#e3f2fd
    style C fill:#fff3e0
    style D fill:#fce4ec
    style S fill:#f5f5f5
    style Q fill:#f5f5f5
    style STR fill:#f5f5f5
    style ARR fill:#f5f5f5
    style BT fill:#f5f5f5
    style TREE fill:#f5f5f5
```

> 图读法：主链（粗线）= 四种逻辑结构**逐层泛化**的方向；虚线 = 每种「衍生结构」是如何从主链上的结构**加约束或推广**变出来的，换来了什么。

## 2. 树家族：向二叉树降维

```mermaid
flowchart TB
    T["树 / 森林<br/>孩子数不限·无序或有序"]

    T == "左孩子右兄弟法：<br/>第一孩子当左孩子，兄弟当右孩子" ==> BT["二叉树<br/>度≤2 且孩子有序"]

    BT == "约束：完全二叉树（只允许最后一层缺右边）" ==> CBT["完全二叉树<br/>换来：可用数组编号存储"]
    CBT == "约束：父≥子（或父≤子）" ==> HEAP["堆<br/>换来：O(1) 取最值·O(n) 建堆<br/>出口：堆排序·优先队列"]

    BT == "加数据序：左<根<右" ==> BST["二叉搜索树 BST<br/>换来：查找沿单支下行 O(h)"]
    BST == "约束：|平衡因子|≤1<br/>失衡即旋转（LL/RR/LR/RL）" ==> AVL["AVL 树<br/>换来：树高严格 O(log n)<br/>代价：插入删除旋转多"]
    BST == "放宽 AVL 的严格平衡<br/>用红黑五性质保证黑高相同" ==> RB["红黑树<br/>换来：调整次数少<br/>代价：高度≤2log₂(n+1) 稍高"]

    BT == "加贪心：每次合并权值最小的两棵" ==> HUF["哈夫曼树<br/>换来：WPL 最小<br/>出口：前缀编码·数据压缩"]

    T -. 只存双亲指针 .-> UF["并查集<br/>= 树的双亲表示法应用<br/>换来：近 O(α(n)) 判连通<br/>出口：Kruskal 判环·连通分量"]

    style BT fill:#e3f2fd
    style HEAP fill:#fff3e0
    style AVL fill:#fce4ec
    style RB fill:#fce4ec
    style HUF fill:#e8f5e9
    style UF fill:#e8f5e9
```

> 图读法：粗线 = 从树到各种受限二叉树的**约束叠加**过程，每个节点写明「加了什么约束、换来什么、代价是什么」；虚线 = 树的存储结构（双亲表示法）直接支撑并查集。

## 3. 存储结构：正交维度（跷跷板）

```mermaid
flowchart LR
    subgraph L["逻辑结构（回答：元素间是什么关系）"]
        L1["线性表"]
        L2["树"]
        L3["图"]
    end
    subgraph P["存储结构（回答：关系如何在内存落地）"]
        P1["顺序存储<br/>连续内存·按地址计算<br/>查快 O(1)·插删搬移 O(n)"]
        P2["链式存储<br/>指针串联·散布内存<br/>插删 O(1)·不可随机访问"]
        P3["索引存储<br/>附加索引表逐层定位<br/>典型：B/B+ 树"]
        P4["散列存储<br/>散列函数直接算地址<br/>典型：散列表"]
    end

    L1 == "顺序表 ↔ 单/双/循环/静态链表" ==> P1
    L1 ==> P2
    L2 == "完全二叉树可编号顺序存<br/>一般树用二叉链表" ==> P1
    L2 ==> P2
    L3 == "邻接矩阵 = 顺序思想（稠密）<br/>邻接表 = 链式思想（稀疏）" ==> P1
    L3 ==> P2
    L2 -. "树+有序 → 多路平衡搜索树<br/>一个结点存多个关键字" .-> P3
    L1 -. "放弃有序性换函数直达 O(1)<br/>冲突靠探测/拉链解决" .-> P4

    style P1 fill:#e8f5e9
    style P2 fill:#fff3e0
    style P3 fill:#e3f2fd
    style P4 fill:#fce4ec
```

> 图读法：逻辑结构与存储结构**正交**——同一逻辑结构换不同存储，性能随之改变；实线 = 考纲直接给出的组合（表格对应关系已并入连线标签），虚线 = 演化出的高级组合。跷跷板总原则：`顺序 = 查快改慢，链式 = 查慢改快`。

## 4. 查找演化链：每一步都是「拿自由换性能」

```mermaid
flowchart LR
    SEQ["顺序查找<br/>无任何前提要求<br/>ASL=(n+1)/2 · O(n)"]
    BIN["折半查找<br/>代价：必须有序+顺序存储<br/>换来：每次比较范围减半 O(log n)"]
    BLK["分块查找<br/>代价：块间有序块内无序<br/>换来：折中顺序与折半"]
    BST["二叉搜索树<br/>代价：树形需动态维护<br/>换来：插入删除也不破坏有序"]
    AVL["AVL 树<br/>代价：失衡即旋转 LL/RR/LR/RL<br/>换来：树高严格 O(log n)"]
    RB["红黑树<br/>代价：维护红黑五性质<br/>换来：旋转少·近似平衡"]
    BTREE["B/B+ 树<br/>代价：结点关键字数受限 ⌈m/2⌉−1~m−1<br/>换来：一结点一磁盘页·矮胖树"]
    HASH["散列表<br/>代价：彻底放弃有序性<br/>换来：跳过比较·函数直达 O(1)<br/>冲突靠探测/拉链·ASL 看 α"]

    SEQ == "前提：有序+顺序存" ==> BIN
    BIN == "块间折半+块内顺序" ==> BLK
    BIN == "改用树形·允许动态插入" ==> BST
    BST == "加平衡约束" ==> AVL
    BST == "放宽平衡·着色" ==> RB
    AVL == "多路化·为磁盘而生" ==> BTREE
    SEQ -. "另一条路：不比较了" .-> HASH

    style BTREE fill:#e3f2fd
    style HASH fill:#fce4ec
```

> 图读法：主链（粗线）= **缩小比较范围**的进化方向，每条边标注「付出什么代价·换来什么性能」；虚线 = 从顺序查找分岔出的**跳过比较**路线（散列）。

## 5. 排序演化链：三种 O(n log n) 对应三种二叉树视角

```mermaid
flowchart TB
    INS["插入排序<br/>逐个插入有序段<br/>O(n²)·稳定·基本有序时 O(n)"]
    BUB["冒泡排序<br/>相邻逆序交换<br/>O(n²)·稳定"]
    SEL["简单选择排序<br/>每趟选最值<br/>O(n²)·不稳定"]
    SHELL["希尔排序<br/>= 插入排序按增量分组加速<br/>O(n^1.3)·不稳定"]
    QS["快速排序<br/>= 枢轴划分+左右递归<br/>≈ BST 建树：枢轴即根<br/>O(n log n)·最坏 O(n²)·不稳定"]
    HEAP["堆排序<br/>= 完全二叉树顺序存储上调整<br/>建堆 O(n)+调整 O(n log n)<br/>空间 O(1)·不稳定"]
    MERGE["归并排序<br/>= 两两合并有序段<br/>≈ 自底向上合并的二叉树<br/>恒 O(n log n)·稳定·空间 O(n)"]
    RADIX["基数排序<br/>= 不比较·按位分配收集 d 趟<br/>O(d(n+r))·稳定"]
    EXT["外部排序<br/>= 归并思想搬到磁盘<br/>败者树+置换-选择+最佳归并树"]
    OLOG["O(n log n) 三兄弟<br/>分治思想的三种落地"]

    INS == "分组插入" ==> SHELL
    INS == "选枢轴分两半递归" ==> QS
    INS --> OLOG
    QS ==> OLOG
    HEAP ==> OLOG
    MERGE ==> OLOG
    SEL -. "选择思想的堆化升级<br/>完全二叉树选最值" .-> HEAP
    BUB -. "交换思想的分治升级" .-> QS
    RADIX -. "基数思想：分配不比较<br/>外排归并段组织也用它" .-> EXT
    MERGE -. "归并思想外延" .-> EXT

    style OLOG fill:#fff3e0
    style EXT fill:#e3f2fd
```

> 图读法：三种 $O(n \log n)$ 排序（粗线汇合）各自对应一种二叉树视角——快排划分=建 BST、堆=完全二叉树、归并=自底向上合并；虚线 = 各朴素排序的升级/外延路线，外部排序是归并思想在磁盘上的延伸。

## 6. 遍历：结构到线性的统一接口

```mermaid
flowchart LR
    TRAV["遍历<br/>= 把结构拍扁成线性序列<br/>= 给每个结点编线性地址"]

    subgraph DFSF["DFS 一族（辅助结构：栈/递归）"]
        D1["树：先序/中序/后序<br/>递归=系统栈<br/>非递归=显式栈"]
        D2["图：深度优先搜索<br/>+visited 数组防兜圈"]
        D3["拓扑排序（DFS 法）<br/>逆后序即拓扑序"]
    end
    subgraph BFSF["BFS 一族（辅助结构：队列）"]
        B1["树：层序遍历<br/>队列+分批出队"]
        B2["图：广度优先搜索<br/>+visited 数组"]
        B3["无权最短路<br/>BFS 首达即最短"]
    end

    TRAV ==> DFSF
    TRAV ==> BFSF
    D1 == "同一套栈思想搬到图上" ==> D2
    D2 == "DFS 的逆后序变形" ==> D3
    B1 == "同一套队列思想搬到图上" ==> B2
    B2 == "队列的层次性=按距离扩散" ==> B3

    TRAV -. "遍历序列可逆构造：<br/>中序+先序 唯一确定二叉树<br/>（中序+后序同理）" .-> RECON["由遍历序列建树<br/>⭐408 必考大题"]

    style DFSF fill:#e3f2fd
    style BFSF fill:#fff3e0
    style RECON fill:#fce4ec
```

> 图读法：遍历只有两族——**栈思想（DFS）**与**队列思想（BFS）**，从树到图只是加了 visited 标记；「中序+先序建树」是遍历可逆性的直接产物，也是必考大题来源。

## 7. 跨章缝合点总图

```mermaid
flowchart LR
    DS1["三·栈队列数组"]
    DS2["二·线性表"]
    DS3["四·树和二叉树"]
    DS4["七·排序"]
    DS5["五·图"]
    DS6["六·查找"]
    UF["并查集"]
    BTREE["B+ 树"]
    CP["关键路径"]
    MYSQL["MySQL 索引<br/>（408 外的缝合点）"]

    DS1 == "循环队列 = 顺序数组 + 取模环化<br/>顺序存储的高级用法" ==> DS2
    DS3 == "堆 = 完全二叉树的顺序存储<br/>四章的结构直接变成七章的算法" ==> DS4
    DS3 == "树的双亲表示法<br/>只存双亲指针" ==> UF
    UF == "Kruskal 加边前判两端<br/>是否已连通（防成环）" ==> DS5
    DS3 == "哈夫曼构造 = 贪心策略具象化<br/>每次合并权值最小两棵·WPL 最小" ==> DS4
    DS4 == "快排的划分过程 = BST 的建树过程<br/>枢轴即根·左右段即左右子树" ==> DS6
    DS1 -. "串的模式匹配<br/>KMP 用 next 数组避免主串回溯" .-> DS6
    DS5 -. "拓扑排序定活动顺序<br/>再在 AOE 网求最长路" .-> CP
    BTREE -. "叶子层链表 = 线性表<br/>故支持范围查询" .-> DS2
    BTREE -. "树+索引 思想外延<br/>数据库磁盘索引同源" .-> MYSQL

    style UF fill:#e8f5e9
    style BTREE fill:#fce4ec
    style CP fill:#e3f2fd
```

> 图读法：粗线 = 考纲内部的高频缝合点（连线标签写明「缝的是什么、为什么能缝」）；虚线 = 思想外延（串、AOE、数据库索引），每条线一句话即可回忆整条推理链。
