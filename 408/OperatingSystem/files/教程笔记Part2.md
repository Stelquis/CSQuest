## 二、第 3 章存储管理收尾（p121-128）

### 3.4.3 段页式存储管理

**基本思想**：
- 段页式 = 段式管理 + 页式管理。**每一段不必占据连续的存储空间，而是存放在不连续的主存页框中**
- 同样可以扩充成虚拟存储管理：只要装入进程的部分段、或这些段中的部分页面，进程就可以运行

**地址结构与转换**：

```
逻辑地址：[段号 s | 页号 p | 页内地址 d]
```

地址转换流程：
1. 先查**快表**（联想存储器），命中则形成 (页框号, 单元号) → 物理地址
2. 不命中则查**段表**（段内含「标志 / 页表限长 / 页表基址」）
3. 由段表找到该段**页表**，再查页表得页框号
4. 物理地址 = 页框号 × 页大小 + 单元号
5. 同时把 (段号, 页号, 页框号) 登记入快表

**段页式虚拟存储**：
按逻辑地址查快表 → 否，查段表 → 段表是否在主存？否 → **缺段中断**；是 → 该页超出页表长？是 → **越界中断**；否 → 该页在主存？否 → **缺页中断**；是 → 形成物理地址。

共四种中断：缺段、越界、缺页、保护。

### 第三章本章小结要点

- 存储管理基本功能：**存储分配 / 地址转换 / 存储保护 / 存储共享 / 存储扩充**
- 地址转换：通过静态或动态地址重定位将逻辑地址映射到物理地址
- 五种主要管理方式：单连续 / 固定分区 / 可变分区 / 页式 / 段式 / 段页式
- 虚拟存储管理：让进程的"部分"装入主存即可运行，扩充逻辑可用空间
- 关键问题：缺页中断、抖动（thrashing）、页面置换（OPT/FIFO/LRU/LFU/Clock）、Belady 异常

## 三、第 4 章 设备管理（p129-162）

### 4.1 设备管理基础

#### 4.1.1 设备管理概述

- **I/O 设备 = 外围设备 = 外部设备 = 外设**
- I/O 系统 = I/O 设备 + 接口电路 + 控制部件 + 通道 + 管理软件
- 设备分类视角：速度（低/中/高）、信息组织（字符/块）、共享属性（独占型/共享型/虚拟型）、用途（输入/输出/存储）

#### 4.1.2 I/O 控制方式

| 方式 | 工作机制 | 特点 |
| --- | --- | --- |
| **轮询** | CPU 不停查询设备状态寄存器 | 简单但 CPU 利用率低，"忙等" |
| **中断方式** | 设备完成后向 CPU 发中断 | CPU 与 I/O 部分并行 |
| **DMA 方式** | 直接存储器访问；设备控制器直接读写主存 | 一次传一块；CPU 仅在开始/结束参与 |
| **通道方式** | 引入"通道"专用 I/O 处理器，执行通道程序 | CPU 完全脱离 I/O 细节 |

**通道工作流程**：
1. CPU 遇 I/O 任务 → OS 组织通道程序 → 首地址存入**通道地址字（CAW）**
2. 启动通道 → 通道从 CAW 取通道程序 → 控制 I/O 设备
3. I/O 完成 → 通道发出中断 → CPU 处理中断
4. **通道状态字（CSW）** 寄存器保存通道 I/O 进展状况

**通道分类**：**字节多路通道 / 选择通道 / 数组多路通道**

#### 4.1.3 总线与 I/O

- 单总线 → 三级总线 → 含南北桥的多级总线 → 含 I/O 通道的多级总线

### 4.2 设备管理软件

#### 4.2.1 I/O 软件实现层次

I/O 软件设计四大目标/原则：
1. **设备无关性**（编程时不关心物理设备）
2. **出错处理**（尽量在低层处理）
3. **同步/异步传输**（同步=阻塞；异步=CPU 继续干别的）
4. **缓冲技术**（建立缓冲区匹配速度差）

**四层结构（自底向上）**：
```
用户空间 I/O 软件（库函数 fwrite/fprintf；SPOOLing 软件；POSIX 库）
─────────────────────────
独立于设备的 I/O 软件（缓冲管理；命名；权限；分配/释放）
─────────────────────────
设备驱动程序（针对具体设备的代码；接收上层请求；操作设备寄存器）
─────────────────────────
中断处理程序（最底层；唤醒等待设备的进程）
```

#### 4.2.2 设备驱动程序

驱动程序三大功能：
1. **设备初始化**（系统启动或传输前预置状态）
2. **执行设备驱动例程**（启动设备、传输数据；通道系统还要生成通道指令）
3. **调用与执行中断处理程序**（处理设备/控制器/通道的中断）

#### 4.2.3 I/O 缓冲区

为何要缓冲？
- CPU 与设备速度不匹配
- 逻辑记录 ≠ 物理记录
- 减少 I/O 中断次数 / 放宽 CPU 中断响应时间

种类：**单缓冲 / 双缓冲 / 循环缓冲 / 缓冲池**

### 4.3 独占型外围设备的分配

**设备独立性**：
- 用户应用与具体物理设备无关；增减设备无需改源码
- 实现：用户用**逻辑设备名**，OS 维护"逻辑名 ↔ 物理名"对照表

**分配方式**：
- **静态分配**：作业执行前分配，结束后回收。简单、防死锁，但利用率低
- **动态分配**：用时分配，用完即收。利用率高，**但有死锁风险**

### 4.4 共享型外围设备的驱动

#### 4.4.1 磁盘驱动

**磁盘存取时间计算公式**（核心考点）：

```
Ta = Ts + 1/(2r) + b/(rN)
```

- `Ts`：寻道时间（移臂）
- `r`：旋转角速度（每秒转数）
- `1/(2r)`：平均旋转等待时间（半周）
- `b`：要读写的数据字节数
- `N`：每磁道字节数
- `b/(rN)`：传输时间

#### 4.4.2 磁盘驱动调度

**移臂调度算法**：

| 算法 | 思路 | 评价 |
| --- | --- | --- |
| **先来先服务 FCFS** | 按请求到达顺序 | 公平但移动距离大 |
| **最短查找时间优先 SSTF** | 选离当前磁头最近的请求 | 综合寻道好；有"饿死"问题 |
| **单向扫描 SCAN** | 移臂只朝一个方向扫，到头返回不服务 | 适用大吞吐 |
| **双向扫描 LOOK/SCAN** | 双向扫描都服务 | 优于单向 |
| **电梯调度** | 双向扫描，方向前方无请求时即时反向 | 最常用、近似 SSTF 但公平 |

### 4.5 虚拟设备（SPOOLing）

**SPOOLing 系统组成**：
- **输入井/输出井**：磁盘上的缓冲区
- **输入进程/输出进程**：负责数据转送
- **井管理程序**：控制井的分配与回收

**优点**：
- 将独占设备改造成共享设备
- 提高了 I/O 速度
- 实现了虚拟设备功能

## 四、第 5 章 文件管理（p163-194）

### 5.1 文件系统概述

**文件**：具有符号名的一组相关信息的逻辑集合

**文件系统功能**：
- 文件组织（逻辑结构 + 物理结构）
- 目录管理
- 文件共享与保护
- 文件操作（创建/打开/读写/关闭/删除）

### 5.2 文件的组织

**逻辑结构**：
- **流式文件**：字节序列（无结构）
- **记录式文件**：有逻辑记录边界

**物理结构**：
- **连续文件**：物理块连续存放（访问快，难扩展）
- **链接文件**：用指针链接（扩展方便，随机访问慢）
- **索引文件**：用索引表记录（随机访问快，有索引开销）

### 5.3 文件目录

**目录结构**：
- **一级目录**：所有文件在同一目录（简单，不能重名）
- **二级目录**：每个用户一个目录
- **树形目录**：层次结构（现代 OS 都用）

**目录操作**：创建、删除、查找、遍历

### 5.4 文件共享与保护

**共享方式**：
- **硬链接**：多个目录项指向同一 i 节点
- **符号链接**：一个文件指向另一个文件的路径名

**保护方式**：
- 存取控制矩阵
- 存取控制表（ACL）
- 口令保护

### 5.5 文件系统实现

**外存分配方法**：
- **连续分配**：文件占连续块
- **链接分配**：块通过指针链接
- **索引分配**：索引表指向每个数据块

**空闲空间管理**：
- **位示图**：用位图表示空闲块
- **成组链接法**：UNIX 使用的方法
- **空闲链表**：空闲块链成链表

## 五、第 6 章 并发程序设计（p195-240）

### 6.1 顺序与多道程序设计

**顺序程序设计**：一个程序从头执行到尾，前一步没做完后一步不开始
- 特点：环境封闭、过程可重现、结果确定

**多道程序设计**：多个程序同时进入主存，使外设和 CPU 充分并行
- 核心：提高资源利用率

### 6.2 临界区管理

**与时间相关的错误**：
- **结果不唯一**（race condition）
- **永远等待**（死锁雏形）

**临界区管理原则**：
- 互斥使用、有空让进、忙则等待、有限等待

**硬件实现方式**：
- 关中断、TS 指令、Swap 指令

### 6.3 信号量与 PV 操作

**信号量**：整型变量，只能通过 P 和 V 操作访问

**P 操作**：S = S - 1；若 S < 0 则进程阻塞
**V 操作**：S = S + 1；若 S ≤ 0 则唤醒一个等待进程

**经典问题**：
- 生产者-消费者（单缓冲/多缓冲）
- 哲学家进餐
- 读者-写者

### 6.4 管程

**管程**：将共享数据和对它的操作封装在一个模块中，每次只允许一个进程进入管程执行。

**霍尔管程 vs 汉森管程**：对条件变量的处理方式不同。

### 6.5 进程通信（IPC）

**低级通信**：信号量、PV 操作
**高级通信**：
- 管道（pipe）
- 消息缓冲
- 共享存储
- 信箱（mailbox）
- RPC（远程过程调用）

### 6.6 死锁

**死锁定义**：一组进程处于死锁状态——每个进程都在等待只能由该集合中的另一个进程才能引发的事件。

**4 个必要条件**：互斥、占有和等待、不剥夺、循环等待

**死锁处理**：
- 死锁预防（破坏四条件之一）
- 死锁避免（银行家算法）
- 死锁检测（资源分配图）
- 死锁解除（撤销进程、回退）
